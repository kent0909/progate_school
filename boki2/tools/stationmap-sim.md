# 出店の地図の測定ツール（実装中）

`docs/CODEX-TASK-stationmap-sim.md` の依頼を、設計書版0.5で測る。

## パラメータ表

`data/stationmap-params.json` は、項目名ごとの `{v,lo,hi,src}`。
`null` は設計書に指定のない値。探索幅の `null` は自由に探索してよいという意味ではない。
`foot.tierRatio` と `foot.distRatio` は比の制約。個別の倍率の探索範囲に読み替えない。
`hours.closedSaving.v`、保証金の確率、λの段の一括倍率の探索幅、機構の未決定を補完しない。
PRで取りまとめ役に確認し、決定とコメントIDをここに記録する。

## 実装前に相談していること

1. 閉店時間帯で減る費用の初期値（幅は16万〜20万円）。
2. λの段の倍率の探索幅。段ごとの値はあるが倍率の幅はない。
3. 検査⑥の単純規則の中の選び方・上手なボットの方策と参照情報。
4. 参入の予兆から開店までの期間、閉じた時間帯の常連の離れ方、増員時の削減費。
5. 保証金6/8/10か月の確率・居抜き造作の分布。
6. 旧回帰は当時の453駅965候補地で照合する（現行は452駅886候補地）。
