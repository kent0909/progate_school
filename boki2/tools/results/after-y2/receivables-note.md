# 売掛金の初teachと、それ以前の表示

PR #6 コメント6395546937の依頼への結果。対象はラーメン版の現行台本（開店前〜4年目6月）。217の実経路と近道の合格4通りを調べた。

|対象|初teach|teach前の表示|
|---|---:|---:|
|通常|0か所|0か所|
|近道|0か所|0か所|

現行台本には売掛金を教える場面がなく、読み込んだ `SIMDATA.namings['売掛金']` の定義もない。teaches/b4.teachesの静的照合でも0か所。全経路の `firstTeaches` / `beforeTeach` の実表示記録から作った通常・近道のreceivables.tsvも、ともにヘッダだけである。クレジット売掛金と売掛金は別の科目として走査している。

## 関係する場所の全一覧

|場所|現行の扱い|
|---|---|
|`js/sim/ramen-y1.js:528` d-allowの試験文|指示に従いクレジット売掛金へ修正。売掛金は表示しない|
|`js/sim/ramen-y1.js:235`・`js/sim/ramen-y2.js:33` カード売上のopts|売掛金を候補の定義に含むが、未習ならengine.jsの`filter(knows)`で表示から外れる。今回の全経路で表示0か所|
|`js/sim/ramen-y1.js:615` 近道の入口の第1問のopts|売掛金が選択肢にある。今回の負荷判定外。「既習の確認。教える画面ではない」（6395466037）|
|`js/sim/ramen-y1.js:616` 近道の入口の第2問のopts|同上|
|`js/sim/ramen-y1.js:611` applyPro3の既習語|売掛金は含まない。入口の選択肢を見たことを、新たなteachに読み替えていない|
|検定会場の自由練習・閲覧メニュー|今回の判定外。すべての表示場所を調べた一覧ではない。既存lexicon-checkも閲覧メニューの実DOMを開いては調べていない|

この仕事で売掛金の名前札や掛け販売の新しい場面は追加していない。現在の台本の範囲で初teachがないことを報告する。将来、掛け販売を入れるときの教える順と画面の分け方は、取りまとめ役・オーナーの設計の判断である。
