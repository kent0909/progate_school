# 画面と月の科目負荷の検査資料

対象はPR #6、`87f6678`を元にした `codex/ramen-after-y2`。ゲームの表示・台本を変更して負荷を解消する仕事ではない。超過は検査を失敗させ、場面の分け方は取りまとめ役へ相談する。

## 実行

```sh
node boki2/tools/lexicon-screen-check.js
node boki2/tools/lexicon-check.js --ramen --account-report /tmp/accounts.json
node boki2/tools/lexicon-screen-tables.js /tmp/accounts.json boki2/tools/results/after-y2
```

`lexicon-check` は既存の語句・字数等の検査を残し、追加の画面負荷の検査も実行する。`--account-report` がなくても画面の超過と月の注意を出す。全札の結果を実際の世界・仕訳とともに走らせるため、以前の仮の月順だけの検査より時間がかかる。`画面の集計中` が5経路ごとに出る。`lexicon-screen-accounts.js --sample` は試走用の24経路で、全結果の受入検査の代用にはしない。

`lexicon-screen-check` は対照資料を別Nodeプロセスで実行し、実終了コードを検査する。子プロセスの作成を禁止する実行環境では、作成失敗を検査成功とみなさない。

## 表の読み方

- `screens.tsv`：検査した画面idごとの初出科目数の最大と、その値が出た台本の経路。ゼロの画面も残す。同じ名前でも月・台本の区切り・場面・段が違えば別id。
- `months.tsv`：同じ月の複数の決算の区切りをまとめ、その月の初出科目の集合が最大の経路を示す。開店前とプロローグは通常の営業月と区別する。内訳は初出候補がある画面を列挙し、誤答や任意表示の別経路で同じ科目が現れる場合もあるため、内訳の個数を単純加算しない。
- `shortcut/screens.tsv`・`shortcut/months.tsv`：同じ実経路の近道の別表示。applyPro3の既習語から始め、入口の確認に合格する4通り（3問中2問または3問正解）の自動仕訳の違いも含む。
- `paths.tsv`：画面・月・初teachの表の経路idと、種・判断・強制した結果の対応。
- `non-card-options.tsv`：開店前など札以外の判断の各選択肢への実到達（2026/2027別）。
- `outcomes.tsv`：2年目以降の札の選択肢と結果への実到達。whenを無視して画面を出したことにはしない。
- `receivables.tsv`（通常・shortcut双方）：売掛金が初めてteachされる画面と、teachされる前に表示された画面。経路ごとの初teachなので、別の経路の科目を先に教わったことにしない。
- `retained-labels.md`：旧呼び名を残した全一致行と理由、変更/維持した場所の表。

科目の既出集合は経路ごとにリセットする。「画面に出た」と「teach済み」は別に保持する。書類の選択候補のknowsによる絞り込みにはteach済みの集合を使う。現金・給料・商品など、日常語にも見える勘定科目も数える。長い科目・概念の語を先に走査し、損益計算書の一部を損益の初出として重ねて数えない。

名前カードの問いと、解いた後の説明は実際の別の表示状態。発見の理由は選択後に現れ、ヒントは1段ずつ増える。警告・結末も原因／数字／届いた書類／その後／制度／学びを別の画面として扱い、1つの合計にしない。月報の後の帯・ふりかえり・分かれ道も別に数える。発見の名前と折りたたみの試験文は同じ画面として数える。誤答の反応、確認して選び直せる判断の結果、任意の手帳・ヒントは、見ずに進む経路もある。その表示を後続の必須画面の既出集合へ先取りさせずに検査する。月の科目集合は重複を除いて数える。

## 到達範囲と限界

通常の2026/2027モード各12種、1年目の書類を持つ旧札の各選択肢、2年目以降の全札の全結果と、札以外の判断の各選択肢を、既存のstory/economicStory/forcedStoryと__onEventで追う。札ごとに条件を満たす種・前の選択を使い、到達できない結果は失敗する。条件付きの生成テンプレートすべてが実際に出るわけではないため、生成されたテンプレート数を検査済みの出来事数とは書かない。

PR #6コメント6395466037に従い、近道のdiscoverLiteを含める。入口の確認（gateScreen）は「既習の確認。教える画面ではない」、検定会場の自由練習は「規約：本試験の形の再現」を理由に今回の判定外とする。帳簿・札で見る等の閲覧メニューも判定外。既存のlexicon-checkは台本の文と札の兄弟等を調べるが、閲覧メニューの実DOMを開いて漏洩を検査してはいない。

これはengine.jsとramen/ui.jsの表示の区切り・候補の絞り方を投影する検査であり、ブラウザのDOMを読み出す検査ではない。モード・札の分岐の直積、無限にある種、すべての任意操作順を網羅した証明ではない。画面の種類を増やすと未定義の種類として失敗するが、既存の種類の表示を変更したときも投影を照合する必要がある。ブラウザを操作して検定会場の自由練習・閲覧メニューを開く検査ではない。

## 検出した教材の直し

初めの診断では1年目決算のd-allowの名前と同じ画面の試験文で、貸倒引当金・貸倒引当金繰入・売掛金の3科目が初出した。PR #6コメント6395546937の判断に従い、試験文だけをクレジット売掛金へ合わせた。name・line・teachesと画面の区切り、検査の規則は変えていない。
