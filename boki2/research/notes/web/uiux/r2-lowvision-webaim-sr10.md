WebAIM の第10回読み上げソフト利用者調査（2023年12月〜2024年1月、有効回答1,539）。

要点：
- 回答者の約2割はロービジョン。読み上げは全盲の人だけの道具ではない。
- PC の主な読み上げソフトは JAWS と NVDA がほぼ同数。ただし地域差が大きく、アジアでは NVDA が7割を超える。Windows に標準の Narrator は主に使う人は1％未満だが、ときどき使う人は4割近い。OS は Windows が86％。
- ブラウザは Chrome が半数、次に Edge。NVDA と Chrome、NVDA と Edge の組み合わせも多い。
- スマホの読み上げを使う人は9割超。スマホは iPhone が7割で、VoiceOver が主流。
- 長いページで情報を探すとき、最初にすることは「見出しをたどる」が7割強。見出しの階層も役に立つと答える人が9割近い。
- 困るもの上位：CAPTCHA、思った通りに動かないメニュー・タブ・ダイアログ、意味の分からないリンクやボタン、予告なく変わる画面、キーボードで操作できないこと、画像の説明がないこと。

評価への使い方：人物は Windows＋NVDA（日本語）＋Chrome、スマホは iPhone の VoiceOver とズーム、とするのが統計に沿う。ゲームの確かめ方として、①見出しで画面の構造が分かるか（a11y で heading が取れるか）、②ボタンの名前が読み上げで意味を持つか（「▶」だけ等になっていないか）、③操作したときに画面が予告なく入れ替わって読み上げの位置を失わないか、④ダイアログがキーボードで閉じられるか、を見る。
