NN/g（Feifei Liu、2018年）『子どもの運動発達の段階に合わせた設計』。3〜12歳の米国・中国での利用者テストの要約。6〜8歳は、マウス/トラックパッドのクリックと簡単なキー操作ができ、9歳ごろから高度な操作が可能になり、11歳ごろに大人と同じ範囲の操作ができる（個人差あり）。細かい運動は粗い運動より遅れて発達するため、画面を指でたたく・払う大きな動きは易しく、トラックパッドやマウスでの長い距離のドラッグ、小さい対象のクリックは難しい。

具体的な勧め：幼い子にはタッチ対象を2cm×2cm以上（大人向けの1cm×1cmの4倍）にする。ドラッグには、タップなど代わりの手段も用意する。小さな閉じるボタンやドラッグの位置ずれで『消えてしまう』作りは、子どもには過酷。9歳未満のデスクトップは、クリックと簡単なキー操作にとどめる。両手の協調を要する操作や、すばやい操作を迫る作りは避ける。

このゲームへの当て方：小学生の読み手（9歳・11歳）の操作で、ドラッグが必須でないか、タップ領域が大きいか、誤タップが取り返しのつかない結果にならないかを確かめる。ターゲットの大きさは CSS ピクセルで測るため、2cm との換算（約76 CSS px）は目安にとどめる。
