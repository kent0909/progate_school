国会会議録検索システムの API で「フランチャイズ 加盟店」を検索した結果（JSON、発言の本文つき）。185件の発言のうち新しい順の30件（2019年3月〜2025年5月）を全部読んだ。ほとんどがコンビニの24時間営業の問題（2019年）と、こども性暴力防止の法律でのFCの扱い（2024年）。

加盟店の側の数と言葉（議員と大臣が紹介したもの。本人の言葉の又聞き）：
- 経済産業大臣の答弁（2019年4月3日）：大手コンビニの全店へのアンケートで、2014年の調査と比べ、人手不足を感じるオーナーは22%→61%、本部に不満は17%→39%、このまま続けたいは68%→45%。
- 議員の紹介：経産省のオーナーへのヒアリングは12回、フランチャイズ契約の抜本的な見直しを求める声、本部が同意なく紙1枚で新しいことを始めるという声（2019年11月）。人手不足で24時間営業をやめた店主が本部から1,700万円の違約金を求められたという報道（後に求めないと伝えられた）。店長の月の労働時間が350時間前後という例。
- 議員の主張：ロイヤルティが粗利にかかるので、本部は近隣への集中出店で既存店が減っても全体の売上が増えればよく、本部と加盟店の利益が相反する（2019年5月）。
- 公取委の答弁：コンビニの取引の実態調査を2001・2011・2020年の3回、2020年は加盟店約5万7千社が対象。加盟の時に十分説明され同意した24時間営業は直ちに違法ではないが、契約の後の一方的な変更や見直しの一方的な拒絶は優越的地位の濫用になりうる。ガイドラインに時短営業の協議の拒絶を違反の例として加えた。

ゲームへ：加盟店の満足と続けたい意向は、外の環境（人手不足）で数年のうちに大きく動く（続けたい68%→45%）。コンビニの数で、ラーメンのFCではない。
