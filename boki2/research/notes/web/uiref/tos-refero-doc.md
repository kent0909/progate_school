Refero の Terms of Use（doc.refero.design）。描画して取った。禁止事項の段と、13章 MCP and API access、許される使い方の段を読んだ。支払い・責任などの後半は読んでいない。

読み取ったこと：文書化された取り出しの機能の外で、スクレイピング・クローリング・自動化・系統だった取り出しで中身を写すことを禁じ、自動の道具での大量の取り出しも禁じている。一方で、MCP と API による利用の章があり、自分の画面・流れ・試作・アプリを調べて作るための使い方は許されている（機械学習の学習やデータの作成は不可）。結論：頁の自動取得はしない（no-automation）。調べに使うなら、オーナーが公式の MCP を接続する道がある。
