ハル研究所の UI の2人（UI アーティストとリード UI デザイナー）が CEDEC 2020 で話した『星のカービィ』の UI の作り方の記事。目標は3つ（迷わせない・不快にさせない・心が動く）、そのための考え方も3つ（使いやすさ・ゲーム全体の流れ・遊び心）。

使えるところ：
- 情報は優先順位→分類→近接・整列・反復・強弱・視線の順で並べる。目に入りやすい左上を「特等席」と呼び、ベストタイムの画面では見出しの文字ではなく数字そのものをそこへ置き、キャラの絵も外した（やりこむ人向けの画面だから）。我々の上部の帯（w26〜w60）で、いちばん大事な1つの数字に特等席を与える根拠になる。
- UI は前後の画面とのつながりで作る。手帳から開くボタンは手帳の中に書いてある形にする。
- 使いやすさと遊び心は引っぱり合うので、世界観の絵（辛さを顔の絵で見せる難易度など）を足す。
- あたたかさの作法：尖った形を避けて丸を使う、真っ黒・真っ白の強い対比は強調だけに使う、1画面に情報を詰めずに散らす（遊ぶ人の幅が広いので）。
- 待ち時間の多い作品では、常にどこかが動く UI とメリハリのある切り替えで、読み込みを感じさせないようにした。

反対側の材料：情報を散らすことは、上級者の早さとぶつかる（記事は対象の広さを理由に挙げている）。
