アトラスの2人（UI 専属デザイナーとプロデューサー）が CEDEC+KYUSHU 2017 で話した『ペルソナ5』の UI の作り方。開発費が限られた危機の中で、裏方だった UI を「主張の強い主人公」に変えると決めた。UI を強くすると作品の色が強く出て、ゲームの素材を包み、安く体験を上げられるから。

作り方：まずメインカラーを1つ決める（3は青、4は黄、5は赤）。5では赤を立たせるため、ほかの色はほとんど入れなかった。その代わり、使いやすさは色ではなく「線を追って目が動く」性質で守った（メニューの真ん中に白い線）。下の階層ではレイアウトや角度を変えて階層を分からせ、大事な情報は明るく、そうでないものは暗くした。操作とともに3Dの人物が動き回る。

我々への読み：チープさ（P7）の直し方として「1色を決めて強く押す」「UI そのものを作品の顔にする」は、絵を描き込む前でもできる大胆な写し方。予算が少ないから UI に寄せた、という作り手の判断は我々と同じ条件。悪い面：赤と黒の強い画面は中高生〜社会人の誰にでも合うわけではなく、学びの画面では読みやすさとぶつかる。

前回の読みの訂正：会社の危機と「少ない予算で新しい客をつかむ」課題は『ペルソナ3』（2006年）のときの話で、UI を主役にする方針はそこで生まれた。ペルソナ5 はその流れの上の作品。P5 の作りは安くない：場面ごとに UI 専属のプログラマーがいて、デザイナーが横で1ドット・1フレームまで直し、紙の仕様書は千枚を超え、拡大縮小に耐える線のデータを作るのにアルバイトを雇った。
