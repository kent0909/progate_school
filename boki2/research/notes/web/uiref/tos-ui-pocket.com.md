UI Pocket の利用規約（2024年1月2日制定、2025年2月17日改定）。全14条と附則を全部読んだ。

読み取ったこと：禁止事項（第5条）は、法令違反・知的財産の侵害・サーバーの妨害・不正アクセス・ほかの利用者の個人情報の収集・なりすまし・勝手な宣伝などで、機械による取得やスクレイピングを名指しで禁じる条項はない。有料の部分（第4条）と、ログインの ID の管理（第3条）がある。ここから、ログインせずに公開の頁を1枚ずつ間隔をあけて見るのは禁止に当たらないと判断し、site-policy で gray にした。ただし第5条の「知的財産権を侵害する行為」と「運営者が不適切と判断する行為」は広いので、画面の写真は分析のために見るだけで、報告やリポジトリに画像を載せない。ログインの要る画面には入らない（オーナーの依頼文の決まりとも一致）。
