サイバーコネクトツーの UI アーティストが CEDEC 2022 で話した、原作つきのゲームの UI の作り方の記事。機能だけなら黒い画面に文字だけがよいが、それでは原作らしさが出ない。両立のために大事にしていることは3つ（情報を詰め込まない／世界観を前に出す／ゲームの演出が UI にも及ぶ）。

具体：結果の画面ではキャラクターを前面に出し、コアな人が求める細かい数（連続ヒット数など）は別の画面に分ける。モードを選ぶ画面では、選ぶたびに3Dの人物のポーズが変わる（反応は少し遅くなるが世界観を優先した）。ピンチで覚醒するとゲージの横の顔の絵も覚醒版に変わる。

我々への読み：月の結果（w36 の森さん、月報）でも、細かい表は別の画面へ回し、先に店主・客・一杯の絵を出す、という並べ方の根拠。反応の遅さとの引き換えは、記事自身が認めている（悪い面）。UI は仕様の間違いが最後に見つかる場所（最後の砦）という言い方もある。

再読（R2、2026-10-30）：原文を頭から末尾まで通して読み直した。記事の本文は文書の前6割ほどで、後ろ3分の1は 4Gamer の新着・ランキング・フッターの一覧（通読したが記事の中身はない。最後の anchors の1つはそこから取った、通読の証拠）。画像は手元にない（記事のギャラリーの番号つきの説明だけ）。キャプションは2つ（体力のゲージの横の顔が覚醒で差し替わる、ローカライズのクイズの答え）を読んだ。
前回拾っていなかったこと：①世界観に寄せすぎると UI の軽快さと分かりやすさを失う、どちらを優先するかは作品の性質で決める、という条件つきの話。②原作の権利元の監修は造形・ポーズ・仕上げの段ごとにあり、作る側にも権利元にも負担と認めている。③UI の担当は仕様の段から加わり、画面の移り変わりの流れを早く作ると大きな仕様の変更が減る。④翻訳の担当者に「新聞の書体みたいでゲームらしくない」と言われた書体の話（書体がゲームらしさを左右する）。⑤対応する言語が6から15に増え、文字の素材を自動で並べる工夫をした。⑥UI の仕事は地味で泥くさいと本人が言う。講演に何人・どれだけの期間をかけたかは書かれていない（探したが出てこない）。
