GAME Watch の同じ CEDEC 2020 の講演のレポート（吹越友一）。本文を全部読んだ（記事の画像は遅延読み込みで取れておらず、開いていない）。電ファミのレポートにない細部：

- 目指すのは「迷わない UI」「ストレスや不快感を与えない UI」「印象・心に残る UI」の3つ
- 手順：画面に出す情報に優先順位を付ける（その場面でどの要素がどれだけ大事か）→ 情報の種類（いまの場所・点数・進み具合）を分け、同じ種類は近くに → 縦・横・中心の線をそろえて並べる → 他の画面と同じ部品をくり返す（反復）→ 大きさ・色で選んでいるものとそうでないものの差を付ける → 視線の流れ
- 頻繁に使う UI は汎用の作りに、1回限りの UI はその場面に特化した作りに
- 「あたたかさ」の作り方：攻撃的な形（鋭い角）を避け、星の先も丸める。目に痛いコントラスト（真っ白・真っ黒の多用）を避け、目立たせたい所以外は灰色にして抑える
- 1画面に情報が多いと難しそうに見えるので、あえて情報を分ける

このゲームへの含意（担当 C）：
- 上部の帯（P8）は、優先順位→種類分け→そろえ→反復、の手順でそのまま直せる。いまは口座・借入金・手もとのお金・目的・年・進み具合・8つのタブが同じ強さで並ぶ（w29）
- 毎月くり返す画面（書類・仕訳）は汎用で落ち着いた作り、1回限り（開店・決算・検定の合格）は特化した演出、という強弱の規則の根拠
- 角を丸める・真っ白真っ黒を避ける・目立たせない所は灰色、は規則の案1の色と形の決まりに入れる
