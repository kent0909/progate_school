Collect UI の「Funny Animation（おかしみのある動き）」の分類ページ。描画して取り、カード15枚を見た。カードの元の作品は X（旧 Twitter）の投稿の動画で、Collect UI の置き場（cdn.collectui.com）にある動画を取って切り出して見た（2本）。元の投稿の X のページは、X の規約が許可のない自動の収集を禁じるので開いていない（やっていないこと）。

見た2本から言えること：
- 正解の札（FarzadGodarz）：色が押し寄せて札全体が「正解」に変わり、続けて「+1」の数字が波に乗って現れ、紙吹雪は札の中だけで散る。約2.7秒で元に戻る。手ごたえを「札の中」に閉じ込めているので、周りの文字を読む邪魔をしない。これは仕訳の札・選択肢の札の正解の動きにそのまま写せる型（札が緑に満ちる→「+1万円」が出る→札の中だけ紙吹雪）
- 国旗の紙吹雪（JC_builds）：選んだものに固有の絵（その国の旗）が紙吹雪になる。紙吹雪の中身が「何を選んだか」を伝える。ラーメンなら、仕入れた食材の札を押すとネギ・チャーシューの小片が舞う、売上なら小銭が舞う、という形で「意味のある紙吹雪」にできる
