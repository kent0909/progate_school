『ペルソナ3 リロード』のアートディレクターたちへの UI のインタビュー。メニュー画面は主人公の心の中（海）として、青と水中の浮遊感で作った。メニューの主人公は UI のためだけの3Dモデルで、表情や仕草を細かく動かす。5 の UI は素早さと弾けた感じ（ポップパンク）、3R は水の漂いと、作品ごとに動きの性格が違う。

もう1つ大事なのは、新しい機能 ROLLBACK：選択肢などで失敗しても、数日前までならゲームの中の日付をすぐにさかのぼれる。オーナーの困りごと P4（1つだけ直したい）の、ゲームの側の実例。

速さも同時に守っている：5 で培った反応の速さと操作の分かりやすさを大事にしている、と言う。動きの多い UI でも、開くのは速い。我々への読み：動きを足すなら、まず「押してすぐ開く」を守ったうえで、店の UI の性格（湯気・のれん・木）を1つ決める。
