電ファミニコゲーマーの CEDEC 2020 の講演のレポート（ハル研究所の UI アーティスト伊藤晴香氏・リード UI デザイナー剣持紫氏）。本文を全部読み、講演の画面4枚を開いた。

要点：
- UI の役目はプレイヤーとゲームをつなぐこと。使いやすさは情報の扱いと整理
- 仕様の1画面だけでなく、前後の画面・周りに出る表示物を見て作る（UI の外側を見る）
- 遊び心のある絵の UI は魅力を直接伝えるが、やりすぎるとプレイヤーが見ているだけの過剰な演出になる。絵を強くしたいあまり毎回さじ加減に悩む（作り手の声）
- シリーズの UI は「可愛らしさ」ではなく「あたたかさ」で統一。骨太のアクションなので、遊びと見た目が離れないように。幅広い年齢のために、難しそうに見せない、コントラストをきつくしない
- 時代と機械に合わせて変える：タッチの機械では一目でボタンと分かる質感の強いボタン、HD の機械では可愛くなりすぎないフラットデザインとモーショングラフィック、どの年齢にも清潔に見える色

このゲームへの含意（担当 C）：
- 対象が中高生〜社会人なので、「可愛い」ではなく「あたたかい」を軸にする（ラーメン屋の湯気・木・灯り）。規則の案の言葉にそのまま使える
- 一画面を作るときに前後の画面とのつながり（矢印でつないだ img2）を見る。いまの画面は、プロローグ（白いカード）→ 開店の前（上部の帯とタブ）で急に見た目が変わる（w12→w13→w25）
- 重要な場面だけ絵の文字（グラフィックフォント）のリッチな札にし、ふだんの選択は簡素に（モード選び・難易度選び）

再読（R2、2026-10-30）：記事を末尾まで通読し直した（後ろは電ファミの新着・ランキング・連載の一覧）。足すこと：①グラフィックフォント（飾りの文字の画像）の各国語版もチームの中で作っている（質疑で会場がざわついた）。②飾りの文字のメニューは、モードの多さを際立たせ、飽きさせずに長く遊んでもらう工夫として紹介された。③HD の作品ではどの年齢にも清潔に見える色とロード画面の工夫がある。④道具で開発の環境を良くし、UI のデザインにもっと時間を使いたい、というのが道具の話の結び。人数と期間は書かれていない。
