デジタル庁デザインシステム β版の文字の規則（2026年8月5日更新）。日本語の画面の文字の決まりとして要点を読んだ。書体は Noto Sans JP、太さは Normal（400）と Bold（700）の2段。大きさは用途で3つの帯に分け、本文と UI は 16 CSS px を基準の下限とし、それより小さい字はフッターなど領域の制約がある時だけ。行の高さは、ボタンなどの1行は 100%、業務の画面で情報量を優先する時は 120〜130%、見出しは 140%、本文は 150% を最低に 160〜175%（175% は心理的な負荷を下げる用）。テキストスタイルを「種類-大きさ太さ-行高」の名前（例 Std-17N-170）で呼ぶ。ピヨ商店の上部の帯は 11〜13px の字が多く（ramen.css の r-kpi small・r-gl・r-tabs）、この基準より小さい。業務の画面の 120〜130% の行高が「情報量を優先する時」の扱いで、遊ぶ画面の本文に使う値ではない、という区別がピヨ商店の文字の段の決め方に効く。
