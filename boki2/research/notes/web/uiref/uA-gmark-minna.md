2021年度グッドデザイン賞のみんなの銀行の受賞ページ。作り手の側の説明と、審査委員の評価がある。作り手の説明：デジタルネイティブの世代の調査で、今の銀行の分かりにくさと、お金への漠然とした不安が多く見られたので、分かりやすさを重んじたシンプルでミニマルな UI とした。デザインのポイントに、お金の管理と支払いを極力シンプルにし、モノクロとイラストで表したミニマルで独自の銀行体験、とある。審査委員（太刀川英輔）は、白黒だけで簡潔かつ個性的な UI を作ったことと、色を絞った分、動き（モーションデザイン）に力を入れていて、それが使う気持ちよさに直結している、と評している。ピヨ商店に効くのは「色を絞る」と「動きに力を入れる」が対になっている点：色と絵で安っぽさを消すのではなく、色を絞って動きで気持ちよさを出す道がある。画面の動きそのものはこのページでは見られない（静止画だけ）。
