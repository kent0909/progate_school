Mobbin の利用規約（Terms）。全文を語の検索（scrap・crawl・robot・spider・automated・AI）で当たり、当たった条項の前後と、AI Credits の章を読んだ。全条は読んでいない。

読み取ったこと：禁止事項に、スクレイパー・ロボット・スパイダー・クローラーなどの自動の手段で頁の中身を取る・写す・見張ることがはっきり入っている。検索エンジンなどの自動の道具には別の条件が書かれているが、私たちの使い方（設計の参考に画面を集める）はそれに当たらない。さらに、AI や機械学習を使って派生物を作ることも禁じている。一方で、有料の API と MCP（AI Credits の消費で使う）が用意されている。結論：自動取得はしない（no-automation）。使うなら、オーナーが公式の MCP を接続する道がある（WANTED.md と相談で伝えた）。
