GeekDad の Supergiant の Greg Kasavin への聞き取りの後半（2019年10月、Hades の早期アクセスの最中）。Game Developer の Hades の開発の記事（r6-rp-gd-hades-devprocess、robots.txt の禁じる経路）の差し替えに使う。

自分の言葉の要約：
- Pyre に続き大勢の人物を出し、今回は全部に声を当てた。変化はゲームの状態の側にあり、人物は今の場面（体力が少ない、どこまで進んだか、誰に先に会ったか）に合わせて話す。書き手は場面ごとに台詞を書いて全部入れ、ゲームがその場に合うものを選ぶ。
- 深く非線形で遊び直せる作りなので、どの順でも起きる。書いた本人でも、並びの組み合わせで驚く。
- これまでの作品は始まり・中・終わりがあり完結していた。早期アクセスの物語は連続ものの第1話のように出し、1〜2か月ごとの更新で足し、最後の結末は正式版まで取っておく。
- Pyre は3年かけて書いても、遊ぶ人は48時間ほどで遊び終え、それで終わった。早期アクセスでは新しい人物が受けるかがすぐ分かる。
- 失敗の調子：うまくいっていたのに一つの間抜けな失敗で戻される。主人公は自分を笑って再挑戦する。入口の壁は低くしたいが、上手な人にも見る物は残す。
- 繰り返す台詞は、20〜30周しないと同じ行に当たらない量を書いた。

Game Developer の記事の「重なる仕組み」「データの側に置いてコードを変えずに足す」「短い時間でも遊べる」「見て楽しい」の言葉は、この聞き取りには出てこない。
