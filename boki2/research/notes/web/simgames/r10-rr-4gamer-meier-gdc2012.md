4Gamer の GDC 2012 の講演の報告（2012-03-08）。Sid Meier が「デザインとは興味深い選択の連続」という 1989 年の自分の言葉を考え直した講演。robots.txt の禁じる経路で取った Game Developer の同じ講演の記事（r4-sim-gd-meier2012）の差し替えに使う。

自分の言葉の要約：
- 興味深い選択とは、何かを決めるとき、どちらを先にするかを選ばせること。RPG で高い剣を今買うか、サブクエストを急ぐか。Civ で偵察を先に作って広げるか、戦士で蛮族に備えるか。
- 選択は短い・中くらい・長い先に何段にも響くもので、遊ぶ人の遊び方や人柄で変わるべき。
- 選んだ結果がどう響くかを画面ではっきり見せないと、興味深くならない。歴史の題材を好むのは、遊ぶ人が状況を理解しやすいから。
- いつも遊ぶ人の席に座ったつもりで作る。今でも開発の半分は自分の試遊。
- 締め：選択を並べるだけでは良いゲームにならない。仕組みの無機質な所をファンタジーで包むのが、遊ぶ人との良い関係の秘訣。

Game Developer の記事にあった「街に名前をつける」「試した要素の3分の1以上を削る」「他のゲームの部品の寄せ集め」「出目が仕組まれていると思う人」は、この報告には出てこない。同じ講演の別の記者の要約なので、言葉の細部は違い、どちらが講演に近いかはここからは分からない。
