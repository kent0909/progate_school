4Gamer の GDC 2012 の講演の報告（2012-03-08）。Maxis の Ocean Quigley・Andrew Willmott・Dan Moskowitz による SimCity（2013）のエンジン GlassBox の講演。Game Developer の同じ講演の記事（r6-sd-gd-glassbox2012、robots.txt の禁じる経路）の差し替えに使う。

自分の言葉の要約：
- これまでのシリーズのエンジンは、起きることが前もって決まった静的なもので、大きな乱数の表が土台だった。GlassBox はデータで動く模擬のエンジン。
- 部品は4つ：資源（石油・木材・お金・電気・労働力・幸福など、上限のある瓶の単位）、ユニット（家・工場・人。資源を溜め、広さを持つ）、地図（埋まった資源・汚れ）、全体（持っている資源の一覧）。これを規則でつなぐ（お金10で木材2、工場は時間ごとにマスタードを瓶詰めし汚れも出す）。
- 単純な規則のユニットが互いに影響して、思いがけない状況が出る。新しい建物ごとに交通や電力が変わり、遊ぶ人はその都度応じる。
- ユニットの間をつなぐのは道（道路・電線・水道）、区画（建物を生む・壊す）、エージェント（合図を送る・交通を運ぶ）。工場の朝に見えないエージェントが住宅へ送られて人が出勤する。火事は熱波のエージェントが隣へ広がり、警報が消防署へ届く。
- 基本の考えは、単純な規則を無数に積み重ねて、複雑な模擬を作ること。

Game Developer の記事の「1万以上のエージェント」の数は、この報告には出てこない。
