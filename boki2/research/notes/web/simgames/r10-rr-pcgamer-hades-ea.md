PC Gamer の Hades の早期アクセスについての記事（Kasavin と Amir Rao への取材、正式版の後）。Game Developer の Hades の開発の記事の差し替えに使う。

自分の言葉の要約：
- 何より先に早期アクセスで作ると決めた。小さな版を早く出し、残りを共同体と一緒に作る。ローグライクの形は、作り足しながらも遊び直せるので早期アクセスに合う。
- 前作の部品（Bastion の戦い方、Transistor の組み合わせ）を作り直して使った。
- 負けて家に戻るのを、負けより帰宅と感じさせたい。どの周も無駄にならない（飾り・物語・成長）。
- 早期アクセスでは大きな更新ごとに新しい中身（新しい神など）を入れ、声に答えた。Discord の票だけでなく全部読み、配信者の遊びを見て、匿名の遊びのデータ（どの武器で初めて抜けたか、どこで詰まるか）も見た。
- 武器を全部同じ強さにするのが目的ではない。武器の幅が周ごとの違いを作る。人ごとに好む武器はあるが、資源の報酬や Dark Thirst で持ち替えを促す。罰の契約（Pact）を使う人への報酬として武器の相を足した。

Game Developer の記事の「最適の組から別の道具の組へ押しやる」の言葉はなく、言えるのは武器の持ち替えを報酬で促すまで。
