公庫「小企業の経営指標調査」2025年度の、飲食店・宿泊業を従業者の人数（1〜4人・5〜9人・10〜19人・20〜49人）で分けた表（6ページ）。飲食店宿泊業、一般飲食店、食堂レストラン、中華料理店、遊興飲食店、酒場ビヤホールの6業種。

中華料理店（ラーメン店を含む）の規模別（1〜4人25社／5〜9人42社／10〜19人29社／20人以上13社）：
- 営業利益率：−3.6% → −0.1% → −0.7% → +0.4%。いちばん小さい店が一番苦しい。
- 人件費の売上比：34.8 → 32.7 → 34.5 → 31.9%。諸経費：33.6 → 28.5 → 29.0 → 27.8%。総利益率はどの規模も64〜66%。
- 1社の店の面積：58.6㎡（約18坪）→ 111.7 → 139.2 → 211.8㎡。3.3㎡あたりの年売上：198万 → 269万 → 273万 → 371万円。
- 損益分岐点比率：106.5 → 101.4 → 102.1 → 100.2%。
- 従業者1人あたり人件費：313万（1〜4人、代表者の報酬を含む）→ 250万 → 227万 → 211万円。

私の計算：1〜4人の中華料理店は、面積58.6㎡×3.3㎡あたり197.7万円で年売上およそ3,500万円（月約290万円）。1杯1,000円なら月2,900杯、26日営業で1日約110杯【計算】。5〜9人なら年約9,100万円。食堂・レストランも同じ傾向（1〜4人の営業利益率 −4.5%）。

ゲームへ：屋台から上がった最初の店（2〜4人）は「1日100杯前後・月商300万円・営業利益は赤字すれすれ」が現実の中心。人を増やすと人件費率は下がるが、店も広く家賃も要る。規模が上がるほど損益分岐点比率が100%に近づき安定する、という拡大の筋道の根拠になる。
