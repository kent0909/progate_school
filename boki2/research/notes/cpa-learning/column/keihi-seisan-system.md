# 経費精算システムとは（メリット・注意点）
URLは簿記分類だが内容は経理実務。経費の申請・承認・支払いを自動化するシステムの紹介。
- できること：スマホで領収書を読み取りアップロード、自動仕訳（会計ソフトへの入力不要）、申請から承認までシステム上で完結（規程違反をブロック、カラ出張などの不正防止）、電子帳簿保存法の要件確認とペーパーレス、法人カード・交通系ICとの連携（小口現金や立替払いが不要に）。
- メリット：作業ミスの防止。従業員が迷いやすい科目の例として、接待のタクシー代を旅費交通費にしてしまう、香典（交際費だが消費税がかからない）を課税で申請する、ガソリン代を車両費でなく旅費交通費にする、を挙げる。一度決めた科目は理由なく変えない（継続性）。分かりやすい名目（「タクシー代（接待）」など）で選ばせれば解決。業務効率化、人件費削減、ペーパーレス。
- 選び方：料金（オンプレミス型とクラウド型）、サポート体制、規模に応じた機能、既存の会計ソフト・勤怠・給与との連携。
- 宣伝部分の主張：経理は日次業務が細かく全体像を見失いやすいので、仕事を点でなく線で捉え、仕訳のたびに自社や取引先の財政状態を意識すると、支払い・入金の見通しが立ち黒字倒産を防げる。
示唆：「名目から科目を自動で決める」仕組みは、ゲームの自動仕訳ルール（PEDAGOGY 1.6）と同じ発想で、条件の外の取引（接待のタクシー代、香典の消費税）を監査が仕込む素材になる。科目の継続性（同じ事柄は同じ科目）は、自動化の前提として説明できる。
