為替手形（振出人が支払人に、受取人への支払いを依頼する証書）の意味、3種類（他人宛・自己受・自己宛）、振出しと記載要件、仕訳（手形の受取：受取手形／売掛金、為替手形の振出し：買掛金／売掛金、期日の取立て：当座預金／受取手形）、知っておくべき点（裏書による譲渡、振出人が空欄の手形、印紙税）を説明する記事。

読み取ったこと
- 振出人の仕訳は、支払人への売掛金と受取人への買掛金が同時に消える（買掛金／売掛金）。振出人には新しい債権債務が生じない、という説明。
- 記載要件として、支払人・振出人の名称、支払約束の文言、金額、受取人、振出日・振出地、支払期日・支払地を挙げる。
- 不正確・危うい点：冒頭の定義が「振出人が支払人に代わって受取人に支払うよう依頼」と主語と目的語が入れ替わったような文。振出しの説明でA社・B社・C社の役割の説明が途中で入れ替わる。振出人の欄が空いていても受取人が自分で名前を書けば効力が生じる、と書くが、振出人の署名は手形の必要的記載事項で、受取人が振出人欄に記入するのは偽造に当たりうる（白地の補充とは別）。印紙を貼り忘れた手形について「受取人が印紙税を補完する」と書くが、納税義務者は作成者（振出人）で、記事の説明は根拠が示されていない。

2級との接続
- 為替手形は現行の2級（2019年度からの出題区分）ですでに範囲外で、さらに2027年改定では s-tegata 全体が外れる方向（scope.js で out）。この記事の仕訳は旧範囲の内容として扱う。ただし「売掛金と買掛金が相殺される」という考え方は、s-denshi（電子記録債権の譲渡）や債権債務の相殺の理解に流用できる。

ゲームへの示唆
- ゲームでは為替手形を扱わない（範囲外）。E17（手形：参考回）でも約束手形にとどめるのがよい。振出人欄の空いた手形を受け取る場面は、BE10（取引停止）ではなく、怪しい取引先を見抜く小イベントとしてなら使える。
