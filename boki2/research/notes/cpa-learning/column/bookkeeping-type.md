# 日商簿記・全商簿記・全経簿記の違い
3つの簿記検定を受験者数・受験者層・受験料・難易度・試験形態で比べ、結論として日商を勧める記事。
- 受験者層：日商は社会人中心、全商は商業高校生、全経は経理専門学校生。
- 受験料：全商が最も安い。日商は当時1級7,850円・2級4,720円・3級2,850円・初級2,200円。
- 難易度：級の名前と難しさが検定ごとにずれる（日商3級≒全商2級）。市販テキストは日商の級を基準に作られている。日商は級が上がるごとに範囲が一気に膨らむ（ある出版社のテキストは3級1冊・2級2冊・1級4冊）ので途中の到達度が測りにくく、全経は級が細かく実力試しに向く。
- 税理士受験資格：日商1級か全経上級。日商1級は会計士受験生も受け母集団のレベルが高いので、資格目的なら全経上級を勧める。
- 形態：ネット試験は日商2・3級のみ。日程の自由と合格率の安定（統一試験の2級は一桁の回も）。
- 各検定の詳細（日程・範囲・合格基準・受験料・申込方法）。日商1級は70％かつ各科目40％以上。全経上級は4科目各40点以上かつ合計280点以上。
示唆：「日商は級が上がると範囲が倍々で増える」という指摘は、2級の学習量（3級の約3倍の時間）の背景。ゲームでは2級の範囲が「会社の成長で必要になる知識」として段階的に増える設計なので、到達度を細かく見せる（原理マップ）ことで、この検定の弱点（途中が測れない）を補える。
