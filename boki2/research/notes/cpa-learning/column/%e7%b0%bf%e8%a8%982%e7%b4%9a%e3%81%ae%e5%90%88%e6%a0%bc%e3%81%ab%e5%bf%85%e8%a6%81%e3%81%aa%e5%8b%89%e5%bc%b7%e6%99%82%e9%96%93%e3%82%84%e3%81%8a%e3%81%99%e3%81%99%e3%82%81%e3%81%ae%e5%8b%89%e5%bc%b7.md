# 簿記2級の合格に必要な勉強時間とおすすめの勉強方法
2級の試験情報と勉強法の総説。数字が新しい（2024〜2025年）。
- 2級の位置づけを商工会議所の説明で示す。統一試験の直近4回（2024年6月〜2025年6月）の平均23.7％。試験回ごとの難易度調整はないので難しい回は合格率が下がる。ネット試験は2023年度35.2％・2024年度35.7％。主催者は難易度は同じとしており、差の原因は不明でいずれ収れんするだろう、と見る（他記事の「ネットのほうが受かりやすい」とは温度差）。
- 2級は商業（応用）3問・工業（基礎）2問、60点・40点。工業は製造業の経験がないとイメージしにくい。
- 勉強時間は各社の公表値（100〜350時間）を並べ、中心は250時間程度、1日2時間で約4か月。動画教材が独学・講座のどちらでも外せない時代。
- ポイント：強弱（リズム・テンポ）をつけて飽きずに継続、自分に合うテキストを実物で選び同じシリーズでそろえる、試験日から逆算してスケジュールを立てる（立案も勉強の一部）。
- 方法：参考書を3回（全体像→重要点の理解→分からない所をつぶす）。工業を先に学ぶ見解が多い（2級の工業は基礎、商業は応用で難しいから）。問題集は参考書と交互に、3回でとどめ（答えを覚えてしまうので）、その後は類似問題→過去問（最初は時間超過でも全問）→予想問題。苦手は本番に出るので作らない。同じ所で何度も間違えるならそこが苦手。理解できないのは3級の理解があやふやな可能性（70点合格なら3割は分かっていない）。
- 独学が簡単でない理由：工業簿記（用語・計算）、改定で連結・外貨建取引・リースなど1級の範囲が入った。
示唆：商業と工業の順序について、このサイト内でも「商業が先」「同時並行（インターリーブ）」「工業が先」と記事ごとに主張が分かれている。ゲームは会社の成長順（商店→工場）で商業が先になるが、工業の基礎（原価の流れ）は早めに小さく体験させ、商業と交互に進める設計にすると、どの主張の利点も取り込める。「3級70点合格は3割分かっていない」は、2級の冒頭で3級の土台（b-xxx）を確かめ直す場面を置く根拠。
