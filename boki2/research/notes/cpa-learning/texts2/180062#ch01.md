# 第1章 工業簿記の基礎（PDF 1〜40）

## 前付け
- はしがき・CPAラーニングの宣伝・「合格への道」（教科書→問題集→模試の3段。例題は3回反復を推奨）・本書の使い方（見開きの借方/貸方ページ番号の遊び、CHECK用語欄、ひと言アドバイス、例題）。
- 試験制度の頁は2020年12月のネット試験導入時点（90分、配点 商60・工40、受験料4,720円）。2027年度改定には当然触れていない（刊行2022年4月）。新試験の方が回ごとの難易度のぶれが少ないという立場。
- 目次で全14章の並びが分かる：基礎→材料費→労務費→経費→製造間接費→部門別→個別→総合→その他の総合（工程別・組別・等級別）→決算と財務諸表→標準→直接原価計算→CVP→本社工場会計。PDF頁＝本書頁＋20。PDF 1・2・12・20・40 は白紙（画像で確認）。

## 導入の仕方
- 入口は「商業簿記との対比」。仕入先→当社→得意先という3級で見慣れた横一列の図に「工場（製造活動）」の箱を1つ差し込むだけで違いを見せる。新しいのは「作るのにいくらかかったか」を数える必要が出ること、という一点に絞る。
- 次に「なぜ原価計算が要るか」を財務諸表から逆算させる：売った製品の原価が分からないと P/L の売上原価も、B/S の材料・仕掛品・製品も書けない。目的を管理ではなく「決算書を作るため」に置いているのが特徴（管理目的は差異分析・CVPで後から出すと予告）。
- 原価／非原価の区別（支払利息や異常な原因の原価は営業外・特別損失）→総原価＝製造原価＋販管費 という積み上げ。7つの費用（原材料・工員賃金・工場の光熱費・本社職員給料・本社の光熱費・広告費・支払利息）を「工場か本社か財務か」で仕分けるケーススタディ。場所（工場/本社）で原価を見分ける発想はゲームの工場フロアにそのまま使える。
- 製造原価の3つの切り口：発生形態（材料・労務・経費）／製品との関連（直接・間接＝賦課と配賦）／操業度との関連（変動・固定）。3つ目は「財務諸表用ではなく管理用」と注記して後の章へ送る。積み上げ図（直接費・間接費の3×2マスの上に販管費・利益を重ねて販売価格まで）を例題1-1の数字で埋め直す。
- 原価計算期間は1か月、理由は「早く原価を知るため」。勘定を「原価要素の勘定（材料・労務費・経費）」「集計の勘定（製造間接費・仕掛品）」「その他（製品・売上原価・販管費）」の3群に整理。
- 手続は第1次 費目別→第2次 部門別（製造間接費の配賦）→第3次 製品別。第2〜7章は個別原価計算を前提にすると宣言し、総合は第8・9章。

## 勘定の流れの見せ方
- 1つのケーススタディ（材料105,000・賃金208,000・経費115,250 → 間接費207,250配賦 → 完成400,000・月末仕掛品28,250 → 350,000分を420,000で掛売り → 販管費20,000 → 月次損益）を、取引ごとに「仕訳＋T勘定の小さな連絡図」で7段に分けて流す。同じ数字を最後まで使い回すので、どの箱から何が出たかを追跡できる。
- 締めの一枚が要点：材料費・労務費・経費の合計（製造原価428,250）が、矢印で「売上原価350,000（P/L）」「期末製品50,000」「期末仕掛品28,250（B/S 棚卸資産）」の3つに分かれる図。原価計算とは製造原価を B/S と P/L に按分する手続だ、と1文で定義する。PEDAGOGY の P6（使った価値は製品に乗り移り、残りは資産・出た分は次の箱）とほぼ同じ骨組み。
- 最後に勘定連絡図（材料・労務費・経費→仕掛品／製造間接費→仕掛品→製品→売上原価→損益）。実線が直接費、破線が間接費経由。「いまどの計算をしているかを常に意識せよ」と念押しし、第2章以降の各章冒頭でこの図の該当部分を「Step1 費目別／Step2 間接費の配賦／Step3 製品別」として再掲する（現在地の地図として使う）。

## つまずきへの先回り・注意点
- 「原価」と一言で言えば製造原価のこと、販管費は製品に集めず期間の費用、という但し書き。
- 労務費は前月末未払・当月末未払が勘定の中に最初から描かれており、第3章の未払賃金の伏線になっている。

## ゲームへの示唆（分析文書に展開）
- E35「工場、動き出す」の発見は、この章の「横一列に工場の箱を差し込む」図と、「製造原価が3方向（売上原価・製品・仕掛品）に分かれる」図の2枚で足りる。社長の「全部費用でいいよね」に対して、売れていない瓶（期末製品）と作りかけ（仕掛品）が B/S に残る、を手で分けさせる操作に置き換える。
- 7つの費用を「工場・本社・財務」に仕分ける場面は、工場長と総務の請求書が混ざって届く証憑イベントにできる（数字は変える）。
