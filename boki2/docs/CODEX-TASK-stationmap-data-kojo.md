## うまくいく理由
- 試しの台本が元とバイト一致 → 同じ台本で作った規則ごとの地図がある → Codex の出力と全件で照らせる → 写しただけ・件数だけの照合が見つかる。
- 規則と手順を1つに決めてから出す → Codex が既定値を選ぶ余地がない → 設計の判断が Codex に移らない。
- 案β（印を足す）を選べば → 測定の道具の置き値が1つも変わらない → ADD1 の測定と数が比べられる。

## うまくいかない理由
- 試しの台本の誤りを、照らす相手として Codex に写させてしまう（試しは正本ではない）。和らげる手：違いが出たら PR で聞く（7章2）。
- 新しい点のメッシュの値（D7）や、候補地0の駅の見せ方（7章5）は、この依頼の中で決めきれない。
- 案α を選ぶと、湾岸の置き値を工場の値の写しにした時点で、別の種類にした意味が測定に出ない（見た目だけ別）。

## 反証と限界
- X2 は町の名で当てる。町が同じでも、点が流通業務団地の区域の線の内側かは確かめていない（計画図を重ねていない）。板橋区の高島平7丁目の住宅地の候補地（s395-1）も町の名では当たる（工場でないので外していない）。
- X2b の「流通業務」の字は、地価の鑑定の地域の区分で、都市計画の流通業務地区とは別。X2 と X2b で当たる所が違う（平和島3丁目は両方、新砂1・辰巳3・港南5は X2b だけ、臨海町3は X2 だけ）。
- 都は流通業務団地に「働く人を支える場所」を入れる向きに都市計画を変えている [[web:ramencount23:tokyo-kubu-ryutsu-danti|「就業者支援スペース等の導入を可能にします」]]。X2 の「出せない」は、これからは弱まりうる。
