# 経営の打ち手と法律・会計処理（BIZ-LAW）

最終更新：2026-10-22（調べもの担当 r4-law）

ピヨ商店に「売上が動く打ち手」（チラシ・SNS・インフルエンサー案件・値引き・ポイント・キャンペーンなど）と「コスト・投資の側の変動」（食品の廃棄・衛生、仕入先の品質不良、設備投資、補助金、保険）を入れるための土台。打ち手ごとに次の4つを書く。

1. **守る決まり**（法令・告示・ガイドライン）
2. **破ったときに起きること**（行政処分・課徴金・罰則・炎上・取引停止）
3. **会計処理**（仕訳の例。簿記2級で使う勘定科目で書く）
4. **ゲームでの出し方の案**（正しくやる／うっかり違反する分岐と、その返り）

## 0. 凡例と、この資料の限界

- 根拠は二重の角かっこ（取得元:集合:文書）で読了ノートを指す。ノートは `boki2/research/notes/` にある。
- **【要確認】** は、一次資料で確かめきれなかったもの。ゲームの画面には出さない（このプロジェクトは未確認の法令を画面に出さない決まり。`tools/law-check.js`）。
- 2026-10-22 の取得時に、**e-Gov 法令検索（メンテナンス中で403）・国税庁（503）・消費者庁の特定商取引法ガイド（メンテナンス中で503）・公正取引委員会（取得用のUser-Agentを403で拒否）** が取れなかった。そのため次のものは条文や国税庁の説明で確かめられていない：景品表示法4条の条文そのもの、商法526条、所得税法204条（報酬の源泉徴収）と税率、少額の減価償却資産の基準、短期前払費用の通達、交際費と広告宣伝費の区分の通達、特定商取引法11条（通信販売の広告）、食品表示法の条文、下請法から取適法への改正。これらは【要確認】のまま残す。次の担当は §9 の一覧を取り直すこと。
- 会計処理は簿記2級の範囲で書く。2級の出題区分（2027年4月施行）には、契約負債、圧縮記帳（直接控除方式に限る）、建設仮勘定、未決算、長期前払費用が入っている [[kentei:kubun2027:2027kubunhyo_fixed]]。範囲の外にはみ出すもの（ポイントの見積りの詳しい計算など）は、そう書く。
- 仕訳の金額は説明用の例。消費税は税抜経理（仮払消費税・仮受消費税）で書く。税抜でも税込でも納める額は同じ [[law:primary:nta-6375]]。

## 1. 共通の土台：景品表示法のしくみ

ピヨ商店の売上側の打ち手のほとんどは、**不当景品類及び不当表示防止法（景品表示法、昭和37年法律第134号）** にかかる。

### 1-1 何が禁止されているか

| 区分 | 中身 | 根拠 |
|---|---|---|
| 優良誤認（5条1号） | 品質・規格などの中身を、実際より、または競合より著しく良く見せる | [[law:primary:r4-law-caa-yuuryou]] [[law:primary:r4-law-stema-yuushinkai]]（参考1に条文） |
| 有利誤認（5条2号） | 価格・取引条件を、実際より、または競合より著しく得に見せる | [[law:primary:r4-law-caa-yuuri]] |
| 指定告示（5条3号） | 内閣総理大臣が指定するもの。無果汁の清涼飲料水、原産国、おとり広告、ステマなど | [[law:primary:r4-law-caa-hyouji]] |
| 過大な景品（4条） | 景品の上限を超える提供 | [[law:primary:r4-law-caa-keihin]]（条文そのものは【要確認】） |

- **わざとでなくても違反になる**。誤って表示した場合も優良誤認・有利誤認に当たる [[law:primary:r4-law-caa-yuuri]] [[law:primary:r4-law-caa-yuuryou]]。
- 効果・性能をうたう表示は、消費者庁から根拠資料を求められ、出せなければ措置命令では不当表示と**みなされ**（7条2項）、課徴金では**推定される**（8条3項）。不実証広告規制 [[law:primary:r4-law-caa-yuuryou]]。
- 規制の対象は**売る側の事業者（広告主）**。頼まれて投稿したインフルエンサー本人は景品表示法の対象ではない [[law:primary:r4-law-caa-stema]]。

### 1-2 破ったときに起きること

| 処分 | 中身 | 根拠 |
|---|---|---|
| 指導 | 違反とまでいえないが、おそれがあるとき | [[law:primary:r4-law-caa-violation]] |
| 措置命令（7条1項） | やめる・違反だったと一般消費者に知らせる・再発防止策・今後しない。消費者庁が社名と中身を公表する | [[law:primary:r4-law-caa-violation]] [[law:primary:r4-law-stema-yuushinkai]] |
| 課徴金納付命令（8条） | **優良誤認・有利誤認だけ**（5条3号の指定告示＝ステマなどは対象外）。対象期間の売上額×**3%**。10年以内の再違反は**4.5%**。額が**150万円未満なら命じない**。知らず、知らないことに相当の注意を怠っていなければ命じない。対象期間は最長3年 | [[law:primary:r4-law-kachoukin-8jou]] [[law:primary:r4-law-caa-violation]] |
| 確約手続（26〜33条） | 疑いの段階で是正計画を出し、認定されれば措置命令・課徴金を受けない（2024年10月1日施行） | [[law:primary:r4-law-keihyo-kaisei2024]] |
| 直罰（48条） | **故意の**優良誤認・有利誤認に100万円以下の罰金（両罰規定あり。2024年10月1日施行） | [[law:primary:r4-law-keihyo-kaisei2024]] |
| 都道府県知事 | 知事も措置命令ができる | [[law:primary:r4-law-caa-violation]] |

**ゲームの設計上の要点**：課徴金は売上×3%で150万円未満は課されない。売上5,000万円が分かれ目なので、**小さな店のうちは課徴金より「措置命令と公表による信用の傷」「炎上」「取引先・モールからの取引停止」の方が現実的な返り**。会社が大きくなってから課徴金の返りを出すと正確になる。ステマはどれだけ大きくなっても課徴金の対象外で、措置命令と公表が中心 [[law:primary:r4-law-kachoukin-8jou]]。

### 1-3 会計処理（処分を受けたとき）

```
（課徴金の納付命令を受けた）
課徴金（または雑損失・特別損失）  1,800,000 ／ 未払金  1,800,000
（納付した）
未払金                            1,800,000 ／ 普通預金 1,800,000
```
- 勘定科目の名前は簿記2級の決まった札にはない。ゲームでは「雑損失」（金額が大きければ「特別損失」として表示）でよい。
- 税金の計算で課徴金が費用（損金）にならない扱い【要確認：法人税法55条】。税効果の論点につなげるなら、条文を確かめてから。
- 自主返金（課徴金の減額の制度。電子マネー等での返金も可）[[law:primary:r4-law-keihyo-kaisei2024]] をしたときの勘定科目（売上の取消か雑損失か）は【要確認】。

## 2. 打ち手ごとの整理（売上の側）

### A. チラシ・ポスター・店頭の表示

**守る決まり**
- 「レモン果汁たっぷり」「国産レモン100%」などの中身の表示は優良誤認に注意。根拠（仕入れの記録）を用意しておく [[law:primary:r4-law-caa-yuuryou]] [[law:primary:r4-law-caa-hyouji]]。
- 「疲れが取れる」など効果をうたうと、不実証広告規制で根拠資料を求められうる。食品の健康効果の表示は健康増進法・食品表示法の規制もある【要確認】。
- 果汁の少ない飲み物の表示には指定告示（無果汁の清涼飲料水等）がある [[law:primary:r4-law-caa-hyouji]]。告示の中身（何%未満で何を書くか）は【要確認】。レモネード屋に直結するので次に取る。
- 看板・のぼりの屋外広告物の条例（自治体ごと）【要確認】。

**破ったとき**：措置命令と公表（§1-2）。SNSでの指摘からの炎上。

**会計処理**
```
（チラシ5,000枚の印刷を頼み、代金を払った）
広告宣伝費   30,000 ／ 現金  33,000
仮払消費税    3,000
（ポスティングを業者に頼み、月末払い）
広告宣伝費   20,000 ／ 未払金 22,000
仮払消費税    2,000
```
- 仕入税額控除には相手の**適格請求書（インボイス）** が要る。登録していない相手（免税のフリーランスなど）からの仕入れは原則控除できず、2031年9月30日までは80%〜30%を控除とみなす経過措置がある [[law:primary:nta-6375]]。
- 看板・什器：使える期間が1年以上で金額が大きければ備品（固定資産）にして減価償却。少額なら消耗品費。**少額の基準のうち、中小企業者等の特例は「40万円未満・年300万円まで・2029年3月末まで」（租税特別措置法67条の5。BIZ-CALIB.md で e-Gov の条文を確かめた。この文書の初版は30万円未満と誤っていた）。10万円未満・20万円未満の一括償却は国税庁のページが取れず【要確認】**。簿記2級の問題では、問題文が「備品として処理」と指示する形が多いので、ゲームでも社長の判断として提示し、基準の数字は確かめてから出す。

**ゲームでの出し方**
- 正しく：仕入れ伝票を見て「国産レモン使用」と書ける量かを確かめる→チラシを出す→売上が伸びる。
- うっかり：仕入先を安い輸入レモンに変えたのにチラシを刷り直さない→客の指摘→店頭での訂正と謝罪、信用（評判）が下がる。会社が大きい段階なら措置命令と公表。
- 会計の学び：広告宣伝費は**出した月の費用**。「チラシの効果は来月も続くから資産にしたい」という社長に対し、効果が続いても費用になる（資産にはしない）ことを示す。

### B. 値引き・二重価格・タイムセール

**守る決まり**（価格表示ガイドライン [[law:primary:r4-law-kakaku-gl]] [[law:primary:r4-law-caa-nijuu]]）
- 「通常500円→300円」のように過去の価格と並べるなら、その元値が「最近相当期間にわたって販売されていた価格」であること。目安：**セール開始からさかのぼる8週間**（売っていた期間が8週間未満ならその期間）のうち、**その価格で売った期間が過半**。ただし、その価格で売った期間が**通算2週間未満**、または**最後にその価格で売った日から2週間以上**たっていれば当たらない。
- セールを決めてから売り出した商品の「セール前価格」は実績作りとみられうる。
- 将来の価格（「来月から600円」）との比較は、その価格で本当に売る根拠がなければ不可。
- 希望小売価格はメーカーが事前に公表したものだけ。競合・市価との比較はきちんと調べた最近の価格だけ。
- タイムサービスや、売れ残りを避けるための閉店前の値下げで当初の価格と並べるのは、通常問題ない。
- 「全品大幅値下げ」「他店より安く」などの強調は、実際は一部商品だけなら不当表示のおそれ。

**破ったとき**：有利誤認。措置命令・公表。売上が大きければ課徴金（売上×3%）。

**会計処理**
```
（その場の値引き。300円で売った）
現金  300 ／ 売上 300        ← 値引き後の額で売上を立てる（元値500円は帳簿に出ない）
（売ったあとに、品質の問題で値引きした＝売上値引）
売上  50 ／ 売掛金（または現金） 50
```
- 値引きは費用ではなく**売上の減少**。広告宣伝費とは違う。

**ゲームでの出し方**
- 会計とのつながりがいちばん強い打ち手：「通常価格500円」と書くには、**売上の記録（どの価格で何日売ったか）が証拠になる**。帳簿を見て8週間のうち何日500円で売ったかを数える場面。
- うっかり：新メニューを1週間だけ500円で売ってから「通常500円→半額」→有利誤認。
- 正しく：閉店1時間前の値下げ（タイムサービス）で廃棄を減らす→廃棄損が減る（§K につながる）。

### C. SNS・インフルエンサー案件（PR表記）

**守る決まり**
- **ステマ告示**：令和5年内閣府告示第19号（2023年3月28日）、**2023年10月1日施行**。景品表示法5条3号に基づき、「事業者が自分の商品の取引について行う表示で、一般消費者がそれを事業者の表示だと見分けにくいもの」を不当表示に指定 [[law:primary:r4-law-stema-kokuji]]。
- 運用基準（2023年3月28日 消費者庁長官決定）[[law:primary:r4-law-stema-kijun]]：
  - **事業者の表示になるもの**：インフルエンサーにSNS投稿を頼む、ECレビューを頼む、アフィリエイト。明示の依頼がなくても、対価（お金・品物だけでなく招待・もてなしも含む）や今後の取引をにおわせて書かせれば当たる。
  - **事業者の表示にならないもの**：無償で渡しても相手が自分の判断で書いた投稿、キャンペーンへの応募の投稿、不特定の人への試供品配布の結果の投稿、取材記事・書評。
  - **明瞭な表示**：「広告」「宣伝」「プロモーション」「PR」、または「A社から商品の提供を受けて投稿している」などの文章（ただし全体で判断）。
  - **不明瞭な表示**：表示がない、一部だけ、冒頭は「広告」なのに本文で「第三者としての感想」と書く、動画で一瞬・末尾だけ、小さい字・薄い色、大量のハッシュタグに埋める。
- 規制されるのは広告主（ピヨ商店）。インフルエンサー本人は景品表示法の対象外 [[law:primary:r4-law-caa-stema]]。
- 個人のインフルエンサー・クリエイターへの発注には**フリーランス・事業者間取引適正化等法**（§G）。

**破ったとき**：措置命令と公表（**課徴金は対象外**）[[law:primary:r4-law-kachoukin-8jou]] [[law:primary:r4-law-caa-violation]]。第1号の措置命令（2024年6月6日）は、医療機関が口コミに星5か星4を付けることを条件に料金を割り引いた事案 [[law:primary:r4-law-stema-yuushinkai]]。実際には「ステマだった」と分かったときの炎上の方が影響が大きい。

**会計処理**
```
（インフルエンサー（個人）に投稿1本を依頼し、報酬を払った）
広告宣伝費  50,000 ／ 普通預金 50,000
（商品の現物を渡して紹介してもらった。三分法）
広告宣伝費   3,000 ／ 仕入      3,000
（成果報酬：紹介コード経由の売上の10%。月末に額が確定し、翌月払い）
広告宣伝費  12,000 ／ 未払金   12,000
```
- 成果報酬は、**額が確定した月の費用**。確定していれば未払金、契約に従って時の経過で発生していくもの（月額の運用代行など）を決算で見越すなら未払費用。
- 個人への報酬に**源泉徴収**（所得税法204条）がかかるかは、報酬の種類（デザイン料・原稿料・モデル料などは対象、単なる投稿の依頼が対象かは解釈がある）で決まる。**税率（100万円以下10.21%）と対象の範囲は国税庁のページが取れず【要確認】**。源泉徴収するときの形は次のとおり（金額は確かめてから使う）：
```
広告宣伝費  50,000 ／ 預り金    5,105   ←【要確認：対象と税率】
                      普通預金 44,895
```
- インフルエンサーが適格請求書発行事業者でなければ、仮払消費税の全額は控除できない（経過措置）[[law:primary:nta-6375]]。

**ゲームでの出し方**
- 分岐1（表示）：PR表記を「冒頭に大きく」「末尾に小さく」「ハッシュタグの中」「なし」から選ぶ。冒頭以外は不明瞭→フォロワーの指摘→炎上→評判低下と、措置命令の可能性。
- 分岐2（頼み方）：「感想は自由に書いて」と「この文で投稿して、星5で」。後者は事業者の表示であることが明白で、表記がなければ違反。
- 分岐3（お金）：報酬を現金で払う／商品を渡す（広告宣伝費／仕入）／成果報酬（未払金）。インボイスの有無で仮払消費税の扱いが変わる。

### D. 口コミ・レビュー施策

**守る決まり**
- 「口コミに星5を付けたら1杯無料」は、星の数を条件にした割引で書かせた口コミ＝事業者の表示で、見分けにくいので違反（第1号の措置命令の型）[[law:primary:r4-law-stema-yuushinkai]]。
- レビューのお礼に次回のクーポンを配るのは、投稿の内容について一切やりとりしていなければ事業者の表示にならないことがある [[law:primary:r4-law-stema-kijun]]。
- 自社サイトに客の投稿を載せるとき、良い意見だけを抜き出したり、良い点だけを切り取ったりすると事業者の表示として扱われうる [[law:primary:r4-law-stema-kijun]]。

**会計処理**
```
（レビューのお礼のクーポン（次回100円引き）を使った客に売った）
現金  200 ／ 売上 200        ← 使われたときに値引き後の額で売上
```
- 配っただけでは仕訳はない（使われたときの値引き）。ポイントのように「重要な権利」として契約負債を立てるかは §F。

**ゲームでの出し方**
- 「星5で1杯無料」を社長が思いつく→経理部（先輩）が止めるか、見逃すか。見逃すと、ある日、星5の口コミが不自然に並んでいると指摘されて評判が急落、という返り。

### E. 景品・おまけ・抽選キャンペーン

**守る決まり**（景品規制 [[law:primary:r4-law-caa-keihin]]）

| 種類 | 例 | 最高額 | 総額 |
|---|---|---|---|
| 一般懸賞 | 抽選・じゃんけん・クイズで一部の客に | 取引額5,000円未満：取引額の**20倍**／5,000円以上：**10万円** | 懸賞に関わる売上見込みの**2%** |
| 共同懸賞 | 商店街の歳末セールなど、地域の多数の店が共同 | 取引額にかかわらず**30万円** | 売上見込みの**3%** |
| 総付景品 | もれなく・先着順 | 取引額1,000円未満：**200円**／1,000円以上：取引額の**10分の2** | なし |
| オープン懸賞 | 購入・来店を条件にしない応募 | 景品規制の外（2006年4月に上限撤廃） | — |

- 景品類＝客を引きつける手段として、取引に付けて渡す物・お金・その他の経済上の利益。
- 上限の数字は消費者庁のページで確認済み。告示の原文（懸賞告示・総付告示）は未取得なので、告示番号を画面に出すなら【要確認】。

**破ったとき**：消費者庁長官が景品の提供を制限・禁止できる（措置命令）[[law:primary:r4-law-caa-keihin]] [[law:primary:r4-law-caa-violation]]。景品の違反は課徴金の対象ではない（課徴金は5条の表示の違反だけ）[[law:primary:r4-law-kachoukin-8jou]]。

**会計処理**
```
（レモネード300円に、もれなく付けるコースターを2,000枚まとめて買った）
広告宣伝費（または販売促進費）  200,000 ／ 現金 220,000
仮払消費税                       20,000
```
- 決算時に残っていれば貯蔵品に振り替える論点がある（未使用の販促物）【要確認：2級での扱いの例】。
- 景品の消費税（課税仕入れ）、もらった客側の扱いは今回は扱わない。

**ゲームでの出し方**
- 計算の場面：300円の商品にもれなく付けられるのは200円まで（取引額1,000円未満）、抽選なら1人6,000円まで（20倍）、総額は売上見込みの2%まで。
- うっかり：「抽選で1名に1万円の商品券」を300円の客に→上限超え。
- 正しく：購入不要の応募（オープン懸賞）にすれば上限なし、ただし来店客が増えるとは限らない、という効果の差。

### F. ポイント・スタンプカード・クーポン

**守る決まり**
- 景品表示法上、値引きと認められる経済上の利益は景品類に当たらない扱いがある（「景品類等の指定の告示の運用基準」）【要確認：未取得】。
- 「ポイント10倍」などの表示は有利誤認に注意（実際の還元率と合っているか）[[law:primary:r4-law-caa-yuuri]]。

**会計処理**（収益認識）
- 自社ポイントが「その契約をしなければもらえない重要な権利」なら、売った代金の一部をポイントに配り、**契約負債**にする。使われたとき（または失効したとき）に売上に振り替える [[web:bizmkt:r4-mkt-jicpa-point]]。
```
（10,000円売って100ポイント付与。95ポイント使われる見込み。配分：商品9,906円・ポイント94円）
現金      10,000 ／ 売上      9,906
                    契約負債     94
（1年目に45ポイント使われた：94×45/95≒45円）
契約負債      45 ／ 売上         45
```
- 簿記2級の区分には契約負債がある [[kentei:kubun2027:2027kubunhyo_fixed]]。ただし、ポイントの独立販売価格の見積りと配分は2級の典型的な出題ではない【要確認：2級でどこまで出るか】。ゲームでは「ポイントの分は、まだ果たしていない約束なので負債」という考え方（P3 期間帰属）を体験させ、計算は簡単な比にとどめる。
- 他社のポイント（共通ポイント）を付けて他社に払うだけなら、その分は売上から除いて未払金 [[web:bizmkt:r4-mkt-jicpa-point]]。
- 消費税：買う側でポイントを使ったときの扱いは、レシートの書き方（値段の値引きか、支払いへの充当か）で決まる [[law:primary:nta-6480]]。

**ゲームでの出し方**
- スタンプカード（10個で1杯無料）を始めるかの判断→売上の一部が契約負債になり、「売れたのに売上が少ない」ことに社長が驚く→スタンプが使われると売上に戻る。
- 見込み（使われる割合）を変えると配分が変わる。使われないカードが多いと、契約負債が小さくなる。

### G. 外注（デザイナー・カメラマン・動画編集者など個人への発注）

**守る決まり**：フリーランス・事業者間取引適正化等法（特定受託事業者に係る取引の適正化等に関する法律、令和5年法律第25号、**2024年11月1日施行**）[[law:primary:r4-law-freelance-setsumei]]
- 対象：事業者どうしの業務委託で、受ける側が**従業員を使わない個人、または代表者1人だけの法人**（従業員＝週20時間以上かつ31日以上の雇用見込み）。消費者からの依頼や、作った物の売買は対象外。
- **発注者が誰でも（個人の発注者も）**：発注したら**直ちに**、書面またはメール・SNSのメッセージなどで、給付の内容・報酬の額・支払期日などを明示する（3条）。
- **発注者に従業員がいれば**：
  - 給付を受け取った日から**60日以内**のできるだけ短い期間で支払期日を決めて払う（4条）。決めなければ受領日、60日を超えて決めれば受領日から数えて60日を経過する日の前日が期日になる。再委託なら元の支払期日から30日以内の例外。
  - 募集広告の正確な表示（12条）、ハラスメントの相談体制（14条）。
  - 1か月以上の委託なら、受領拒否・報酬の減額・返品・買いたたき・購入の強制などの禁止（5条）。6か月以上なら育児介護との両立の配慮（13条）と、中途解除の30日前の予告（16条）。
- 下請法は2026年1月1日から「中小受託取引適正化法（取適法）」に変わったと公正取引委員会が案内している【要確認：資料を取得できなかった。資本金・従業員の基準、手形払いの禁止など】。小さなピヨ商店が発注者のうちは主にフリーランス法、会社が大きくなり受注側が中小企業なら取適法、という段階を作れる。

**破ったとき**：公取委・中小企業庁・厚労省による助言・指導・勧告・公表・命令、命令違反には50万円以下の罰金（法人両罰）[[law:primary:r4-law-freelance-setsumei]]。実際の返りは「勧告と社名の公表」と「クリエイターから次の仕事を断られる」。

**会計処理**
```
（チラシのデザインを個人に頼み、納品を受けた。支払いは翌月末＝受領から60日以内）
広告宣伝費（または支払手数料） 55,000 ／ 未払金 55,000   ← 受け取った時点で費用と未払金
（翌月末に払った）
未払金 55,000 ／ 普通預金 55,000
```
- デザイン料は源泉徴収の対象になりうる（所得税法204条1項1号）【要確認：条文と国税庁の説明、税率】。確かめたら §C の預り金の形を使う。
- 支払いまでの日数を数えるのは「受け取った日」から。請求書が届いていないことを理由に遅らせてはいけない、という扱いを公取委が示しているとの情報があるが資料未取得【要確認】。

**ゲームでの出し方**
- 社長が「口で頼んでおいた、金額はあとで」と言う→経理部が条件をメッセージで送るか。送らないと、納品後に金額でもめる。
- 資金繰りが苦しい月に「デザイン代は3か月後に払う」と社長が言う→60日を超える（従業員がいる段階なら違反）。

### H. 顧客リスト・LINE・スタンプカードの名簿

**守る決まり**：個人情報保護法（個人情報保護委員会「個人情報保護法の基本」2023年9月）[[web:bizmkt:r4-law-ppc-kihon]]
- 取る前に利用目的をできるだけ特定し、公表しておく。書面（申込用紙など）で取るときは目的を明示（17・21条）。
- 目的の外に使うなら本人の同意（18条）。
- 安全管理、従業員と委託先の監督（23〜25条）。
- 漏えいが、要配慮個人情報・財産被害のおそれ・不正の目的・**1,000人分超**のどれかなら、委員会への報告と本人への通知が義務（26条）。
- 第三者に渡すには原則本人の同意。例外は法令、オプトアウト（届出）、委託・事業の承継・共同利用（27条）。

**破ったとき**：委員会の勧告・命令、命令違反は罰則（法人は重い罰金）【要確認：金額は条文で】。実際の返りは、流出の報道と顧客離れ、お詫びの費用。

**会計処理**：LINE公式アカウントの月額費用は通信費または広告宣伝費。流出時のお詫び（クーポン配布・郵送費）は雑損失など。

**ゲームでの出し方**：友だち登録のポップに「何に使うか」を書くか／隣の店に名簿を貸すか（同意がなければ不可）／名簿のファイルを無防備に置いて流出。

### I. 持ち帰り・瓶詰め・通販

**守る決まり**
- 食品表示基準は「容器包装に入れられた加工食品」に適用。その場で注いで渡す、客の注文でその場で容器に詰める、包まずにばら売りは、表示は不要（生食用牛肉を除く）[[law:primary:r4-law-shokuhyo-qa-kakou]]。
- 瓶詰めして並べて売る、通販で送るなら、名称・原材料・内容量・期限・保存方法・製造者などの表示が要る。期限は、傷みやすい物は消費期限、比較的傷みにくい物は賞味期限 [[law:primary:r4-law-shokuhyo-qa-kakou]]。
- 通販でも容器包装への表示が必要。基準に合わない表示の食品を売った販売者にも責任が及ぶことがある [[law:primary:r4-law-shokuhyo-qa-kakou]]。
- 食品表示法そのものの条文（違反時の指示・命令・罰則）【要確認：e-Gov 未取得】。
- 通販の広告には特定商取引法の表示義務（価格・送料・支払時期・引渡時期・返品の可否など、11条）【要確認：消費者庁の特定商取引法ガイドがメンテナンス中で未取得】。

**ゲームでの出し方**：屋台→瓶詰め→通販と広げるたびに「表示のラベルを作る」コストと手間が増える。賞味期限の設定を根拠なく長くすると、事故時に責任を問われる。

### J. 接待・贈答と広告宣伝費（税の概要だけ）

- 不特定多数への宣伝（チラシ・試供品・抽選の景品）は広告宣伝費。特定の取引先の接待・贈答は交際費。区分の通達（措置法通達61の4(1)-9）は【要確認】。
- 交際費は税の計算で全額が費用にならない。資本金1億円以下の法人は年800万円までの定額控除か接待飲食費の50%を選べる。1人10,000円以下の飲食費は交際費から除ける。適用は2027年3月31日までに始まる事業年度 [[law:primary:nta-5265]] [[law:primary:egov-sotoku-ho]]。
- 簿記2級の仕訳では「交際費」の勘定を使う。税の調整（申告調整）は2級では税効果の対象外の扱い（交際費の損金不算入は永久差異）。

## 3. コスト・投資の側

### K. 食品の衛生・廃棄・事故時の回収

**守る決まり**
- 2018年改正の食品衛生法が**2021年6月1日に完全施行**。原則すべての食品等事業者にHACCPに沿った衛生管理（計画を作り、実施を記録し保管）[[law:primary:r4-law-mhlw-shokueihou-kaisei]]。
- **小規模な営業者等**（自家製品を併設の店で売る製造者、飲食店・喫茶店など調理する営業者、包装済み食品だけを扱う店、量り売り・小分け、食品を扱う従事者50人未満の事業場）は、業界団体が作り厚労省が確認した**手引書**に沿った簡略版でよい。手引書で危害要因を理解→衛生管理計画→従業員に周知→記録→保存→見直し、の6つをすれば、食品衛生法51条2項の基準を守っているとみなされる [[law:primary:r4-law-mhlw-haccp-kangae]]。
- 営業許可（保健所）：業種が見直され、許可の要らない業種には営業届出が新設 [[law:primary:r4-law-mhlw-shokueihou-kaisei]]。営業許可の条文（55条）は [[law:primary:egov-shokuhin-eisei]]。
- **自主回収（リコール）の届出**：違反の食品等を回収するとき、回収に着手したことと状況を都道府県知事に届け出る（58条）。届出は一覧で公表される [[law:primary:egov-shokuhin-eisei]] [[law:primary:r4-law-mhlw-shokueihou-kaisei]]。

**破ったとき**：保健所の指導、営業停止などの行政処分【要確認：条文】。食中毒が出れば営業停止と報道、売上の急減。回収の届出は公表されるので信用に響く。

**会計処理**
```
（期限切れのレモンシロップを廃棄した。決算の棚卸で）
商品廃棄損（または棚卸減耗損）  8,000 ／ 繰越商品 8,000
（瓶詰め商品を回収し、客に返金した）
売上（返品）  30,000 ／ 現金 30,000         ← 返金は売上の取消し
（回収の告知・送料などの費用）
雑損失（または特別損失） 50,000 ／ 未払金 50,000
```
- 「商品廃棄損」は2級の決まった札ではないので、ゲームでは棚卸減耗損との違い（数が減った原因が分かっているか）を説明に使う程度にする【要確認：2級での科目の扱い】。
- 衛生管理の記録は手間（人件費）として出す。

**ゲームでの出し方**
- 正しく：毎日の記録（冷蔵庫の温度・手洗い・清掃）を付ける＝毎月の手間。事故が起きても「記録がある」ので説明でき、回収の範囲を絞れる。
- うっかり：忙しくて記録を飛ばす→事故→原因が分からず全部回収→大きな損と信用の傷。
- 廃棄を減らす打ち手：閉店前のタイムサービス（§B）。値下げで廃棄損が売上に変わる、という比較。

### L. 仕入先の品質不良（契約不適合）

**守る決まり**
- 民法（2020年4月1日施行の改正）：届いた物が種類・品質・数量で契約の内容に合わない（**契約不適合**）とき、買主は ①修理・代わりの物・不足分の請求（追完請求）②代金減額 ③解除 ④損害賠償 ができる（新562〜564条）。使えるかは帰責事由で変わる：買主のせいならどれもできない／双方とも責任なしなら損害賠償以外はできる／売主のせいなら全部できる [[law:primary:r4-law-moj-saiken-leaflet]] [[law:primary:r4-law-moj-kashi-minaoshi]]。
- 権利を守るには、不適合を**知ってから1年以内に売主に通知**（新566条。通知は不適合の種類とおおよその範囲でよい）[[law:primary:r4-law-moj-kashi-minaoshi]]。
- 請負など売買以外の有償契約にも、性質に反しない限り同じルール [[law:primary:r4-law-moj-saiken-leaflet]]。
- **会社どうしの売買（商人間）**：受け取ったら遅滞なく検査し、不適合を見つけたら直ちに通知しないと権利を失う。すぐに分からない不適合でも6か月以内に見つけて通知する（商法526条）【要確認：e-Gov がメンテナンス中で条文未確認】。ゲームの画面に条番号を出すのは、条文を確かめてから。
- 民法の条文そのもの（562〜566条）も e-Gov で未確認。法務省の資料で中身は確かめたが、画面に条番号を出すのは条文を取ってから【要確認】。

**破ったとき（買主として権利を失う側）**：検査しないで使ってしまう／通知が遅れる→返品も値引きも求められず、損をかぶる。

**会計処理**（三分法・税抜）
```
（不良品を返品した＝仕入戻し）
買掛金 11,000 ／ 仕入       10,000
                 仮払消費税  1,000
（使える分は残し、代金を減らしてもらった＝仕入値引）
買掛金  5,500 ／ 仕入        5,000
                 仮払消費税    500
（不良品のせいで売れなくなった商品の損害の賠償を受けることが決まった）
未収入金 20,000 ／ 雑益（受取損害賠償金） 20,000   ←【要確認：勘定科目名】
```

**ゲームでの出し方**
- 届いたレモンの箱を開けて検査する手間をかけるか（毎回少しの人件費）。検査しないと、不良が見つかったときにはもう遅い（商法526条の考え方。条文は【要確認】）。
- 不良が見つかったとき：交換（追完）・値引き（代金減額）・解約（解除）を選ぶ。値引きは仕入値引の仕訳、返品は仕入戻しの仕訳に直結する。
- 仕入先を変える判断（安いが不良が多い仕入先）と、表示（§A）のずれの事故につなげられる。

### M. 設備投資（工場・店舗の新設、機械の購入、修繕、除却、補助金）

#### M-1 建設工事の請負契約・工期の遅れ

**守る決まり**
- 建設業法19条1項：請負契約は**着工前に書面**（電子契約も可）で交わし、工事内容・代金・着工と完成の時期・前払いの定め・設計変更や中止のときの扱い・天災時の負担・物価変動・検査と引渡し・支払時期・契約不適合の責任・**遅延の違約金**・紛争解決などを書く。工事内容を「○○工事一式」とあいまいにしない [[web:bizmgmt:r4-law-mlit-hacchusha-gl]]。
- 工期や追加工事の変更も、原則として変更の工事の前に書面で（19条2項）。受注者に一方的に負担させると、不当に低い請負代金の禁止（19条の3）に触れるおそれ。遅延の違約金は過大にしない [[web:bizmgmt:r4-law-mlit-hacchusha-gl]]。
- 読んだガイドラインは2011年版で、その後の改正で記載事項は増えている【要確認：現行の項目と条文】。
- 引き渡された建物の不具合は請負の契約不適合（§L のルールが請負にも使われる）[[law:primary:r4-law-moj-saiken-leaflet]]。
- 紛争は建設工事紛争審査会（あっせん・調停・仲裁）[[web:bizmgmt:r4-law-mlit-hacchusha-gl]]。

**会計処理**（建設仮勘定 [[kentei:kubun2027:2027kubunhyo_fixed]]）
```
（工場の建設を頼み、着手金を払った）
建設仮勘定 10,000,000 ／ 当座預金 10,000,000
（中間金）
建設仮勘定 10,000,000 ／ 当座預金 10,000,000
（完成・引渡し。残金を払い、登記費用も払った）
建物       30,500,000 ／ 建設仮勘定 20,000,000
                         当座預金   10,500,000   ← 登記などの付随費用も取得価額に入れる
```
- 減価償却は**使い始めてから**。建設仮勘定のうちは減価償却しない。
- 工期が遅れ、契約の違約金を受け取ったときの処理（収益にするか、取得価額から引くか）【要確認】。ゲームでは「契約書に違約金を書いていなかったので、遅れても何ももらえない」という分岐の方が教えやすい。
- 遅れの返り：工場が動き出すのが遅れ、その間の売上を失う（機会損失は帳簿に出ないことを示す）。

#### M-2 固定資産の取得価額・資本的支出と修繕費

- 取得価額＝購入代価＋付随費用（運送・据付・試運転・登記など）。
- 修理の支出のうち、価値を高めたり使える期間を延ばしたりする部分は**資本的支出**（固定資産に加える）、元の状態に戻す部分は**修繕費**。税の形式基準：20万円未満またはおおむね3年以内の周期なら修繕費、60万円未満または前期末の取得価額のおおむね10%以下なら修繕費、区分が明らかでなければ30%と前期末取得価額の10%の少ない方を修繕費とする特例 [[law:primary:nta-tsutatsu-7-8]]。
```
（店の改装に600万円。うち400万円は用途を変える改装（資本的支出）、200万円は元に戻す修理）
建物     4,000,000 ／ 当座預金 6,000,000
修繕費   2,000,000
```

（古い冷蔵庫（取得価額300,000円、減価償却累計額270,000円）を捨てた。売れる見込みなし）

#### M-4 補助金（交付決定・返還・圧縮記帳）

**守る決まり**：補助金等に係る予算の執行の適正化に関する法律（昭和30年法律第179号）[[law:primary:r4-law-hojokin-tekiseika]]
- 申請（5条）→審査して**交付決定**（6条）。交付決定には、内容を変える・中止するには承認が要る、予定どおり終わらなければ報告、などの条件が付く（7条）。完了したら実績報告（14条）→額の確定（15条）。
- 他の用途に使う・条件に違反すると、交付決定を取り消せる（17条）。取り消した分は期限を決めて返還を命じる（18条）。返還には、受け取った日から納付の日までの日数に応じて**年10.95%の加算金**、期限に遅れれば年10.95%の延滞金（19条）。国税滞納処分の例で取り立てられる（21条）。
- 補助金で買った・価値が上がった財産は、承認なしに目的の外で使う・売る・貸す・担保にすることはできない（22条）。
- 不正の手段で受け取れば5年以下の拘禁刑か100万円以下の罰金（29条）。
- 中小企業向けの補助金（ものづくり補助金など）は、国の補助金を事務局経由で出す形が多く、実際の条件（交付決定の前に発注した経費は対象外、財産を処分できない期間など）は各補助金の交付規程・公募要領に書かれる【要確認：個別の補助金の資料を取る】。

**会計処理**（圧縮記帳は直接控除方式に限る [[kentei:kubun2027:2027kubunhyo_fixed]] [[kentei:kouhyou2:146]] [[kentei:kouhyou2:153]]）
```
（補助金2,000,000円を受け取った）
普通預金   2,000,000 ／ 国庫補助金受贈益 2,000,000
（補助金を使って機械6,000,000円を買った）
機械装置   6,000,000 ／ 当座預金 6,000,000
（直接控除方式で圧縮記帳した）
固定資産圧縮損 2,000,000 ／ 機械装置 2,000,000   ← 以後の減価償却は4,000,000円をもとに
```
- 返還を命じられたとき（勘定科目は2級の札にない）：
```
補助金返還損（特別損失） 2,000,000 ／ 未払金 2,219,000   ←【要確認：科目名と、加算金の扱い】
支払利息（加算金）         219,000
```
- 加算金は年10.95%で日数に応じて計算（上の219,000円は、1年分の目安。365日あたりの割合 [[law:primary:r4-law-hojokin-tekiseika]]）。

**ゲームでの出し方**
- うっかり1：交付決定の通知が来る前に、社長が機械を発注してしまう→その経費は補助の対象外（交付規程による【要確認】）。
- うっかり2：補助金で買った機械を、承認を受けずに数年後に売る→交付決定の一部取消・返還＋年10.95%の加算金。
- 正しく：圧縮記帳で、補助金の分だけ減価償却が小さくなり、利益の出方（税）がならされる。「補助金をもらった年に税金が一度に増えない」しくみとして見せる。

### N. 保険金の受取り（火災・事故）

**会計処理**（未決算・保険差益 [[kentei:kubun2027:2027kubunhyo_fixed]] [[kentei:sample2:q3-s3]]）
```
（倉庫（取得価額5,000,000円、減価償却累計額2,000,000円）が火災で焼けた。保険をかけている）
建物減価償却累計額 2,000,000 ／ 建物 5,000,000
未決算             3,000,000
（保険金3,500,000円の支払いが決まった）
未収入金 3,500,000 ／ 未決算   3,000,000
                     保険差益   500,000
（保険金が2,400,000円に決まった場合）
未収入金 2,400,000 ／ 未決算   3,000,000
火災損失   600,000
```
- 未決算は「保険金の額が決まるまで損か得かが分からない」状態を置いておく札。保険をかけていなければ未決算を使わず、すぐ火災損失。
- 保険差益の圧縮記帳（代わりの資産を買ったとき）は税の制度で、2級は国庫補助金の圧縮が中心【要確認：2級で保険差益の圧縮が出るか】。

**ゲームでの出し方**
- 保険に入るか（毎月の保険料＝費用）の判断と、事故の確率。入っていれば未決算→保険差益／火災損失、入っていなければ火災損失だけ。
- 「保険金が入ったら得をした」と喜ぶ社長に、保険差益は帳簿の価額（減価償却で下がった額）との差にすぎず、建て直すお金は足りない、という気づき。
