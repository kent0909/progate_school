## 3. 浅い所・楽な道・誤りの具体例

### 3.1 資料の読み違い・言い過ぎ（第2版で見つけたもの。DESIGN-RAMEN に入った先も書く）

- **A（タウンメールの条件）** 73行。500通以上はタウンプラスの条件で、タウンメールは配る町の全戸が条件。ゲームの選択肢の制約（タウンメールは町単位で丸ごと、タウンプラスは500通から）が入れ替わっている。ノートも誤り。
- **B（景観の地区の看板）** 253・304行。資料は経過措置で既存の適法な看板を続けて使える、としている。ゲームで「景観の地区に指定されたら作り直し→除却損」を出すなら、「表示を変えたとき・新しく立てるとき」に限らないと資料と逆になる。DESIGN-RAMEN の s-sale「看板の作り替え（K11）」（566行）も条件を確かめる必要がある。
- **C（炎上の影響の分母）** 40・119・239行。39%・75%・32% は「炎上を見聞きした人」だけの値で、意向の答え。全体では 23.7%・45.7%・19.8%。BIZ-CALIB K18 と DESIGN-RAMEN 271行の「客数 −5〜−20%」は「方向」としてこれを引いている。分母を取り違えたまま幅の上限を決めたおそれがある。
- **D（呼び戻し9%）** 176・228・300行。「あまり来ない客」に「催しの招待券」（2005年の1例、スーパー、分母・期間・比べる群なし）。それが BIZ-CALIB K7 で (b)（資料から筋道を立てた）とされ、DESIGN-RAMEN 205・316・318行で LINE の呼び戻し9%として使われている。業種（スーパー→ラーメン）、手段（招待券→LINE）、対象（低頻度客→休眠客）の3つが入れ替わっていて、(b) ではなく (c)（資料がなく仮に置いた）が正しい。
- **E（参照価格の25%）** 167行。25%はロイヤルティ0のときの上限で、平均は7〜20%。DESIGN-RAMEN 206行は `p_ref ← 0.75×p_ref＋0.25×…` とエリア全体の更新式にしている。上限値を全員の値にしたので、値引きの癖が強く出すぎる。
