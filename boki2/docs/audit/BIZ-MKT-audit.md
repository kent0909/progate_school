## 3. 浅い所・楽な道の具体例

1. **舞台がレモネードのまま、数字をラーメンに持ち込んだ**。29行「安い商品は1回の粗利が小さいので、ほとんどの打ち手はリピートが付かないと元が取れない」はレモネード（粗利200円）の結論。ラーメン（1杯900〜1,000円前後で粗利は数百円）なら CPA と1回の粗利の比が3倍ほど変わり、チラシや SNS 広告の採算の分かれ目が動く。DESIGN-RAMEN の flyer・snsad・influencer の重み（DESIGN-RAMEN 312〜315行）は、この比を確かめずに BIZ-MKT の重みをそのまま入れている。客層も同じ（ラーメンは男性・一人客・昼の回転が中心で、「女性に強い折込」（53行）や「女性向け商品なのにフォロワーが男性」（118行）の分岐が逆向きに働きうる）。
2. **確率の数字が「置き値」なのに設計の土台になった**。インフルエンサーの「大当たり10・そこそこ35・来ない35・偽フォロワー15・PRなし発覚30・別件炎上5・投稿されない5」（234〜240行）は全部【推測】で、資料は成功例しか載せない業者の1本だけ。DESIGN-RAMEN 315行はこれを [K9 (c)] として採り、BIZ-CALIB も「各重み±10」を付けただけで根拠は増えていない。「PRなしを頼んで発覚30%」は、発覚の経路（投稿者の告白・消費者の通報・行政の調査）を調べずに置いた数字。
3. **「公的な統計がない」で止めた**（10行・53行・64行）。業界団体の調査（DM の開封・行動の割合の調査、新聞の閲読の調査など）や、口コミの点数が売上・来店に与える効果を測った研究（海外の口コミサイトの研究には数字がある）を探した跡がない。取得拒否（366〜369行）のあと代わりを取りに行っていない。
4. **「なぜ効くか」の代わりに「〜がある」**。SNS の自前運用は「ほとんどの投稿は空振りで、ごくまれに大当たり【推測：…一般的な経験則。数字の資料は読んでいない】」（91行）。インフルエンサーの効果は「いいねの数」しかないと書き（116行）、そこで調査を止めた。
5. **「2級の範囲外」で単純化**（101行・120行）。QUALITY 2.4 違反の型。ゲームとして面白いか（海外の広告に払う税の扱いが違う、インボイスのない個人に頼むと得か損か）で判断していない。
6. **費用の空欄を「読んでいない」で残した**：SNS運用代行（88行）、看板（134行）、サンプリング（142行）、イベント出店料（150行）、フリーペーパー掲載料（158行）。後で BIZ-CALIB K20 が「各±50%」の置き値で埋めた＝調べないまま数字が決まった。
7. **組み合わせの表の半分が推測**（292・293・297・306〜308行）。特に「インフルエンサー＋在庫不足→行列→品切れ→悪い口コミ→次の打ち手が効きにくい」（292行）はゲームの面白さの中心になる鎖なのに、どの段にも資料がない。
8. **内部の検算をしていない**：259行「定価に戻した月に客が2〜3割減る」は、自分で引いた論文の「約25%反映」と値引き幅・価格弾力性を掛ければ1割未満になる（BIZ-CALIB K13 が直した）。

## 4. 足りないもの

### 問い
- 肯定側：ラーメン店の集客で、**実際に客を増やした打ち手は何で、なぜ効いたのか**（行列が行列を呼ぶ、評論家・賞の選定→雑誌・フェス→グルメサイトの点数の連鎖、限定麺の告知→「限定20食」の行列→写真の投稿、の各段の因果）。
- 否定側：打ち手が効かなかった・逆効果だった例（テレビの後に常連が離れた・キャパを超えて評判が落ちた、開店景気のあと客が引いた、インフルエンサーに払ったが来なかった、グルメサイトの有料掲載をやめたら順位・点数が落ちたと店が感じた件）。
- 効果の**分布**：当たる確率だけでなく、当たったときの大きさの幅、裾の重さ（ごく一部が桁違い）、効果が出るまでの日数と残る長さ（チラシ・Instagram・TikTok・YouTube・テレビ・ランキングで違う）。
- **打ち手の重ね合わせ**：同じ打ち手をくり返したときの逓減、異なる打ち手の相乗（知る→選ぶ→来る→並ぶ→投稿する）、打ち手どうしの食い合い。
- **頼まずに起きる露出**（評論家・YouTuber・テレビが勝手に来る、ランキングに選ばれる）と、頼む露出（案件・有料掲載）の違い。前者はプレイヤーが直接は買えず、評判を上げることで確率を上げる。
- ゲームへの写し方：最小（打ち手ごとの確率表）と大胆（町の人の注意・評判・行列・グルメサイトの点数を状態として持ち、打ち手はそこに働く。点数は算法で動き、プレイヤーには一部しか見えない）の両方。

### 資料（種類の目標に対して）
- 一次資料・統計：業界団体のDM・折込の閲読・行動の調査、総務省の動画サービス（YouTube・TikTok）の利用率、グルメサイトの運営会社の公開資料（掲載店数・有料プラン・点数の考え方の説明）。

- 実務者・業界：ラーメン店主・ラーメン評論家・グルメ誌・フェス運営の話（集客の手応え、限定麺の作り方と告知、行列の扱い、整理券）。
- 事例（成功と失敗の両方）：ラーメン賞の受賞店・ラーメン百名店の選出店のその後、テレビに出た店・有名 YouTuber に紹介された店のその後、グルメサイトの点数をめぐる争い（店とサイトの訴訟など）、ステマの措置命令の飲食の事例。
- 利用者の声：グルメサイト・地図の口コミ、X の投稿を数十件以上数えて分類（「行列を見て入った」「テレビで見た」「限定目当て」「写真を見て」「並んだのに品切れ」「動画を見て来たが期待外れ」など）。

- 反対意見：「インフルエンサーは来店につながらない」「グルメサイトの点数は当てにならない」「行列は作られる」という側の資料。

### 論点
- ラーメンの値段と粗利で CPA／LTV を計算し直す（BIZ-MKT 15〜31行の土台の作り直し）。
- グルメサイト：無料掲載と有料プランの費用、点数・順位の動き方、有料をやめたとき、口コミの荒らし・削除依頼。
- 評論家・賞・ランキング・百名店：選ばれる条件（覆面の訪問）、選ばれた後の客の増え方と長さ、行列への対応（整理券・予約・限定食数）。
- 限定麺：告知の手段（X・店頭）、食数を絞る判断、写真の映え、転売・並び代行の問題、限定が常連にどう効くか。
- コラボ：店どうしのコラボ麺、カップ麺の監修、アニメ・ゲームとのコラボ（特典の景品規制・在庫・炎上の型（シエンプレの「コラボ特典の持ち出し」のノートにある））。
- メディア出演：テレビの取材依頼（無料）と有料のパブリシティの違い、放送の後の何日・何週で客が戻るか、キャパを超えたときの評判の下がり方。
- 動画：YouTube（長尺・検索で長く残る）・Shorts・TikTok・Instagram リールの違い、ラーメン系の動画の作り手の型（食レポ・大食い・店主インタビュー）、撮影の可否と営業への影響。
- 写真映え：ラーメンでは何が映えるのか（盛り・色・器・湯気・店の外観）、店内撮影の禁止との両立。
- 行列そのものを打ち手として見る：行列が客を呼ぶ／待ちが評判を下げる、近所への迷惑と苦情、行列の整理の人件費。
- 費用の空欄（運用代行・看板・出店料・掲載料・サンプリング）を資料で埋める。
- 「範囲外」で単純化した2点（国外事業者の広告の消費税、インボイスのない相手）を、面白さの観点で入れるか外すかを決め直す（外すならオーナーの決定を書く）。
