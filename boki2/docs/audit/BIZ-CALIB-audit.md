## 1. 判定

**アウト**（調べ直し）。一行の理由：**平均値しか拾っておらず、読んだ表に載っていた標準偏差（成功と失敗の幅）を捨てている。そのうえ、シムの面白さを決める数字（需要・ライバル・集客の効果・家賃・立ち上がり・工場）の大半は (c)（資料なしの仮の値）のままで、問いが「前の報告の【要確認】を埋める」から一歩も出ていない。**

書き直しではなく調べ直しを頼む。(a) の行のうち、費用の構造（M17・M18・M22・M25・M26・M28・M29）、補助金（M60〜M63）、火災（M57）、廃業率（R12）、法令（L1〜L17）は資料と照らして正しく、残してよい。足りないのは「分布」「ライバルと市場の構造」「拡大の道の経済」の3つの種類の数字。

## 3. 浅い所・楽な道の具体例

**(1) 標準偏差を捨てた（いちばん重い）**
公庫の表 08a の中華料理店（109社）は、平均・黒字企業平均・中央値に加えて **上方信頼限界・下方信頼限界・標準偏差** の列を持つ。08c（規模別）は **平均と標準偏差** の組で並ぶ。ノート 08c は `read: full`。それなのに報告にもノートにも標準偏差が一つも出ない。手元で確かめた値：

| 中華料理店 | 平均 | 標準偏差 |
|---|---|---|
| 営業利益率（全体109社） | −1.0% | **7.6** |
| 営業利益率（1〜4人25社） | −3.6% | **12.6** |
| 営業利益率（5〜9人／10〜19人／20人以上） | −0.1／−0.7／+0.4% | **6.2／4.3／3.1** |
| 損益分岐点比率（1〜4人） | 106.5% | **19.9** |
| 3.3㎡あたり年売上（1〜4人） | 198万円 | **201万円**（平均と同じ大きさ） |
| 1社の店の面積（1〜4人） | 58.6㎡ | 32.5 |
| 人件費率（1〜4人） | 34.8% | 13.2 |
| 自己資本比率（全体） | −24.2% | 107.5 |

ここから言えること（報告が言わなかったこと）：
- **小さな店ほど「当たり外れ」が大きい**。1〜4人の店の営業利益率の幅（標準偏差12.6）は20人以上の店（3.1）の4倍。平均の改善（−3.6→+0.4%）よりも、**ばらつきが縮むこと**が規模の利点の本体。これは「店を増やすと経営が安定する」というシムの手ごたえの、そのままの根拠になる。
- **売上の差が利益の差の源**。3.3㎡あたり売上の標準偏差が平均と同じ大きさ＝同じ広さの店でも売上が数倍違う。費用の比率の幅（原価率の標準偏差 6.7）より売上の幅のほうがずっと大きい。シムで「何が店の成否を分けるか」の重みづけ（需要側の変数を厚く）の根拠。
- **DESIGN-RAMEN の「上手な店で営業利益 ≒ +10%」**（DESIGN 68行、[試算]）は、1〜4人の店の平均から標準偏差1つ上（−3.6+12.6≒+9%）にほぼ当たる。つまり「上位の約15%の店」と言える根拠が手元にあったのに、DESIGN は根拠なしで置き、BIZ-CALIB は渡さなかった。同じ表から「下の15%は −16% 前後」という失敗側の幅も出る。

**(2) 平均の積で「1日110杯」を作り、別の資料と突き合わせていない**（65行・209行）
平均の面積 × 平均の3.3㎡あたり売上は、店ごとの売上の平均と一致しない（両方とも幅が大きい）。さらに「客単価1,000円」で割って「杯数」にしており、客数と杯数を混ぜている（M23 64行は客単価にトッピング・ギョウザを含むと書いている）。2014年の厚労省の調査（84.7人／日・客単価885.8円）とは月商で約1.5倍違うが、触れていない。DESIGN-RAMEN はこの110杯を需要の式の較正点にしている（196行）。

**(3) 手元の資料にあった分布を拾っていない**
BIZ-CALIB が引いたノートの中に、分布の数字が既にあった：
- `r4-ramen-tdb-tosan2024`：ラーメン店の2023年度の業績は赤字33.8%・減益27.7%・増益37.3%。
- `r4-ramen-tdb-market25fy`：2025年度は増収38.8%・横ばい47.2%・減収14.0%、増益38.5%・減益34.8%。上位50社で6,305店（チェーンの店数＝市場の構造）。価格は500円前後・1,000円前後・1,500円以上の三極。
- `r4-ramen-jfc-kaigyo2025full`：開業1年以内の月商は100万円未満39.5%・100万〜500万円44.2%、予想月商の達成は約6割、黒字基調67%。開業費用は平均975万円・中央値600万円。
- `r4-ramen-tsr-2024`：倒産の業歴10年未満が59.4%、従業員5人未満が85.9%。
- `r4-mgmt-jfc-panel2016`：生き残った企業で黒字基調の割合 55.4%（1年目）→72.5%（2年目）→78%台（3年目以降）。

これらは「1年目の結果の分かれ方」「市場のどれだけがチェーンか」「ライバルの型（価格帯）」「倒れる店の顔ぶれ」にそのまま使えるのに、M65（121行）で「約6割」を方向として使った以外は表に入っていない。

**(4) ライバルの数字がほぼゼロ**
ライバルに関わる行は M13（49行、競合出店で −10%、(c)、資料なし）と K15（153行、値引き合戦15%、(c)）だけ。市場の構造（チェーンと個人店の割合、毎年の新規の店・閉店の数、商圏の店の密度）、ライバルの型ごとの損益、競合出店の効果を測った研究、のどれも探していない。DESIGN-RAMEN 419行は「損益は BIZ-CALIB の比率（安売り型：原価38%・人件費30%、こだわり型：原価40%・人件費35%…）」と書くが、**この比率は BIZ-CALIB のどこにもない**（引用の取り違え。BIZ-CALIB が渡さなかったので設計者が埋めた）。DESIGN 975行も M13 を「要確認」に戻している。

**(5) 費用の「変動」が1年分の点**
「コストの変動」（オーナーの要望）に要るのは、豚肉・小麦・油・電気・ガスの値段が**年ごとにどれだけ上下したか**の時系列。報告は2025年の消費者物価（+4.0%、食料+6.8%）の一点だけ（64・80行）。2022年と2026年の光熱費の急上昇（`r4-ramen-tsr-2026h1`）の大きさも数字にしていない。家賃（M9 45行）は (c) のままで、立地ごとの賃料（坪単価）の資料を一本も探していない。立地はシムの最初の大きな分岐なのに。

**(6) 拡大の道の数字が (c) か空白**
DESIGN-RAMEN の4本の道（多店舗・工場と卸・FC・通販）のうち：工場の製造原価（R14 220行 (c)、有報を読まず）、工場の稼働率（M65 121行 (c)）、FC 本部の加盟店の増え方・解約（なし。R5 は加盟条件の相場だけで、それも業者の比較記事1本・二郎系に偏る）、事業の買収の値段（M46 92行 (c)、DESIGN f.2 は「営業利益の2〜3年分【推測】」）、2号店の売上の食い合い（なし）。**DESIGN の 1億 の到達年数（18・40行、8〜10年）はこの (c) の上に立っている。**

**(7) 「仮の値で十分」という言い切り**（135行）
集客の効果を「(c) が多いが、ゲームの核には仮の値で十分」と言い切って、K1〜K20 の17行を (c) にした。チラシ・SNS 広告・インフルエンサーの反応率には、公的な統計はなくても、研究（広告の効果の実証）、プラットフォームの公開資料、業者の調査を複数つき合わせる道がある。「公的な統計がない」を理由に探すのをやめている。

**(8) 確率の重みの大半を「そのまま ±15」で残した**（79〜96行、240行）
M36・M38・M45〜M49 の8本は「資料なし。そのまま。各重み ±15」。重みの根拠を探す代わりに、幅を書くことで (c) を正当化している。±15 の幅が (a)(b) と矛盾しないという240行の主張も確かめていない。

## 4. 足りないもの

### 問い（立てていなかった問い）
1. 肯定側：**上手なラーメン店は、平均の店と何が・どれだけ違うか**（売上の差か費用の差か、立地か味か回転か）。上位の店の数字はどれくらいか。
2. 否定側：**失敗する店はどんな数字の形をしているか**（1年目の月商、赤字の続く月数、借入の大きさ）。倒れるまでの道筋の典型。
3. 分布：各数字の**平均だけでなく、ばらつき（標準偏差・四分位・上位と下位）**。
4. ライバルと市場：商圏にラーメン店は何軒あり、毎年何軒開いて何軒閉じ、チェーンと個人店はどう分かれ、近くに出店されると何%減るか。
5. 時系列：原材料・光熱・賃金・家賃・金利が年ごとにどう動いたか（上がる年と下がる年の幅）。
6. 拡大：2号店・工場・FC・通販・事業の買収の、投資額と成否の分布。
7. ゴール：現実のラーメン会社で「10年でネットキャッシュ1億」はどれくらいの珍しさか（上場チェーンの来歴、上位50社の規模）。

### 資料（種類）
- 一次統計：公庫の表の**標準偏差の列**（手元にある）、公庫の新規開業パネル・新規開業実態調査の分布の表、経済センサス（店数・開業・廃業）、e-Stat の小売物価統計・企業物価（豚肉・小麦粉・ガス・電気の月次）、公庫の基準金利の推移、法人税の税率（中小法人の軽減税率）。
- 有報・決算説明（実務の数字）：ギフトHD・幸楽苑・山岡家・ハイデイ日高・力の源などの**製造原価明細書・店舗数の推移・新店と既存店の売上・閉店数・FC 店の増減**。工場と拡大の道の数字はここにある。
- 研究：競合出店の効果（飲食店の参入と既存店の売上の実証）、口コミ・メディア露出の効果（Luca 以外）、価格の弾力性の店単位の推定。
- 事例（成功と失敗の両方）：倒産の事例記事（TSR・TDB の個別事例）、多店舗化に失敗・成功した会社の数字。
- 実務者：店舗の賃料の相場（立地別の坪単価）、居抜き物件の開業費用、開業支援・FC 本部の公開資料（JFA は401だったので代わりの資料）。
- 反対意見：公庫の表（法人・融資先のみ）に対する、個人事業主を含む調査（厚労省の生活衛生関係営業経営実態調査の新しい年など）。
