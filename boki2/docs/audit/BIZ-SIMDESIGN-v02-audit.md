## 1. 判定

**要補強（重い）。** 次の版で7章の必須の項目が直っていなければ、アウトとする。

理由（一行）：語句206件が全部原文にあり、71本の大半の主張は原文どおりで、受け入れの基準1〜9は数の上では満たしている。しかし、**この版の看板の結論（要点2・3、4.2、捨てた案、推し）を支える検算が、都合のよい1点の置き値と探索の上限でできている**。加えて、手元の原文の中に結論を変える材料がある所（RCT の店の値段は気温で動く、Markstrat の理想点は「徐々に・規則的に」しか動かない、Juul の「分岐する物語は遊び直しの価値が低い」）を落としている。

重いと判断した4点：

1. **「d.2 は最適が1,000円に貼りつく」（要点2・195行・414行）は ε=1.25 の1点だけの結果**。d.2 自身の係数の幅（DESIGN-RAMEN 223行、本報告368行の「ε の基準1.0〜1.5」）の下端 ε=1.0 では、最適はライバル0〜3軒で 1,220／1,150／1,100／1,060円と動く。さらに d.2 の常連 L（天気に半分・弾力性に半分）を入れると、ε=1.25 でも天気で最適が動く（L=1,000で 1,060／1,030／1,010円）。スクリプトは L=0 で d.2 を表し、その省略を書いていない（3.3 の C1・C3）。
2. **「折れ目を外すと値上げがいつまでも得＝式として誤り」（415行）は ε=1.25・1.5 では誤り**。探索を3,000円まで広げると最適は 1,780〜2,080円（ε=1.25）、1,050〜1,200円（ε=1.5）で有限。上限1,500円に張り付いたのは探索の範囲のせい（C2）。
3. **M2 の「9組中9組で最適が動く」（要点3・198行）は、動いたかどうかを数えただけ**。1円刻みで解くと動き幅は3〜33円、天気を無視して「ふつう」の最適値段のまま売ったときの利益の損は 0.002〜0.04%。同じ報告が引く Pecorella の原文の基準（技術的に最適でも、効きを感じられなければ考える価値がない）で、判断にならない動きである（C4）。推し（4.3「最適が状況で動く性質を検算で確かめられた唯一の案」）の根拠が崩れる。
4. **B1 を捨てた理由「崖に貼りつき天気で動かない」（199・417行）は、自分の模型で支えられない**。10円刻みにすると天気で動き（ふつう・3軒で590円、雨・3軒で640円）、崖（予算×1.3）を外しても最適は620〜720円で崖の位置（中央値で約1,170円）と無関係。しかも B1 の手本の RCT は、手元の Guest.cpp で**店の品の価値を気温で変え、断りを確率のなだらかな形にしている**（3.1 の E6）。論証の表の「崖の位置が動く形は未検算」は、手元の原文がすでに実装している形を拾っていない。

アウトにしない理由：QUALITY 3章のアウトの目安（1種類中心・羅列・延長だけ・範囲外で落とす・反証なし）には当たらない。資料は71本で最多の種類が38%、反証と限界の章もある。直しの大半は手元の原文と、スクリプトの引数を広げることで足りる。
