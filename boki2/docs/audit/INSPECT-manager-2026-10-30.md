【確かめた】同じ会社負担率を両候補へ使ったまま、一方が他方より常に劣る許容例がある。下の差は「育成−経験者」で、非雇用に勝つ意味ではない。便益vと機会損失Lの区間の4隅で線形の差の符号を確認した。

## 6：捨てた案と理由を全行検査

| 捨てた案 | 判定 |
|---|---|
| 【確かめた】N店で必ず採用 | **棄却理由は不当**。雇用が必須でも、N店に増やす時期、誰を雇うか、資金繰りには判断が残り、固定費を計算する意味も残る。任意採用を採ることと、必須採用には学習価値がないとすることは別 |
| 【問い】雇うだけで全店売上を一律に上げる | 「役割を介さない倍率では学びが薄い」は検討できる。しかし二重計上は、既存の効果と同じ効果を重ねる場合の問題で、一律倍率という形だけから必然ではない。現在の式のどれと重複するかを条件にする |
| 【確かめた】既存アルバイトへ自動加算 | この最小案では店長の役割を委任と定め、生産能力の上乗せと分けている。この定義の下で重複を防ぐ理由は妥当。現場作業もする店長という別の役割まで常に不正確だとは一般化しない |
| 【確かめた】同額・同能力の候補 | **「いつ」の選択まで消えるという理由は不当**。候補間の違いは消えても、雇う／待つ、時期、配属先、教育費を払うかの判断は残りうる |
| 【確かめた】無予告の離職・翌月無料交代 | 引継ぎと支払を消さず、見通しを与える方針は筋が通る。離職の予告・確率・交代費をまだ設計していないため、実際の楽しさの確認とは分ける |
| 【確かめた】給与・福利費・預り金の同時初出 | 3つとも未習なら、1画面2科目に反するため学習効果の理由は妥当。既習の給与を含むすべての画面を禁止する話ではない |
| 【確かめた】仮の率を一律の法定率として表示 | 仮の会社負担率を制度の事実として表示しないという正しさの理由は妥当 |

【確かめた】7行とも4分類の名前は使うが、分類の意味まで適合するとは言えない。QUALITY 2.4で「正しさ」は会計・法令を指すため、売上倍率の因果の弱さだけでは該当しない。人件費の二重計上なら会計上の問題になる。PEDAGOGY 7は学習設計の規則で、robots.txt・利用規約と同じ「規約」の根拠にはしない。3科目同時初出は学習効果を理由にすれば足りる。分類名が合うことと推論の正しさも分ける。とくにオーナーの「ある程度の店舗数」を具体化する際、必須採用の案を誤った理由で先に除かないことを求める。
