## うまくいく理由（B が正しく言えている所とその理由）

1. **コードの行の大半が主張を支える**：131か所の引用はすべて実在の行で（B の count-rows も私の refs も同じ131）、79行中71行で程度・いつ開く・欄の中身が原文と合う。理由：B は程度を付ける前に「押したら口座が動くか」を probe で、札は月報に返るかを出力で確かめると決め、それを守った（1章の前書き）。
2. **打ち手の数が再現でき、数え直しても合う**：4周の走らせ直しが完全一致し、自分の定義で数えた P1〜P5・2.0・2号店の48か月がほぼ同じ数になった。理由：B は seed だけの v4 保存と Math.random の固定、localhost 以外の拒否という既存の初期化をそのまま使い、生の出力（画面ごとの記録と最終の状態）を全部残した。

4. **打ち手の限界を自分で書いている**：反証と限界の1行目で「2号店を出さない・配当を配らない・増資は最大・赤字の2号店を閉めるは打ち手の規則から来る面が大きい」と書き、2号店を出させた6周を別に通した。4章の分類で「頼る」とした結論の多くに B 自身が【推論】か限界の注を付けている。
5. **短期借入が画面にない、の指摘は正しく、写真でさらに強まる**：倒産の結末が「借りる手を打つ」を正解に出す（S322）のに、その手は押せない。

## うまくいかない理由（誤り・弱さの所とその原因）

1. **生の出力に書いてあることを、コードの1行で否定した**（R5・2.6 の「店ごとの数を出す画面がない」）：原因は、world.js:255 の `res.stores` を ui.js・ramen-view.js で探すときに、`r.stores`（月報の中での変数名）を探さなかったこと。B の出力 `out/skilled-site2-*.json.gz` の月報の文を読めば「店ごとの営業」の表が20か月出ていた。
2. **画面の試算と、打ち手が記録した数を取り違えた**（2.2・R2・うまくいかない理由2・論証の表5行目）：原因は、`run-full.js` が判断の画面で `D.decide.trial` の cashMin/cashMax を記録し、それを「画面の試算」と読んだこと。2年目からの札は自分の `c.trial` を持つ（cards-y2.js:186）。論証の表で B は「画面の試算は札の money と同じ数を出す（ramen.js:86 の trial）」を暗黙の前提に書いており、ramen.js:86 は1年目の札の試算で、2年目からの札には当たらない。前提を書いたのに確かめなかった。
3. **写真を開かずに S 番号を付けた**：80か所中、開いたと書いたのは7枚。INDEX.md の種類の対応表で「choice・card・作戦の机・月の途中の出来事」がすべて S025 なので、札・制度・看板・社長の車・外の機会の写真として S025 を引き、写真には物件選びしか写っていない（違う7か所のうち5か所）。依頼書（BRIEF-CINC-REBUILD）の手抜きの予想「写真集の S 番号を見ずにコードだけで書く」を、番号は付けたが見なかった形で避け切れていない。
4. **「8か月で閉めた」打ち手の結果を「2号店は会社を縮める」に広げた**：2号店の赤字の48か月は全部が開店から8か月以内。8か月目以降は測っていないのに、「伸びる道が見えず」と書いた。原因は、2号店の中の手（赤字の札の改装・一杯の変更・粘る）を通す周を作らなかったこと（やっていないことには「改装・一杯を変えるを選んだ周はない」と書いてある）。
5. **中央値と「手もとに残るお金」の定義を書いていない**：偶数個の下側の値と、ゲームの中の計算（帯の値ではない）を「中央値」「上の帯と同じ」と書いた。結論の向きは変わらないが、上手の口座の伸び・1億までの割合が小さめに出る。

## 反証と限界

- **この判定も人の遊びではない**：2号店の黒字の道は、乱数なし・札なしの式（4.1）と、打ち手に choose で手を渡した通し（7章）で確かめた。人が実際に粘る・改装を選ぶか、その判断が楽しいかは見ていない。
- **式の写し方の限界**：4.1 の1号店の手は上手の打ち手そのものではない（smartPolicy ではなく、値段の年表と主な手を写した）。「1号店から1人回す」の行は私の1号店の手のせいで実際より悪い。式の方が実際の通しより赤字が小さい（札と週の揺れがない）。黒字の道の大きさ（+5.7万・+9.1万）はその分大きめに出ている可能性がある【推論】。
- **probe-hands は走らせ直していない**：R4・E2・うまくいく理由1の値段の山（−50円 +6.5万、−100円 −18.5万）は B の `out/probe-hands-t14.json` の数で、私は走らせていない。
- **ライバルの閉店が要因に出ない理由**は確かめていない（B と同じく【推論】のまま）。
- **写真は1枚につき B が言っていることが見えるかだけを見た**。写真から読める B の言っていない事実（銀行の言う値と帯の値が違う、S089・S333）は既知の傷に書いたが、原因（帳簿と式の口座の差）は確かめていない。
