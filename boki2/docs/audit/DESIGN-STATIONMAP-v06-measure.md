- **参入したライバルは、自店と同じ市場（同じ候補地）に入れた**。設計書の「その駅の候補地の空き」に入る形（距離で効きが弱まる、駅の別の候補地のピンが埋まる）は入れていない。参入の λ は自店の候補地の λ（駅の λ ではない）。
- 「自店と同じ型」は老舗と読んだ。平均の店でない上手な店（値段・評判の違う店）では読みが変わる。
- 平均の店（850円・パート1人・宣伝なし・通し）だけ。⑥の「上手なボット」は本当の上位10 と、検査役が足した「見える情報のボット」（同じ候補地・同じ開店の前の軒数の、ほかの世界の平均。K＝6 なので5つの平均で荒い）。どちらも設計書にない。
- 営業時間は「3年間ずっと同じ時間帯」で比べた。毎月の切り替え・切り替えの月の常連の離れ +1% は入れていない。評判は昼と夜の世界で別々に動く（近似）。参入の s に使う評判は2つの世界の客数の重みの平均。
- 閉めて減る費用の「slot」（パート1人でも閉めた時間帯の給料20万が全部減る）は、**設計書の形の外**（検査役が置いた）。昼4・夜5時間の割り振りは幅のない置き値で、5・4 にした組（h11〜h17）は「幅のない値を動かした」もの。
- 探しは格子と乱数で、幅の中の置き値だけの組119・形の外か幅のない値の組10・幅の外7。幅の中を全部回したわけではない（各項3〜5点の格子と乱数40組）。とくに churn の倍率（幅が書かれていない）・型の重み・λ の表・席の上限は動かしていない。
- ⑤ は「K 個の世界の最大」で判定した（版0.5 と同じ）。K＝6 と K＝12 で最大が 14→17（g29）と動くので、⑤ の判定は K に強く依る。設計書は世界の数を決めていない。
- 赤字のくじ50%は、設計書 4.4 の R₀ の探す範囲の線で、6章の検査ではない。表に出しただけで合否に入れていない。
- 設計書の論証の表（5章）の各行の妥当・弱い・不当は付けていない（この依頼は数字の論証だけ）。事実の判定（データの照合）もしていない。
- 用途地域で店を建てられない候補地（松濤1丁目など）を外した母集団では回していない。
