## 3. 肯定側の問いへの答え（版0.7 がなぜうまくいくかを、いちばん強い形で組んでから崩す）

**組む。**
1. 版0.6 の失敗の中心は「0軒の小さい駅が勝ち、大きい駅は赤字」だった（`neither_so6.txt` の段ごとの利益：段1 +51万・段5 −150万・段6 −313万・段8 −36万）。オーナーの原文「人が多いところは複数の競合がひしめきやすい」は、大きい駅は客も多いがライバルも多い、の両方を求める。版0.7 は客の差（段の比 1:6）とライバルの差（λ×2）を**同時に**広げた。そのため、大きい駅は勝てる所になった（段8 +146万）。一方で、ライバルが多いので必ず勝つ所にはならない（⑥「大きい駅」の規則は本当の上位の 19〜35%）。0軒の所は小さい駅の住宅地に限られ、そこは客が少ない。立地の三つ（客・競合・家賃）が実際に引っぱり合う形になった。
2. 手元のデータもこの形を支える。宿泊・飲食の事業所は駅の人通りの約0.51乗で増え（68倍で8.7倍）、版0.7 の λ の段の形（段8÷段1＝8.67）とほぼ同じ（`food-by-tier.txt`）。人通りを駅のピン数で割ると段8÷段1 は約8.4倍、飲食店1つあたりの人通りは約5.2倍で、1:6 はその間にある【推論】。
3. 結果は seed を変えても週の揺れを入れても崩れない（2章：⑤ 5〜15、⑧ 50〜54%、⑨ 1.34〜1.38、① 43〜45）。参入をピンで割る弱い端でも、⑤ は12の世界のうち10が15以下（E4p）。
4. 基準の組を2軒にするのは、λ の中心が2になったことの帰結で、較正の手順（4.2）を変えない。

**崩す。**
1. 「0軒が多すぎる」は原因の説明として外れている（主張1）。λ だけでは⑤も⑨も外れ、0軒の寄り方は強まる。効いたのは段の比のほう（勝つ所の入れ替わり）。設計書の 0章の表は、効いた理由を「0軒の割合」で書いているので、遊び手が見る中身（大きい駅が勝てる所になった）と、オーナーに聞く9章9の問い（「ライバルも2倍にする」）の重みづけがずれている。
2. 組む側の2は λ の**形**を支えるが、**水準**（2倍）は支えない。事業所の数は全飲食で、ラーメン店の軒数の水準はどこにもない（設計書 245行の調べ物「まだ」）。2倍は⑤を通す値として選ばれた。
3. 組む側の3は、検査役の台本（期待値・季節や札なし）の上で、置き値を選んだのと同じ物差しで測った結果。物差しのうち3つ（⑦の線・効きの向きの測り方・常連と段の比の幅）は、版0.7 で動いている（0章）。物差しが動いた分を戻すと、⑦は線20%で外れ、効きの向きは設計書の幅で外れ、基準の組の2つ目をこだわりにすると①と赤字が外れる。
4. 「通る」ことは「面白い」ことと別。段6（東京・新橋の12本）は私の回した全部の組で利益の中央 −214〜−313万。E4 では客38人で段1（43人）より少ない。E4 の3つの seed でオフィス −165〜−172万・工場 −192〜−210万で、属性まるごと選ぶ価値がない（`out/table.md` の off・kojo 列）。遊ぶ人は「東京駅は人が多いのに客が来ない」を見る。
5. 赤字のくじは週の揺れで 54.2%。4.4 の「50%を越えない所まで」の線を越えている。

**残る結論**：版0.7 の仕組み（段の比とライバルの数を一緒に広げる）は、⑤を直す向きとして筋が通る。ただし版0.7 が書いた理由（0軒の割合・0.42乗・較正のため・測り方の誤り）は、どれもそのままでは言えない。物差しを動かさずに説明し直す必要がある。
