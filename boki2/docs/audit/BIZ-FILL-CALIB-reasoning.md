### 0.1 不当のうち重いもの

1. **「急拡大型＝借入8か月」の否定**（0章8・DEBT・論証の表）：比べた6社はすべて**上場して生き残った会社の、いちばん新しい健全な年**。同じ会社の別の時点を同じ表で取ると、幸楽苑 2021年3月末 2.85か月・2023年3月末 2.66か月（報告の2026年は0.44）、山岡家 2015年1月末 2.70か月、**急な出店（2010→2012年に店数+34%）の直後の2012年1月末は推計4.6か月**（上の端の負債総額で5.8か月）、ギフトの上場前（2016年10月）は負債総額で4.5か月が上の端（検算A）。しかも DESIGN の急拡大型は**借入で年2〜3店を出し、金利・物価の年に倒れる非上場のライバル**（DESIGN-RAMEN 411行）で、比べる相手は公庫の融資先の分布か倒産の事例。公庫の中華料理店で8か月は平均+0.36〜0.39標準偏差（平時）、衝撃の年は平均より下。報告が引く倒産の事例（BIZ-CALIB 版0.2 X4）の（有）太郎は負債3.3億円÷売上4.8億円で**8.2か月**（倒産前の売上で割った下の端）。版0.2 V6 の「8か月は上の側として範囲内」を、選ばれた母集団で覆した。言えるのは「上場の会社は今は借入が軽い。8か月は小さな会社の分布と倒産の事例の範囲にある」まで。報告の論証の表の注は「結論は『8か月の根拠は上場の実例にない』まで」と書きながら、0章・結果の表は「**否定**」のまま。
2. **FC の加盟金 R5 を (c)→(a)、「比較記事の200万円より正式な値で修正」**（0章3・FC）：DESIGN の FC は2か所あり、どちらも対象がずれる。①始め方 D「FC加盟」（DESIGN 156行）は**プレイヤーが1号店を加盟で始める入口**。有報の2本は大きな上場の本部で、幸楽苑の契約先は「㈲嶋藤商事・共和メンモンド㈱…」の**7法人**、丸源は1店の出店費用が1億8,800万円（ノート）で料率が「30店目以降」まである法人の多店舗加盟の契約。②プレイヤーが本部になる fc（350行）は小さなブランドの本部で、大手の条件は上の端。200万円は**別のブランド（堀切系）の値**で、誤りではない。点は4つ（0・200・300・500万円、検算I）で、「より正式な値で修正」ではなく「ブランドで0〜500万円に散る」が資料の言える所。報告自身が「1社・1ブランドの値は…業界の値とは書かない」「対象がずれたら (a) ではない」（12行）と決め、同じ理由で R4（席数）・V6（借入）を上げなかった（捨てた案、153行）のに、R5 だけを上げた。(c) の割合の改善（43→41）の半分はこの行。
3. **立地の型で「1店の売上が約1.8倍」→「同じ店でも立地で売上の水準が変わる」**（0章4・うまくいく理由1）：同じ表の従業者数で割ると、**従業者1人あたりの売上は 379〜466万円で1.23倍**しか違わない。1店の売上の差（log の分散 0.042）の約74%は1店の従業者の数（0.031）で、1人あたりの売上の差は約10%（0.004）（検算B）。ロードサイド型は1店10.5人、その他地区は5.9人。1.8倍は**大きな店がどこに建っているか（チェーンの郊外店）**の写しで、同じ店を移したときの効果ではない。BIZ-FILL-RAMEN の検査（K22「5倍の多くは人の数と値段」）と同じ型。オーナーの「地域で採算が変わる」に寄せる向きの水増しにもなる（5.4）。
4. **「中華料理店の事業所は増えている」と細分類の「ラーメン店+6.4%・中華料理店−14.5%」**（0章4・CENSUS）：同じ報告のスクリプトの出力で、飲食店全体（76）も 2012→2016 に **+16.0%**（391,053→453,541）。76B の伸び +11.2% はそれより小さく、76 に占める割合は 8.99%→8.62% と**下がっている**（検算B）。調査の作り（名簿の広がり）で全体が増えた可能性を、厚労省の数（減少）との逆を「定義が違う」で片づける前に、同じ表の全体と比べていない。さらに **2016年の 76B 39,084 のうち 6,339（16.2%）は細分類のどちらにも入っていない**（2012年の格付不能は994・2.8%）。残りの振り方で、ラーメン店は +6.4〜+43.8%、中華料理店は −14.5〜+22.3% と符号まで変わる（比例に振ると +27.0%・+2.0%）。報告の2つの数は、残りをどちらにも入れない読み方。
5. **猛暑の記述を M5「夏の谷を消す」への反対の事実に**（0章7・SUMMER）：力の源の原文は同じ段で「夏休み（7〜8月）及び年末年始（12〜1月）などの**繁忙期に売上高が増加**する一方、梅雨シーズンなどの閑散期には売上高が落ち込む」と書き、酷暑は「繁忙期に台風、酷暑、厳寒などの天候の悪影響が及んだ場合…減少する可能性」という**事業等のリスク**。夏は谷ではなく山と書く資料で、M5 の「夏の谷を消す」を支える向き。ギフトの2つの語句（「猛暑日などの異常気象により」「平均気温上昇により、来店頻度が減少」）は、**TCFD のシナリオ分析の表**（「対象年 2030年」「4℃シナリオ」「2100年において…平均気温上昇が想定されるシナリオ」の下の物理リスク）で、測った客の動きではない。実際に暑さで客が減った記録は手元の力の源の決算短信2026（「猛暑や残暑等の気候変動による既存店来店客数減少」）にあるのに使っていない（③）。言えるのは「夏（7〜8月）は暦で山。その中で猛暑の年は客が減った記録が1社にある」まで。
6. **うまくいかない理由3「急拡大→利益率が下がる」（ギフト）**：根拠の「売上+21%でも経常利益率11.3%→4.7%」は**コロナの2020年10月期**。同じ有報の5年で、売上が年+23.7%・+24.2%・+29.8%と伸びた2017〜2019年は経常利益率が 9.6→11.4→11.2→11.3% と**保たれている**（検算E）。急拡大の年には利益率は下がっておらず、下がったのは外の衝撃の年だけ（①向きが逆、④相関を因果に）。
7. **うまくいく理由2「規模→借入が軽い・ばらつきが小さい→衝撃に耐える」**：上場の生き残りと公庫の融資先を並べた相関で、BIZ-CALIB 版0.3 が自分で取り消した「店を増やすと安定する」（検査 Y02）を因果の鎖で戻している。規模の大きい会社も衝撃の年に借入が重くなった（幸楽苑 2.85か月・自己資本比率7.75%）。
8. **設計34・計算23を「資料で埋める種類ではない」として外した**（30行・60行・255〜256行）：57か所を付け直すと、**資料で確かめられる推論が11**（計算の中に6、設計の中に5）、うち**7は手元の資料で確かめられた**（検算G）。例：C072「人件費は人数の段で固定費に近い」は、書き手自身が取った公庫の2019→2021年度で、3.3㎡売上が0.706倍に落ちたとき人件費率が35.5→43.2% に上がった＝平均で約52%（中央値で約27%）が固定、と同じ表で確かめられる（検算D）。C077「分布の形は物価で変わりにくい」も公庫の4年度で確かめられる。C010・C011（センサスとの差の理由）は書き手が取ったセンサス3回で、C140（流れの多い所ほど家賃が高い）は立地の表とアットホームで、C145・C154（長く遊ぶ人の褒め・気づかれる前提）はリポジトリにある声の表で。設計の34のうち7は印の説明・自己申告（「【推論】の印を守った」など）で、「説明」に入れるべき行を「設計」に数えて設計の数を膨らませている。どれも書き手の手間が減る向き（⑥）。
9. **国立国会図書館・J-STAGE・CiNii を使わずに「公開の研究がない」「統計がない」**（埋まらなかったものの表・やっていないこと246行）：やっていないことは「学術の索引は M1 にしか要らなかった」と書くが、並行の担当（BIZ-FILL-RAMEN 1.1）の検索の記録 `research/searches/fill-ramen.jsonl` には、この環境で J-STAGE の検索 API と国会図書館サーチが使え、「天候 来店客数」「飲食店 廃業 要因」の検索で**経済センサスの飲食店の数の検証**の論文が出たと書いてある。センサスと厚労省の逆（0.1-4）、猛暑の量（SUMMER）、事故の頻度（EVENT）、工事の遅れ（BUILD）、分岐の重み（DEC）、値上げの係数（P2）、地方の賃料（RENT）にも索引は要る。特に BUILD は「探したもの」に「版0.2の範囲から先へ探していない」と書きながら、理由の欄は「頻度の統計がない」（未探索を「ない」と書く）。
