# Codex への依頼書：いまの画面の全数の写真集と目録（UI の参考の調べの下ごしらえ）

## 依頼の原文（オーナーの言葉。要約しない）
- 調べ全体の依頼（2026-10-30）：「簿記２級アプリのUI・UXデザインがマジで終わってるんだけど、本コンセプトに適うUI/UXデザインとしてリファレンスできるもの相当な深度まで勉強・分析・考察してくまなく探してきて。その際に障害があったら都度相談して。」

- 「Codexに手伝わせることある？」→ 取りまとめ役の推し「いまの画面の全数の写真集と目録」

## 役目
UI の参考の調べ（依頼文 `boki2/docs/BRIEF-UIREF.md`）では、参考の実例ごとに「我々のどの画面の何を変えるか」を書く。いま取りまとめ役の手元にある画面写真は、プロローグ〜開店の前の60枚だけ。**ゲームの全種類の画面を、スマホ幅と PC 幅で撮り、画面の目録を作る**のがこの仕事。調べの担当と統合の報告は、この目録の画面番号で写し方を書く。

**外部への通信はしない**（AGENTS.md）。ゲームのファイル（`boki2/js`・`boki2/css`・`*.html`）は変えない。

## 撮るもの（受け入れの基準。数で確かめる）
1. **画面の種類を全部**：少なくとも次の種類。各種類につき、スマホ（390×844、指で押す端末）と PC（1280×800）の両方で、最初に出たときの1枚以上。見つからない種類は「見つからなかった」と目録に書く（飛ばさない）
   - タイトル・ゲームの設定・セーブの枠／名前と年度を決める画面／プロローグの会話・note（ノート）・sort/tap（並べる・押す）／月の書類（docScreen）／choice・card・理由・予想・名前の札／作戦の机（値段・人・看板・問屋など）／一杯の組み立て／開店・月の途中の出来事／月報・締め・開始記入・決算／ふりかえり／上部の情報と8つのタブ（お金・町・店・帳簿・日誌・ほか…の全部を開いた画面）／町の地図・ライバル・順位／練習室・検定会場（`boki2/ramen.html` から行ける所）・成長の記録／倒産・結末
   - 時期で姿が変わる画面（上部の情報、月報、町）は、1年目の4月・9月・3月（決算）と2年目の最初の月の4時点で撮る
2. **ダークの配色**（`colorScheme: 'dark'`）でも、上の種類のうちスマホ幅で10種類以上
3. **目録** `boki2/docs/screens/INDEX.md`：1枚1行。列：番号（`S001` から）／ファイル名／幅／配色／時期（年・月）／画面の種類（上の分類）／仕訳の画面の作り直しの段（① note ② docScreen ③ sort/tap ④ 選択肢・文字・背景 ⑤ 月報・締め・開始記入。該当なしは空）／画面に見えている文字数（`innerText` の長さ）／押せる部品の数／見えている文字の大きさの種類の数（計算値の font-size の異なり）／一番小さい文字の大きさ（px）／縦に何画面ぶんか（scrollHeight ÷ 画面の高さ）
4. **数を出す道具** `boki2/tools/screens/inventory.js`：上の列を画面から機械で取る（目で数えない）。撮り直すと同じ目録ができること（seed を固定）
5. **一覧の画像**：種類ごとに並べた一覧（スマホ幅12枚ずつ）を `boki2/docs/screens/sheets/` に。jpg・品質55・1枚の幅1200px 以下
6. 画像の大きさ：全部で 40MB 以下（jpg・品質55。PC は横1280のまま、縦が長い画面は縦に全部撮ってよい）

## 手抜きの予想（先に禁じる）
- **最初の数か月だけ撮って「全部」とする**：上の種類の表を目録の先頭に置き、種類ごとに「撮った／見つからなかった（どこまで進めて探したか）」を書く
- **撮りやすい画面だけ撮る**：タブ・地図・練習室・検定会場・決算・倒産のように、自動の打ち手がふだん通らない所は、道具で押して開く（`window.__sim` への書き込みで画面を飛ばさない。人が押せる所を押す）
- **文字数・文字の大きさを目で数える**：道具で取る
- **ゲームを直してしまう**：撮っていて誤り・崩れ（はみ出し・重なり・読めない）を見つけたら、直さずに目録の「気づいたこと」の章に、番号つきで書く

## 報告（PR の本文）
- 依頼の対応表（上の原文と、撮るものの1〜6の各行に、どこでどう応えたか）
- 種類ごとの枚数（道具の出力から写す）、全体の大きさ
- 見つからなかった種類と、どこまで進めて探したか
- 気づいたこと（崩れ・読めない所）
- やっていないこと（空にしない）
- 終わる前に AGENTS.md の6つの検査を走らせ、出力の最後の行を写す（ゲームのファイルを変えていないことの確かめ）
