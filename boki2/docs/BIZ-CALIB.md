# ゲームの数字と確率の根拠の表（BIZ-CALIB）

版：0.1（2026-10-22）。書き手：調べもの担当（数字の較正）。読み手：ピヨ商店の経営の分岐・初期値を実装する人。
対象：BIZ-MGMT.md・BIZ-MKT.md・BIZ-LAW.md・BIZ-RAMEN.md（8章）に残っていた【要確認】【推測】を、1つずつ次の3つに分けた。

- **(a) 一次資料で確かめた値**：出典の札・年・範囲を書く。法令は e-Gov の現行条文。
- **(b) 資料から筋道を立てて決めた値**：使った数字と計算の筋道を書く。分母や当てはめに推測が入るときはそう書く。
- **(c) 資料がどこにもなく、ゲームの仮の値として置くもの**：置く理由と、動かしてよい幅を書く。
- ほかに **(—) 未解決**：ゲームの数字ではない（法令の通達・制度の細部）が、資料が取れず確かめられなかったもの。画面には出さない。

今回読んだ資料：35本（`r4-calib-*`。公庫の経営指標の表3本・補助金の採択結果7本・火災と食中毒と食品ロス4本・FC 2本・国交省の工期の調査1本・e-Gov の条文18本）。取得できなかったもの・読まないと決めたものは末尾の6章。
読み方の約束：確率の「重み」は合計100の分岐の重み。現実の確率そのものではなく、**同じ状態から何度も遊んだときに現実の割合に近づく**ように置く。

## 0. 要点（10行）

1. **小さなラーメン店の損益は「原価35%・人件費33〜35%・その他の経費28〜34%・営業利益はほぼ0」**（公庫の中華料理店109社、2025年度調査）[[web:bizmgmt:r4-calib-jfc-shihyou-08a]]。BIZ-MGMT の初期案（原価30%・人件費28%・営業利益18%）は甘すぎる。黒字かつ自己資本プラスの会社でも営業利益率は3.3%。
2. **1〜4人の店は面積約18坪・年売上約3,500万円・1日約110杯**【計算】。人を増やすほど赤字が減る（営業利益率 −3.6% → +0.4%）[[web:bizmgmt:r4-calib-jfc-shihyou-08c]]。
3. **パン屋は原価41%・人件費39%、喫茶は原価28%・人件費30%**（2025年度）[[web:bizmgmt:r4-calib-jfc-shihyou-07a]] [[web:bizmgmt:r4-calib-jfc-shihyou-08a]]。どれも平均の営業利益はマイナス。
4. **「1年で4割・3年で7割が廃業」は公庫の追跡調査と合わない**。2016年開業組は1年目末2.2%、飲食・宿泊でも3年で12.3%・5年で14.7%（過去の組で19〜24%）[[web:bizmgmt:r4-mgmt-jfc-panel2016]]。ゲームではうわさとしてだけ使う。
5. **補助金の採択は、大型（ものづくり・新事業進出・再構築）で「3件に1件」、持続化（販促）で「2件に1件」**（2024〜26年の各事務局の発表）[[web:bizmgmt:r4-calib-monodukuri-saitaku]] [[web:bizmgmt:r4-calib-shinshutsu-results]] [[web:bizmgmt:r4-calib-saikouchiku-result]] [[web:bizmgmt:r4-calib-onamae-jizoku17-20]]。BIZ-MGMT の「3〜4割」は大型について正しかった。
6. **飲食店の火災は1店あたり年約0.5%（中華料理店は約0.7%）、ほとんどはぼや**。原因の最多は大型ガスこんろ、その半分は放置（東京、2024年）[[web:bizmgmt:r4-calib-tfd-youto]] [[web:bizmgmt:r4-calib-tokyo-inshoku-jigyosho]]。
7. **外食の食品ロスは年66万トン、原因は仕込みすぎ約4割・食べ残し約6割** [[web:bizmgmt:r4-calib-env-foodloss-r5]] [[web:bizmgmt:r4-calib-tokyo-inshoku-jigyosho]]。
8. **アルバイトが半年以内に辞める確率は約13%**（飲食の年離職率25.1%からの換算）。BIZ-MGMT の重み30は高すぎる【計算】[[law:primary:r4-mgmt-mhlw-koyou]]。
9. **法令の【要確認】はほぼ解消**（e-Gov が復旧したので取り直した）。ただし**中小企業の少額減価償却の特例は現行「40万円未満（年300万円まで、2029年3月末まで）」で、BIZ-LAW の「30万円未満」は古い** [[law:primary:r4-calib-egov-sotoku67-5]]。国税庁（通達・タックスアンサー）は終日503で取れず。
10. **件数の内訳（後の表で数えたもの）**：全130項目のうち、作業前は (a) 0・すべて【要確認】【推測】。作業後は **(a) 36・(b) 31・(c) 52・(—) 11**。(c) の多くは、どの資料にも確率が書かれていない分岐の重みの割り振りと、集客の効果の大きさ（チラシの反応率など、公的な統計がない）。
