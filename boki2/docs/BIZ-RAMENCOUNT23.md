## 2. Q1 駅の大きさとラーメン店の数
### 2.1 数え方
- **ラーメン店の点**：OSM の飲食の点（23区の中 29,597）のうち、amenity が restaurant・fast_food・food_court で、cuisine に ramen を含むか、店名にラーメン系の語（ラーメン・らーめん・拉麺・中華そば・つけ麺・担々麺・まぜそば・油そば・家系・二郎 など）を含むもの＝1,613（cuisine で1,330・店名だけで283）（出力の冒頭）。店名だけで拾った点の抜き取り40本は、タイのラーメンを名乗る1本のほかはラーメン店。cuisine が noodle・chinese でラーメンの語のない2,354点は数えていない（取りこぼす向き）。
- **網羅**（出力§1）：23区の経済センサス2021 の76B（中華料理店＋ラーメン店）は5,821。OSM のラーメン店はその28%（1,613÷5,821）。中華料理店とラーメン店は2012年の市場でほぼ半分ずつ [[web:ramencount23:mhlw-chuka-h26-hosaku|「1兆1,629億3千万円」]] なので、ラーメン店だけに対する OSM の網羅はおよそ半分強【推論：2012年の売上の割合を2021年の店の数に当てた】。区ごとの OSM ラーメン÷76B は板橋区0.12〜千代田区0.46、都心3区0.35・外周6区0.21。OSM の飲食の点÷76 飲食店は0.29〜0.99（中央0.53）で、区の店の多さとの順位相関は0.048（店の多い区ほど拾う、という偏りは飲食全体では見えない）。ラーメンの網羅と76B の数の順位相関は0.269（弱い正）。
- **町丁・メッシュの単位の公的な数はない**：統計GIS の町丁の表は産業の大分類まで [[web:ramencount23:estat-def-T001167|「産業(大分類)別民営事業所数」]]、平成28年の町丁の表も中分類まで [[web:ramencount23:estat-files-2016-tokyo-t9|「31産業(中分類)別民営事業所数」]]。市区町村の小分類の表（9-1A）はある [[web:ramencount23:estat-search-chuka-shikuchoson|「産業(小分類)別全事業所数」]]。
- **3つの数え方を並べた**：(a) OSM の点そのもの、(b) OSM の点÷区の網羅（OSM 飲食÷C21 76）、(c) **代理**：駅の500mメッシュの宿泊・飲食サービス業の事業所数 × 区の76B÷M（宿泊・飲食サービス業の全体）。(c) はラーメン店の数ではなく、飲食全体の数を区の中華料理店の割合で割り振ったもの（ずれの向き：都心の区は76B の割合が低いので、都心の大きい駅のラーメン店を少なめに出す【推論】）。
- 駅の点は `tokyo23.js` の x・y（ゲームの駅の位置）。円は半径300m・500m・800m。

## 5. 設計書への効き
### 5.1 人通りの差（段8÷段1）：8倍か2倍か
- **資料からはどちらとも決まらない**。ラーメン店1店あたりの駅の人通りの差は約4〜5倍（7本の中央4.49・幾何平均4.81）。8倍（7.9）は7本の上の側、2倍（2.14）は下の側の外にある（最小2.71）。
- 別の確かめ（設計書の試しとの比べ、【推論】）：設計書 4.1 は、段の比7.9 で試しの sim の中の1店あたりの需要の比（段8÷段1）が約2.0〜2.1倍にとどまると書く。実際の23区の駅前の飲食店の1店の売上の比は3.55倍（出力§4.2）。**1店の売上で比べると、7.9 でも実際の差より小さい**。2.14 にすればもっと小さくなる見込み（試していない）。一方、従業者1人あたりでは1.15倍で、ゲームの店が大きさを変えられないなら、比べるべきは1.15倍のほうかもしれない（そうなら2倍の側）。**どちらの読みを採るかは「ゲームの店の大きさが変わるか」で決まり、資料では決まらない**。
- 設計書への提案（決めるのは司令塔とオーナー）：(e) の測る組に、7.9 と 2.14 に加えて**資料の中央の4.5前後**を足す。幅 5.4〜9.4 の下の端は、ラーメン店の資料では下げる向き（2.7〜11.0）。
### 5.2 λ（ライバルの数）
- **段の形**：段1〜6 は λ とほぼ同じ。段8 は λ より急（OSM 14.8倍・代理9.2倍、λ 8.7倍）。λ の段8 を2.6 から上げる向きの資料。ただし上限5軒と m の幅が効く。
- **0軒の割合**：全体の量は合う（OSM 200m 53%・設計44%）が、**大きい駅でも0軒の候補地が実際にある**（段4 37%・段5 29%・段8 16% 対 設計18%・5%・0%）。設計は段4以上で中心 c≥1 のため0軒がほぼ出ない。くじの幅（c−1・c・c+1）を広げる、または属性の倍率の開きを実際に合わせる（繁華街3.0・住宅地0.22 の向き）と、大きい駅の中の外れ（裏通り・住宅地）に0軒が出る【推論】。
- **段1 は全部 c＝0**（0.3×最大1.4＝0.42）。OSM の段1 の候補地の200m の0軒は72% で、設計の80% に近い。
### 5.3 工場の仕組み（オーナーの決定「勝てる仕組みを足す」）
- 裏づけのある順：A 競合の空白（湾岸・物流の型の7か所）→ B 店を大きくできる → C 昼の客が多い。D は弱い。E・F は裏づけなし、G は逆の事実。
- 25か所を1つの属性で扱うと、湾岸・物流の型（住む人がいない・飲食がない）と住工混在の型（住宅地と同じ）が混ざる。仕組み A は湾岸型にしか効かない【推論】。属性を2つに分けるかは設計の判断。

## 6. 肯定側の問い（なぜうまくいくか）
**いちばん強い形**：「大きい駅は客もライバルも多い」は、東京の数で言える。駅500m のラーメン店は段1 の中央1軒から段8 の中央36軒へ増え、0軒の駅は段1 の38% から段4 で3%・段5以上で0% に減る（出力§2）。同時に、駅前の飲食店の1店の売上は段1 の2,343万円から段8 の8,325万円へ3.55倍になる（出力§4.2）。ライバルが多い所でも1店の売上は多い、つまり「人が多い所は客もライバルも多い」はオーナーの原文「人が多いところは複数の競合がひしめきやすい」と同じ向きで、λ の段の形（段1〜6）も実際の数とそろう。
「工場の町にも勝てる所がある」もいちばん強く言うと：湾岸・物流の型の7か所には、昼に約2,000人の働き手がいて、飲食の事業所は中央1つ、ラーメン店は6か所で0軒。全国では工業地区の中華料理店の1店の売上は住宅地区の1.42倍、工場・オフィス街の店の1日の客は住宅地区の2.54倍。「客の素はあるのに店がない」所が実際にある。

**言えない所・逆の事実**：
- 大きい駅の1店の売上の差は、店の大きさの差でほとんど説明され、働く人1人あたりでは1.15倍（出力§4.2）。ゲームの店が同じ大きさなら、「大きい駅の店は客が多い」の差は小さい。
- 段8 は3駅だけで、駅の点の置き方で数が大きく動く（新宿26 に対し隣の新宿西口62）。
- OSM の網羅は28%で、区で4倍近く違う（0.12〜0.46）。
- 工場の町の働き手が店に来るかの資料はない。社員食堂は製造業で多い。工場・オフィス街の店の資料は11施設で、オフィス街と混ざっている。工場の候補地の中央で見ると、働く人あたりの飲食の店は多くも少なくもない（6.8、オフィス街4.1・住宅地8.8）。

## うまくいく理由
1. **人の多い駅 → 店が集まる → ライバルが多い**：駅の foot とラーメン店の数の順位相関0.546、飲食の事業所とは0.624（出力§2.1）。λ の段の形（段1〜6）は OSM の数とそろう（2.2）。
2. **人の多い駅 → 1店が大きくなれる → 1店の売上が多い**：段8 の駅前の飲食店は段1 の3.55倍の売上、1店の働く人も多い（従業者1人あたりは1.15倍しか違わない）（3.1）。ライバルの多さと1店の売上の多さが同時に成り立つ。
3. **働き手がいるのに店がない → 競合の空白 → 来れば独り占め**：湾岸・物流の型（働く人1,000人あたり0.8、ラーメン店0軒6/7）（4.1）。ゲームでは「foot の小さい駅の外れでも客の素がある」という発見の楽しさになる【推論】。
4. **家賃の安さ → 大きな店 → 売上の天井が上がる**：工業地区の中華料理店の1店の従業者8.7人・売上1.42倍、工場の候補地の地価はいちばん安い（4.2・4.3）。

## うまくいかない理由
1. **OSM の網羅が低く、区で違う → 数の絶対値と比が揺れる**：ラーメン店で76B の28%、都心0.35・外周0.21（出力§1）。都心の大きい駅を多めに数え、段8÷段1 を大きく出す向きの偏りがありうる。
2. **大きい駅の隣の小さい駅 → 段1 の数がふくらむ**：新宿西口62・末広町44・京成上野28。除くと段8÷段1 は14.8→23.2倍（2.2）。どちらを「段1」と見るかで λ の形の結論が変わる。
3. **売上の差は店の大きさ → ゲームの店の大きさの扱いで読みが逆になる**（5.1）。
4. **工場の町の昼の客が来る資料がない → 仕組み A は推論に立つ**。社員食堂・弁当・コンビニとの取り合いの量が分からない。
5. **工場・オフィス街の資料は標本が小さく、オフィス街と混ざる → 工場の町の客の多さは言い切れない**（11施設・18施設）。

## 反証と限界
- 2.3 の7本のうち3本は2倍の側（駅ごとの中央3.66・0軒を0.5軒2.71・大きい駅の隣を除く3.13）。8倍を支える数だけを選べば「8倍が正しい」と言えてしまうが、同じ重さで並べると真ん中。
- 代理 (c)（メッシュの宿泊飲食の事業所×区の76B の割合）は7.87倍で8倍とほぼ同じだが、ラーメン店の数ではなく飲食全体（宿泊を含む）を割り振ったもの。都心の区は76B の割合が低い（千代田0.103・中央0.068）ので、都心の大きい駅を少なめに出す向き。それでも8倍に近い。
- 工場の候補地の「働く人1,000人あたりの飲食」は中央で6.8 で、オフィス街（4.1）より多い。「工場の町は飲食が少ない」は、湾岸・物流の型（7か所）にしか言えない。住工混在の型（17か所）は住宅地とほぼ同じ。
- 全国の工業地区の中華料理店の売上1.42倍は、地方のロードサイドの大きな店を多く含む見込みで、23区の準工業地域の小さな店に当てはまるかは分からない【推論】。
- 中華料理店の調査は2014年、経済センサスの売上は2020年（コロナの年）、OSM は2026年の状態。年がそろっていない。
- 中華料理店の調査で駐車場が工場・オフィス街に少ない（27%）のは、オフィス街の店が多く入るためかもしれない（分けられない）。
- 駅の点は tokyo23.js の位置（駅をまとめた点）で、実際の改札の位置とずれる駅がある（新宿の500m は26軒、新宿西口は62軒）。
