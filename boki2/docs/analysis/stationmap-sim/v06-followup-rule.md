# N300追加確認の選び方（6620188403）

120組×station/pinのK2/N3探索を読み、通過組と「近い不合格組」をN300で再確認する。
近い組は、期待値・乱数込みの両方で、**外れた全ての数の目標が境界値から10%以内**の組とする。
上限は `(値−上限)/上限`、下限は `(下限−値)/下限`、複数の値は最大を取る。範囲なら両端を調べる。
④は0.44まで、⑤は16まで（16.5までの整数）、⑥は0.935まで、⑦は18%以上、⑨は1.17以上等。
赤字のくじも55%以下を要求する。目標の合否は元の境界から変えず、追加確認の選び方だけに使う。
③の段・属性・住商本数も下限との比を調べる。⑩・4.3の「どちらが大きいか」は数の目標がなく、
距離による除外条件にはしない（他の数が全て近ければ再確認する）。
測定不能がある組は別に数え、近いと推定しない。全試行と選択理由をv06-followup-plan.jsonに残す。
N300再確認も同じseed=20261104・K2を使い、全981候補地の期待値/乱数込みを出す。
この再確認も端条件の仮判定であり、最終合否・採用候補ではない。
