## 0. 要点（先に結論）
1. **問題集は「教科書の例題の改題（基本編）」→「本試験の形（試験対策編：第4問・第5問）」の2段**。基本編14章・計約70題、試験対策編7題。各問は「問題→解答欄→解答・解説→Point（公式1〜3行）」の固定型で、解説の主役は勘定連絡図・ボックス図・シュラッター図・面積図 [[cpa-learning:texts2:180063]]。
2. **同じ数字で方法だけ変える比較が多い**：先入先出／総平均、公式法変動予算／固定予算、直接配賦／相互配賦（簡便法）、総括配賦率／部門別配賦率、要素別／形態別の製造原価報告書、差異なし／差異ありの報告書、シングル／パーシャル、全部／直接原価計算（2期・4期）。違いが「方法の違いだけ」から生まれることを数字で見せる教え方。
3. **読み取りのひっかけが体系的**：諸手当は賃金勘定を通らない、水道の検針日と月末のずれと基本料金、旅費交通費の前払、工場消耗品費は加工費、前工程費は数量で按分、工程ごとに評価方法が違う、等価係数が容量・重量、無償支給材料、製品倉庫が本社にある本社工場会計、など。
4. **模試は2系統**：CBT想定のオリジナル3回（手順の細かい解説、2022年度以降の論点）と、書籍収録の紙試験型3回（記号解答、手形が多い旧来型）。どちらも本試験の配点（20・20・20・28・12）どおりで、**時間配分の指導はない** [[cpa-learning:texts2:150113]]。
5. **私たちに足りない問われ方**：①複数期間・期首在庫つきの全部原価／直接原価比較、②工場から仕掛品・製品への「一連の取引」を3仕訳でつなぐ形、③予算段階で補助部門費を配ってから部門別予定配賦率を作る形、④部門費勘定への記入と差異の向き、⑤理論の○×、⑥値下げ後に同じ利益を得る販売量・固定費の削減額の逆算、⑦2製品共通材料の標準消費量の合算、⑧諸手当・検針日・前払経費など経費・労務費の読み取り、⑨副産物（この教材セットでも欠落）。詳細は6章。

### 1.2 導入の仕方
第1章は「工場か本社か」で費目を3つの箱（製造原価・販管費・非原価）に分ける→直接費と間接費を「総額−直接分」で出して原価の階段（製造原価→総原価→販売価格）を登る→9本の仕訳で工業簿記の一巡（材料購入から月次損益への振替まで）。月次損益に販管費を直接振り替えることで「期間原価」の考えを最初に示す。

### 1.3 段階の踏み方（章内）
- 第2章：副費の範囲（読み取り）→副費の予定配賦と差異→先入先出と総平均の比較→予定単価と消費価格差異（先入先出）→移動平均の元帳＋予定単価。差異→売上原価の流れを工業簿記で最初に見せるのが「材料副費配賦差異」で、後の賃率差異・配賦差異と同じ型の予告になっている。
- 第5章：実際配賦→配賦基準3種→予定配賦→配賦差異の勘定→差異分析（変動予算と固定予算を同じ数字で）→図の点を1つずつ求める段階問（月間予算→予算許容額→予定配賦額→勘定記入）→語群つき仕訳。
- 第6章：第1次集計（共通費の基準は自分で選ぶ）→直接配賦→相互配賦（同じ数字）→総合→第3次集計（実際）→部門別予定配賦→予算段階で補助部門費を配ってから予定率を出す。
- 第8章：月初なし→先入先出→平均→計算表（工場消耗品費の位置）→逆算（月初数量が「？」）→減損の発生点2通り×2（平均・先入先出）。
- 第11章：標準で箱を埋めるだけ→総差異→全差異分析（4分法）→シングル／パーシャル→報告書と損益計算書。

### 1.4 つまずきへの先回り（Point欄の反復）
- 差異は常に「予定（標準）−実際」、プラス＝有利＝貸方、マイナス＝不利＝借方。ほぼ全章で同じ文言。
- 「予定配賦額＝予定配賦率×**実際**の基準数値」を何度も注意する。
- 「直接工の間接作業分は製造間接費」「諸手当は賃金勘定に入らない」「月末在庫は実際購入単価で評価」「前工程費は数量で按分」「減損の発生点が月末進捗より前なら両者負担、後なら完成品のみ」。
- 報告書は予定ベース、損益計算書で差異を戻して実際ベース、という二段の関係。

### 1.5 模試の解説の教え方 [[cpa-learning:texts2:150113]]
オリジナル模試の解説は、各仕訳を①②③の一手ずつに分け、それぞれに「なぜその科目・その金額か」を1文で添える。決算問題では整理事項ごとに「財務諸表に反映される箇所と金額」を明記し、最後に損益の簡易メモで繰越利益剰余金を検算する。連結はタイムテーブル→開始仕訳（過年度の費用は利益剰余金）→当期仕訳→「仕上げの手順」。CBTの採点仕様（同じ科目を2行に分けると不正解、カンマ不要）を注意事項で先に教えている。書籍収録の模試の解説はこれより短く、式中心。

### 1.6 誤植・版の違い（教材の品質として）
- 問題集：5-5 解答「4.000円」、9-3 解答欄「Ａ組製品」（等級別なのに組）、第8章扉と解答用紙にある「8-8 副産物の処理」の問題が本文にない [[cpa-learning:texts2:660022]]、試験対策4-3 で千円単位を時間で割った大きすぎる予定配賦率。
- 前の刷 600037 では、年額を「月間」と書いた式、「1,620.000円」、資料表への行の重複があり、後の刷で直っている。受験料（4,720円→5,500円）と合格率の目安（40%→30%）も後の刷で更新 [[cpa-learning:texts2:600037]]。
- 模試：解説本文の金額の誤記が r1・r3 に1か所ずつ、単位の誤記（r2）、表の1行目の科目名の誤り（r5）など（詳細は 150113 のノート）。
→ 私たちの問題でも「単位・桁区切り・資料表の重複・本文と解答の金額一致」を検査項目にする価値がある（tools/validate.js に足せるもの）。

## 3. 問われ方（形式・設定・数字の作り方・難易度）

### 3.1 形式
- 基本編：金額だけ／仕訳／勘定記入（相手科目も書く）／表（部門費配賦表・指図書別原価計算表・総合原価計算表・製造原価報告書・損益計算書）の4種。勘定記入の比重が大きい。
- 試験対策編・模試：記号選択の仕訳（ア〜カ）、プルダウン想定の科目選択、空欄補充の表（一部の数字は印字済み）、○×、借方/貸方・有利/不利・＋/△の向きの指定。
- 採点：仕訳は1組4点（科目と金額が全部合って4点）、表は網掛け箇所2〜4点。模擬配点を各問に付ける。

### 3.2 設定と数字の作り方
- 端数が出ない設計が基本（単価・配賦率がきれいに割り切れる）。あえて小数を出すのは移動平均（101.2 など）と単位原価（小数第1位・第2位の四捨五入指示）。
- 逆算を仕込む：月初仕掛品の数量「？」（8-5）、前T/Bの「？？？」（r1・r3）、子会社の過年度利益（r3）、第二工程の完成品「？？？」（試験対策4-2）。
- 単位を揺らす：千円単位（部門別・連結）、kg・㎥・g の等価係数、進捗度を分数で。
- 会社名・工場名をつける（千葉工業、小田原工業、日吉工場、CPA工業）が、場面の物語はない。

### 3.3 難易度の段階
- 基本編：1章あたり易→標準→総合。各章の最後に「総合」（6-4、7-4、9-7、10-4、11-5、12-4）。
