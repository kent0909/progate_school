# Figma Community の候補（UI の参考の調べ・BRIEF-UIREF）

2026-10-30、取りまとめ役。オーナーの選択「Communityの候補を挙げて」への答え。

**限界（先に）**：www.figma.com は robots.txt で ClaudeBot を全面禁止しているため、候補のページは開いていない。下の説明は WebSearch の検索結果の要約だけから書いた（中身・画面数・利用条件は未確認）。Figma の道具（MCP）は、ファイルの URL（`figma.com/design/<キー>/…`）がないと中を見られない。オーナーが Community のページで「複製（Open in Figma / Duplicate）」して自分の下書きに入れ、その URL をチャットに貼ると、取りまとめ役が MCP で画面を撮って分析に入れる。
