# 「一杯と衛生」：お金を変えずに1年目の手ごたえを見せる3案

依頼：PR #4 コメント6386361976。**1年目のお金の釣り合いは現状維持、案A〜Dは不採用**というオーナー決定を前提とする。今回の3案は既存の実測表示の焦点を変える案であり、効果の係数を上げる案ではない。採否・本体・画面の変更は行っていない。

## 問いの設計

「10月までの初黒字に差が小さい」と「画面に出る差がない」を分ける。利益が先行しない原因と、遅く効く良さの両方を測る。数を上げて成功したことにはせず、現行の表示値で差を確かめる。

基準は前回と同じ6ff66e6の実装。PR #2/#3取り込み後の版ではない。正式検査のplay/smartX/idlePolicyを実行時に読み、world.monthで60か月。seed 0〜299、3立地×3つの一杯は公式の組合せ。9条件×300周で、一杯と衛生と放置の対を各条件で比較した。割合はWilson95%、差は同じseedを組にして2000回bootstrap（rng991）。母数は全300周。差は独立2標本として計算していない。

### どこが遅いか

- `coef.js` のdecayStart=13と `bowl.step`：初年度にFbaseの古びを防ぐ利点はない。一方、手直し/限定のpeakは初年度にも立つ。古びと話題の山を混同しない。
- `world.js` 290〜302行：体験→評判の更新→常連の追加/離れ→翌月以降の客という積み上がり。Rは月次で動き、常連のストックは後から太くなる。
- 高い仕入先は品質に加え月3万円・材料倍率約1.1714を伴う。品質だけ上がるわけではない。看板・宣伝等の方針全体の費用もあり、初黒字だけでは育成の効果が見えにくい。
- 衛生は直接毎月売上を上乗せする項ではない。`cards.js` haccp札の重みが衛生ONなら1/OFFなら3。札のkeep/skipには別の結果分布があり、方針の衛生ONと札でkeepを選ぶことは同一ではない。事故率を単純に3分の1と断定しない。回避した事故を実際に起きた数として表示しない。

## うまくいく理由（遅く効く形の良さ）

基準の一杯と衛生は放置にNCで、3年末299/300＝99.7% [98.1,99.9]、5年末298/300＝99.3% [97.6,99.8]で勝つ。長期の強みを再測定した。

【推論】手直しや高い仕入先には今月の支出があり、評判と常連の資産が後で返る。この時間差は「今月の利益だけなら節約したいが、客を育てたい」という判断を作る。標準仕入先の診断では5年目の勝率が87.0% [82.7,90.3]へ下がり、品質を守る代償を消せばよいとは言えない。ただし複数の動きが組み合わさる方針の比較であり、各機構の独立寄与を全て分離したわけではない。

## うまくいかない理由

【確かめた】非金銭の表示は既にある。今回分かったのは「差が数として存在する」ことで、「今の画面で遊ぶ人が気づき、楽しいと思う」ことではない。表示を追加するだけでなく、既存の行をどう読むかの導線が検討対象になる。

【推論】評判・常連・魅力を同時に目標へ増やすと、別の成績表を増やすだけになり得る。3案を全部採るのではなく、試遊で気づき方と負荷を確かめる必要がある。衛生の価値をFや評判の差にすべて帰属させるのも誤りである。

## 反証と限界

- 9条件は因果の単独感度で、全ての交互作用の分解ではない。各方針の乱数の消費が異なり、同じseedでも出来事の実現値が常に同一とは限らない。
- 衛生OFFの初黒字37周とON36周の僅差を、衛生が不利な証明にはしない。
- 方針固定のシミュレーションであり、表示を見て人が方針を変えた場合の3〜5年の強さは未測定。
- ボットは最初から方針の手を使う。実プレイの解禁順を再現した初見試遊ではない。
- PR #2/#3統合後の挙動や、実際のレンダリング画像の確認はしていない。表示の実在は当該ソースで確認した。
- 差を増やすための費用ゼロ・評判係数変更は診断に限る。採用すると効果だけの上乗せになるため、合わせ込みの危険を明示する。
