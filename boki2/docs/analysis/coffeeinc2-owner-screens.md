## うまくいく理由
数が多いのに読めるのは、**店と支社で同じ型（2つの数→棒→表）がくり返され**、全社の週の業績も先頭の2つの数だけは同じなので、一度読み方を覚えれば同じ目の動きで読めるから（全社の層まで同じ型とは言えない。判定役の指摘で弱めた）。同じ型のくり返しは BIZ-COFFEEINC2 2章の「同じ形の判断が層を変えてくり返し出る」と同じ向きで、判断だけでなく画面の読み方でも起きている。安く見えないのは、絵の画風（平らな等角・目鼻のない人）と色の役（自社＝朱、層＝地の色）が全画面でそろうから【推論：12枚の中で例外を見ていないだけで、全画面を見たわけではない】

## うまくいかない理由
- 前週差の % を整数に丸めるので、桁が大きいと小さな変化が 0% に消える（s01・s08 の売上。純利益の −42% は意味を持つ）
- 経理の遅れは秘書の文で示すが、大きな数そのものに「古い」の印はない（棒の日付で分かるだけ）
- 利益とお金の差の理由は画面にない（s01：純利益 33,652,742 と営業キャッシュフロー 57,947,567 の差 2,429万の内訳が出ない）。こちらの版 c が差の内訳を見せれば上回れる所
