# 経営シムの周回の声：分類のコード（BIZ-REPLAY 版0.2）

`replay-mgmt-voices.py` が、カイロソフト3作（ゲーム発展国++・こだわりラーメン館・同 全国編・大盛グルメ食堂）と Good Pizza, Great Pizza の口コミ643件から「周」「週」の字を含む34件を拾い、この表で数える。本文は写さない（`--dump` で原文から読む）。原文は BIZ-FUNVISUAL の担当が取得した APPLION のページ。

- 関係：`周` = 周回（2周目以降・周回の回数・周回の仕組み）に触れた。`-` = 「周」「週」の字はあるが周回の話ではない（「1週間」「周知」、1周目の途中の感想だけ、など）。
- 中身：G 2周目以降で目標（大賞・グランプリ）に届いた／P 持ち越し・引き継ぎ・強くてニューゲーム／N 次の周で新しい要素（新キャラ・追加素材・前に見つけられなかったこと）／K 組み合わせ／M 奥の深さ・慣れ／R 前の周の反省で次の周を計画する／Z 飽きない・黙々と続く／x 遊べる期間が短い／L 1周が長い
- 回数：書いてある場合だけ。
