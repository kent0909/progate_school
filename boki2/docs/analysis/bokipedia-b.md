## 2. 構成と教え方（講評・解説から読み取れる型）

**大問の組み方**
- 練習模試は「第1回＝易しい・第2回＝普通・腕試し＝難しい」の3段で同じ回を囲む。腕試しは「第1回・第2回を優先し、自信がなければ使うな」と明記して、難問で自信を失わせない配慮をしている。
- 1つの大問に複数論点を「つなげる」作りが多い。部門別＋個別（195）、部門別＋工程別（213）、固定資産の資料から勘定記入・税効果・連結修正まで（205）、合併と連結の比較（292）。講評も繰り返し「解答を覚える勉強では解けない」「単元を線で捉えろ」と書く（195・213・205・254）。
- **同じ数字で条件だけ変える**：仕損の発生点を4通り（245）、2通り（291・309）、同じ生産データを個別と総合の両方で（197）、全部原価計算と直接原価計算の比較（226・261・273・288）。条件の違いが結果をどう変えるかを比べさせる。
- 本社工場会計は倉庫の置き場所を変えた3パターンを回ごとに出している：製品倉庫が本社（227・291）、材料も製品も工場（243）、本試験は製品勘定が工場だけ（255）。「どちらの帳簿に仕訳が立つか」を設定から判断させる。
- 実在の検定の流れを先取りする：「新論点」として製造業の決算を本試験前に出し（193）、「本試験では月次決算が前提になる」と予想（193）、本試験で初出（304）。「差異分析より勘定記入の出題が増える」と実務の動向から予想（305）。

**解説の教え方**（過去問の解説）
- 計算の前に勘定連絡図や手順を示す：部門別計算の3手順（235）、製造業の勘定連絡図（304）、標準原価計算の一巡（235）。
- 制度の目的から説明する：補助金を受贈益にすると課税されて設備資金が足りなくなるので同額の圧縮損を立てる（254）、本社工場会計の目的は業績評価（255）、本支店の費用負担は業績評価のため（260 講評）、200％定率法はどこかで定額法に切り替えないと帳簿価額がゼロにならない（263 の10年間の償却表）。
- ボックス図・シュラッター図・資本の推移の図（タイムテーブル）を多用（223・264・287・254）。連結は最後に利益剰余金と非支配株主持分の「分析表」で検算（254）。

- **E33 棚卸は面倒だから来月で**（s-genmo s-revenue）：出荷したが得意先に着いていない80本を、社長が売上に入れた。検収基準なので売上を取り消し、期末の帳簿在庫にも戻す（310・312 の修正の連鎖）。在庫の数え直しとセットで体験。
- **E40 修理班の費用はどのライン？**（k-bumon）：修理班の費用を予定配賦にして、修理班の実際額との差は修理班に残し、ラインには予定額だけ流す（223）。「修理班の浪費がラインの成績を汚さない」責任の分け方を判断にする。水道代の基本料金と検針日のずれ（281）を部門費の集計に入れる。
- **E41/E42 特注ボトルと量産ライン**（k-kobetsu k-sogo）：同じ1か月の作業を、注文ごと（指図書）と期間ごと（総合）の2通りで集計し、月末仕掛品の金額が違う理由を比べる（197）。
- **E43 瓶が割れた・ジュースが減った**（k-shison）：同じ生産データで、割れる場所（工程の30％・70％・最後）をスライダーで動かし、月末仕掛品が仕損費を負担するか（月末の進捗50％より前か後か）が切り替わるのを見せる（245・291・309）。
- **E44 2本目のライン・大瓶**（k-kotei）：大瓶・中瓶・小瓶の重さ（1,500g・750g・500g）から等価係数3：1.5：1を作らせる（195）。ホットのラインは月初の進捗が記録されていない→先入先出法は使えないので平均法を選ぶ、という推論の判断（281）。
- **E45 工場の1年を1枚に**（k-honsha）：社長が「製品は本社の倉庫に置け」「やっぱり工場に置け」と言うたびに、完成時・販売時の仕訳がどちらの帳簿に立つかが変わる（227・243・291 の3パターンを1つの判断に）。
- **E50 グループの中で売り買いした分**（s-naibu）：運送子会社への請求が「未検収」で、子会社側に仕入が立っていない→不一致を直してから相殺（270）。子会社に売った土地の一部を子会社が外部へ転売→その分の未実現利益は実現（290）。2027年版として、手形の割引ではなく、子会社に対する電子記録債権を親会社が銀行で割り引いた場合を連結では借入れに組み替える（254・270 の考え方を置き換える）。
- **E52 1本あたりの「あるべき原価」**（k-hyojun）：差異を毎月は売上原価にせず年度末まで繰り越す設定（262）を、月次の報告で社長が「今月は差異がこんなにある」と慌てる場面にする。
- **E53 何本売れば黒字？**（k-cvp）：6か月の売上高と電気代から、売上高を操業度にして変動費率（％）を出す高低点法（206）。正常操業圏の外の月を外すかの判断（196）。
- **E56 検定会場**：○×の正誤10問を「先輩の確認クイズ」として入れ、全部○・全部×は0点にする（244）。仕訳は記号選択（158回用の形式、309〜312）。

**教え方の工夫の吸収**
- 「同じ数字で条件だけ変える」（245・197・226）は、栞（判断ごとの状態保存）で「もしこの条件だったら」を比べる仕組みとそのまま相性がよい。PEDAGOGY の「判断の結果を確認してから」に合わせ、条件を変えたときの数字の変化を試算パネルで見せる。
- 制度の目的からの説明（254 の補助金と課税、255 の業績評価、263 の定率法の切替え）は、4拍の「原理の問い」の材料にする。例：圧縮記帳を教える前に「補助金に税金がかかったら、工場を建てるお金は足りる？」と問う。
- 解説の「分析表で検算」（254）は、連結のエピソードで「グループの利益剰余金を2つの道で数えて一致させる」月末の見直しにできる。
- 本試験のボーダー（大問ごとの目標点）と「部分点を狙う大問」の考え方は E56 の戦い方（c47）に足せる。
