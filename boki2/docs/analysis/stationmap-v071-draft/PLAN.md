- ⑤を直す仕組みの案（α〜δ と参入の効きの間の形）が、**物差しの全部を同時に満たす向きがあるか**の当たりをつける。**ここで案を1つに絞らない**。絞るのは正本の測定のあと（設計書 4.9 の選ぶ規則）。
- Codex の道具の結果と照らす相手（同じ置き値の台本の数）を残す。

## 2. 物差しの線（設計書 6章に書いたもの。ここで回す前に固定する）
| 検査 | 線 | 理由 |
|---|---|---|
| ⑪ 属性ごと | 6属性のそれぞれで、3年目の利益（候補地のくじの平均）が全候補地の上位30%に入る候補地が、その属性の候補地の **10%以上・かつ2か所以上** | 面白さ：属性ごとの遊び方（オフィスの昼だけ・繁華街の夜・住宅地の常連）が選べる形で残る。偏りがなければ各属性30%、その3分の1。2か所＝選ぶには2つ要る |
| ⑫a 段ごと | 7段のそれぞれで、同じ（10%以上・2か所以上） | 同じ。オーナーの原文「各駅の人口に合わせて出店できるピン数」で段が地図の骨格なので、段まるごと選ぶ価値がない形を避ける |
| ⑫b 逆転 | 段の順に、**需要（入れなかった客を含む来たい客）の中央値**が下がらない（期待値の列で厳密に。乱数込みで2%未満の逆転は「揺れ」として報告） | 現実：飲食の事業所1つあたりの駅の人通りは段8が段1の約5倍（facts71 の出力）。売れた客は席の上限で頭打ちになる（オーナーの決定「人が足りない場所は作る」）ので、売れた客の逆転は報告だけ |
| ⑬ 0軒に頼らない | 各世界の利益の上位50のうち、**開店の前にライバル1軒以上**の所が **25以上**（全世界で） | 面白さ：「ライバルのいる所でも勝てる」が半分以上。オーナーの原文「人が多いところは複数の競合がひしめきやすい」で、よい所に競合がいるのが普通の姿 |
| ⑭ 赤字のくじ | **週の揺れを入れた列**で 50%以下 | 4.4 の線（版0.5 から。版0.7 の結果の前に決まっていた）。学習効果：1号店が「たいてい赤字」だと、判断より運に感じる（PEDAGOGY 1.5「運は小さく」） |
| ⑥ に足す規則 | 「属性Xだけ（人通り順）」の6本も 85% 未満 | ⑪ に上の線を置く代わりに、1つの属性で勝てる形を ⑥ の物差しで見る |

①〜⑩ の線は版0.6 のまま動かさない。
