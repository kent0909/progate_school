# 周回についての利用者の声：分類のコード

BIZ-REPLAY.md の利用者の声の件数は、この表を `replay-voices-count.py` が数えて出す（頭で数えない。QUALITY 6.2-2）。
口コミの本文は写さない（著作権・30字ルール）。本文は `python3 -I boki2/docs/analysis/replay-voices-count.py --dump` で原文のページ（research/raw）から切り出して読む。番号はそのダンプの通し番号。

## 資料
APPLION（App Store の口コミの転載サイト）の5作品・14ページ。Slay the Spire 5ページ、Balatro 3ページ、FTL 2ページ、Stardew Valley 3ページ、Game Dev Tycoon 1ページ。読了ノートは research/notes/web/simgames/r6-rp-applion-*.md。

## コードの決め方
- 関係：`周` = 何度も始め直すこと（周回・ラン・やり直し・別のキャラや牧場で始め直す）に触れた。`長` = 長く遊び続けたこと（時間・中毒・飽きない）に触れたが、始め直しの仕組みには触れていない。`-` = どちらにも触れていない（不具合の報告だけ、翻訳の要望だけ、など）。
- 楽しみ（一つの口コミに複数つけてよい。`_` でつなぐ）：
  K 組み合わせ・毎回違う展開／M 上達・習熟・理解が深まる／A 難度の段を上げる／N 新しい発見・解放／S 1回が短い・隙間に遊べる／G 目標・記録・実績・収集を埋める／P 持ち越しの成長（牧場が便利になる等）／E 物語・人物・世界／F 自由・好きな遊び方・改造／T 運・予想外／Z 理由を書かない中毒・時間泥棒・飽きない／D 日替わり・順位／W 間をあけて戻ってくる
- 不満・やめた理由：x 飽きた・することがなくなった／y 新しさが減る・作業になる（予想も含む）／r 運・理不尽／d 難しすぎる・初めに挫ける／u 操作・画面・不具合／l 1回が長い／b 解放が遅い・出ない／k 偏り・強すぎる選択／v 負けたときの虚無感
- 量：書いてある場合だけ。`数十時間`（10〜99時間）、`百時間以上`、`周回の段を上まで`（全キャラ最高難度・全実績など）、`月・年単位`（遊んだ期間だけ書いてある）。
- 迷った場合は弱いほうに倒した（「無限に遊べる」だけは Z、仕組みを書いていなければ K にしない）。
