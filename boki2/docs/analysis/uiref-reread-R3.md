## 4. 動画の実測（Collect UI の8本）

### 4.1 測り方

`python3 -I boki2/docs/analysis/uiref-motion-measure.py --sens`（終了コード 0）。決まり（スクリプトの頭に書いた）：
- ffprobe で長さ・コマの速さ（固定）・コマ数を読む。ffmpeg で全コマを灰色・幅160px にして読み、読んだコマ数が nb_frames と合うことを確かめた（8本とも一致）
- 隣のコマとの差が 12（0〜255）を超える画素の割合を「動きの量」とし、0.2% を超えるコマを動いたコマとする。すき間 100ms 以下は同じ区間。始まり＝最初に動いたコマの時刻、終わり＝最後に動いたコマの時刻、長さ＝終わり−始まり＋1コマ
- 区間の中は、最大の15%を下回るコマが3コマ以上続く所と、谷（3コマの中央値でならし、前後150msで最も低く、前と後に谷の2倍以上の山がある所）で「山」に分けた
- 1コマごとの差では拾えないゆっくりの薄れは、約100ms 離れたコマの差でも探した
- しきい値は動画を見る前に決めた。感度（8・0.1% と 16・0.4%）を変えた結果も出す。何が動いたかの言葉は、山の始まり・終わりのコマを画像にして開いて付けた（長さは目で付けていない）
