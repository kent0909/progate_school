# 1年目の赤字：実装の原因比較と4つの改善案

21,000周の原因比較と4案の長期検査を完了。**4案の採用は決めない。** 坂の変更は早期黒字化を大きく改善するが長期の合否も壊す。その他固定費10万円の案は数値のバランス基準を通過したが、既存の係数範囲から外れ、3方針の早期黒字の目安案も満たさない。

## 問いの設計

依頼 `CODEX-TASK-y1-economy.md` に従い、手を打つと1年目に黒字が見えてくるか、放置との差が見えるか、改善と引き換えに既存の判断が壊れないかを問う。係数を合わせて「直った」とは判断しない。案の採否と目安の決定は取りまとめ役とオーナーに委ねる。

基準は `6ff66e66edf6ae375a0d72fbf4972f485eceb59a`（分岐時の最新 `boki2-quest`）。PR #2/#3 の変更は含めない。Git 接続のプロキシに接続できなかったため、GitHub 接続ツールでコミットを指定してファイルを取得した。取得した実装・検査・参照資料137ファイルは Git blob のハッシュで基準との一致を確認した。ハッシュは `ramen-y1-economy-source.json`。

## 資料の内訳

外部調査は行っていない。根拠は対象コミットの実装と、その実行出力。依頼書・AGENTS・HANDOFF 5章・PEDAGOGY・QUALITY と、DESIGN-RAMEN の関連節を参照した。既存の版1.3メモの数を新しい結果として転記していない。研究資料・実店舗統計・利用者の声による検証ではなく、実装に対する反実仮想の比較である。

### 測り方

- 原因比較は全条件で seed 0〜299。変更した要因以外の係数を基準へ戻してから各条件を測る。坂の始まり/終わり、家賃/その他/返済、retain/churn は個別の行も設けた。範囲は `variants.md`。
- 方針は正式検査 `tools/sim-ramen.js` の `play`・`smartX`・`idlePolicy` を実行時に読み出す。需要・損益・口座・乱数・札の計算は実装の `world.month`。模型は使わない。
- 正式な放置は地図のみ・850円・パート1人・衛生なし。依頼の `world.policy0` は衛生ありで別の方針なので、どちらも載せる。3立地と3種類の一杯は正式検査と同じ seed による組合せ。3種類の上手はそれぞれ同じ300 seedで測る。3方針を合わせて900個の独立な町と数えない。
- 月の乱数は正式検査どおり `seed*104729+t`、方針の乱数は `seed*7919+13`。方針が乱数を消費する順まで公式と同じであり、方針が異なれば出来事の実現値も変わりうる。同じseedは全ての天気・札が一致するという意味ではない。
- 初黒字は1年目4月〜3月の `res.op>0`（表示を丸める前の値で判定）。年度内なしを分布の13番目に置き、中央値は公式と同じ上側の中央要素。到達周だけの中央値も併記し、未到達を外した数字だけで早くなったとは言わない。
- 年間営業利益は各周の12か月の合計の中央値（万円）。月の営業利益中央値は `monthly.md`。倒産後は新たな利益を加算せず、年度内黒字率の分母に残す。月ごとの連続値には観測数を添える。
- 口座の最低は開店直後と1年目の各月末の `W.cash` の最小（追加借入を含む現金）。5年の正式な勝敗は `netCash`（口座−借入）であり、物差しを混ぜない。
- 率は分子/分母とWilson95%区間。推定対象はこの実装のseed分布で、人間の成功率ではない。正式合否は従来の点推定の線のまま。区間を理由に不合格を合格へ変えない。
- 感度分析ではPを再較正しない。retainだけを変えた効果と「retainを変えてPを引き下げた」効果を混ぜない。案AはPの較正候補を15%増やした値で、最適値の探索や新しい目標への適合はしていない。3年目の客数のずれも記録する。

## うまくいかない理由

【確かめた】返済すえおきだけを3→6か月へ延ばしても、3方針と放置の1年目の黒字率・営業利益は基準と同じ。口座と営業利益を別の指標として扱う必要がある。

【確かめた】常連の定着を0.035→0.05へ上げると、Pを据え置いた比較では1年目の年間利益と年度内黒字率が改善した。「定着を速めると逆効果」は再較正でPを下げる操作を含む別の比較であり、定着単独の効果とは言えない。一方で3年目の客数も増えるため、長期の釣合いが維持されるとは断定しない。

【確かめた】開店時に+0.15の話題の山を置いても、常連と地図・一杯と衛生の初黒字率と年間利益は基準と同じだった。これらの方針は最初の月に手直しを行い、開店時の山が実装上の手直しの山で置き換わる。開店の山一般が無効だという意味ではない。

【確かめた】案Aの放置の3年目客数中央値は48.0人/日で、中心44からは離れるが、既存の許容帯36〜52には入る。Pを増やすことが直ちに既存の客数基準の変更を必要とする、とは言えない。

【確かめた】案Aは長期検査でF7が9/300＝3.0%（Wilson95% 1.6〜5.6%）、価格の入れ替わりが59/150＝39.3%（31.9〜47.3%）、放置同士の家族店の3年末勝率が114/300＝38.0%（32.7〜43.6%）となり、既存基準を外した。係数範囲は変えていない。全4案の正式行は [案(b)の全表](ramen-y1-economy-results/proposals-b.md)。無変更の正式コマンドは終了0。

### 全案の長期検査の結論

- 案A 潜在客×1.15：F7・価格の長期入れ替わり・放置同士の家族店の勝率が不合格。
- 案B 坂0.75→0.95：上記3項目に加え、集客と席が放置へ勝つ割合も不合格。rampStartは既存の係数範囲の外。
- 案C その他固定費10万円：正式な数値のバランス基準は全て通過。**既存の係数範囲の検査だけが不合格**で、検査全体が通ったわけではない。早期黒字も3方針それぞれ70%には届かない。採用には根拠と目安の合意が要る。
- 案D 坂＋固定費：案Bと同じ種類のバランス不合格に加え、2つの係数が既存の許容範囲に入らない。

全ての率・件数・Wilson95%と全不合格行は案(b)に掲載。未達を通すために元の線や範囲を緩めていない。既存の数値の合否を保つという意味では、固定費案も候補となるため「坂が唯一の直し方」とは言えない。ただし固定費案が面白さを満たすことまでは示していない。

## 手ごたえの目安の案と相談

【提案・未決定】3つの上手な方針それぞれで10月までの初黒字70%以上、正式な放置は40%以下とし、差も30ポイント以上あることを確認する。率にはWilson95%を併記する。全周を母数にし、未到達を外した中央値だけを目安にしない。初黒字の後の赤字への戻りと最低口座は、月別表も併せて確認する。これは今回の結果を合格にするために線を決めたものではなく、依頼書の70%の例を3方針へ展開した案である。4案の中に同時達成する案はない。

取りまとめ役への相談は、最終の正式検査表と一緒にPRコメントへまとめる。

1. 手ごたえの目安は3方針それぞれに求めるか、選んだ方針の一部で早期黒字が可能ならよいとするか。
2. 中心44の厳密な再較正と、既存の許容帯36〜52に入ることのどちらを今後の比較で維持するか。
3. 正式検査の副作用を見たうえで、坂・潜在客・費用のどの方向を次に検証するか。今回は採用しないまま、独立した論証検査も依頼したい。

## 反証と限界

【推論】月次黒字の発生は手ごたえの候補指標であり、面白さそのものの実証ではない。初黒字の後に赤字へ戻る月も表に残す。家賃なしの延長は特に、営業の力が育ったのか、支出が先送りされたのかを分けて読む必要がある。

既存の正式検査では価格の長期入れ替わりは最大150周。他の主な行は300周、予兆は札が出る町が分母、同点を除く行はその分だけ母数が減る。元の検査で少数のseedを使う補助回帰も、そのまま実施する。300周を指定したから全ての補助回帰が300周とは言わない。

本体の画面・帳簿・台本は変更していない。係数の実験を採用する場合は、家賃・返済の月、教材の金額、将来の入れ替わりや倒産の帯を改めて整合させる必要がある。別の担当による事実の判定と論証の検査は取りまとめ役へ依頼する。本報告の自己検査は独立した第三者の判定ではない。
