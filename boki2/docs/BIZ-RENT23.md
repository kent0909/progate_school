# 東京23区の1階の小さな店の家賃・保証金・造作（BIZ-RENT23）版0.1

書いた人：調査の担当（Claude、2026-10-30）。**別の担当の判定（QUALITY 2.3）と論証の検査（QUALITY 5章）の前**。
使い道：出店の地図の候補地（`js/data/tokyo23.js` の sites）に、10〜15坪の1階のラーメン屋の月の坪家賃・保証金の月数・居抜きの造作の値を置く根拠（DESIGN-STATIONMAP 4.4）。
数の出し方：`docs/analysis/rent23-land-match.py`（出力 `rent23-land-match.out.txt`）・`docs/analysis/rent23-derived.py`（出力 `rent23-derived.out.txt`）・`docs/analysis/rent23-jrei-addr.py`（日本不動産研究所の PDF から住所別の表を抜く）。資料の読了ノートは `research/notes/web/rent23/`。

## 0. 要点
1. **家賃は地価に比例しない。地価が10倍で、1階の家賃はおよそ1.8〜2.1倍**（両対数の傾き 0.25〜0.32）。独立した2つの資料（日本不動産研究所の住所別の1F平均 n=24、アットホームの小さな貸店舗の中央値 n=9）で同じ向き・近い大きさ。人通りに対しても家賃の伸びは小さい（通行量が1.5倍で家賃は約1.09倍、弾力性約0.2）。→ 式の案は「べき（指数0.25〜0.3）」。比例は資料と合わない。
2. **10〜15坪の小さな1階の水準は、都心の9エリアで坪1.6万〜3.5万円、中心は2万〜3.3万円（共益費込みの中央値、2期）**。同じ街の1Fの「平均」（大きな区画・よい通りを含む面積加重、共益費別）は坪4.25万〜6.4万（5エリア、2025年下期）、通りの相場感は坪5万〜20万超。どの数を使うかで2〜5倍違う。ゲームの基準は小さな店の中央値の側に置き、よい通りは「上」に置くのがよい。
3. **表（地価の段4×属性6＝24セル）のうち資料で埋まったのは9セル**。地価100万円/㎡未満の段、住宅地・工場倉庫の列は全部「資料なし」。23区の外れや住宅地の駅の1階の家賃は、飲食店ドットコムの駅のページにしかなく、取得の道具に403を返すので取れなかった（オーナーに頼むページとして `research/WANTED.md` に載せた）。
4. **保証金は家賃の6〜10か月**（実務の解説）。又貸しの会社の決算から割ると、東京の小さな飲食店の預り保証金は月の売上の約6.2か月分で、家賃だけで割ればそれより長い。いまの設計の6か月は下の端。**居抜きの造作は100万〜300万円が通説**で、13坪のラーメン屋の実例は工事費650万円に対し造作200万円（約3割）。
5. 損得の判断の芯：坪4.5万の1階で家賃を売上の15%に収めるには、1坪あたりの売上を中華料理店の中央値の1.6倍にする必要がある（坪6.5万なら2.3倍）。人通りの多い所は「人通りほどは家賃が高くない」ので、**客を取り込める（席・回転・人手がある）店なら得、取り込めない店なら損**になる。

読み方：
- A と B は会社・集計（面積加重の平均／中央値、共益費別／込み）・地点の合わせ方（丁目／駅の周り）がすべて違うのに、傾きはともに 0.25〜0.32 で、95%の幅は 0.16〜0.47（A）と 0.03〜0.47（B）。**どちらも 1（比例）を大きく下回る**。A の2019春も 0.32 で、時点を変えても形は同じ。
- C の傾きがほぼ0なのは、上位10駅だけで家賃の幅が4.2万〜5.0万に切られているため（家賃の側で選んだ標本）。「上位の駅どうしでは地価が4倍違っても家賃はほとんど同じ」とは言えるが、全体の傾きの推定には使わない。発表自身も上位100駅の平均が[[web:rent23:prtimes-inshoku-ekirent-2025h2|「中位レンジ（4.2万〜4.4万円台）」]]に集まると書く。
- D は地価を通らない別の道：国交省のガイドラインは天神の研究を引いて、通行量が増えると家賃が上がると推計した図を載せ（[[web:rent23:mlit-hokosha-guideline|「店舗賃料の価格形成要因」]]、通行量50%増で[[web:rent23:mlit-hokosha-guideline|「108.9」]]）、同じ都市の商業地では人の多い地点ほど地価が高いと書く（[[web:rent23:mlit-hokosha-guideline|「沿道の地価が高い傾向がある」]]）。下北沢でも家賃と歩行者の量に正の相関（[[web:rent23:jstage-shimokita-rent-gps|「positive correlation」]]、ただし大きさは抄録にない）。
- 理屈との対比：鑑定の決まりの積算法は「基礎価格に[[web:rent23:mlit-kanteikijun|「期待利回りを乗じて得た額」]]に費用を足す」なので、それだけなら家賃は地価にほぼ比例する。資料の傾き 0.25〜0.32 は、1階の小さな店の家賃が比例では決まらず、同じ基準の別の手法（[[web:rent23:mlit-kanteikijun|「収益分析法」]]＝そこで稼げる額、賃貸事例比較法＝近くの事例）の側で決まっていることと合う【推論】。地価の高い所の地価は、上の階（事務所・高い容積率）の値も背負っているので、1階の店の家賃だけが地価に比例する理由はない【推論】。

### 2.2 式の形の案
| 案 | 形 | 資料との合い方 | 判断 |
|---|---|---|---|
| 比例 | 家賃＝k×地価 | 合わない。比例なら地価72万で坪2,160円・3,560万で坪10.7万円（rent23-land-match.out.txt の末尾）と、資料の幅（約2万〜8.6万）を両端で大きく外れる | 捨てる（正しさ） |
| **べき（推し）** | 家賃＝R₀×(地価／1000万)^b、b＝0.25〜0.3 | A・B・D の3つの道で b≈0.2〜0.32。小さな店（B）なら R₀≈28,000（地価1000万で 28,443） | 採る。b は 0.25 を中心に置き、判定で揺らして試す |

## うまくいく理由
因果の鎖（人通りの多い立地が家賃の高さを越えて儲かる時）：
1. 人通り→客数：通行量と売場の面積あたりの売上に正の相関（[[web:rent23:mlit-hokosha-guideline|「床面積当たりの売上高の相関」]]、68都市、R²0.33）。人の多い所は客になりうる人が多い。
2. 人通り→家賃は弱い：家賃は人通りの約0.2乗、地価の0.25〜0.32乗（2章）。人通りが2倍でも家賃は約1.15倍（2^0.2）【推論：Dの弾力性を2倍へ延ばした】。
3. だから、**客を取り込む力（席・回転・人手・単価）が人通りに比例して伸びる店なら、家賃の売上比は下がる**。中華料理店の中央値の店（1坪あたり月約18.7万円の売上、[[web:rent23:jfc-shihyo-08a|「店舗面積3.3㎡当たり売上高」]]、[[web:rent23:jfc-shihyo-08a|「中華そば店、ぎょうざ店を含む」]]）は坪2万の家賃で売上の約11%、黒字の企業の平均（月約25.9万円/坪）なら坪3万で約12%（rent23-derived.out.txt の2節）。
4. 小さな店は1階の割増が小さい：小さな区画の中央値で1階は1階以外の1.18〜1.23倍（[[web:rent23:athome-kashitenpo-2025h2|「率にして 17.7％上回った」]]・[[web:rent23:athome-kashitenpo-2024h1|「率にして 23.1%上回った」]]）。面積加重の平均では1.22〜1.71倍（銀座が最大、rent23-derived.out.txt の5節）。**10〜15坪の店にとって、1階の路面に出る割増は大きな店ほど重くない**。
5. よい場所は空きにくく借り手が集まる：空き店舗がない理由の最多は[[web:rent23:tokyo-shotengai-2025|「立地条件が良い」]]、空き店舗がある商店街の割合は繁華街39.3%（[[web:rent23:tokyo-shotengai-2025|「繁華街（N=224）」]]）・オフィス街29.0%で、一般住宅地53.2%（[[web:rent23:tokyo-shotengai-2025|「一般住宅地（N=342）」]]）より低い。又貸しの会社も小規模・居抜き・よい立地を仕入れ（[[web:rent23:jpx-tenpoinnov-2024q1|「「好立地」「小規模」「居抜き」」]]）、駅の外れ・[[web:rent23:jpx-tenpoinnov-2024q1|「空中階の店舗物件」]]は需要が弱いと書く。

絡み（ゲームで面白さになる所）：家賃（地価で緩やかに上がる）×客数（人通りでほぼ比例に上がる）×取り込む力（席・人・回転＝プレイヤーの判断）×ライバル（人の多い所にひしめく）。**前の2つの伸び方の差が「よい場所の得」を作り、後ろの2つがその得を食う**。取り込む力が足りないままよい場所に出ると、家賃は払うのに客を取りこぼす。

## うまくいかない理由
1. 一等地の1階の家賃は売上を食う：中央値の店（月18.7万円/坪）が坪4.5万の1階に入れば家賃は売上の約24%、坪6.5万で約35%、坪10万で約53%（rent23-derived.out.txt の2節）。家賃を売上の15%に収めるには、坪4.5万で中央値の1.6倍、坪6.5万で2.3倍、坪10万で3.6倍の1坪あたりの売上が要る（同3節）。
2. 撤退の数：2025年度のラーメン店の倒産は57件（[[web:rent23:tsr-ramen-tosan-2025fy|「過去2番目の57件」]]）、原因の8割は[[web:rent23:tsr-ramen-tosan-2025fy|「販売不振の46件」]]、地区は[[web:rent23:tsr-ramen-tosan-2025fy|「関東が25件」]]が最多で、記事は[[web:rent23:tsr-ramen-tosan-2025fy|「競争の激しい都市部で倒産が目立った」]]と書く。**ただし家賃を原因に挙げた数はない**。「一等地で家賃負けして撤退した店の数」は、どの資料にも見つからなかった（反証と限界）。
3. 家賃が高すぎる場所は空いたまま：空き店舗が埋まらない理由に「家賃が高い」が28.0%（[[web:rent23:tokyo-shotengai-2025|「家賃が高い」]]）。家主の事情・老朽化（各39.0%）より少ないが、3割の商店街で家賃が客の取れる額に見合っていないと見られている。
4. 居抜きの影：前の店の悪い評判が残りうる（[[web:rent23:mf-inuki-kaigyo|「前店舗のイメージが残る可能性」]]）。居抜きは安い（[[web:rent23:mf-inuki-kaigyo|「スケルトン比で半額程度に圧縮」]]）が、閉めた店の跡に入ることでもある。
5. 値のぶれ：同じエリアの小さな区画の中央値が半期で−31%〜＋23%動く（rent23-derived.out.txt の8節）。資料Aも銀座で[[web:rent23:reinet-tenpo-2026spring|「優良物件はゼロに等しく」]]、募集の平均が下がって見えると書く。募集の値で場所の家賃を決めると、ぶれを場所の差と取り違える。

## ゲームへの写し方
### 最小
- 候補地の月の坪家賃＝R₀×(地価／1000万円)^0.25 × 属性の倍率 × 歩く距離の倍率。R₀＝28,000円（資料Bの式の地価1000万の値 28,443 を丸め）。地価72万で約1.5万、153万で約1.8万、448万で約2.3万、1,560万で約3.2万（1.1の表のBの列）。
- 「上」の場所（大きな駅の駅前・繁華街の通り）だけは、資料Aの値（坪4.5万〜8万）に寄せる倍率を置く【推論：どの候補地を「よい通り」とするかの資料はない】。
- 属性の倍率：資料で比べられるのは繁華街・商業地・商店街の3つで、同じ地価の段の中の差は資料Aで商業地を1として0.9〜1.2倍ほど（300万〜1000万の段：商業地の中40,185・商店街の2点の平均47,332〔1.18〕・繁華街の2点の平均41,250〔1.03〕。1000万以上の段：繁華街の中54,757〔0.86〕・商店街1点70,277〔1.10〕、商業地の中63,666。rent23-land-match.out.txt）。オフィス街・住宅地・工場倉庫は資料なしで、置くなら【推論】と書く。
- 保証金6か月（今のまま、下の端）。造作は内装の工事費の約3割・上限300万円・0円もありうる。

### 大胆
- 家賃を契約のときに決め、更新（2年ごとなど）でだけ動かす（鑑定の決まりの継続賃料は、今の家賃を出発点に[[web:rent23:mlit-kanteikijun|「スライド法」]]などで少しずつ動かす）。新しく借りる店の家賃は、その時の人通り・空き・ライバルで動く。
- 空きの動き：属性ごとの空きやすさ（繁華街・オフィス街は空きにくく、住宅地・一般の商業地は空きやすい、東京都の調査の割合）で空きが出て、空いた区画の家賃は人通り×(1−空室)で決まる。飲食店は空き店舗の前の業種の最多（22.7%）で、居抜きの物件として次の店に回る（[[web:rent23:tokyo-shotengai-2025|「空き店舗の以前の業種」]]）。
- 家賃が客数に見合わない区画は空いたまま（「家賃が高い」で埋まらない28%）。プレイヤーは空いたままの区画を値下げの交渉の材料にできる。
- 半期ごとの募集の値のぶれ（±20〜30%）を「掘り出し物」「割高な募集」として見せる。

## 反証と限界
- **一等地で家賃負けして撤退した店の数は、見つからなかった**。東京商工リサーチは原因を販売不振とまとめ、家賃を分けない。否定側の問いは「家賃が売上を食う計算」（JFC の売上×資料の家賃）と「家賃が高くて埋まらない空き店舗28%」で間接に答えただけ。
- **低い段と住宅地・工場の列が空**：23区の外れや住宅地の駅の1階の家賃は、取得の道具では取れなかった（飲食店ドットコムの駅ページは403、アットホームの調査は都心の9エリアだけ）。候補地の74%（地価300万未満）は、式を資料の範囲の外へ延ばした【推論】になる。延ばした式の下の端（72万で約1.5万）は、地方の郊外の道沿いの坪1.25万円より高く、矛盾はしないが確かめてはいない。
- **傾きの幅は広い**：A の95%の幅は 0.16〜0.47、B は 0.03〜0.47。B は半期だけで見ると 0.17〜0.32 と動く。「比例ではない」は確かだが、0.25 か 0.4 かは決められない。
- 資料Aの丁目の値は件数（3年で5〜240件）が丁目ごとに違い、件数の少ない丁目はぶれる（銀座6丁目は2025下期に1件で12.9万）。地価の地点は1丁目に1〜8点で、丁目を代表するとは限らない（銀座4丁目は地価5,135万なのに家賃は5.1万：資料はよい物件が少ないためと書く）。
- 募集の値で成約ではない（すべての資料）。共益費の扱いが資料Aと資料Bで逆。
- 天神の弾力性（D）は福岡の研究を国交省の図から読んだ又引きで、原論文は読んでいない。
- 地価との相関は、地価が人通り・容積率・ブランドの集まりなどをまとめて表す結果で、地価が家賃を決める因果ではない（ゲームで地価を家賃の入力に使うのは代わりの物として）。
