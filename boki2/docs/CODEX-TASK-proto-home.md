1. **着手の知らせ**：PR を開いたらすぐ、PR #8 にコメント「着手：<この依頼書の名前>。PR #<番号> を開いた。依頼書を全文読んだ」を書く
2. **読了報告（受領）**：取りまとめ役のコメントを受け取ったら、まず**あなたの PR** に「受領：<コメントID>。読んだ。次にすること：<1行>」を返す（同じコメントに依頼が複数あれば、どれを受けたかも）。PR #8 に来たコメントなら PR #8 にも同じ1行を返す
3. **送ったら待つ**：質問・相談・報告を送ったら、**取りまとめ役の返事を待つ**。待つ間は、返事に左右されない部分の作業を続ける。左右されて進められないときは、あなたの PR に「待ち：<コメントID> への返事」と書いて止まる（黙って止まらない・勝手に決めて進めない）
4. **返事を確かめる**：作業の区切りごと（目安30分ごと）に、あなたの PR と PR #8 の**全部の**コメントを見て、取りまとめ役の新しいコメントがないか確かめる（末尾だけ見ない）
5. **催促**：送ってから1時間たっても返事がなければ、PR #8 に「催促：PR #<番号> のコメント <ID> への返事を待っています。待っている内容：<1行>」と書く。さらに1時間返事がなければ、もう一度催促し、オーナーにも分かるように同じ文を書く
6. **終わりの知らせ**：作業を終えたら、PR #8 に「完了：PR #<番号>。依頼の対応表とやっていないことを本文に書いた。確かめをお願いします」と書く
