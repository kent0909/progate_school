## 0. 要点（ここだけ読めば設計に入れる）

1. **ラーメンの集客の芯は「お金で買う露出」ではなく「頼まない露出の連鎖」**。ラーメンはテレビ・雑誌・ブログが他の料理より桁違いに取り上げ、費用をかけずに宣伝してもらえる業態だと、ラーメンのプロデューサー自身が言う [[web:bizmkt:r5-mktr-advertimes-ramenpr|「一億総ラーメン評論家」]]。メディアはブロガー（熱心なファン）の情報を見て店を選び [[web:bizmkt:r5-mktr-advertimes-ramenpr|「まずはブロガーのサーチにかかり」]]、番組の制作会社はネット検索で取材先を探す [[web:bizmkt:r5-mktr-mynavi-gyoretsu|「子飼いの制作会社」]]。最大手の動画の作り手は個人店の案件を受けない [[web:bizmkt:r5-mktr-bunshun-susuru2#p4|「特に個人店は絶対に受けない」]]。→ プレイヤーが**お金で直接買えない露出**が大きく、それは評判・グルメサイトの順位・発信の見つかりやすさという**状態**で確率が上がる。打ち手は「露出を買う」より「露出が起きる確率を上げる」の形が多い。
2. **当たりの大きさは裾が重く、時間の形が打ち手で違う**。米国のテレビ番組に出た店の店主の話では、1か月後に売上・客数が500%増の店、売上60%増の店、放送直後は何も起きず数年かけて2倍の店、辺鄙で放送の前後で伸び方が同じだった店が並ぶ [[web:bizmkt:r5-mktr-tcbmag-ddd|「up 500 percent」]] [[web:bizmkt:r5-mktr-tcbmag-ddd|「Nothing at all.」]]。再放送のたびに客が来る（年金のように効く）[[web:bizmkt:r5-mktr-tcbmag-ddd|「functions as an annuity」]]。札幌のラーメン店は取材のすっぽかしを正直に投稿したら2日で2,000万回表示され、翌日の売上が通常の約5倍になった [[web:bizmkt:r5-mktr-jprime-ginparo#p2|「売り上げは通常の5倍ほど」]]。→ 確率表の「大当たり10%」ではなく、**大きさの分布（多くは小さく、まれに桁違い）と、効くまで・残る長さの曲線**で持つ。
3. **当たりはキャパと近所で裏返る**。ミシュランの一つ星を取った9席の店は約2週間後に、人手不足と行列への近所の苦情で2号店を休業した [[web:bizmkt:r5-mktr-jcast-tsuta|「人手不足もありますが、苦情も多く」]]。行列の苦情で閉店・移転した名店はほかにもある [[web:bizmkt:r5-mktr-note-fututuka|「あまりの行列の長さ」]]。テレビに出た店では3時間並ばれて常連が入れない [[web:bizmkt:r5-mktr-tcbmag-ddd|「bad for your regulars」]]。最大手の動画の作り手は、老夫婦の店では客が押し寄せるのを避けて動画にしないことがある [[web:bizmkt:r5-mktr-bunshun-susuru2#p3|「老夫婦がおふたりで切り盛り」]]。→ 「行列→評判が上がる」と「行列→苦情・常連離れ→評判が下がる」の板挟みは、資料で両方向が支えられる。
4. **グルメサイトの点数は、まさに「算法で動き一部しか見えない状態」**。食べログの点数は単純平均ではなく、経験の多い投稿者の影響度で重み付けし、口コミが2〜3件では上がらず、席数が少ない・営業時間が短い店の不利を補う変数があり、月2回だけ更新され、算法の見直しで店が何もしなくても上下する。3.50以上は上位約3% [[web:bizmkt:r5-mktr-tabelog-score|「全体のTOP約3%」]]。有料プラン（月1万〜10万円）で買えるのは検索の並び順で点数ではない [[web:bizmkt:r5-mktr-kakaku-q1fy26|「25,000円 / 50,000円」]] [[web:bizmkt:r5-mktr-tabelog-score|「「標準順」において優先的に表示」]]。
5. **他人の選択が見えると客は動く（行列・順位の仕組みの研究上の裏づけ）**。北京の料理店の無作為の実験で、人気上位5品を「人気順位」として示すとその5品の注文が約13〜18%増え、ただ目立たせただけでは増えず、常連ほど影響が小さかった [[web:bizmkt:r5-mktr-cai-observational|「almost 18% increase」]]。口コミの星が一つ上がると個人店の売上が5〜9%増える（シアトル、チェーンには効かない）[[web:bizmgmt:r4-mgmt-luca-yelp|「5-9percentincrease」]]。格付けは客数より**値段を上げる余地**に大きく効く（ニューヨーク、掲載で価格約37%）[[web:bizmkt:r5-mktr-aawe-michelin|「37% from 2004 to 2007」]]。
6. **ラーメンで CPA／LTV を計算し直すと、チラシは「1回では赤字、常連が付けばとんとん」の境目に来る**（レモネードでは常連が付いても赤字だった）。8章。
7. **イベント出店は売上より資金繰りの打ち手**。主催者が「2,000杯は出る」と言ったフェスで実際は800〜900杯、仕込みのロスが出て、入金は2か月後で給料の支払いを待ってもらった店主の話 [[web:bizmkt:r5-mktr-note-soranoiro|「出たのは800～900杯」]] [[web:bizmkt:r5-mktr-note-soranoiro|「売上の入金がイベントから2か月後」]]。
8. **DESIGN-RAMEN で直すべき数字**：e.2 の flyer（若い町で空振り+20 を外す）・sns（バズ3%の点を分布に）・influencer（PRなし発覚30%は根拠なし、大物は頼めない形に）・line（呼び戻し9%は (c) に下げる）・coupon、d.2 の参照価格の更新 0.25（上限値）、d.4 のテレビ ×2〜3（分布と時間の形へ）・ランキング、d.6 の炎上の客数 −5〜−20%（分母の取り違え）。11章に行番号つきで並べる。

## 問いの設計

### 問うたこと
- **肯定側**：ラーメン店で実際に客を増やした集客は何で、なぜ効いたのか（因果の鎖で）。頼まない露出（評論家・賞・テレビ・大物の動画）とお金で買う露出（案件・有料掲載・広告・チラシ）は、効き方・残り方がどう違うか。行列・限定麺・写真映え・コラボ・施設やフェスへの出店は、何と何（評判・キャパ・告知・食数・客層・立地・季節）が絡むから効くのか。
- **否定側**：効かなかった・逆効果だった例（キャパ超え、近所の苦情、常連離れ、取材の空振り、フェスの見込み外れ、発信の口調の炎上、報復の低評価、撮影の迷惑、名店の劣化、味は良いのに知られない）。
- **ゲームへの写し方**：最小（打ち手ごとの分岐の表）と大胆（注意・評判・行列・グルメサイトの点数を状態として持ち、打ち手はそこに働く）の両方。各打ち手を「誰に・何を・いくら・いつ・どう測る」に分解し、費用の幅・当たりの確率・当たったときの大きさ・効くまでの日数・残る長さ・事故を幅で。
- **数字の作り直し**：CPA／LTV をラーメンの値段と原価率で。DESIGN-RAMEN の数字の差し替え（行番号つき）。

### 1.3 置き値の筋道（[推] のマスのうち、ゲームの初期値に使うもの）

資料がない所は「資料なし」と書いた。ゲームに数字が要る所だけ、次の筋で置く【推論】。

- **頼まない露出の確率**（R1・R2・R13・R14）：評判 R とグルメサイトの順位とネットで見つかりやすさ（G6・G4）の関数にする。根拠は、作り手がグルメサイトの上位を見て店を選ぶこと [作]、制作会社がネット検索で取材先を探すこと [実]、メディアがブロガーを見ること [実]。確率の大きさは資料がないので、1年に1回起きる程度から評判が最上位で数回、の幅【推論】。
- **当たりの大きさの分布**（R13・R14・G4）：テレビの事例（変化なし／+60%／+500%／数年で2倍）[事] と、正直な投稿が5倍の日を作った例 [事] から、「多くは小さく、まれに数倍」の裾の重い分布（例：対数正規。中央値で+20%、上位5%で+200%以上）【推論】。研究の裏づけとして、ネットの拡散の大きさは極端に偏るという研究（Goel らの「構造的な拡散」）は今回読んでいない（やっていないこと）。
- **時間の形**：テレビは放送の週に山、1か月で大きく下がり、再放送のたびに小さな山 [事]。チラシは当日〜2週間 [宣]。賞・格付けは年単位 [推]。限定は当日だけ【推論】。
- **キャパと苦情**：行列が席数×回転の上限を越えた分は、近所の苦情の重みと常連の離脱に入る。住宅地・集合住宅の店で重い（蔦はマンションの1階）[事]。

## 2. うまくいく理由（因果の鎖）

鎖ごとに、資料で支えられた段と【推論】の段を分けて書く。

1. **こだわりの見え方 → 熱心なファンの発信 → メディアの取材 → 行列 → 「行列＝おいしい」 → 通りがかりの客**。メディアはブロガーを見て店を選び [[web:bizmkt:r5-mktr-advertimes-ramenpr|「まずはブロガーのサーチにかかり」]]、制作会社はネット検索で取材先を探す [[web:bizmkt:r5-mktr-mynavi-gyoretsu|「「検索結果」を事実とする前提」]]。行列は最も効く看板と業界の人は言う [実]。他人の選択を見ると不慣れな客ほど同じものを選ぶ [[web:bizmkt:r5-mktr-cai-observational|「6 or more times」]] [研]。→ 何と何が絡むか：①発信が見つかること（G4・G6）②品質（取材の後に残るのは実力の分だけ [実]）③キャパ（行列を作れる席数と回転）。
2. **賞・格付け → 客の殺到 → 値上げの余地**。星の後に世界中から客が来て [事]、その店は移転を機に1杯1,300〜3,550円に上げ「1000円の壁」を越えた [[web:bizmkt:r5-mktr-nippon-tsuta|「最も高いメニューはなんと3550円」]] [事]。ニューヨークでも格付けで価格が約37〜88%上がった [研]。→ 評判が値段の弾力性を下げる（DESIGN-RAMEN d.2 の R≧4.5 で ×0.7 の向きと合う）。
3. **限定麺 → 映え → ネット・テレビ → 目当ての客 → 定番化**。渋谷の店は周りに倣って期間限定で青いラーメンを出し、女性と訪日客が来て、ネットとテレビで広まり、目当ての客が大半になって定番にした [[web:bizmkt:r5-mktr-jprime-blue#p2|「期間限定で作ってみました」]] [実]。→ 絡むもの：①立地（渋谷＝訪日客の多い町）②店構え（ガラス張り）③定番の実力（評論家の言う「定番がおいしいから変わり種もおいしい」[実]）。
4. **施設・フェス・催事 → 地方の店が首都圏・全国に知られる**。1994年に福岡の1店だった店がラーメン博物館に出て関東に知られ、翌年東京に出店、のちに世界へ [[web:bizmkt:r5-mktr-digitalpr-raohaku|「1994年当時は福岡の本店1店舗のみ」]] [一]。米国のラーメンのイベントの反響で海外出店を決めた例（BIZ-RAMEN が読んだ JETRO の資料）。→ 遠方の客と出会う場として効く。ただし売上と現金の時期がずれる（鎖 3-4）。
5. **頼まない紹介（テレビ・大物の動画）→ 遠方からの「目的地」になる → 再放送・動画で長い尾**。テレビに出た店は、遠方・海外から客が来る目的地になり、再放送のたびに山が来た [[web:bizmkt:r5-mktr-tcbmag-ddd|「We are a destination.」]] [事]。通販を持つ店は全国の注文を取り込めた [事]。→ 絡むもの：①ジャンル（バーベキュー・二郎系のように熱心なファンのいる系統ほど大きい [事][作]）②立地（辺鄙だと効かなかった [事]）③通販・持ち帰りの受け皿。
6. **正直な発信 → 同情・共感 → 桁違いの拡散 → 来店**。取材のすっぽかしを責めずに材料の使い道を相談した投稿が2日で2,000万回表示、翌日は売上約5倍 [事]。→ 口調と中身（責めない・困っていると正直に）が符号を決める（鎖 3-3 の二郎府中店・つじ田と対）。
7. **開店前の注目 → 準備の発信・近隣の挨拶・プレオープン → 初回の来店 → 優良客化**。公的な手引きは、開店前は近所が気にしている時期で、チラシが「どんな店か」を詳しく見てもらえると書く [一]。開店直後は優良客（2割が8割の売上）を作るのが大事とする [[web:bizmkt:r5-mktr-jnet21-kaigyo928|「8：2の法則や働きありの法則」]] [一]。
8. **口コミの動機は「知っている優越感」**。初回の満足→再来店→人を誘う、口コミは「おいしい店を知っている」という優越感を満たす行為 [[web:bizmkt:r5-mktr-jnet21-hitmenu|「「私はおいしいお店を知っている」という優越感」]] [一]。→ まだ知られていない時期ほど口コミの動機が強い【推論】。

## 3. うまくいかない理由（因果の鎖）

1. **当たり → キャパ超え・近所の苦情 → 営業の縮小**。星の約2週間後、人手不足と苦情で2号店を休業、行列を道に出さないよう求められ、整理券でも苦情の電話が毎日続いた [[web:bizmkt:r5-mktr-jcast-tsuta|「行列客が道路に出ないよう店舗内で管理」]] [事]。行列の苦情で一度閉店し移転した名店 [声]。→ 住宅地・集合住宅・席の少ない店で重い。
2. **当たり → 常連が入れない → 常連の離れ**。3時間の行列で常連が入れないことを店主が気に病む [事]。【推論】常連は値段の弾力性が小さく天気に強い（DESIGN-RAMEN d.2）ので、常連が離れると当たりが過ぎた後の底が下がる。
3. **店の発信の口調 → 炎上／報復の低評価**。店主がマナーを訴えた投稿の翌日に星1が6件 [事]。店主が自分の動画で客の食べ方を揶揄して炎上、すぐ謝罪 [事]。口コミに強い言葉で返信して何度か炎上した店は評価が真っ二つ [事]。（二郎府中店の「どうぞご自由に」の件は記事の本文を照合できず、根拠に使わない。）
4. **フェス・イベント → 見込みの外れ → 仕込みのロス＋入金の遅れ → 資金の詰まり**。見込み2,000杯が800〜900杯、入金は2か月後、給料と支払いを待ってもらった [実]。→ 打ち手の失敗が現金の失敗になる（資金の棚の判断：入金の条件を確かめる・仕込む量）。
5. **取材の空振り → 仕込みの廃棄**。最大8kgの大盛りの材料を用意したが撮影に来なかった [事]（この例は投稿が同情を集めて逆転した）。米国の店では撮影の休業と廃棄で約1.2〜1.5万ドル [事]。
6. **露出が効かない立地・知られない店**。辺鄙な立地では放送の前後で伸び方が同じ [[web:bizmkt:r5-mktr-tcbmag-ddd|「roughly the same rate」]] [事]。味は良いが人の流れから外れた立地・発信が X だけ・現金のみ・ワンオペの家系の店が1年半で閉店 [[web:bizmkt:r5-mktr-note-calmcougar|「決済手段は現金のみ。情報発信はXのみ」]] [実]。
7. **評判の維持を怠る → 周りの水準の上昇で相対的に落ちる**。20年続く元行列店が「時間が止まっている」と感じられ、1杯1,500円が珍しくない今、客は外れの日を許さない [声]。
8. **行列で来た客の期待外れ**。45分並んで「並ぶ価値がない」と前の客も言った [声]。【推論】行列で来た客は期待が高く、体験との差で評判が下がりやすい。
9. **無名の発信者の飛び込み撮影 → ほかの客の体験の低下**。営業中にいきなり撮影を始める YouTuber の来店を断った京都の店に、客の側からも「食べている時に撮られて落ち着かなかった」という声 [[web:bizmkt:r5-mktr-soranews-ytban|「filming fee」]] [声]。
10. **案件の効果を測れない**。仲介業者の事例集でさえ効果の証拠はいいねの数で、来店の数字がない [宣]。→ 測る仕組み（合言葉・投稿を見せたら1杯無料）を入れないと「空振りかどうかも分からない」。

## 4. 打ち手の組み合わせ（相乗・食い合い・逓減・順番）の因果の鎖

### 10.1 最小の写し方（今の e.1 の形で表を差し替える）

### 10.2 大胆な写し方（状態を持ち、打ち手は状態に働く）
状態を5つ持つ【推論：資料の仕組みを状態に写した設計案】：
1. **知られている度合い（認知）A**：打ち手ごとに「入り方」と「残り方」が違う（テレビは急に入って再放送で小さく戻る、チラシは2週間、限定は当日、賞は年単位）。
2. **グルメサイトの点数 S（客には見える、算法はプレイヤーに一部しか見えない）**：口コミの数が溜まるまで上がらず [一]、月2回だけ更新され [一]、影響度の高い投稿者の評価が重く [一]、年に1回ほど「算法の見直し」の札で店と無関係に上下する [一]。席数が少ない・営業時間の短い店を補う変数がある [一]。有料プランは S を動かさず、一覧の並び順（見つけられやすさ）だけを動かす [一]。
3. **評判 R（品質の感じ方）**：今の d.1 のまま。ただし期待との差で動く（行列で来た客は期待が高い【推論】）。
4. **行列 Q（目に見える待ち）**：席×回転を越えた需要。Q は通りがかりの不慣れな客を呼び（他人の選択を見て選ぶ [研]）、常連と「並ばない客」（V27・V47・V53）を遠ざけ、近所の苦情の重みを上げる（住宅地・集合住宅で重い [事]）。整理券・記帳・呼び出しは Q を「見えない待ち」に変える（呼ぶ力は下がり、苦情も下がる【推論】）。
5. **発信の見つかりやすさ D**：地図・情報の正しさ（G6）、SNS の継続（G4）、ブロガーに見つかるこだわりの見え方（P7）。D が高いほど、制作会社・作り手・評論家の「頼まない露出」の札の重みが上がる [実][作]。

打ち手はこの5つに働き、客数は今の d.2 の式（魅力度にA・R・待ち）で決まる。頼まない露出の札は「D×R×ジャンル」で重みが変わる（二郎系・家系は動画の当たりが大きい [作]）。当たりの大きさは裾の重い分布から引く（1.3）。
