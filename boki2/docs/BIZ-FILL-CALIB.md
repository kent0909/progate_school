## 仕分け（186か所を1か所ずつ）

### 区分の定義と、計算・設計から外す基準

`fill-calib-reclass-v2.out.md` の頭に同じ文を出している。

- **埋まった**：資料で値か向きが置けた（区分が上がる、または元の推論を原文で確かめた・否定した）
- **一部**：一部の値・条件つきで置けた、または元の推論の一部だけを原文で確かめた
- **埋まらず（探した）**：今回、取得記録か検索の記録に残る探し方で探し、資料が無かった
- **埋まらず（規約）**：資料はあるが規約で取らない。**埋まらず（探していない）**：探していない（理由を書く）
- **引き継ぎ**：並行の担当の範囲で、引き継ぎ先の版でその行が扱われたことを確かめたもの。扱われていなかった行は自分で探して上の区分にした
- **計算**：(a) の値の按分・積・割り算・複利で、式が元の行にあるもの（記事自身が書く前年比からの割り戻しを含む）。**因果・定義・前提を主張する行は計算にしない**（版1は C009〜C011・C072・C077 を計算に入れていた）
- **設計**：設計の案・推し・見出しの推論、作業（検査の実装など）の未達で、資料で値を置く種類でないもの。**手元の原文で確かめられる事実の主張は設計にしない**（版1は C127・C132・C140・C145 を設計に入れていた）

## うまくいく理由（因果の鎖）

1. **立地 → 来る客の顔ぶれ（家族か単身・勤め人か）→ 曜日の形と、店の大きさの選び方 → 1店の売上の水準。** 家族の外食は土日に月〜木の2.2〜2.5倍、単身世帯は1.44（2019年）で、客の混ざりで店の曜日の形が変わる（W1）。1店の売上は立地の型で1.79倍違うが、そのうち74%は店の大きさ（従業者の数）で、1人あたりは1.23倍（CENSUS）。**同じ店を移したときの売上の差は1.2〜1.5倍の幅**（1人あたり1.23倍、幸楽苑の県別1.49倍・四分位1.24倍）。ゲームでは「立地で客の顔ぶれと曜日の形が変わり、大きな店を建てられる立地で売上が伸びる」を、「同じ店でも立地で売上が1.8倍」とは書かない。曜日の形の立地の差そのものの資料は無い【推論】。
2. **大手の本部の FC の条件は、加盟金が高いほど開業支援が厚く、加盟店が残りやすい。** 加盟金は0〜500万円に散り（FC）、加盟金が多額だと加盟店の廃業率が低い（2006年の研究）。丸源のロイヤリティは店数で下がる（5.00%→3.40%、10店目以降は条件で別の料率）ので、大きな加盟企業ほど得になる。ゲームでは本部を選ぶ画面で「加盟金・ロイヤリティ・支援の厚さ・潰れにくさ」を並べる材料。
3. **工場を持つ → 原価の8割の材料を集中して買う → 原価率が下がる。ただし工場が1か所だと事故で多くの店が止まる。** ギフトは仕入量の増加で仕入条件が良くなったと書き、上場チェーンの原価率は30%前後、公庫の中華料理店の中央値は約34%（差の内訳は資料に無い）。幸楽苑は台風19号で郡山工場が止まり、東北・北関東・甲信越の店が約1か月休んだ（PLANT）。
4. **急拡大を、借入でなく利益と増資で賄う → 利益率を保ったまま伸びる。** ギフトは売上が年+24〜30%の3年に経常利益率9.6〜11.4%を保ち、上場の年に純資産が7.8億→26.8億円に増え、借入は月商の1.06〜1.53か月だった（GIFT・DEBT）。肯定側の問い（何が絡むから倒れずに伸びるか）への、1社の答え。ゲームでは「上場で増資する道」の材料（1社の例、因果の確かめはない）。

## うまくいかない理由（因果の鎖）

1. **外からの大きな衝撃 → 営業赤字が普通になり、店の差も開く → 借入が月商の倍に増える。** 公庫の中華料理店の衝撃の年は営業利益率の中央値 −12.8%・−12.2%、標準偏差25.3・16.0、借入は月商の11.5・11.7か月（JFC）。経常との差（約14ポイント）は営業外の収入で埋まった【推論：協力金などの中身は表に無い】。借入÷月商の倍には売上の落ち込み（3.3㎡売上0.706倍）も含まれる。
2. **急な出店を借入で賄う → 借入が月商の数か月分に積み上がる → 利益率が落ちる年に詰まる。** 山岡家は急な出店の直後の2012年1月末に借入が推計4.63か月（負債の総額で5.82）、その後に返済して2016年1月末に2.05か月（DEBT）。幸楽苑は業績が悪い年に2.0〜2.9か月で、継続企業の前提の注記が出た。小さな会社の借入の分布では8か月は平時の平均より上の側で、倒産の事例（弁当・惣菜の店）は8.2か月以上。**ライバルが借入で倒れる筋の置き値として、8か月は支えがある**（上場の値ではなく公庫の分布と倒産の事例の範囲）。非上場の急拡大の会社の借入の分布そのものは無い。
3. **他社の FC に入って業態を変える → 本部の崩れや自社の危機と重なると数年で畳む。** 幸楽苑の他業態は5年で38店→2店（KOURAKU）。いきなり！ステーキは本部の崩れ、2021〜2023年は幸楽苑自身の赤字の時期と重なり、「業態が合わない」と分けられない（1社の例）。
4. **猛暑の年 → 夏の山が削られる。** 夏は暦で山（夏休み・お盆）で、猛暑の年は客が減った記録が1社ある（SUMMER）。量は資料に無い。

版1のうまくいかない理由3「急拡大→利益率が下がる（ギフトはコロナの年に…）」は消した（Z55）。ギフトは急拡大と高い利益率が両立した例で、山岡家（X1：100店を超える段で利益率が落ちた）とは逆の例。違いの理由は資料に無い。版1のうまくいく理由2「規模→借入が軽い・ばらつきが小さい→衝撃に耐える」も、上場の生き残りと公庫の融資先を並べた相関で、大きな会社も衝撃の年に借入が増えた（幸楽苑2.85か月・自己資本比率7.75%）ので、因果の鎖からは外した（Z51）。
