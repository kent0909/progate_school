# 推論の補填：BIZ-CALIB と BIZ-SIMDESIGN（BIZ-FILL-CALIB）

版：1.0（2026-10-22）。書き手：推論の補填の担当。読み手：BIZ-CALIB・BIZ-SIMDESIGN の判定役と論証検査役、DESIGN-RAMEN の数字を決める設計者、取りまとめ役。
対象：BIZ-CALIB.md **版0.2**（git 37b2376。`(c)` 43/115＝37.4%）と BIZ-SIMDESIGN.md **版0.2**（git d3bfa93）の【推論】【資料なし】【要確認】と「やっていないこと」の未達、および事実の判定役（`docs/audit/BIZ-CALIB-v02-audit.md` 3.6）が挙げた「手元で答えられた・取れた可能性が高い」6行。**元の2つの報告は書き換えていない**。行番号は版0.2のもの（作業中に BIZ-CALIB は並行の担当によって版0.3になったが、この報告は依頼の時点の版0.2を対象にし、スクリプトも git の版を固定して読む）。

担当の境界：季節を4つ（気温・暦・地域の行事・立地）に分ける件と地域の採算（G3 の分岐点の計算）は **BIZ-FILL-RAMEN** の担当の成果を引く前提で、ここでは計算しない（「引き継ぎ」）。ただし、判定役が挙げた「猛暑で客が減るという手元の記述」と、地域の採算の入力になる事実（都市別の価格・名古屋大阪の賃料・立地の型ごとの1店の売上）は、原文に当たってここに書いた。

## 読み方

- 結果の行の形：**元の報告・行／元の値と区分／見つかった根拠 `[[src:coll:doc|「語句」]]`／判定（支持・修正・否定・埋まらず・引き継ぎ）／新しい値の分布と区分**。
- 区分は BIZ-CALIB と同じ：(a) 原文で確かめた値（対象がずれたら (a) ではない）、(b) (a) からの計算・当てはめ（式を見せる）、(c) 資料がない仮の値。**(c) から計算した値は (b) にしない**。**1社・1ブランドの値は、その会社の値として書き、業界の値とは書かない**。
- 【推論】は資料にない推論・見積もり。印のない文は「原文にそう書いてある」の意味。
- 数はすべてスクリプトで数えた（`docs/analysis/`）：対象の一覧 `fill-targets-calib.py`→`fill-targets-calib.tsv`、全件の結果 `fill-calib-status.py`→`fill-results-calib.tsv`・`fill-calib-status.out.txt`、区分の数え直し `fill-calib-recount.py`→`.out.md`、資料の内訳 `fill-calib-sources.py`→`.out.md`、各項目の計算 `fill-calib-youbi.py`・`fill-calib-jfc4.py`・`fill-calib-census.py`・`fill-calib-price.py`・`fill-calib-debt.py`（出力は同じ名の `.out.*`）。
- Excel は道具で読んだ：`tools/sheet-text.py`（xlsx は openpyxl、旧形式の xls は LibreOffice で変換してから）を足し、`tools/research-check.js` が中身が表計算のファイル（拡張子によらず）の語句を照合できるようにした。

## 0. 要点

1. **公庫の2021・2023年度の表は取れた**（国立国会図書館 WARP の保存版。公庫のサイトは今も503で、ファイル名も版0.2の推測と違った：2021年度は `sme_findings2_202302_08a`、2023年度は名を戻した `sme_findings2_08a` の2024年時点の版）。4つの調査年度を並べると、BIZ-CALIB 0章1の「年ごとの平均の動き（0.2ポイント）より店ごとの差が35倍大きい」は**平時の2年度（2019・2025）だけの比べ**だった。コロナの年度は中華料理店の営業利益率の**中央値が −12.8%（2021年度）・−12.2%（2023年度）**、平均 −21.4%・−15.8%、損益分岐点比率の中央値121.5%・119.4%、借入金は月商の11.5・11.7か月。外からの大きな衝撃の年は、年の動き（約20ポイント）が平時の店の差（標準偏差7前後）より大きい（**否定**）。規模でばらつきが縮む形は衝撃の年も同じ（**支持**）。
2. **曜日の需要の倍率が資料で置ける**（家計調査の日別支出12か月を曜日に並べ直した）。家計の中華そば（外食）の支出は、その月の1日平均を1として **月〜木 0.65・金 0.84・土 1.61・日 1.59・祝日 1.57・お盆 1.42・年末年始 1.35**。DESIGN の「週末 ×1.3〜1.5」は向きは合うが弱い（**修正**、M16 (c)→(b)）。二人以上の世帯の家計で、単身者と小遣い払いの平日の昼食が入らない向きの偏りがあるので、家族客の多い立地の倍率として使う。
3. **FC の加盟の条件は上場本部の有報に載っていた**：丸源ラーメン（物語コーポレーション）は加盟金 1店目500万円・保証金400万円・ロイヤルティ売上の5.00%（店数とともに下がり30店目から3.40%）、幸楽苑は加盟金300万円・保証金100万円・ロイヤリティ4.5%か5%。ギフトの豚山などは「加盟金一定額・ロイヤリティ毎月一定額」（定額）、一風堂は「加盟金と売上の一定の料率」。版0.1・0.2の「200万円」（比較記事）より正式な値で、**修正**（R5 (c)→(a)、2ブランドの値）。
4. **立地で1店の売上が約1.8倍違う**（経済センサス2021年の立地環境特性編、中華料理店76B）：ロードサイド型の商業集積 年4,365万円・駅周辺型4,006万円・オフィス街3,282万円・住宅地区2,668万円・その他地区2,436万円。事業所数は2012年35,161（7623＋7624＋762A）→2016年39,084→2021年40,852（76B）と**増えている**。ラーメン店（細分類）は2012→2016年に16,960→18,041（+6.4%）、中華料理店（細分類）は17,207→14,704（−14.5%）。
5. **全国の食中毒の表は手元にあった**（xlsx）。2025年は1,172件・患者24,727人、原因施設が分かった985件のうち飲食店が658件・1件あたり約17.8人。前年・前々年は1,037件・1,021件で、患者は年で約2倍動く（M56 の重さの分布を全国の値で置ける）。
6. **外食は消費税の引下げの対象外**（国税庁 No.6102：外食は今の軽減8%の対象に含まれない。リーフレットは引下げ後1%の範囲を今の8%と同じと書く）。店内のラーメンは10%のまま、持ち帰り・通販の麺は1%。
7. **猛暑で客が減る記述が手元の有報2社にある**（力の源：繁忙期の台風・酷暑・厳寒は売上を下げる、梅雨は閑散期。ギフト：猛暑日などで来店頻度が減る、平均気温の上昇で来店頻度が減る）。BIZ-CALIB M5 の「夏の谷を消す」への反対の事実（**修正**：向きだけで量はない）。季節の形は BIZ-FILL-RAMEN へ。
8. **上場チェーンの借入は月商の0〜1.9か月**（借入金等明細表÷売上）：日高屋0・山岡家0.44・幸楽苑0.44・力の源0.92・物語1.11・ギフト1.94。公庫の小さな中華料理店（中央値4.1か月）より軽い。DESIGN の「急拡大型＝借入8か月」は、急拡大の実例（ギフト）と合わない（**否定**、型の値は1社ずつ）。
9. **埋まらなかった主なもの**：1軒の店の値段の弾力性（M1、推定が見つからない。反対の向きの研究1本）、倒産の個別事例の5件目、地方都市・郊外・過疎の店舗の賃料、工場の稼働率、事故の頻度（品質不良・故障・目減り）、分岐の重み、Big Ambitions・カイロソフト・Two Point の需要の式。(c) は **43→41行（35.7%）** で、目標の30%には7行足りない。
10. 全166か所の結果（`fill-calib-status.out.txt`）：埋まった20・一部24・埋まらず37・引き継ぎ24・計算23・設計34・説明4。**Excel・503 を理由に残した行は0**。

## うまくいく理由（埋めた値から見える因果）

1. **立地 → 客の顔ぶれ → 曜日と1店の売上**：家計（家族）の外食は土日に平日の約2.5倍（W1）。立地の型で1店の売上が約1.8倍違い、ロードサイド型と駅周辺型が高い（CENSUS）。家族客の多い郊外は週末に寄り、オフィス街は平日に寄る【推論：オフィス街の曜日の資料はない】。だから**同じ店でも立地で曜日の形と売上の水準が両方変わる**——SIMDESIGN の「客層の混ぜ方が状況で変わる」形（M2 の案）を、立地×曜日で資料から支えられる。
2. **規模 → 借入が軽い・ばらつきが小さい → 衝撃に耐える**：上場チェーンの借入は月商の0〜1.9か月（DEBT）、公庫の小さな店は中央値3〜9か月（JFC）。規模でばらつきが縮む形はコロナの年も同じ（JFC 規模別 比2.1）。
3. **本部の契約 → 店数とともに料率が下がる → 大きな加盟企業ほど得**：丸源のロイヤルティは1店目5.00%から30店目3.40%（FC）。FC に入る側の「何店まで増やすか」の判断に、料率の逓減が効く。

## うまくいかない理由（埋めた値から見える因果）

1. **外からの衝撃 → 売上が一斉に落ちる → 営業赤字が普通になり借入が倍に**：2021・2023年度の中華料理店は中央値で営業利益率 −12%台、借入は月商の11か月台（JFC）。経常との差（約14ポイント）は営業外の収入で埋まっていた【推論：中身は表にない】。平時の分布だけで作ると、この年の形が出ない。
2. **既存店の業態転換で他社の FC に入る → 合わない業態は数年で畳む**：幸楽苑の他業態は6年で38店→2店（KOURAKU・EXIT）。
3. **急拡大 → 利益率が下がる**：ギフトはコロナの年に売上+21%でも経常利益率が11.3%→4.7%（GIFT）。山岡家の急な出店の失敗（版0.2 の X1）と合わせ、拡大の速さと利益率の引き換えがある。
