## 0. 要点

1. **画面の診断**：帯は 196px（23.2%）、帯の字は幅390で 9〜17px で、デジタル庁が原則として許さない14px 未満が多い（[[web:uiref:uA-dads-typo|「14 CSS px未満の大きさの使用」]]）。ゲームの設定の文字の大きさを 150% にすると字は 15px になるが、帯は 357.5px（画面の42.4%）に伸び、固定（sticky）が外れる（125% で 298.6px。J2 の道具で統合の担当も再現）。**「字が小さいのは設定で直る」とは言えない**。
2. **上部の帯（P8）**：3人とも「1つを大きく」で一致。ウマ娘は能力の値を画面を移っても消さず（[[web:uiref:uB-gw-umamusume-ui2|「基礎能力をつねに表示」]]）、表示の決まりがあったので仕様が変わっても足すだけで済んだ（[[web:uiref:uB-gw-umamusume-ui2|「情報表示ルールがあると」]]）。カービィの左上の特等席は横長の画面が前提（[[web:uiref:uB-4g-kirby-ui|「テレビなどの横長の画面」]]）。結論は「数は残し、既定の100%のまま字を14px 以上にし、いま大事な1つを大きく」。
3. **チープさ（P7）**：ペルソナ3 は低予算の中で UI を主役にし、作り手は [[web:uiref:uB-fami-p5-ui|「低コストでのユーザーエクスペリエンス」]] の向上ももたらすと説明した（**支える側**。費用の数はない）。ペルソナ5 は場面ごとの UI 専属のプログラマー・千枚を超える仕様書で作った（**費用の側**）。Balatro の統一は1人で作りながら育った（[[web:uiref:uB-gi-balatro|「came up organically」]]）。結論は「主役（世界の絵か UI の形か）を1つ決めて厚く作り、動く試作で直す」。安く上げた例はペルソナ3 の作り手の説明1件で、「規則で安く上がる」とも「絵を足せば直る」とも一般には言えない。
4. **動き（P1・P6）は「有無」と「強さ」を分ける**：状態を伝える手ごたえの有無では、Liang 調査1 で派手な版の課題の点が 2.703→2.832 と有意に上がり（[[web:uiref:uC-arx-juicy-vis|「p = 1.577」]]）、使い込み・美しさも有意に上がった。ただし参加者は Prolific の47人（平均38.4歳、西洋の英語圏）、課題は可視化の図を操作して3問答えること、1回きりで、著者は探索的な比べと書く。Juul（点は下がる向き p=.12、出来の評価は上がる向き p=.20）・Fabre（成績は下がらない）・Campos（派手な版だけ不具合とドラッグの操作が交じる）は有意でないか検定なし。強さでは、Liang 調査3 は 無し2.396→低2.625→中2.412→高2.180 と単調でなく（有意でない）、上げる得の材料はない。**結論：状態を伝える短い手ごたえを足す側に有意な材料が1つ増えた。強さを上げる側の材料はない。一般化はしない**。
5. **声の数え直し**（R1）：動きを褒める・求める声 17→27、待たされる声 8→16、テンポ・飛ばせるを褒める声 9→28（比 2.1→1.7）。R1 が足した待たされる声8件のうち、演出の長さだけが原因の物は1件。Pokémon Sleep の利用者は、飛ばす設定が足されても止まる演出の不満が残り、演出は [[web:uiref:uB-applion-pokesleep-rev|「背景でやってもらう」]] か小さな知らせにと書く。**「飛ばせる」より「操作を止めない」が直し方**。
6. **動きの長さ**：Heer の実験は 1.25秒・2秒、「約1秒」は他の研究の勧めの引用。Collect UI の作品集の見本 akhakim の数字の数え上げは、数字が最後の値で止まるまで目で数えて 533〜967ms（J2）。版2の 333〜467ms は縮めた機械の測りで、終わりの遅い転がりを拾っていなかった。**DESIGN-JOURNAL-UX の 400ms と C の約1秒の割れは残るが、実測は約1秒の側に寄る**【推論】。
7. **Coffee Inc 2（P9）の4つのエッセンス**（地図のピン・シェアの円・2つの大きな数と3表・担当者の顔）は残す。悪い面：ピンが建物に隠れて誤タップ、週の業績で30秒待ち、毎回右上の×まで指を伸ばす、作業感。同じ編集部は煩雑さを [[web:uiref:uB-applion-coffeeinc2|「それも経営の面白さ」]] とも書く（両面）。
8. **オーナーの仮説への反対の事実**（各2つ以上は11章）：動き＝Liang 調査3 の強さ・Tversky の時間のコスト・止まる演出の不満、ドラッグ＝Unpacking の指・押す方が早い声・Campos の動く的を追うドラッグの不満（ただしお金を指で移す操作を褒める声は2件）、Coffee Inc 2＝誤タップ・待ち・作業感、チープは絵＝パブロフ・絵の読み違いが誤答になる（Duolingo）・カービィが絵を外した画面。**作り手の仕事が減る向きへの反対の事実**：「動きは控えめに」＝Liang 調査1 の有意な結果・Fabre・Campos の交絡、「規則で絵は要らない」＝Duolingo の規則は大量に描くため・P5 の量。
9. **作り直しの担当へ**：段の索引は5章（184行）、ぶつかる点は6章（21行）。判定1への対応は15章（22件）、読み直しの反映は16章（118件、漏れ0）、判定2への対応は17章（31件）。
