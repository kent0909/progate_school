# 店ごとの仕事を先に作る設計案（版3）

**途中版・設計案・未実装。店長案は保留。** コメント6568916887（オーナー決定11/2）への改訂。目標は段0で「2〜3店は社長が自分で回せ、4店前後から店長が勝つ条件が現れる」。この目標は判定する条件であり、値を後から動かす理由にしない。店舗拡張・机・新しい札を本体へ実装したPRではない。

結論：**加算模型には目標に合う条件があるが、雇用が広く有効になる釣り合いを得たとは言えない。** 代表条件は2〜3店の自己操作100%、4店の育成24/1,440件（約1.7%）、経験者0件。追加店の出来事がない対照とも比べる。出来事を加えただけで4店から雇用が必要になったとは主張しない。損の強い一部の範囲は新たに12か月すべて赤字になる店を作るので、採用候補から外す。

## 1. 決定・現行との関係・資料

オーナーの原文：「あと別件だけど複数店舗展開するときはある程度の店舗数を超えたら店長自体も雇うみたいな仕様であるほうが良いよね。」

11/2の決定は「先に店ごとの仕事を作る（推奨）」「4店くらいから（推奨）」。比較していた(a)追加店の仕事、(b)手の効きを強める、(c)店長を出さない、のうち(a)を先に進める。店長は捨てずに保留し、(a)を実worldで測ったあとで再検討する。(b)の倍率を本稿で実装しない。

現行公開版63d071eでは段0、社長時間は5〜6枠、追加店はpolicy0の地図と衛生を社長時間なしで行い、札は原則1号店向け。現行が3店以上で遊べると扱わない。3号店以降の札・工事・資金・旧保存の移行は、下に保存する版2第3節の案を維持する。ただし新模型の1号店の調整は本稿第2節を優先する。

## 2. 全店の作戦の机と社長の時間

以下は【推論・置き値】。机は会社で1画面、店ごとに「今月の利益見込み」「継続する手」「出来事と期限」「社長枠」「店に任せた枠」を並べる。店を選ぶと明細を同じ画面で開く。会社のBを各店へ複製しない。Bは現行のtimeBudgetを出発点に、初店の働き手と前月の札の時間負担から求める。

**提案の中心は1号店の調整を免除する案。** 1号店は社長の通常の持ち場としてcを取らず、社長が追加店の手を1つ以上行う月に、その店の調整c=0〜1を足す。第6節では初店も含む案を対照に残す。旧模型の1店と2店の保存を突然変更せず、移行前に予算と前後の差を出す。初店を含む案では移行直後に社長の使える時間が実質1枠減ることを明示する。

店ごとの手は地図・SNS・予報等の既存の操作と、下の出来事の処理。既存の時間単位（地図初回2、以後1など）は実装試作で維持する。今回の格子は開店直後ではないt18〜29のため、通常の各手1枠で比べている。値段・仕込み・仕入先の既存の時間0の判断を勝手に有料の枠へ変えない。検品は現行の金銭効果0で、利益を作るための手として数えない。

月の順は①前月の指示を読み出す→②今月の店固有の札を期限と見積りつきで出す→③会社の予算内で社長の手を割り当てる→④締めに実行・未実行と費用を確定する。月の途中の未知の札を月初から知っていたとするUIにはしない。初期試作は月初に知ることができる予定・警報だけを使う。突発の週次札を作るときは、月初の予約枠と途中の再配分を別に実装・測定する。

全店へ同じ指示を継続でき、通常月は再入力0回。変更は対象店を選び、手・担当を選んで1回確定する。予算超過は予定を直す画面へ戻し、入力順や乱数で手を消さない。「いまは店を増やさない」「今月は追加店の手を行わない」も選べる。支払不能の判断は既存の会社全体の口座で行い、店別に創業資金を配り直さない。

## 3. 店固有の出来事の札

全て未実装の【推論・置き値】。会社の配当・融資・増資の札を店数分に複製せず、店固有の人・器材・納品・注文だけを候補とする。1店1月は最大1枚、発生したら1枚の処理に1枠、同じ月に同じ店の複数札を束ねて余計な無料処理を得ない。店数Nなら発生枚数の期待値はN×p、p=0.25/0.5/0.75を事前の探索範囲とする。pは現実の発生頻度ではない。

札は店ID・原因・期限・無対応の損・処理後も残る費用を持ち、画面から月報と店別帳簿へ追える。発生の有無と種類はseed・店ID・月だけで引き、選んだ担当・給与・資金に応じて不利な札へ差し替えない。社長と将来の店長の比較でも同じ札を使う。イベント損の強さsは0.5/1/2を事前に走らせる。結果を見てpやsを動かし、選んだ1点だけを示さない。

`CMd = max(0, 売上−材料費−売上×0.04) / 26`、`MATd = 材料費/26`。0.04と26は公開63d071eの光熱変動率・営業日数。CMdは固定費を引く前の1営業日相当の限界利益の代理であり、1日の売上を利益と呼ぶものではない。売上と材料費は同じ店・同じ月のworld.monthの出力。以下の「損」は費用増または失う限界利益で、直接売上と二重に控除しない。

今回の格子では無処理でD、処理しても0.25Dは損として残り、避けられる損は0.75D。処理による代替調達・応援・修理等の内訳を一律25%と置いた**未確立の模型値**で、実務の修理料金ではない。実装試作では札の契約資料の直接費用と、休業等による売上減を別々にworldへ渡し、残損25%の近似を置き換える。処理のための直接費をさらに25%と二重に引かない。

期限を過ぎた未処理はその月だけにDを適用する。翌月へ無制限に同じ損を重ねる借金のような仕組みにはしない。ただし現実に修理が未了・予約返金が未払なら、事実と支払債務を保存して次の資料へつなぐ。この継続は今回の格子では未測定であり、処理しなくても器材が翌月自然治癒する本体仕様として承認するものではない。

札の主な選択は「社長が処理」「今月の機会を見送る」。将来の店長が配属され、担当範囲と枠を満たす場合だけ「任せる」を出す。全店の札を一括で既読にして無料で処理しない。複数店で同じ問屋の遅れが起こる相関や、応援を出すと元の店の能力も落ちる影響は大胆案として別の同時測定が必要。

**巡回枠の理由**：2つの店の通常の3手ずつで6、出来事があれば最大8件の候補になる。3は片方の店の通常の手だけ、6は両店の通常の手まで、4はその間の部分委任を試す位置である。業務時間の観測値でなく、負担の交換を調べる置き値。4を雇用が勝つよう選んだ確定値にはしない。2店の表では対象の追加店が1つだけなので、通常3件＋その月の札が上限。上限6でも実在しない仕事を足さない。

会社時間・担当2店・給与の制約は版2を維持する。パート増員も、計算済みの生産能力と給与20万円の差、時間が本当に増える場合の0/1枠を含めて比べる。社長のLは他店の手の配分の差から求める。委任先の便益と同額に置かない。店長の選び方は担当店の高い手から枠を埋める規則であり、全ての社長/店長の分担を網羅する大域最適化ではない。

**判定の読み方**：「目標に合う条件」は、同じ(p,s,c,初店の扱い,巡回枠,H)で2店と3店に雇用の単独勝ちがなく、4店に経験者か育成の単独勝ちが現れる条件、として示す。ただし存在が1件あることを、面白い釣り合いの達成とはしない。2〜3店で早く雇用が勝つ条件、4店でも勝たない条件を残し、割合で強さを見せる。

損による釣り合いは、同じ月のopからDを引く無対応の厳しい対照で確認する。①黒字月が全くない店が新たにできるか、②元から全月赤字の店はいくつか、③黒字月の数と黒字→赤字の件数、④1店/月の損と営業利益を同じ表で出す。新たに12か月全て赤字になる条件は、今回のデータでは採用候補にしない。赤字の店を測定対象から消さない。この対照は、通常の手の配分を変えた新模型や給与支払後まで含む健全性を保証しない。

## 3. 店を増やす仕組みと、全店の作戦の机

以下はすべて【推論・置き値】。現行の2号店を出す経路と、追加する3号店以降の経路を分ける。

### 3.1 出店の札・資金・完成

3号店以降は四半期の「次の店の計画」で、候補物件を2件と「増やさない」で比べる。前の開店から最低3か月、同時工事は1店、営業中の店があることを入口の案とする。直近3か月の既存店合算の営業キャッシュと、今後3か月の支払予定・借入返済・出店投資を同じ画面で見せる。黒字連続を絶対条件にはせず、資金を出せるなら赤字店を立て直すための移転・増店も選べる。

資金は会社の同じ口座から出す。`K=保証金+造作+器材+初回在庫+採用/教育/契約費`、手付日に保証金と造作の半額、完成日に造作残額と器材、納品日に在庫を払う。保証金は費用にしない。承認前の試算値は既存の保証金90万・造作150万・器材等60万を出発点にし、物件別の契約資料で額を与える。初回在庫は既存bowlの原価と仕込み数量から算出する。物件名だけで造作・保証金の科目を決めない。

契約前は見送り無料、契約後は資料に示した解約金と返還される保証金を区別する。途中で資金が足りなければ「工事が無料で完成」は起こさず、追加融資を申し込む／工事を止める／計画を解約する判断へ渡す。融資は既存の審査と返済予定へつなぎ、店を増やすたびに創業融資を再配布しない。完成前には売上を作らず、家賃の発生日・採用開始日を契約ごとに与える。

3店、4店…と同じ原理で繰り返す。案の比較・試遊はまず6店までを必ず含め、データ構造は可変長のままにする。「6店で必ず打ち止め」という仕様は置かない。5年の残り月数が少なければ、投資回収できないことを隠さず出す。

### 3.2 1か月の配分

入口は1枚の「全店の作戦」。店の行に売上・店別利益・社長が必要な枠・委任した枠・未実行の手を出し、行を選ぶと同じ机で店を切り替える。値段・仕込み・仕入先は時間を使わない既存の判断として残す。地図・SNS・予報等は店ごとに選ぶ。衛生は札に関係するため、金銭便益を測ったSNSへ読み替えない。検品を有料委任の利益例には使わない。

社長の時間は**会社で1つだけ**、既存の`timeBudget`を起点にする。各店に同じ5/6枠を複製しない。各店を社長が見る月は調整c枠を払い、その店の手の必要枠を足す。cは0〜1の整数で比較し、案の中心は1枠。初店の地図初回2枠・以後1枠という既存の単位も維持する。入力の順番でランダムに手を消さず、予算を超えた時点で実行予定を選び直す。

例：段0・パート2の6枠。各店で調整1＋地図1なら3店で使い切る。4店目を増やすと、1店の地図をやめる／SNS等を入れ替える／人を任せる、の比較になる。これは枠の計算であり、地図をやめる利益損失を固定の25万円にする意味ではない。月報は「手を打たない場合との差」と「給与・投資・借入の支払」を分ける。

### 3.3 policy0との接続・保存

新模型では`policy0`を値段・人員などの出発点として使うが、全店の時間を検査する前に地図・SNS・予報を実行済みにしない。社長／店長が実行予定に入れた手だけを`prepareStore`へ渡す。地図を無料で残してから同じ地図を委任の便益として数えない。

1店・既存2店の保存には`operationsVersion:legacy`を与え、勝手に赤字や時間超過へ変換しない。新しい拡張計画で「全店の時間を配る形へ移る」を選んだ月から`operationsVersion:2`へ移す。移行前後の全店の手・予算・予想差を確認でき、契約前なら取消可能。新しい周でも同じ入口を使う。旧型を続ける場合は現在の2店までを遊べるが、新しい3号店の契約には新模型が必要。模型を切り替える条件は保存する。月の途中で切り替えない。

【推論】この移行には二つの遊び方が並ぶ悪い面がある。罰のない互換を優先する案と、新しい周の2店目から一律に配分させる案は試遊で比較する。旧型維持を面白さで実証済みとしない。

## 5. 四つの道・lo/hiの制約・勝つ割合

【推論】版2で比べるのは①追加店を今月は見ずに待つ、②社長が自分で見る、③経験者へ任せる、④育てて任せる。いずれも店を増やさない道と組み合わせられる。社長が自分で見る道のLは、会社全体で他店の手を最適配分した利益`V(B)-V(B-1)`から出す。経験者の引継ぎでは、委任した手を除いた残りの配分で同じ差を取り、既に店長が行う手を失うLとして再び引かない。店長候補の委任先の便益と同じ数を代入しない。

【推論・置き値】1店だけの任意の手では費用に届きにくいため、**巡回する店長が近い追加2店を担当する案**を比較対象に加える。1店専任案をこっそり2店へ変えたものとして扱わず、役割の変更として承認対象にする。各店で4手ではなく、2店を合わせて月4手。社長は1店でも雇えるが2店分の給与は取らない。店長の現場作業によるcap上乗せは付けず、給与もパートへ二重加算しない。離れた地域を巡回するなら1店専任か、別の移動負担を見積もる。地域IDだけで分を換算しない。
