# 集客・広告・販促の打ち手：費用・効果・分かれ方・会計（調べもののまとめ）

版：0.1（2026-10-22）。書き手：調べもの担当（集客・広告・販促）。読み手：ピヨ商店に「売上が動く経営の意思決定」を足す設計者・実装者。
読んだ資料：22本（取得元18か所）。読了ノートは `boki2/research/notes/{web/bizmkt,law/primary}/r4-mkt-*.md`。`node boki2/tools/research-check.js` で自分のノートのエラー0を確認済み。

## 0. このまとめの読み方

- **印**：【要確認】＝資料を読んでいない・資料どうしが食い違う・法令の細部まで確かめていない。【推測】＝資料にない数字や因果を、資料から筋道を立てて置いたもの（ゲームの初期値の案はほぼ全部これ）。**宣伝の数字**＝業者が自社サービスに誘導する記事の数字（調査の方法が示されず、良い方に寄りやすいので割り引く）。
- **出典の質**：公的（消費者庁・総務省・日本郵便・J-Net21・山梨県・厚労省）＞学術（学習院大の論文）・専門団体（公認会計士協会）・会計の専門家（TKC）＞報道・業界誌（ITmedia・宣伝会議）＞業者メディア（ほぼ全部が宣伝の数字）。
- **一番大事な注意**：チラシの反応率・インフルエンサーの来店効果など、ゲームの「効果」の数字の多くは、**公的な統計が存在しない**か、業者の目安しかない。検索で見た「折込の反応率0.01〜0.3%」「ポスティング0.1〜0.3%」は、業者記事の要約を見ただけで本文を読めていない（取得拒否や未取得）ので、根拠には使わず【推測】として扱う。逆に言えば「効果は事前に分からず、測る仕組みを入れた店だけが次に正しく判断できる」こと自体が、現実の経営のいちばん大事な事実である（[[web:bizmkt:r4-mkt-jnet21-hansoku]]：チラシは売上目標を決めて効果を測れ、DMは送ったら必ず測れ）。
- 金額の例は、**ピヨ商店のレモネード1杯300円・原価100円（粗利200円）**で計算する【推測：ゲーム内の値に合わせて置き換える】。

## 1. 効果の測り方（15歳以上が分かる言葉で）

| 言葉 | 意味 | ピヨ商店の例 |
|---|---|---|
| 届いた数（リーチ） | 広告を見た（届いた）人・家の数 | チラシ3,000枚＝3,000世帯に届いた（ただし読んだとは限らない） |
| 反応率（反響率） | 届いた数のうち、来た・買った・問い合わせた割合 | 3,000枚で6人来たら 6÷3,000＝0.2% |
| CPM | 広告が1,000回表示されるごとの値段 | Instagram広告は1,000回で500〜3,000円が業者の目安（宣伝の数字）[[web:bizmkt:r4-mkt-honichi-instaads]] |
| CPC | 広告が1回押されるごとの値段 | 1クリック40〜100円（同上） |
| CPA（来店1人あたりの費用） | 打ち手の費用 ÷ その打ち手で来た人数 | 21,000円のポスティングで6人なら CPA＝3,500円 |
| 粗利で見る | 来た人が落とした粗利と費用を比べる。売上と比べると甘くなる | 6人×1杯＝粗利1,200円。費用21,000円なら1回では大赤字 |
| リピート率 | 初めて来た人のうち、また来た人の割合 | 6人のうち2人が常連になった＝33% |
| LTV（客の一生分の粗利） | 1人の客が、通っている間に落とす粗利の合計 | 月4杯×12か月×200円＝9,600円。常連2人なら19,200円 |
| 増分（上乗せ分） | その打ち手が**なかったら来なかった**分だけを数える | クーポンを使った10人のうち7人が元々の常連なら、上乗せは3人だけ（7人分は値引きの損） |

**判断の型**：「CPA（1人連れてくる費用）」と「LTV（1人が残す粗利）」を比べる。CPA ＜ 1回の粗利なら即黒字、CPA ＜ LTV なら時間をかけて黒字、CPA ＞ LTV なら打つほど損。レモネードのような**安い商品は1回の粗利が小さいので、ほとんどの打ち手はリピートが付かないと元が取れない**【推測：上の計算から】。ここが「バズったのに儲からない」という分岐の土台になる。

**測る仕組み**（ゲームで選べる追加の選択肢）：クーポンの持参・合言葉・「何を見て来ましたか」の聞き取り・LINEの友だち登録経由。仕組みを入れないと結果画面は「先月より売上が少し増えた。理由ははっきりしない」としか返らない（[[web:bizmkt:r4-mkt-jnet21-hansoku]]）。合言葉特典で来店を数える例は [[web:bizmkt:r4-mkt-findmodel-gourmet]]。ただし特典は値引きなので、測るほど粗利が少し減る。

## 2. 前提になる世の中の事実（時代設定2020年代）

- **日本の広告費（2024年、電通の推計）**：総額約7.7兆円、ネット広告が5割弱で、SNSの縦型動画が伸びている。新聞広告は減少。**折込は約2,440億円で前年の95%ほど**（新聞を取る家が減った）。DMは92%ほど（2024年10月の郵便料金の値上げ）。**ポスティングは約1,480億円で横ばい**、折込の代わりに全戸配布が使われる。宛名なしDMも折込からの乗り換えで増加 [[web:bizmkt:r4-mkt-dentsu-adspend2024]]。→ ゲーム内で年が進むと「折込の届く世帯が毎年少し減る」変化を入れてよい。
- **SNSの利用率（総務省、10〜60代、2024年）**：LINEは約95%（60代でも約91%）。XとInstagramは全体の半分ほどで若い人寄り、50代でも4割超 [[law:primary:r4-mkt-soumu-sns-r07]]。→ 高齢の住宅地にはLINE・チラシ、学生街にはInstagram、という客層の分岐の根拠。
- **店の探し方（訪日ラボの調査、20〜50代600人、2025年10月、口コミ対策業者の調査）**：グルメサイト約73%、Googleマップ約69%、2つ以上を併用が約77%、口コミを参考にする人が約95% [[web:bizmkt:r4-mkt-honichi-gourmetsurvey]]。→ SNSで「知る」→地図・口コミで「選ぶ」の二段。
- **炎上（デジタル・クライシス総合研究所、2024年、自社の数え方）**：日本全体で年1,225件。会社が原因は312件。広がるのは8割がX。報道まで24時間未満が約26%。見た人の約39%は、会社の対応が3日以内にないと悪い印象。会社の炎上で購入・利用を止める／考え直すが39%、優先順位を下げるまで含めると75% [[web:bizmkt:r4-mkt-siemple-enjou2025]]。
- **法の枠**：ステマ（広告なのに隠す）は2023年10月から景品表示法違反で、**罰せられるのは頼んだ店の側**（書いた人ではない）[[law:primary:r4-mkt-caa-stealth]]。おまけ・景品には上限がある（もれなく配るなら取引1,000円未満は200円まで、1,000円以上は2割まで。くじなら最高は取引の20倍（5,000円以上の取引は10万円）・総額は売上見込みの2%まで）[[law:primary:r4-mkt-caa-premium]]。看板・のぼりは自治体の条例で大きさ・場所・色まで決まることがある [[web:bizmkt:r4-mkt-yamanashi-okugai]]。
- **国が飲食店に期待する経営課題の並び**（厚労省の振興指針の骨組み）に「ネットで新しい客を得て定着させる」と「表示を正しく・苦情に適切に」が同じ表に並ぶ [[law:primary:r4-mkt-mhlw-shinkoshishin]]。→ 集客の打ち手と表示の責任をセットで扱う設計の裏づけ。

## 3. 打ち手ごとの実際

各打ち手は「費用・効果・効果が出るまで・持続・振れ幅・リスク・会計・ゲームでの判断の形・結果の分かれ方」の順。結果の分かれ方の「起きやすさ」は、**ゲームの初期値の案（ほぼ全部【推測】）**で、根拠の欄に何を土台にしたかを書く。

### 3.1 新聞折込チラシ

- **費用**：1世帯に届けるのに印刷込みで約7円（折込会社の役員の話＝売る側の数字）[[web:bizmkt:r4-mkt-advertimes-orikomi]]。デザイン代は A4 で2万〜5万円（業者記事）[[web:bizmkt:r10-rr-imitsu-posting|「2万～5万円が費用相場」]]。3,000部なら配布と印刷で約1.5万〜3万円＋デザイン代【推測：下のポスティングの単価から。【2026-10-23 直した】前の版の2.1万円は crowdworks の記事（robots.txt が ClaudeBot の名の組で禁じる）の例で外した】。
- **効果**：公的な反応率の統計はない。ゲームの初期値は 0.05〜0.3%（3,000部で2〜9人）【推測】。合う客層は40代以上・郊外・戸建て。新聞を取る人の6割はほぼ毎日チラシを見る、折込の1週間のリーチは約3割という（売る側の話）[[web:bizmkt:r4-mkt-advertimes-orikomi]]。女性に強い [[web:bizmkt:r4-mkt-jnet21-hansoku]]。
- **効果が出るまで**：配った当日〜数日。日を選べるのでセールの日に合わせられる。チラシが多い週末を避けると目立つ [[web:bizmkt:r4-mkt-jnet21-hansoku]]。
- **持続**：短い（数日〜1週間）【推測】。くり返すと「店を思い出す」効果がたまる【推測】。
- **振れ幅**：中。町の新聞購読率（若い町ほど低い）と、載せる商品・特典で大きく変わる。
- **リスク**：届く世帯が年々減る [[web:bizmkt:r4-mkt-dentsu-adspend2024]]。景品をうたえば景品規制。
- **会計**：配った月に **広告宣伝費**。前払いなら配るまで **前払金**、月末払いなら **未払金**。期末に配っていない印刷済みのチラシは **貯蔵品**にするかの判断【要確認：毎期ほぼ同じ量を買うなら費用のままでよいとする税の扱いがあると記憶しているが、今回は通達を読んでいない】。消費税は **仮払消費税**。
- **判断の形**：配る町（常連の多い町で深掘りか、少ない町の開拓か）・部数・曜日・載せる特典（なし／クーポン／試飲券）・測る仕組み。返るもの：来店数（特典ありなら数えられる）、新しい客の町の分布、粗利、次月以降のリピート。

### 3.2 ポスティング（郵便受けへの投函）

- **費用**：区域の全戸（ローラー）なら1枚3〜6円 [[web:bizmkt:r10-rr-imitsu-posting|「1枚あたり3〜6円」]]、条件で家を絞ると（戸建てのみ、など）5〜10円 [[web:bizmkt:r10-rr-imitsu-posting|「戸建てのみ」]]。【2026-10-23 直した】**部数が多いほど1枚の単価は下がる傾向で、少ない部数は割高**（[[web:bizmkt:r10-rr-imitsu-posting|「単価が下がる傾向」]]）。前の版の「人件費が大半なので部数を増やしても配布単価はほぼ下がらない」は crowdworks の記事の記述で、取り直した記事とは**向きが逆**なので直した（結論が変わる）。印刷は A4 カラーで1枚2〜4円 [[web:bizmkt:r10-rr-imitsu-posting|「A4カラーで1枚2～4円」]]、デザインは2万〜5万円（業者記事＝宣伝の数字、imitsu の取引の集計を含む）。他社のチラシと一緒に入れる（併配）と安い [[web:bizmkt:r10-rr-imitsu-posting|「併配は費用を抑えやすい」]]。戸建てが中心で家がまばらな所は割高 [[web:bizmkt:r10-rr-imitsu-posting|「単価が高くなるケースが多い」]]。【2026-10-23 外した】「東京で3,000部の例は印刷込み約2.1万円」は外した。
- **効果**：折込と同じく公的な統計なし。新聞を取らない家にも届くので、若い世帯の多い町では折込より有利【推測】。初期値 0.05〜0.3%【推測】。
- **効果が出るまで**：取引の事例の配布期間は4〜15日（[[web:bizmkt:r10-rr-imitsu-posting|「配布期間 ：4日間」]] など）、最短で受付から4営業日で配り終える業者もある [[web:bizmkt:r5-mktr-raksul-posting|「最短4営業日」]]。【2026-10-23 直した】前の版の「3〜5日の指定で実際は3日ほど」は crowdworks の記事の値で外した。
- **振れ幅**：大【推論】。【2026-10-23 外した】「配布員が配らずに捨てることがある（業者自身が注意点に挙げる）」は crowdworks の記事の記述で、取り直した imitsu・ラクスルの資料にもなく、WebSearch でも業者の宣伝と口コミの一覧（Cloudflare で開けない）しか出ないので外した。
- **リスク**：投函禁止の家に入れた苦情、雨で濡れた苦情【推論】（【2026-10-23 外した】根拠の crowdworks の記事を外した）。
- **会計**：折込と同じ（広告宣伝費・前払金・未払金・仮払消費税）。
- **判断の形**：業者の選び方（安い業者／GPSで配布を確かめる業者）、全戸か絞るか、併配を許すか。安い業者を選ぶと「配っていない」分岐が起きやすい、というトレードオフ。

### 3.3 宛名なしDM（日本郵便のタウンメール・タウンプラス・はがきタウン）

- **費用**：タウンメールは25g以内74円・50g以内87円・100g以内105円、同時に500通以上。はがきタウンは日本郵便のはがき（85円）を使う。タウンプラスの料金は郵便局に問い合わせ（公表なし）[[web:bizmkt:r4-mkt-japanpost-townmail]]。1通あたりはポスティングの10倍以上【計算】。
- **効果**：郵便として届くので配布漏れがなく、捨てられにくい【推測：ページに効果の記述はない】。宛名なしDMは折込からの乗り換えで増えている [[web:bizmkt:r4-mkt-dentsu-adspend2024]]。
- **効果が出るまで**：郵便の日数＋3日（タウンメール）、ゆうメールの日数＋1週間ほど（タウンプラス）。タウンプラスは14日前までに計画書。年末年始は使えない [[web:bizmkt:r4-mkt-japanpost-townmail]]。
- **会計**：差し出したときに払えば広告宣伝費（郵送料を **通信費** にする会社もある。決めたら続ける）。料金後納なら翌月払い＝**未払金**。
- **判断の形**：「確実に全戸に届けるが高い」か「安いが漏れる（ポスティング）」か。届くまでの日数を見てセール日との時期合わせを決める。

### 3.4 手配り・店頭配布・カード広告

- **費用**：自分（店員）の時間＝給料・雑給の中に消える。印刷代だけ現金で出る。通行人が自由に持っていくカード広告の棚もある（興味のある人だけが取る）[[web:bizmkt:r4-mkt-jnet21-hansoku]]。
- **効果**：その場で会話でき、試飲と組み合わせやすい【推測】。
- **リスク**：道路で配るには許可が要る場合がある【要確認：道路使用許可・自治体の条例は今回読めていない】。店員が配っている間、店が手薄になる。
- **会計**：印刷代は広告宣伝費。人の時間は仕訳に出ない＝「見えない費用」【推測：ゲームでは店の処理能力の低下として返す】。

### 3.5 SNSの自前運用（Instagram・X・TikTok）

- **費用**：お金はほぼゼロ（自分の時間、写真の撮影）。外注すると運用代行の月額【要確認：相場は読んでいない】。
- **効果**：知ってもらうきっかけとしては強いが、選ぶ段階では地図・口コミが重い [[web:bizmkt:r4-mkt-honichi-gourmetsurvey]]。InstagramとXは利用者の半分ほどで若い人寄り [[law:primary:r4-mkt-soumu-sns-r07]]。投稿をやめると効果も止まる【推測】。
- **効果が出るまで**：遅い（フォロワーがたまるまで数か月）【推測】。ただし1本の投稿が当たると一気に来る（下の「バズ」分岐）。
- **振れ幅**：最大。ほとんどの投稿は空振りで、ごくまれに大当たり【推測：投稿の反応は大きく偏る、という一般的な経験則。数字の資料は読んでいない】。
- **リスク**：店員の不適切な投稿・客の撮影トラブルから炎上（会社が原因の炎上は日本全体で年312件）[[web:bizmkt:r4-mkt-siemple-enjou2025]]。
- **会計**：仕訳がない打ち手。「お金を使わない打ち手もあり、そのぶん時間（人件費）を使っている」ことを見せる。

### 3.6 SNS広告（Instagram／Meta）

- **費用**：1日1ドルから出せる。Metaは1日5ドル以上・6日以上を勧める（約4,500円）。目安は1,000回表示で500〜3,000円、1クリック40〜100円、動画1再生4〜7円（宣伝の数字）[[web:bizmkt:r4-mkt-honichi-instaads]]。
- **効果**：表示→押す→来店の順に細る。来店までの割合は資料なし【推測：1,000回表示で押すのが5〜15回、来店はその1〜2割】。地域・年齢を絞れるのが強み。
- **効果が出るまで**：出したその日から。止めると止まる。
- **振れ幅**：中（予算で上限を決められるので、大赤字も大当たりも起きにくい）【推測】。
- **会計**：クレジットカード払いが多い→月末に **未払金**、引き落としで現金預金が減る。海外の事業者（Meta）への支払いの消費税は特別な扱いがある【要確認：国外事業者のネット広告の消費税（登録国外事業者・リバースチャージ）。2級の範囲外なので、ゲームでは税込みの費用として単純化するか、国内代理店経由にして仮払消費税を付けるかを決める】。
- **判断の形**：1日の予算×日数、配信する地域（半径何km）、年齢。返るもの：表示回数・クリック数（すぐ）、来店（測る仕組みがあれば）。

### 3.7 LINE公式アカウント

- **費用**：月額プランに無料の通数が付き、超えた分（追加メッセージ）は2026年10月から月20万通までは1通3円、超えた分は2.5円（税別）[[web:bizmkt:r4-mkt-lycbiz-msgfee]]。月額プランの金額・無料の通数は公式ページで確かめていない【要確認】。
- **効果**：LINEはほぼ全員が使う [[law:primary:r4-mkt-soumu-sns-r07]]。友だちになった人の過半数が「クーポン目当てで使った」と答えたという（調査の範囲不明・提供元の宣伝）[[web:bizmkt:r4-mkt-lycbiz-coupon]]。来なくなった客を呼び戻す道具として効く（下のポイントカードの「呼び戻し約9%」と同じ型）【推測】。
- **効果が出るまで**：配信した日〜数日。友だちを集めるのに時間がかかる。
- **振れ幅**：小〜中。送りすぎると友だちを外される（ブロック）【推測：資料は読んでいない】。
- **会計**：月額は毎月の **通信費** または **広告宣伝費**。年払いなら **前払費用** に入れて毎月振り替える（2級の「費用の前払い」の題材）。
- **判断の形**：友だちを増やす特典（初回1杯引き等）と、送る回数。友だちが増えるほど一斉送信の費用が上がる＝「登録者を増やす」と「送る回数」のトレードオフ。

### 3.8 インフルエンサー・YouTuberへの案件（PR）

- **費用**：ふつうは「フォロワー数×単価」。フォロワー1人2〜6円（10万人なら20〜60万円）、仲介サイトの成果報酬なら2〜4円、反応の数で払うなら1回3〜30円。ほかに贈る商品と送料、来店の交通費・宿泊費、代理店の進行費、仲介サイトの月額2〜5万円、投稿写真を自社広告に使う二次利用料（宣伝の数字）[[web:bizmkt:r4-mkt-ownly-influencer]]。Instagramは1人2〜4円（1万人で2〜4万円）という別の業者の目安もある [[web:bizmkt:r4-mkt-honichi-instaads]]。
- **効果**：成功事例集でも効果の証拠は「いいねの数」（ふだん500→1,500、開店直後の店で4日で1,800など）で、来店や売上の数字はほぼない（仲介業者の成功例だけの資料）[[web:bizmkt:r4-mkt-findmodel-gourmet]]。来店につなげる店は「フォロー画面を見せたら1杯無料」「合言葉で2本目無料」などの特典を付けている（同）。
- **効果が出るまで**：投稿の日〜1週間に集中【推測】。持続は短い（数日〜2週間）が、地図の口コミが増えれば残る【推測】。
- **振れ幅**：最大。フォロワーを買っている人（数だけで効果なし）、フォロワーの属性が合わない（男性フォロワー中心の人に女性向け商品）[[web:bizmkt:r4-mkt-ownly-influencer]]。
- **リスク**：PR表記を省くとステマ＝景品表示法違反で、**責任は店側** [[law:primary:r4-mkt-caa-stealth]]、炎上の火種にもなる [[web:bizmkt:r4-mkt-ownly-influencer]]。起用した人自身が炎上すると、店にも影響（起用タレントの炎上で止める・考え直すが32%）[[web:bizmkt:r4-mkt-siemple-enjou2025]]。
- **会計**：報酬は **広告宣伝費**。贈った自社商品は **見本品費**（三分法なら 見本品費／仕入 で仕入から振り替える）。交通費は **旅費交通費**、代理店の進行費・仲介料は **支払手数料**。投稿前に払えば **前払金**（投稿されたら広告宣伝費へ）。消費税は仮払消費税だが、相手が免税事業者（インボイスなし）だと仕入税額控除が制限される【要確認：経過措置の割合。2級の範囲外なので、ゲームでは「インボイスの有無を確かめる」場面にとどめる案】。
- **判断の形**：誰に頼むか（フォロワー数・ジャンル・地域・反応率の見え方）、頼み方（直接／仲介／代理店）、特典を付けるか、PR表記（付ける／「付けないで」と頼む）、在庫を事前に増やすか。

### 3.9 地図アプリ・口コミ（Googleマップなど）の整備

- **費用**：ほぼゼロ（写真・営業時間・メニューを整える時間）。
- **効果**：店を探す人の約7割が地図を使い、約95%が口コミを参考にする（口コミ対策業者の調査）[[web:bizmkt:r4-mkt-honichi-gourmetsurvey]]。他の打ち手で「知った」人が、ここで選ぶか落とすかを決める【推測】。
- **持続**：長い（整えた情報と口コミは残る）。
- **リスク**：口コミを書いたら割引、は頼んで書かせた口コミになり、ステマ規制や口コミサイトの規約に触れるおそれ（提供元の記事はこれを勧めている）[[web:bizmkt:r4-mkt-lycbiz-coupon]]【要確認：消費者庁の運用基準の該当箇所は未読】。悪い口コミ1つで探す段階で落とされる。
- **会計**：仕訳なし。
- **判断の形**：他の打ち手の効き目を何割増しにする「土台」として置く（整えていないと、チラシやSNSで知った人の一部が地図で離脱する）【推測】。

### 3.10 看板・のぼり・店頭の工夫

- **費用**：大判ポスターはA0で6,500円程度から1枚でも作れる業者がある [[web:bizmkt:r4-mkt-jnet21-hansoku]]。看板の本体価格の相場は読んでいない【要確認】。
- **効果**：前を通る人にしか効かないが、毎日・長く効く【推測】。
- **リスク・規制**：屋外広告物は条例の対象。自分の店の敷地の自分の看板（自家用）は面積の合計10㎡以下なら許可不要（地域により5㎡）、超えると許可（2年ごと・手数料）。よその土地の案内看板は厳しい。景観の地区では色は3色まで・点滅不可など。のぼりは道路から5m以内なら5m以上の間隔（3本以下は可）。看板を作り替えるときは新しい基準に合わせる [[web:bizmkt:r4-mkt-yamanashi-okugai]]（山梨県の例。ほかの自治体は数字が違う）。看板が落ちて人にけがをさせる危険も規制の目的 [[web:bizmkt:r4-mkt-yamanashi-okugai]]。
- **会計**：長く使う看板は **備品**（地面に立てる大型の物は **構築物**）にして **減価償却費**。安い物（ポスター・のぼり）は **消耗品費** または広告宣伝費。許可の手数料は **租税公課** または **支払手数料**【要確認：会社の勘定の決め方】。
- **判断の形**：大きく派手な看板（効くが許可・手数料・景観の地区では不可）か、条例の範囲内か。資産にするか費用にするかの金額の線引き（2級の固定資産の判断）。

### 3.11 サンプリング（試飲）

- **費用**：配るレモネードの原価＋人の時間。店舗などで配る業者のサービスは1個20円から、という宣伝資料を検索で見たが本文は読んでいない【要確認】。
- **効果**：目的は第一に初めて買ってもらうこと、ほかに理解・口コミ・感想集め・競合からの乗り換え [[web:bizmkt:r4-mkt-honichi-sampling]]。味で選ばれる商品なので向いている【推測】。
- **リスク**：配る場所の許可 [[web:bizmkt:r4-mkt-honichi-sampling]]（見出しのみ確認）。もらうだけの人が多い。
- **会計**：試飲に使った分を **見本品費**（または販売促進費）に振り替える（売上原価に混ぜると、粗利率が実際より低く見え、棚卸ともずれる）。
- **判断の形**：配る量・場所（駅前・学校の近く・イベント）・許可を取るか・試飲券（後日1杯引き）を付けるか。

### 3.12 イベント出店（商店街の祭り・マルシェ）

- **費用**：出店料・屋台の備品・仕込みの材料【要確認：相場は読んでいない】。
- **効果**：その日の売上（現金）と、知ってもらう効果の両方【推測】。人の流れが戻ってイベント・展示は伸びている [[web:bizmkt:r4-mkt-dentsu-adspend2024]]。
- **振れ幅**：大（天気・人出）【推測】。
- **会計**：出店料は **支払手数料** または広告宣伝費。売上は **売上**、つり銭と売上金の差は **現金過不足**。売れ残りの材料の廃棄は **商品廃棄損**（または棚卸の減耗）【推測：ゲーム内の勘定に合わせる】。
- **判断の形**：仕込む量（多すぎ＝廃棄、少なすぎ＝品切れ）、価格（祭り価格か通常か）。

### 3.13 地域メディア（フリーペーパー・地元紙）

- **費用**：掲載料の相場は読んでいない【要確認】。フリーペーパーは物流費・紙代の高騰で縮小中、ただし地域密着の需要はある [[web:bizmkt:r4-mkt-dentsu-adspend2024]]。
- **会計**：掲載料は広告宣伝費。号の発行前に払えば前払金、年間契約なら前払費用。
- **ゲームでの使い道**：地元紙に**取材される**（無料の記事）分岐。工場の自主回収のような悪いニュースも同じ紙に載る（EPISODES.md の自主回収の筋と同じ地元紙を使える）。

### 3.14 クーポン・値引き

- **費用**：値引きした分だけ粗利が減る（お金は出ていかないが、入ってくるはずのお金が減る）。
- **効果**：割引率・期限・対象で変わる。提供元の記事は、新規・常連・休眠客の呼び戻し・客単価アップを挙げる（客単価アップは根拠なし、宣伝）[[web:bizmkt:r4-mkt-lycbiz-coupon]]。期限がないと使われない（同）。
- **副作用1（粗利）**：粗利200円の1杯を50円引くと粗利は150円。元の粗利を取り戻すには **3割強多く売る** 必要がある（200÷150≒1.33倍）【計算】。粗利率の低い商品ほど値引きは重い。提供元自身も「割引率を慎重に、利益が削られ続ける」と注意 [[web:bizmkt:r4-mkt-lycbiz-coupon]]。
- **副作用2（値引きの癖）**：客の頭の中の「ふつうの値段」は過去に見た値段で作られる。**いつも買っているブランドでは値引きを見ても動かないが、なじみの薄いブランドでは今の値段が次の感覚に約25%反映される**（カレールーの購買記録、292世帯、1998〜99年）。だから**出たばかり・常連のいない時期の値引きは、定価に戻したとき客が減る**が、常連の多い時期のセールは害が小さい [[web:bizmkt:r4-mkt-refprice-loyalty]]。
- **副作用3（客層）**：高級感を売る店が割引ばかり配ると高級感が落ちる [[web:bizmkt:r4-mkt-lycbiz-coupon]]。
- **副作用4（もともとの客が使う）**：常連がクーポンを使うと、上乗せの客は増えずに値引きだけ増える【推測：増分の考え方】。
- **会計**：その場の値引きは **売上を値引き後の金額で計上**（2級では「売上を減らす」）。次回使える割引券を配る場合、それが通常の値引きを超える「重要な権利」なら、売上の一部を **契約負債** にする [[web:bizmkt:r4-mkt-tkc-point]] [[web:bizmkt:r4-mkt-jicpa-point]]【要確認：小さな割引券をどこまで重要な権利とするかは判断が要る。ゲームでは「次回半額券」のような大きいものだけに限る案】。消費税は値引き後の金額にかかる。
- **判断の形**：割引率（10%／20%／半額）・期限・対象（初回だけ／誰でも／休眠客だけ）・配り方（紙／LINE）。返るもの：使われた数、上乗せの来店、粗利の減り、定価に戻した月の客数。

### 3.15 ポイントカード・スタンプカード

- **費用**：カードの印刷代と、無料の1杯の原価。
- **効果**：スーパーの調査では、ポイントカードは客の「また行こう」を直接は動かさず、満足の理由の中でも一番小さかった（品ぞろえ・清潔さ・何より近さが大事）。価値はデータで、来なくなった客に招待券を送ると平均約9%が戻ってきた。少額の買い物では得を感じにくいので、来店回数で返す工夫を提案（みずほ情報総研へのインタビュー、2007年、スーパーの話）[[web:bizmkt:r4-mkt-itmedia-pointcard]]。
- **副作用**：競合とのポイント合戦、客の値引き慣れ [[web:bizmkt:r4-mkt-itmedia-pointcard]]。
- **会計（2級の収益認識）**：販売に伴うポイントが重要な権利なら、売るときに代金をポイントと商品に「独立販売価格」の比で分け、ポイント分を **契約負債**。使われたら（または失効したら）**売上** へ。ポイント引当金はもう使えない。来店しただけで配るポイントは引当金でよい [[web:bizmkt:r4-mkt-tkc-point]]。数値例：10,000円売って100ポイント（95ポイント使われる見込み＝値打ち95円）→ 売上9,906円・契約負債94円。45ポイント使われたら45÷95×94＝45円を売上へ [[web:bizmkt:r4-mkt-jicpa-point]]。消費税は売ったときに代金全額にかかり、ポイントを使った値引き分は不課税（会計と税がずれる）[[web:bizmkt:r4-mkt-tkc-point]]。他社のポイント（共通ポイント）を付けるなら、その分は **未払金** で売上から除く [[web:bizmkt:r4-mkt-jicpa-point]]。
- **ピヨ商店の例**：10杯で1杯無料、半分の客が使う見込み→10杯につき無料の値打ち300×0.5＝150円、1杯あたり15円。1杯300円を「商品300：ポイント15」で分けると、売上約286円・契約負債約14円【計算】。2年目の E15（保守とポイントをつけて売ろう）と同じ札を、集客の判断の結果として出せる。
- **判断の形**：入れるか、返し方（来店回数／金額）、期限、データを使って休眠客に送るか（LINEとの組み合わせ）。

### 3.16 紹介（友だち紹介クーポン）

- **費用**：紹介した人・された人への特典。
- **効果**：一人では来にくい店にも友だちとなら来やすい [[web:bizmkt:r4-mkt-lycbiz-coupon]]。紹介された客は合う客である可能性が高い【推測】。
- **会計**：特典は値引き（売上の減少）。
- **判断の形**：特典の大きさ。常連が育っていないと紹介が起きない（打つ順番の学び）【推測】。

### 3.17 景品・抽選（くじ・もれなくプレゼント）

- **上限**：もれなく・先着で配るなら、1,000円未満の取引は200円まで、1,000円以上は取引の2割まで。くじは取引5,000円未満なら最高は取引の20倍、総額は売上見込みの2%まで。商店街などの共同懸賞は最高30万円・総額3%まで。買わなくても応募できる懸賞は上限なし [[law:primary:r4-mkt-caa-premium]]。1杯300円なら、もれなく配れるのは200円までの物。
- **会計**：景品の購入は **販売促進費**（または広告宣伝費）。配る前の在庫は **貯蔵品**。取引先の会社の人に配るなら交際費の扱いが出る【要確認】。
- **判断の形**：景品の値段と配り方。上限を超えると措置命令と社名公表（違反の結末）。

## 4. 結果の分かれ方（打ち手ごと）

書き方：**分岐名**（起きやすさの目安）— 何が起きるか／根拠／その後の出来事／会計（札・書類）。起きやすさは【推測】のゲーム初期値で、状態（客層・常連の数・地図の整備・在庫・測る仕組み）で上下させる。

### 4.1 チラシ（折込・ポスティング・宛名なしDM）

1. **そこそこ**（50%）— 3,000部で数人〜十人ほど来る。根拠：公的統計なし、業者の目安の幅の中ほど【推測】。その後：特典ありなら来店数が数えられ、CPAが出る。会計：広告宣伝費（請求書）、特典を使った分は売上の値引き（レジの記録）。
2. **空振り**（30%）— ほとんど来ない。原因の候補を結果画面に出す：若い町で新聞を取る家が少ない [[web:bizmkt:r4-mkt-advertimes-orikomi]] [[web:bizmkt:r4-mkt-dentsu-adspend2024]]／週末でチラシに埋もれた [[web:bizmkt:r4-mkt-jnet21-hansoku]]／特典がない。その後：同じ費用は戻らない（埋没費用）。会計：それでも広告宣伝費（効果がなくても費用は費用）。
3. **大当たり**（5%）— 特典と町の客層が合って予想の3倍以上。その後：品切れ・行列（4.10の組み合わせ）。会計：売上増、仕入増、買掛金。
4. **配っていなかった**（ポスティングの安い業者で10%、GPS業者で1%）— 一部の町だけ反応ゼロ。根拠：【2026-10-23 外した】業者自身が「配らず捨てる配布員」を注意点に挙げる、の crowdworks の記事は外した。いまは根拠のない場面の案【推論】（10%・1% は前の版からの置き値）。その後：業者に返金を求める／泣き寝入り。会計：返金されたら広告宣伝費の取り消し（または雑収入）、されなければそのまま。**請求書と配布報告書（GPSの記録）を照らす**場面になる（証憑の大切さ）。
5. **苦情**（ポスティングで5%）— 投函禁止の家から苦情【推論】（【2026-10-23 外した】根拠の crowdworks の記事は外した。5% は置き値）。その後：地図の口コミに悪い書き込み（3.9の土台が下がる）。会計：なし（評判だけが下がる）。
6. **リピーターが付く**（来た人の20〜40%）— 初回の体験が良ければ常連になる【推測】。その後：翌月以降の客数の底上げ。チラシの本当の採算は数か月後に分かる（LTV）。会計：翌月以降の売上。
7. **届いていない時代**（年が進むごとに反応が少しずつ下がる）— 根拠：折込の市場が前年比95%ほど [[web:bizmkt:r4-mkt-dentsu-adspend2024]]。

### 4.2 SNS（自前の投稿）

1. **空振り**（70%）— いいねが少し付くだけ【推測】。会計：なし。
2. **じわじわ**（25%）— 続けるとフォロワーがたまり、毎月の客の数%が「Instagramで見た」と答える【推測】。投稿をやめると止まる。
3. **バズる**（3%、写真映えする新メニュー・季節限定で上がる）— 一晩で数千〜数万の表示。その後：翌日から行列（4.10）。会計：売上急増・材料の急な仕入（現金払い・買掛金）・アルバイトの臨時の給料（未払費用）。
4. **炎上**（1%未満、店員の悪ふざけ・客の撮影トラブル・不衛生な写真で上がる）— 根拠：会社が原因の炎上は日本全体で年312件 [[web:bizmkt:r4-mkt-siemple-enjou2025]]。その後：対応の速さで分かれる（4.9）。
5. **真似される**（じわじわ・バズの後に20%）— 近くの店が同じ映えメニューを出す【推測：資料なし】。その後：客の一部が流れる、差別化の判断へ。

### 4.3 SNS広告

1. **予算どおりに表示されたが来店は少し**（60%）— 表示とクリックはすぐ数字で返る、来店は測る仕組みしだい。根拠：目安の単価 [[web:bizmkt:r4-mkt-honichi-instaads]]、来店率は【推測】。会計：カード払いの未払金→引き落とし。
2. **絞り込みが当たる**（25%、配信の地域を店の近くに絞ると上がる）— 近所の若い人が来る。
3. **絞り込みの失敗**（15%）— 遠くの人や対象外の年齢に表示され、来られない人ばかり。その後：配信の設定を直す判断。
4. **予算の上限で大赤字は起きにくい**（設計上の性質）— 「上限を決められる打ち手」と「青天井の打ち手」の違いを見せる。

### 4.4 LINE公式アカウント

1. **呼び戻し成功**（来なくなった客の5〜10%が戻る）— 根拠：スーパーで招待券を送ると平均約9%戻った（2007年）[[web:bizmkt:r4-mkt-itmedia-pointcard]]。会計：戻った客の売上、配信の追加料金（通信費・未払金）。
2. **送りすぎ**（月に何度も送ると）— 友だちを外される【推測：資料未読】。その後：届く人数が減る。
3. **配信費が膨らむ**（友だちが数千人を超えると）— 無料の通数を超えた分が1通3円 [[web:bizmkt:r4-mkt-lycbiz-msgfee]]。その後：プランを上げるか、送る相手を絞るかの判断。会計：月額を年払いにすれば前払費用の振り替え。

### 4.5 インフルエンサー案件

1. **大当たり**（10%、ジャンルと地域が合い、PR表記あり、特典付きで上がる）— 投稿の1週間で客が数倍。根拠：成功例のいいねの増え方 [[web:bizmkt:r4-mkt-findmodel-gourmet]]（成功例だけの資料なので、確率は低めに置く【推測】）。その後：品切れ・行列（4.10）、口コミが増えて地図の土台が上がる。会計：売上増、報酬の広告宣伝費、特典の値引き。
2. **そこそこ**（35%）— 数十人が特典を使って来る。CPAが計算できる（報酬÷特典の利用数）。
3. **いいねは付いたが来店しない**（35%）— フォロワーが遠くに住んでいる・属性が合わない [[web:bizmkt:r4-mkt-ownly-influencer]]。その後：「フォロワー数より、地域と客層を見て選ぶ」学び。会計：報酬は全額が広告宣伝費（効果がなくても）。
4. **偽フォロワー**（安く大きい人を選ぶと15%）— ほぼ効果なし [[web:bizmkt:r4-mkt-ownly-influencer]]。
5. **PR表記なしを頼んで発覚**（「付けないで」と頼んだ場合30%）— ステマ。責任は店 [[law:primary:r4-mkt-caa-stealth]]。その後：消費者庁の措置命令（社名公表）＋炎上（4.9）。会計：再発防止の外注費（支払手数料）、返金（売上の取り消し）、客の減少。
6. **起用した人が別件で炎上**（5%）— 店の商品も巻き込まれる（起用タレントの炎上で止める・考え直す32%）[[web:bizmkt:r4-mkt-siemple-enjou2025]]。その後：投稿の削除を頼むか、店の声明を出すか。
7. **投稿が来ない・約束と違う**（先払いの場合5%）— 会計：**前払金**が広告宣伝費にならないまま残る→返金交渉／貸倒れに近い扱い【推測：2級なら前払金の回収不能＝損失の判断】。契約書・請求書を読む場面。

### 4.6 地図・口コミ

1. **整えた**（費用ゼロ）— 他の打ち手で知った人が離脱しにくくなる（例：来店率に×1.2）【推測】。
2. **整えていない**— 知った人の一部が「営業時間が分からない」で離れる（×0.8）【推測】。
3. **悪い口コミが付く**（行列・品切れ・苦情の後に起きやすい）— 地図の土台が下がる。その後：返信して改善を示すか、放置か。
4. **「口コミを書いたら割引」**を選ぶ— 頼んで書かせた口コミ＝ステマの疑い【要確認】→ 口コミサイトから削除・措置の分岐 [[web:bizmkt:r4-mkt-lycbiz-coupon]] [[law:primary:r4-mkt-caa-stealth]]。

### 4.7 看板・のぼり

1. **じわじわ効く**（前を通る人の来店が少しずつ増える）【推測】。会計：毎年の減価償却費（備品）。
2. **許可が要った**（面積の合計が10㎡を超えたとき）— 申請・手数料・2年ごとの更新 [[web:bizmkt:r4-mkt-yamanashi-okugai]]。会計：手数料（租税公課または支払手数料）。
3. **景観の地区で使えない**（観光地の店で）— 色・大きさ・点滅の制限で、作り直し [[web:bizmkt:r4-mkt-yamanashi-okugai]]。会計：古い看板の **固定資産除却損**、新しい看板の取得（2級の固定資産の除却の題材）。
4. **台風で落ちる**（2%）— 人にけがをさせる危険（規制の目的の一つ）[[web:bizmkt:r4-mkt-yamanashi-okugai]]。その後：損害賠償・修理。会計：修繕費、または **災害損失**、保険金が入れば **保険差益**／未収入金【推測：ゲーム内の勘定に合わせる】。

### 4.8 クーポン・値引き・ポイント

1. **新しい客が来て一部が残る**（開店直後の小さな割引で）— 根拠：初回の得が来店のきっかけ [[web:bizmkt:r4-mkt-lycbiz-coupon]]。
2. **値引きの癖**（開店直後に大きく値引きし、定価に戻した月に客が2〜3割減る）— 根拠：なじみの薄い店の値段は「ふつうの値段」の感覚に入りやすい [[web:bizmkt:r4-mkt-refprice-loyalty]]。数字の大きさは【推測】。その後：また値引きするか、我慢するか（値引きが止められなくなる道）。
3. **常連の時期のセール**— 定価に戻しても客が離れにくい [[web:bizmkt:r4-mkt-refprice-loyalty]]。
4. **常連ばかりが使う**（誰でも使えるクーポンで50%）— 上乗せの客は少なく、粗利だけ減る【推測】。その後：「対象を絞る」学び。
5. **粗利が足りなくなる**（割引率が高いまま続けると）— 月次の損益で営業利益が赤字。根拠：利益が削られ続けるという提供元の注意 [[web:bizmkt:r4-mkt-lycbiz-coupon]]。会計：売上は増えても売上総利益が減る、を月次の損益計算書で見せる。
6. **競合がもっと安くする**（値引き合戦、15%）— 根拠：ポイント合戦の指摘 [[web:bizmkt:r4-mkt-itmedia-pointcard]]【確率は推測】。その後：価格以外で勝つ判断へ。
7. **スタンプカードが使われない**（50%以上が使わない）— 契約負債が売上に戻る時期・額が変わる。使われないまま期限切れなら、そのときに売上 [[web:bizmkt:r4-mkt-tkc-point]] [[web:bizmkt:r4-mkt-jicpa-point]]。決算の数字が分かれる。
8. **景品の上限超え**— 措置命令・社名公表 [[law:primary:r4-mkt-caa-premium]]。

### 4.9 炎上の後（どの打ち手からでも入る共通の分岐）

起点：ステマの発覚、店員の投稿、品切れへの怒り、異物混入（工場の回では自主回収）。分かれ目は **対応の速さ** と **中身**：
1. **24時間以内に事実と謝罪と対策**— 傷は浅い。根拠：見た人の多くが会社の対応を確かめ、3日以内にないと悪い印象を持つ人が約39% [[web:bizmkt:r4-mkt-siemple-enjou2025]]。会計：おわびの品（販売促進費）、返金（売上の取り消し・現金）。
2. **3日〜1週間後に対応**— 悪い印象が半数近くまで広がる（1週間以内までで約53%）[[web:bizmkt:r4-mkt-siemple-enjou2025]]。客が数か月減る【推測】。
3. **放置・言い訳**— 「不誠実な対応」でブランドが大きく傷つく（研究所の指摘）[[web:bizmkt:r4-mkt-siemple-enjou2025]]。取材される（地元紙・テレビ。報道まで48時間未満が約57%）。会計：売上の大幅減、銀行の融資の審査に響く（決算書の数字で返す）【推測】。
4. **ステマなら行政**— 措置命令（社名公表）[[law:primary:r4-mkt-caa-stealth]]。会計：再発防止策の外注（支払手数料）。

### 4.10 品切れ・行列（大当たりの後の共通の分岐）

1. **事前に在庫を増やしていた**— 売上が伸びる。ただし外れたら材料が余る→ 廃棄（商品廃棄損）・期末の **棚卸** で数が合わない（棚卸減耗）。
2. **在庫を増やしていなかった**— 開店1時間で品切れ。売れたはずの売上（機会損失）は**帳簿に載らない**（会計に出ない損失）。来た客の怒りが口コミに（4.6-3）。
3. **急いで仕入れた**— 割高な仕入（近所のスーパーで現金で買う）で原価率が上がる。会計：現金仕入、粗利率の低下が月次に出る。
4. **アルバイトを急に増やした**— 臨時の給料（月末に払っていなければ未払費用）。慣れない人の会計ミス→ **現金過不足**。

## 7. ゲームへの組み込み案（判断の形）

**判断画面の共通の型**（社長が持ってくる「やろう」に、経理部が数字で答える）：
1. 社長の提案（例：「インスタで10万人の人に頼もう！30万円で！」）
2. 経理部が見られる情報：費用の見積書、相手のフォロワーの地域と属性（見る手間をかけると見える）、店の状態（常連の数・在庫・地図の整備・測る仕組み）
3. 選ぶもの：誰に・いくら・いつ・特典・測る仕組み・在庫の準備・表示（PR表記）・支払い方（先払い／後払い）
4. 返るもの（時間差で）：すぐ＝表示回数・いいね／1週間＝来店数（測る仕組みがあれば）／1か月＝月次の損益（売上総利益と広告宣伝費）／数か月＝リピート（LTV）／決算＝契約負債・貯蔵品・減価償却の数字
5. 分岐の抽選：4章の起きやすさを、状態で上下させる（例：PR表記ありで炎上率を下げる、地域が合うと大当たり率を上げる、在庫準備なしで品切れ率を上げる）

**状態変数の案**【推測】：常連の数（値引きの癖の強さを決める）／町の客層（新聞購読率・SNS利用の年齢）／地図の整備度（全打ち手の掛け算）／評判（口コミ）／在庫／測る仕組みの有無／店の処理能力（人手）。

**学びの核**：
- 効果が分からないものに、お金を先に払う（前払金・前払費用）。効果がなくても費用は費用。
- 1回の粗利が小さい商品は、リピートが付かないと広告で損をする（CPAとLTV）。
- 値引きは「お金が出ていかない費用」。売上を減らし、将来の値段の感覚まで下げることがある。
- ポイントは売った時点で売上を一部後回しにする（契約負債）。客が使うかどうかで決算の数字が変わる。
- 測らなければ、次の判断ができない。
- 表示の責任（ステマ・景品・看板の規制）は頼んだ店にある。

**バッドエンドにつながる道の案**：
- 値引きが止められない→粗利が赤字→資金繰り（手形・借入の回につなぐ）
- ステマの措置命令＋放置→客離れ→決算の赤字→銀行の融資の打ち切り
- インフルエンサーへの大きな先払い→投稿されない→前払金が回収できない
