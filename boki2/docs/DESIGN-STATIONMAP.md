### 4.4 家賃・保証金・造作（BIZ-RENT23 から）
- **坪家賃（1階・月・共益費込み）＝ max(下限, R₀×(地価／1,000万円/㎡)^b)×(1＋ばらつき)**。初め：b＝0.25、R₀＝28,000円/坪、下限＝13,000円/坪、ばらつき ±20%（seed）。
- 探してよい幅：**b は 0.15〜0.7**（BIZ-RENT23 版0.2 2章：最小二乗の点で 0.17〜0.32、頑健な推定で 0.15〜0.41、地価の側の測り違いを最大に見た逆回帰の上限で 0.36〜0.71。「b の大きさは資料では決まらない」。0.25 前後は幅の下の側）。初めの b＝0.25 は資料の中央に近い点ではなく下の側なので、sim では 0.25・0.4・0.55 の3つを必ず試す。R₀ は 2.5万〜4.0万（赤字のくじが 50% を越えない所まで。論証 v18：4.5万で66%。BIZ-RENT23 版0.2 の式の値：1階 28,745円・飲食店可 31,040円）。家賃の水準 R₀ を下げると、よい場所と悪い場所の家賃の差の額が縮み、よい場所が勝ちやすくなる（BIZ-RENT23 版0.2 の R4b の向き）。下限は 1.0万〜1.5万。
- 地価300万円/㎡より下（候補地の約73%）は資料の外へ延ばした値【推論】。
- 属性で家賃を掛けない（属性の差は地価に入っている。BIZ-RENT23 の属性ごとの倍率は、割り当ての仕方で 0.58〜1.62 まで動き、置けない）。
- 保証金：家賃の6・8・10か月のどれか（seed）。BIZ-RENT23 の「家賃の6〜10か月」は敷金・礼金をまとめた物件取得費の値（判定 M3）なので、保証金だけならもっと短い可能性がある。今の設計の6か月を下の端として残し、調べ直す（8章）。
- 造作（居抜き）：元の内装の工事費の約3割・上限300万円・0円もありうる。

### 4.6 人が足りない場所（1号店でも作る。オーナーの決定）

### 4.10 なぜうまくいくか（肯定側の問い）と、崩れる条件（版0.7.2 で試しの出力に合わせて書き直した）
**いちばん強い形（設計の賭け）**：
1. 立地の判断が面白くなるのは、**勝てる所の「勝ち方」が場所によって違う**とき。大きい駅は客で勝つがライバルと家賃に食われる。小さい駅の0軒の所は安さと独り占めで勝つが、成功すると寄ってくる（オーナーの決定 (a)、γ）。住宅地は常連で後から伸びる（⑨）。勝ち方が違えば、どの1本の規則でも上手な選び方に届かない（⑥）。
2. 0軒の有利が**時間で減る**（γ・成功で寄る参入）なら、遊ぶ人の判断は「独り占めが何年続くか」と「今から競争に入るか」の比べになる。予兆の札（2か月前）で手を打てる。
3. 客の水準を地図全体で合わせれば（司令塔の決定1）、平均の店で地図の半分ほどが黒字になり、「どこで勝つか」を考える余地がある。
**試しの出力で、成り立っていること**：
- 地図全体の較正で、①は 43.9〜44.3（週の揺れで 42.0〜42.5）、平均の店の赤字の割合は期待値で 48.9〜50.6% まで下がった（版0.7.1 の 67〜77% から）。
- γ・δ は、大きい駅を赤字にせずに（段8 +122〜138万）⑤と⑬を通した（M_g・M_d・M_gdd）。
- 住宅地の常連の伸び（⑨ 1.30〜1.36）、オフィス街の「昼だけが通しより得」（52〜55%）は、どの案でも出る。
**成り立っていないこと**（版0.7.1 の 4.10 が「うまくいく」側に書いていたもの）：
- **(1) の「どの1本の規則でも届かない」は、同じ段の中では成り立っていない**。α・γ では、どの段でも「0軒の所」が得。δ では、どの段でも「軒数の多い所」が得に裏返る（上の表）。版0.7.1 は δ について「避けるのも行くのも正解でない」と書いたが、出力と逆だった（論証の検査 主張5・10）。⑥ は全体の上位10とだけ比べるので、これを捕まえない（6.1 の直しの案⑥'。ただし試しの⑥' の式も、規則の並べ方が人通りの倍率に引っぱられて、この裏返りを捕まえなかった）
- **「どの段・どの属性にも勝てる所がある」は成り立っていない**。工場は全部の組で 0/25。段6 は全部の組で利益の中央 −264万以下。オフィス街は利益の中央 −163〜−186万（⑪' の線の下）。段1 は段の比 7.9 の組で線の上下
- **「繁華街は夜が強い」は成り立っていない**（⑦の繁華街 3〜7%）。オーナーの例「センター街は歓楽街」の手ざわりが数に出ない
- **「オフィス街は昼だけで固定費を削って勝てる」は言えない**：⑦のオフィスは「通しより得」の割合で、黒字かどうかではない。オフィスの利益の中央は全部の組で赤字（論証の検査 主張10）
- **「⑫b 逆転なし」は seed と K で崩れる**（γ M_g18・δ の K6）
- **赤字の割合は、週の揺れを入れると 56〜58%**。PEDAGOGY 1.5 の「運は小さく」は週の客数の揺れの話で、⑭が測っている「平均の店が地図のどこに出ると赤字か」（地図の難しさ）とは別の量（論証の検査 主張10・12）。④（くじの揺れの分 15〜29%、版0.7.2 の M）も同じく運の大きさの直接の数ではない
**崩れる条件**（★は試しで当たっているもの）：
- ★ 段の中の1本の規則（0軒が得／多いほど得）：⑤⑬が通っても、遊ぶ人は段を決めたあとに軒数だけで選べる
- ★ 属性・段が丸ごと死ぬ（工場・段6・オフィス）：死んだ所は地図の飾りになる
- ★ 繁華街の夜が死ぬ
- ★ 赤字の割合が半分を越える（週の揺れの列）
- 情報が多すぎる：開店の前に型と強さまで見えると、上手な選び方が「見える数の計算」になる（ε の問い）

**この節の結論**：賭けは、試しの出力では**まだ成り立っていない**。手続き（線を回す前に置く・案を絞らない）は直ったが、遊びの健全さ（判断が1つに決まらない）は、段の中の軒数・工場・段6・繁華街の夜・赤字の割合の5つで崩れている。どれを仕組みで直し、どれを「現実としてそういう地図」と受け入れるかは、9章 (a)〜(d) のオーナーの答えで決まる。

**(a) 「何も考えずに出した店」が、地図のどれくらいで赤字になってよいか**
- いまの事実：今のゲームの「平均の店」（850円・パート1人・宣伝なし・営業は通し）を、地図の981か所に出すと、3年目に赤字になる割合は、客の水準を地図全体で今のゲームと同じ（1日44人）に合わせたとき、天気や仕込みの揺れを入れない計算で 49〜51%、揺れを入れると 56〜58%。家賃を資料の幅の端まで下げても、前の版の計算で 54%（揺れなし）。
- これは「運の悪さ」の数ではなく、「地図のどこが難しいか」の数。考えて選ぶ遊び手（上手な選び方）なら、もっと低くなる。
- 選択肢：
  1. 何もしない平均の店でも、赤字は半分まで（今の線。揺れを入れた数で50%以下）。今の仕組みのままだと届かない
  2. 何もしない平均の店なら、赤字が半分を越えてもよい。代わりに「考えて選んだ店」（地図とカードで見える数から選ぶ上手な遊び手）の赤字が、例えば4か所に1か所までであることを確かめる
  3. 線を置かず、赤字の割合は報告だけにする（地図の難しさとして見る）
- おすすめ：**2**。理由：オーナーの1号店の決定（人が足りない場所を、警告つきで作る）と同じく、「何も考えずに出すと失敗しうる地図」は現実に近い。大事なのは、考えた遊び手が黒字にできること（学習効果：判断が結果に返る）。ただし2 の「4か所に1か所」の数はまだ決めていない（試しの結果を見たあとで線を引くことになるので、決めるならオーナーの言葉で）。

**(b) 工場・倉庫の近くの候補地（25か所）を、どう扱うか**
- いまの事実：工場の近くの候補地は、どの版・どの仕組みで計算しても、「地図の上位3割に入るよい所」が 0〜1か所。3年目の利益の中央は −192万〜−419万円。人通りが少なく（人通りの倍率 0.6）、ライバルも少ないが、客が足りない。オーナーの例（商店街・オフィス・住宅地・繁華街）には工場は出ていない。データの分類で出てきた属性。
- 選択肢：
  1. 工場にも勝てる所を作る仕組みを足す（例：工場で働く人の昼の外食。資料はまだない）
  2. 「工場の駅前はラーメン屋に向かない」という現実として地図に残し、選ぶ価値のある所がなくてよい（物差しの対象から外す）
  3. 工場の候補地を地図から外す
- おすすめ：**1 をまず調べ、資料で裏づけが取れなければ 2**。理由：オーナーは工場を外すと言っていない。外すのは、仕組みを調べてからでも遅くない。2 は「選ぶ価値がない所もある地図」で、現実の手ざわりとしてはありうる。

**(c) 繁華街（センター街のような所）は、夜が強くないといけないか**
- いまの事実：オーナーの決定「夜の強さを、駅のまわりで飲食業に勤める人の割合で置く」で、東京のデータを当てると、繁華街は昼に働く人もとても多く（昼の働き手の比の中央 0.91）、繁華街でも「夜だけ開けるほうが通しより得」な所は 3〜7%（目標は20%）。夜に働く飲食の人を夜の側へ数え直しても、ほとんど変わらない。一方、住宅地・商店街には「夜だけが得」な所がある。オフィス街の「昼だけが得」は 52〜55%。
- 選択肢：
  1. 繁華街は夜が強い、をゲームで必ず出す。そのために、夜の客は1人あたり多く払う（酒・トッピング）、パートを昼と夜で別に雇う、などの仕組みを足す（どれも資料はまだない。パートを分ける形は、これまでの試しで繁華街の夜が 11〜30% と、線の上下にまたがった）
  2. 繁華街にこだわらず、「地図のどこかで、昼だけ・夜だけが得な所が、それぞれ5か所に1か所ある」ことを求める（「ランチ帯が儲かるのか夜も行けるのか」は場所ごとの話、と読む）
  3. 東京の繁華街は昼も強い、というデータのとおりに残す（時間帯の判断は、オフィス街と住宅地で生きる）
- おすすめ：**2 と 1 の両方を測って、両方を満たす仕組みがあれば採る。なければ 2**。理由：オーナーの言葉「ランチ帯が儲かるのかよるも行けるのか」は場所ごとの話で、2 がいちばん近い。1 の仕組みは資料がなく、置き値で繁華街を夜に寄せると「データで置く」という前の決定と食い違う。

**(d) ライバルが多い所をどう見るか、と、近くに出された店がどれくらい効くか（組で答えてほしい）**
- いまの事実：
  - 今の計算では、同じ大きさの駅の中で比べると「ライバル0軒の所」がいつもいちばん得（「空いている所に出す」が1本の正解になる）。
  - それを直す案の1つ「ライバルが多い所は、実は客も多い印」（オーナーの言葉「人が多いところは複数の競合がひしめきやすい」を、逆向きにも成り立たせる）を入れると、今度は「ライバルが多いほど得」に裏返り、0軒の所はほぼ選ぶ価値がなくなる（同じ駅の大きさで、0軒 +42万・1軒 +85万・2軒以上 +110万円）。効きを半分にした計算でも、勝てる所（上位50）に入る0軒の所は、ふつうの割合の半分以下。
  - もう1つの案「成功した店のそばの空き地には、ライバルが早く来る」（オーナーの決定「成功した店の近くにライバルが寄ってくる」を強める）は、0軒の得を小さくするが、順は変わらない（0軒がまだ得）。しかも、近くに出された店が「同じ駅ならどこでも効く」か「すぐ近く（歩いて5分）だけ効く」かで、効きが大きく変わる（すぐ近くだけにすると、0軒の得がほぼ残る）。
- 選択肢（組で）：
  1. 「ライバルが多い所は客も多い」は入れない。「空き地にはライバルが早く来る」を入れ、近くに出された店は駅のどこでも効く
  2. 同じく入れない。「空き地にはライバルが早く来る」を入れ、近くに出された店はすぐ近くほど効く（距離で弱まる）
  3. 「ライバルが多い所は客も多い」を弱く入れ、2 と組み合わせる（0軒の所も、多い所も、どちらも選ぶ理由が残る強さを探す）
  4. 決めずに、正本の計算で全部の組を見てから選ぶ
- おすすめ：**4 のあとで、3 を第一の候補として見る**。理由：1 と 2 は「空いている所に出す」が残り、「多いほど得」に振れた案は「混んでいる所に出す」が残る。どちらも1本の正解になり、オーナーの「どこに出すか考える楽しさ」を削る。弱く混ぜたときに、段の中で軒数の得が一方向に並ばない強さがあるかは、まだ測っていない。

**(e) 大きい駅と小さい駅の、店の前を通る人の差（版0.7.1 の 13）**
- いまの事実：新宿・渋谷・池袋の候補地の店の前を通る人を、小さい駅（1日3万人未満）の候補地の約8倍に置いている（前の版は約2倍）。根拠は「駅の人数をピンの数で割った数」と「飲食店1つあたりの駅の人数」の2つの見当で、ラーメン店の資料ではない。ライバルや席の上限があるので、実際の客は約2倍にとどまる。
- 選択肢：1. 約8倍で進める 2. 前の約2倍に戻す（その代わり、0軒の小さい駅が勝ちやすい） 3. ラーメン店の数の資料を取ってから決める
- おすすめ：**3、それまでは1で測る**。理由：今の数は資料のない所の見当で、どちらの向きにも裏づけが弱い。
