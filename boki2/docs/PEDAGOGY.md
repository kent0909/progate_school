# 学習設計とゲーム設計の土台

版：1.0（2026-10-19）。開発者と Fable 5.1 の議論で確定。旧 PEDAGOGY_DRAFT.md は廃止。

## 0. 前提
### 0.1 目指す体験
1. 努力している実感がなく、ずっと楽しい
2. 一方的に覚える・暗記する苦痛が緩和されている
3. ユーザーの行動が結果に反映され、双方向である。ログインボーナス・量に応じた報酬のような表層的ゲーミフィケーションは使わない
4. そのうえで、いつの間にか日商簿記2級を習得している

### 0.2 禁止事項
- 新しい用語・概念を羅列して伝えること。用語は「困りごと→既知の原理をあてはめる→結果→名前がつく」の順でしか登場させない
- 用語を先に出してから説明すること
- 教科書を画面に置き換えただけの構造（読む→解く）
- 量・連続日数・ログインに対する報酬
- 1画面で本文60字×3行（180字）を超えて読ませること（例外：本試験の文言の引用、先輩の手帳）

### 0.3 「習得」の3層
| 層 | できること | 測る場所 |
|---|---|---|
| 原理 | 初見の設定でも、原理から仕訳・計算を組み立てられる | 会社の中の判断と理由の選択、原理マップ |
| 処理 | 本試験の文言を読み、速く正確に処理し、所定の形で書ける | 検定会場、月末締め、自動仕訳の棚卸 |
| 現場 | 証憑・台帳・通帳から、どの原理が必要な場面か気づける | 証憑タップ入力、経営ループのイベント |

### 0.4 決定済みの前提
- 1年＝12ターン。受験モードで短縮できる
- 記帳の誤りは月内に会社の状態へ反映し、月末までに必ず修正させる
- 2027年度の区分変更（手形・リース）は現状方針（参考表示・模試から除外）を引き継ぎ、区分表の原文を確認してから差し替える

## 1. 中心の遊び：ピヨの会社を1か月ずつ経営・記帳する
### 1.1 コアループ（1ターン＝1か月）
```
① 届く     証憑（請求書・通帳・契約書・工場日報・ニュース）が机に来る。B/Sパネルが変化の予兆を見せる
② 決める   証憑をタップして「いつ・何が・いくら」を拾い、原理の操作で箱を動かし、理由を選ぶ（型1〜5）
③ 締める   月末。試算表が合うか。合わなければ森さんが場所だけ示す。修正して締める
④ 返る     会社の状態（B/S・P/L・現金）が動く。銀行・株主・税務・監査が反応する
⑤ 広がる   事業が広がり、今の原理では記録できない出来事が起きる（次の論点）
```
- 1ターン5〜10分。新しい判断が要るイベントは1〜3件、残りは自動仕訳で数十秒
- 困りごとは台本で必ず起こす。プレイヤーの正誤に関わらず、原理を発見する場面は飛ばせない
- 誤りの返り方は2種類
  - 即時：てんびんが傾く／森さんが場所だけ示す
  - 遅延：月末に試算表が合わない、通帳と帳簿がずれる、融資審査・税務調査で指摘される
- 帳簿は月末までに修正し、翌月に持ち越さない。修正そのもの（訂正仕訳）も論点として扱う

### 1.2 用語が生まれる4拍
| 拍 | 何をするか | 画面 | 読む量 |
|---|---|---|---|
| 1 困りごと | 証憑が届く。B/Sパネルの箱に「？」が出る。セリフ1〜2行 | 証憑＋B/Sパネル | 2行以内 |
| 2 原理の問い | 原理に対応する手の操作で試す（1.3）。操作のあと、理由を1タップで選ぶ（選択肢は分かれ道表の典型誤答） | 操作画面 | 問い1行＋選択肢 |
| 3 結果 | 選んだ処理の帰結をそのまま会社に反映して見せる。誤りも一度は反映する | B/S・P/L・現金パネル、相手の反応1行 | 2行以内 |
| 4 名前がつく | 「この処理を簿記では○○と呼ぶ」。正式用語、本試験の文言、原理マップに葉が生える | 名前カード | 3行以内＋文言の引用 |

先輩の手帳（旧レッスンの参照版）はいつでも開けるが、読まなくても進める。

### 1.3 原理ごとの手の操作
| 原理 | 操作 | 部品 |
|---|---|---|
| P1 P2 | B/Sパネルの箱を増やす・減らす・別の箱へ移す | bs（操作可） |
| P3 | 期間の帯を決算日で切り、当期分と翌期分を置く | timeline（操作可） |
| P4 | 箱の中にマイナスの箱を置く／箱の目盛りを時価へ動かす | bs（箱内マイナス） |
| P5 | 作った決算書の行を区分へ並べ替える | sort |
| P6 | 原価を箱から箱へ運び、残りと出た分に分ける | flow・box（操作可） |
| P7 | シュラッター図・面積図に「あるべき」の線と「実際」の点を置く | schlatter（新規） |
| P8 | 合算表の対になる行を選んで消す | 合算表（新規） |

操作で決めるのは「どの箱がどちらに動くか」まで。金額の計算と科目名は操作のあとに決める。操作は偶然でも正解できてしまうので、操作のあとに必ず理由を選ばせる（自己説明の代わりであり、分かれ道の集計の入力にもなる）。原理ごとに手の操作が違うこと自体が、原理の違いの体験になる。

### 1.4 判断のある場面
各章に1つ以上、正解が1つでない経営判断を置く。結果は会社の状態に数年単位で返る。
例：償却法、与信限度、支払条件、配当額、リースか購入か、予定配賦率と見積価格、受注の可否、買収価格。
判断の履歴は経営日誌に残り、結果が返ったときに振り返れる。

### 1.5 資金繰り（本物の制約）
- 現金が尽きると仕入れと給料の支払いができない。倒産はしない。銀行に頭を下げて高金利の追加融資を受けて続行し、支払利息が翌期以降に返る（罰ではなく、未払利息・月割の論点の素材）
- 資金繰りが変わる原因は決定論に限る。原因になってよいのは、帳簿の誤り（現金残高の見誤り）とプレイヤーの判断だけ。受注量や相場の運で資金が尽きることはない
- 帳簿残高と通帳残高のズレは、c10（銀行勘定調整表）と現金過不足の発見イベントとして月末に突きつける
- 黒字倒産寸前（売掛金は増えたが現金がない）は台本で1回必ず起こす。利益と現金の違いはP3の最大の発見機会

### 1.6 自動仕訳ルール（熟達の結果としての進捗）
- 同じ型（kind）の取引を3回正しく切り、そのうち1回が別の月なら、その型を「会計ソフトの自動仕訳ルール」として登録できる
- 登録は条件文で行う（「商品を掛けで仕入れたとき → 仕入／買掛金」）。条件文を組むことが原理の言語化になる
- 自動化した取引は自動で記帳され、新しい判断に集中できる。ルーチン月は数十秒で進む
- 点検：やり直しの依頼（間隔反復）に加え、監査が「条件の外」の取引を仕込む（例：自動ルール「貸倒れ→貸倒引当金／売掛金」に当期発生の債権の貸倒れを流す）。分かれ道の点検そのものになる
- 検定会場では自動化は効かない。検定前に「自動仕訳の棚卸」（自動化した型を手で切り直す10問）を任意で出す

### 1.7 証憑タップ入力
- 証憑の該当箇所をタップして値を拾う。対象は金額だけでなく、日付（いつ？→P3・月割）と相手先・品目（アンカーと相手勘定の判断）。型1の問いの順に証憑を見る習慣をつける
- 計算が必要な金額（月割・差額・税抜）は、タップした値を計算パッドへ渡す。差額は最後に求める
- 検定会場はCBTと同じキー入力のまま（タップに慣れすぎて本番で桁を間違えるのを防ぐ）

### 1.8 進捗と報酬（すべて状態の変化）
- 会社の状態：屋台→株式会社→支店→設備→投資→子会社→工場。B/Sの箱が大きくなる
- 任される仕事：新人（現金・預金）→主任（債権・固定資産）→課長（決算）→経理部長（連結）→工場経理→CFO。権限が増えると、触れる勘定と画面が増える（実務カードは「権限証」として再定義）
- 自動仕訳ルールの数（熟達の可視化）
- 原理マップが広がる
- 自分の判断で結果が変わった履歴（経営日誌）
- 廃止：コイン、XP、デイリーミッション、連続日数、ヒント購入、量に応じたバッジ

### 1.9 第2のループ：検定会場
- 年度末と任意のタイミングで受けられる。中身は現在の模試（CBT形式、大問43題＋仕訳バンク）
- 合否は会社の状態に影響しない。結果は原理×分かれ道で集計され、原理マップに弱点として重なる
- 受験直前の人の主な導線は、検定会場→弱点→該当する発見イベント。シムを順に進める導線は従とする

### 1.10 受験モード
- 会社の状態を引き継いだまま任意の段階に飛べる（物語上は「中途入社」）
- 原理の発見は飛ばせない。P1〜P8の発見イベントを各1つに圧縮した「入社研修」（合計30〜40分）を必ず通す
- 飛ばした論点も検定会場の出題範囲に含める

## 2. 背骨の原理（8つ・4群）と操作の型（5つ）
原理は「問い」として定義する。全48章の用語は、この問いに答える過程で必然的に出てくる。

### A. 記録の原理
- **P1 二面性**：何が増え、何が減った／何が原因かを同時に書く。左右の合計は常に等しい。保存則（期首＋増加＝減少＋期末）はP1の時間方向の表現で、T勘定・ボックス図はその絵
- **P2 5要素と純資産**：会社の財産（資産）はだれのものか（負債・純資産）。純資産を動かした原因が収益・費用

### B. 時間の原理
- **P3 期間帰属**：この収益・費用はどの期間の活動に属するか。現金の動きと切り離して考える（発生・実現・対応）

### C. 見せ方の原理
- **P4 評価**：この資産・負債をいくらで見せるか（取得原価・時価・回収可能額・換算）。直接減らさず「マイナスの箱」で見せる場合がある
- **P5 表示と区分**：どこに、どんな区分で見せるか（流動・固定、販管費・営業外、資本金・準備金）。読む人が何を判断するための区分かとセットで扱う

### D. 範囲と計画の原理
- **P6 原価の流れ**：使った価値は消えず製品に乗り移る。残ったものは資産、出たものは次の箱へ（保存則＋按分）
- **P7 計画と差異**：あるべき（予定・予算・標準）を先に決め、実際との差を原因別・責任別に分ける
- **P8 経済的実体**：法律上の形より経済の実態で記録する（グループを1つの会社とみなす、賃借でも実質購入なら資産、本店と支店は1つの会社）

### 用語の3分類
| 分類 | 例 | 扱い |
|---|---|---|
| 導出型（原理から出る） | 貸倒引当金、契約負債、非支配株主持分、操業度差異、完成品換算量 | 4拍の順を厳守。名前は答えのあと |
| 規約型（約束ごと） | 借方・貸方、三分法、資本金の1/2ルール、200%定率法、備忘価額1円 | なぜ約束が要るか（困りごと）は示すが、「約束です」と正直に言う。原理から導けるふりはしない |
| 手続き名 | 差額補充法、先入先出法、相互配賦法、シュラッター図 | 手順を先に体験させ、終わってから名前を貼る |

用語は家族単位で導入する（1つの困りごとから1家族：引当金の家族、差異の家族、のれんの家族）。家族の中の兄弟は並べて違いを1行で言わせる。

### 操作の型（原理を適用する手順。原理マップには載せない）
- **型1 個別取引の仕訳**（P1・P2）：いつ？→何が起きた？→アンカー（確実に動いた具体的な勘定）→相手→金額→指示語→検算
- **型2 ストックを合わせる**（P3・P4）：あるべき残高→今の残高→差を動かす→翌期首・翌期はどうなる
- **型3 按分**（P6）：箱を描く→何で配るか→単価＝どの原価÷どの量→残る側から計算し出る側は差額→左右一致
- **型4 差異分析**（P7）：あるべき→実際→差（正＝有利）→要因に分ける→差異勘定→売上原価
- **型5 連結**（P8）：合算したら何が二重・内部か→対にして消す→誰の取り分が変わるか→開始仕訳→連結B/S一致

ヒントは答えを縮めたものではなく、型の次の問いを3段階で出す（いつ？アンカーは？／相手のグループは？／科目名）。科目名を最初から出さない。

### モデルの用語（全章で言い換えない）
置き場所、マイナスの箱、一時置き場（仮勘定・経過勘定・差異勘定）、純資産に直接、あるべき／今、保存則、4時点（期中・決算・翌期首・翌期）。詳細は `docs/MODELS.md`。

## 8. 説明の作法
- 順番：モデルで見せる→操作させる→結果を見せる→名前を貼る→本試験の文言
- やさしい言葉はモデルの言語化、正式用語はラベル。両者は同じ概念を指していなければならない
- たとえ話は対応表（何が何に対応するか）と破綻点（どこから合わないか）を必ず添える。破綻点が概念の核心にかかるもの（「減価償却＝値下がり」「のれん＝ブランド代」）は使わない
- 小学生と受験生は同じ会社を経営する。違いは前提知識と読解で、前提は屋台期と月初の想起で、読解は証憑タップと検定会場の攻略で吸収する。「読めれば進める」が約束

## 付録A イベント定義の例（c16 減価償却）
- 拍1：12月。10月に買ったトラック300万円の請求書を「車両費」で全額費用にした月次を見て、銀行の田中さん「今期この赤字では、来年の融資は難しいですね」。B/Sパネルの費用の箱が跳ね上がり「？」
- 拍2：P3の操作。timelineに300万円の帯を置き、「どの期間の売上を助ける？」で帯を切る（今年だけ／5年に分ける／売るまで置く）。切ったあと理由を選ぶ（「使う年数の分だけ売上を助けるから」／「払ったのは今年だから」／「まだ持っているから」）
- 拍3：選んだ切り方で5年分の利益が bars に出て、田中さんの反応が変わる。森さん「いくらで買ったかは残しておいて」→P4のマイナスの箱を置く操作
- 拍4：減価償却費／減価償却累計額／間接法。本試験の文言「定額法により、間接法で記帳している」。原理マップにP3の葉、P4へ細い線
- 判断：定額法か定率法か。利益の出方と税金が翌年以降に返る。保証額・改定償却率は必要になった年に出す
- 証憑タップ：請求書の「納品日 10月1日」をタップ→月割の6/12が計算パッドに渡る

## 付録D 型4の符号の約束
差＝あるべき−実際。正＝有利（貸方差異）、負＝不利（借方差異）。図では「あるべき」を線、「実際」を点で描き、点が線より上なら不利。期末は、不利差異を売上原価に加え、有利差異を差し引く。
