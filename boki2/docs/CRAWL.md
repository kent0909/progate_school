## 2026-10-20 の検証
この文書は、もとは cpa-learning.com のページを `tools/crawl.js` で取得し、`tools/compare-crawl.js` で見出しの語を教材と突き合わせる手順書だった。2026-10-20 に、今の仕組み（`research/`、`tools/research-fetch.js`・`tools/research-check.js`）と、取得して全文を読んだ資料（読了ノート）で、記述を1つずつ確かめた。

判定の書き方は `docs/UPDATE_PLAN.md` と同じ：**【裏づけあり】**（出典 `[[取得元:コレクション:文書ID]]`）／**【誤り】**／**【未確認】**。

**結果の要約**
- **手順が古い。** 外部資料の取得は、いまは `tools/research-fetch.js` だけを通す。取得元の台帳 `research/sources.json` に登録して規約の判定を書き、取得記録を `research/ledger.jsonl` に残し、原文を `research/raw/` に置く。読んだら読了ノートを書き、`tools/research-check.js` で検査する。`crawl.js`・`compare-crawl.js` と `boki2/crawl/` を使う手順は廃止した（下の「旧手順」に経緯だけ残す）。
- **規約の扱いに誤りがあった。** 「見出しだけにすれば cpa-learning の規約に合う」は誤り。規約 第4条18号は、自動のダウンロード・複製・保存そのものを禁じている。そのうえ、規約を確かめる前に自動取得していた（台帳の記録）。2026-10-20 にオーナーへ報告し、条件つきで取得と分析を認めてもらった（下）。
- **簿記ペディアの取得範囲の記述に誤りがあった。** 「解答・解説のPDFは会員ログインが必要なので取得していない」は誤り。練習問題は模範解答が、過去問は模範解答と解説が公開されていて、取得して読んだ。会員限定だったのは練習問題の解説。本試験の問題用紙は公開されていない。
- セット数（練習問題65・過去問44、第157回まで）、3秒間隔、robots.txt がないこと、問題用紙の「無断転載・二次利用禁止」の表示は、すべて裏づけが取れた。

## いまの手順（2026-10-20〜）
くわしくは `research/README.md`。

1. **取得元を台帳に登録する**：`research/sources.json` に、ホスト、規約の確認日と判定（ok／gray／owner-approved／no-automation／unchecked）、アクセス間隔（`min_interval_s`）、集める対象（expected）と、対象外にしたものとその理由（excluded）を書く。
2. **取得する**：
   ```
   node boki2/tools/research-fetch.js --src <取得元> --coll <コレクション> --doc <文書ID> [--part <部分>] --url <URL>
   node boki2/tools/research-fetch.js --src … --coll … --doc … --skip "取らない理由"
   ```
   台帳にない取得元、規約が未確認の取得元、自動取得を禁じた取得元は、取得を拒否する。同じホストへのアクセス間隔も守る。原文は `research/raw/<src>/<coll>/` に置く（`.gitignore` 済みで、リポジトリには入れない）。取得記録は `research/ledger.jsonl` に1行ずつ追記する（時刻・URL・状態・サイズ・sha256・保存先）。
3. **全文を読み、読了ノートを書く**：`research/notes/<src>/<coll>/<doc>.md`。原文の sha256、`read: full`（一部だけなら `partial` と `pages:`）、本文にそのまま出る語句（anchors）と、自分の言葉の分析を書く。
4. **検査する**：`node boki2/tools/research-check.js`。取りこぼし、読んでいない資料、拾い読み（文書のすべての区間から anchors が出ていない）、別のファイルを読んだノート、転載（原文と30字以上の一致）、規約違反、存在しないノートを指す出典を見つける。`--write` で `research/STATUS.md` を更新する。
5. **教材に反映する**：分析は `docs/analysis/*.md` に書き、資料に触れるたびに `[[取得元:コレクション:文書ID]]` の出典を付ける。教材（`js/data`）に取り込むのは論点・出題の型・つまずきの分析で、文章や問題をそのまま写さない。数字・設定・解説は独自に作る。

### 見出しの突き合わせ（2026-10-19）の扱い
- `compare-crawl.js` は、見出しの漢字・カタカナ語が教材に出る率で「不足の可能性」を挙げるだけの目安だった。結果（39ページ・746見出し、◎9・○7 など、`docs/UPDATE_PLAN.md`）は、取得結果の `boki2/crawl/` が残っていないので **【未確認】**。
- 本文を読んでみると、見出しだけでは分からないことが多かった。たとえば、ネット試験の記事の本文には「1つの仕訳が終わったらすぐ解答欄に入力」「連結精算表は右端の欄だけが採点される」という具体的な助言があった [[cpa-learning:column:boki2-net-exam-measures]]。また、記事どうしで数字が食い違うこともある（第1問を「1問3点」とする記事 [[cpa-learning:column:different-boki-test]] は誤りで、正しくは1題4点 [[cpa-learning:column:boki2-net-exam-measures]]）。見出しの一致率で網羅性を判断する方法には戻らない。

## 旧手順（2026-10-18〜19、廃止）
経緯だけ残す。いまは使わない。

- 当時のクラウド環境はネットワークポリシーで cpa-learning.com への接続を遮断していた。取得の経路として、A. セッションの Network access の許可リストに追加する、B. 自分のPCで `node boki2/tools/crawl.js https://www.cpa-learning.com/` と `node boki2/tools/compare-crawl.js > boki2/crawl/coverage.md` を実行する、C. PC上の Claude に B を頼む、の3つを挙げていた。
- `tools/crawl.js` の動き：robots.txt の Disallow と Crawl-delay を守り、sitemap.xml を先に読み、開始ホストの外に出ず、URL に boki・簿記・column などを含むページだけをたどる。1.5秒間隔、ログインやクッキーは使わない。既定ではタイトルと見出しだけを `boki2/crawl/pages.jsonl` に保存する（`--text` で本文も保存）。PDFはダウンロードしない。
- 廃止の理由：
  - 取得元ごとの規約の判定と、取得の記録が残らなかった。
  - 読んだかどうか、転載していないかを検査できなかった。
  - 見出しの一致率は網羅性の判断に使えなかった（上）。
- 2つのスクリプトは `tools/` に残っているが、新しい取得には使わない。10-19 の取得は `research/ledger.jsonl` に `via: backfill`（あとから復元した記録）として登録してある。
