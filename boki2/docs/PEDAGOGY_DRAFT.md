# 学習設計の土台（たたき台 v0）

## 0. 何を失敗とみなしたか
前回の方針「各章に図解1・予想クイズ2・たとえ話1」は、数を満たせば終わりになる。概念によって、理解に必要な体験の種類も量も違うのに、それを考えずに済ませてしまう。この文書では、数ではなく「その概念を本当にわかった状態」から逆算して、レッスンを設計する。

## 1. 「本質を理解した」とはどういう状態か（行動で定義する）
学習者が次のことをできれば、その概念を理解したとみなす。
1. **目的を言える**：このルール・科目は、誰のどんな困りごとを解決するためにあるのか（例：貸倒引当金は「売掛金の金額を、回収できそうな額で見せる」ため）
2. **結果を予測できる**：取引を見て、仕訳を書く前に、B/S と P/L のどの箱がどう動くかを言える
3. **似たものと区別できる**：対になる概念との違いを、理由つきで言える（未払金と買掛金、引当金と積立金、前受金と契約負債、予算差異と操業度差異 など）
4. **原理から組み立て直せる**：仕訳や計算を暗記でなく、「何が増えた／減ったか」と目的から導ける
5. **現場で見分けられる**：請求書・通帳・台帳などの実物を見て、その概念が使われる場面だと気づける
6. **自分の言葉で説明できる**：小学生に説明するつもりで、1〜2文で言える

## 2. 概念ごとの分析テンプレート
各章の主要な概念（用語・ルール・計算手続き）を1つずつ、次の項目で分析する。
- **目的**：誰の、どんな困りごとを解決するのか
- **中心の仕組み**：1文で
- **前提知識**：この概念より前にわかっていなければならないこと（前の章へのつながり）
- **つまずき・誤解**：学習者がやりがちな誤解と、本試験のひっかけ
- **対になる概念**：比べることで輪郭がはっきりする相手
- **表現の選び方**：概念の性質に合わせて選ぶ
  - 増える・減る → 貸借対照表の箱（bs）
  - 勘定から勘定へ移る → 流れ（flow）
  - 期間で分ける → 期間の帯（timeline）
  - 時点ごとの推移・比較 → 棒（bars）
  - 抽象的なルールの意味 → たとえ話
  - 手順のある計算 → 例題を一緒に解く → 一部を自分で解く → 全部自分で解く（ヒントを徐々に減らす）
- **思考の手順**：学習者に自分で問わせる順番（例：何が起きた？ → 何が増えた／減った？ → どのグループ？ → 左右どちら？ → 金額は？）
- **負荷の設計**：1枚のカードで新しく出す要素は3〜4個まで。多い概念はカードを分ける。前のカードの要点を思い出させてから進む
- **確認の仕方**：予想 → 理由の説明 → 別の場面への応用 → 本試験の形式
- **実務とのつながり**：どの書類で、誰が、いつ使うのか

## 3. レッスンの流れ（型ではなく、目安）
1. **問い**：シーンの困りごとから「どうすればいい？」を投げる
2. **予想**：答えを見る前に、学習者に一度決めさせる
3. **体験**：図解で動きを見る
4. **言葉にする**：原理を1〜2文にまとめる
5. **比べる**：対になる概念と並べる
6. **例題**：一緒に解く → 一部を自分で → 全部を自分で
7. **まとめ**：用語・表

予想クイズや図解の数は、概念の中で「学習者が判断しなければならない分かれ道」の数で決める。分かれ道が5つある概念には5つ、1つしかない概念には1つでよい。

## 4. 学習者の幅への対応
小学生から受験生までを想定し、説明を2層にする。
- やさしい説明（身近な言葉・たとえ）
- 本試験・実務での言い方（正式な用語・条文的な表現）

内容のレベルは本試験の満点まで落とさない。

## 5. 品質チェック（数ではなく問いで）
章ごとに、次の問いに「はい」と言えるかを確認する。
- 章の主要概念のそれぞれについて、目的・つまずき・対になる概念・予測の機会があるか
- 図解は、その概念の「動き」を見せているか（飾りになっていないか）
- 予想クイズは、学習者が実際に迷う分かれ道に置かれているか
- 例題は、自力で解く前に段階を踏んでいるか
- 章のクイズは、レッスンで作った理解を確かめる形になっているか（暗記の確認だけになっていないか）
