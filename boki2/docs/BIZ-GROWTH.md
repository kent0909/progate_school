# 成長の分かれ道（BIZ-GROWTH）：外食・ラーメン会社の「判断→結果」

ラーメン屋の経営シム（docs/DESIGN-RAMEN.md）の背骨になる「成長の分かれ道」を、上場している外食・ラーメン会社の有価証券報告書・決算説明資料・法定のFC開示書面・統計で調べた報告。依頼文は docs/audit/BIZ-MGMT-audit.md 5.1（第2版の追加を含む）と 5.3、オーナーの原文は docs/OWNER-WORDS.md。BIZ-MGMT.md は書き換えていない。

- **担当の境界**：集客は BIZ-MKT-RAMEN、ラーメンの商品・店・業界は BIZ-RAMEN、法律と会計の条文は BIZ-LAW-RAMEN、需要とライバルの式は BIZ-SIMDESIGN 0.2、数字の分布は BIZ-CALIB 0.2、比較作品は BIZ-FUNVISUAL、Coffee Inc 2 は BIZ-COFFEEINC2。重なる所は「引き継ぎ」と書いて、ここでは深掘りしない。小さな店の数字（客数・原価率など）は判定書 5.2 の担当なので扱わない。
- **出典**は二重の角かっこの中に「取得元:集合:文書|「語句」」を書く形（QUALITY 6章）。語句は原文にそのまま出る4〜20字。読了ノートは `boki2/research/notes/web/bizgrowth/` と、他の担当が取った原文を私が読み直したノート（doc 名の末尾が `#growth`・`#struct`）。
- **計算**：比率・倍率・差は `node boki2/docs/analysis/bizgrowth-calc.js`、FC 開示書面の件数は `boki2/docs/analysis/bizgrowth-fc-disclosures.csv`（書面から写した表）を読む `node boki2/docs/analysis/bizgrowth-fc-count.js`、資料の本数は `node boki2/docs/analysis/bizgrowth-sources.js` で出した。本文で「計算 H3」のように書いたものはその表の id。式は付録A。
- **【推論】**＝資料にない、私の推論・見積もり。「論証の表」（14章）に載せた。印のない文は「原文にそう書いてある」の意味。
- **数字の対象**：数字ごとに「誰の（会社・業種・標本）・何の・いつの」を本文か付録Aに書いた。会社1社の値を業界の値として書かない。

## 0. 要点

1. **伸び方の型は「工場の届く範囲」「FC本部の稼ぎ方」「資本の入れ方」の3つで分かれる。** 日高屋は工場1つ（行田）と直営472店で売上を4年で2.4倍（計算 G5）にし、借りた店が99.3%（計算 P1）。コメダは約95%がFCで、本部の稼ぎは卸売69%（計算 P3）と席数比例の定額ロイヤルティ、営業利益率16.4%（計算 M1）。喫茶店77施設の平均2.8%と一桁違う。ギフトは店が10もない時期にプロデュース（開業支援とPB商品の供給）を始め、工場→買収→海外直営→上場の順で進んだ。
2. **崩れ方の型も3つ。** 急ぎすぎた出店（ペッパー：売上3倍の翌年に44店閉店・減損27億、自己資本比率2.0%。山岡家：2年で店34%増・営業利益率5.1%→0.2%）、工場と店の両方が重くなる（幸楽苑：財務制限条項に抵触し工場を売り、年商39%減）、買収ののれんの減損（トリドール：事業利益は最高なのに当期利益は計画比−58%）。
3. **上場は「2級に出ない」で落とせるものではなく、出入りの手続きと条件のある分かれ道。** グロース市場の上場維持の時価総額は2030年3月から「100億円・上場5年後」に厳しくなる。すかいらーくは上場→MBO（94.38%）→ファンド間の売買→再上場、プレナスは創業家のTOBが90%に届かず株式併合で上場廃止、大戸屋は同業のTOB（46.7%）と株主総会で経営陣を替えられた。
4. **FC の加盟店は毎年どれくらい抜けるか**：法定の開示書面14チェーンの3年分で、中途終了は延べFC店の2.36%/年、加盟店からの訴訟は41チェーン×年で0件（bizgrowth-fc-count.js）。ただしチェーンで0.0%〜13.5%と幅が大きく、花月嵐の中途終了の7割は「店は続き持ち主が替わる」引継だった。
5. **加盟店オーナーの「声」30件は集められなかった**（基準未達）。国会会議録の検索システムは停止中、公取委・経産省・中小企業庁は環境から403。代わりに協会の相談件数（2025年度186件、うち本部と加盟店のトラブル139件）と開示書面の中途終了の数で「抜け方」を数えた（9章）。
6. **DESIGN-RAMEN で差し替えるべき所**（12章）：b.1 の G4（上場を外した理由）、c.3 の S4・S5 の条件（FC・暖簾分けは工場を待たない、工場は店が数店の段で建てた会社がある）、e.4 の fc の料金（定額・段階制・ロイヤルティなしの型が実在）、f.2 の買収の値段【推論】のままの所、128行のエリアの向き（中華料理店の立地では工場・オフィス街と商業地区が多く住宅地区が最少）。

## 3. うまくいく理由（因果の鎖）

### 鎖1：工場の届く範囲に直営を密に置く（日高屋）
工場1つに仕入れ・製造・物流を集める [[web:bizgrowth:r5-growth-hidaka-yuho2026b|「物流までの機能を行田工場に集約」]] → 原価と品質がそろい、同じ駅前に複数店でも配送が短い → 設備投資は原則として営業キャッシュフローの範囲（当期29.4億円 [[web:bizgrowth:r5-growth-hidaka-yuho2026b|「総額29億40百万円の設備投資」]]）→ 年20〜30店を借りずに出し続けられる（2020年の方針 [[web:bizgrowth:r5-growth-hidaka-yuho2020|「年間30店舗を目処に新規出店」]]）→ 売上264億（2022/2）→623億（2026/2）、2.4倍（計算 G5）。店は借りる（443店中440店 [[web:bizgrowth:r5-growth-hidaka-yuho2020|「443店舗中440店舗が賃借物件」]]）が、工場の土地だけは持つ。会社は創業から [[web:bizgrowth:r5-growth-hidaka-yuho2020|「直営店方式にこだわって展開」]] と書く。工場の配送圏の外（新潟）へ出るときだけFCを使い始めた。

### 鎖2：FC本部は「卸」と「定額」で稼ぎ、加盟店の売上の伸びは加盟店に残す（コメダ）
ロイヤルティは [[web:bizgrowth:r5-growth-komeda-yuho2026|「席数比例の定額制ロイヤルティ」]]（開示書面では [[web:bizgrowth:r5-growth-jfa-komeda-fc|「1 席あたり月額 1,500 円」]]）→ 加盟店の売上が伸びても本部の取り分はロイヤルティでは増えない → 加盟店の意欲が続き、出店が続く → コーヒーとパンは自社工場から運ぶので、店が増えるほど卸の売上が増える（卸393億円＝売上収益の68.7%、計算 P3）→ 本部単体の営業利益率12.5%（計算 M2）、HD 連結16.4%（計算 M1）、上場時（2016年2月期）は30.2%（計算 M3）。比べる相手として、喫茶店77施設の売上高対営業利益率は総平均2.8% [[law:primary:r4-mgmt-mhlw-kissaten|「売上高対営業利益率」]]（2013年3月の調査、公庫の融資先の施設、個人と会社を含む）。差の理由は、本部は店の家賃と人件費を持たず、工場の製品と仕組みを売るから。会社は加盟店の売上も利益も [[web:bizgrowth:r5-growth-jfa-komeda-fc|「把握していない」]] と書く。

### 鎖3：工場の稼働を他人の店の注文で埋める（ギフト）
2010年1月、社長の別会社でプロデュース（開業の支援は原則無償、代わりにPB商品を買い続けてもらう）と製麺を始める → 2013年に平塚に製麺工場 → 自社の直営が10店に届く前から、工場の注文がプロデュース店から来る【推論：原文は順序だけを書き、因果は書いていない】→ 2015年3月に家系の会社を買収 [[web:ramen:r4-ramen-gift-yuho2025|「株式会社四天王の全株式を取得」]]、2016年7月に海外直営 [[web:ramen:r4-ramen-gift-yuho2025|「町田商店シンガポール店（海外直営１号店）」]] → 2018年10月に上場 [[web:ramen:r4-ramen-gift-yuho2025|「東京証券取引所マザーズ市場に株式を上場」]] → 国内8工場 [[web:ramen:r4-ramen-gift-yuho2025|「国内８工場体制」]]、売上は4年で2.7倍（計算 G17）。

### 鎖4：多店舗を持つ加盟企業ほど料金を下げ、指導を加盟企業に移す（物語・プレナス）
物語の加盟金は1店目500万円・10店目以降150万円、丸源ラーメンのロイヤルティは1店目5.0%から30店目以降3.4%へ下がる [[web:bizgrowth:r5-growth-monogatari-yuho2025|「10店目〜19店目」]]。加盟企業が [[web:bizgrowth:r5-growth-monogatari-yuho2025|「自社内スーパーバイザー業務を実施する」]] と別の料率。→ 大きな加盟企業を囲い込み、本部の指導の負担を加盟企業に移す。プレナスは [[web:bizgrowth:r5-growth-plenus-yuho2022|「ユニットＦＣ制度を活用し」]] 直営を加盟店に移し、ロイヤルティは [[web:bizgrowth:r5-growth-plenus-yuho2022|「月額８万円」]] の定額。本部の売上の過半は加盟店への卸（第3四半期まで：直営店売上446億円に対し [[web:bizgrowth:r5-growth-plenus-q3-2023|「加盟店向け売上」]] 548億円）。

### 鎖5：FCの店は本部から見て少ない売上で大きな利益を生む（大戸屋）
国内直営152店の売上229億円・セグメント利益9.9億円に対し、国内FC164店の売上101億円・セグメント利益17.2億円 [[web:bizgrowth:r5-growth-ootoya-yuho2026|「セグメント利益は17億18百万円」]]。FCの利益は直営の1.7倍（計算 M7）。ただし、店の家賃・人・在庫の危険は加盟店が負っている（本部の利益率の高さは危険の付け替えの結果）【推論】。

### 鎖6：任せる海外（ライセンス）は資本を使わずに店を増やす（ハチバン・力の源）
ハチバンは [[web:bizgrowth:r5-growth-hachiban-yuho2026|「タイで175店舗、ベトナムで３店舗」]]、国内のラーメン114店より多い。海外事業の営業収益15.4億円・セグメント利益3.8億円。力の源は国ごとに直営とライセンスを分け、[[web:ramen:r4-ramen-chikara-tanshin2026|「直営・ライセンス合わせて世界16カ国」]]。合弁で入り→持ち分を売ってライセンスに→台湾は2018年に買い戻す、と形を変えた [[web:bizgrowth:r5-growth-chikara-yuho2026|「当社所有の全株式を乾杯股份」]]。

### 鎖7：上場で全国に出る信用を得る（魁力屋）
2009年に [[web:bizgrowth:r5-growth-sakigake-yuho2025|「社員独立支援制度」]]（社内FC）、2023年2月に外部の加盟店、2023年12月に上場。店は2021年末119→2025年末175（計算 G15）、上場後に出店した県が急に増えた（宮崎・福島・高知・岩手・石川・徳島・青森・長野・和歌山、多くがショッピングモール）。上場で得たのは資金より、モールのデベロッパーへの信用と採用だった【推論：会社はそう書いていない】。

### 鎖8：買われて、親会社の購買力で立ち直る（大戸屋）
同業のTOBで46.7%を持たれ、2020年11月の臨時株主総会で [[web:bizgrowth:r5-growth-ootoya-yuho2021|「株主提案による役員選任議案の承認可決」]] → 親会社に [[web:bizgrowth:r5-growth-ootoya-yuho2021|「第１回優先株式30株」]] を出して30億円 → [[web:bizgrowth:r5-growth-ootoya-yuho2021|「共同購買による仕入れコスト削減」]] → 売上188億→370億（計算 G10）、経常利益△5.3億→22.1億 → 優先株は30→15→0株 [[web:bizgrowth:r5-growth-ootoya-yuho2026|「第１回優先株式の取得及び自己株式の消却」]]。

## 4. うまくいかない理由（因果の鎖）

### 鎖A：伸び率を目標に置き、店同士で食い合う（ペッパー）
売上223億（2016）→675億（2019）、3.0倍（計算 G4）。2019年に [[web:bizgrowth:r5-growth-pepper-yuho2019|「いきなり！ステーキの店舗同士の競合」]] と類似の競合で既存店が落ちる → 出店計画を [[web:bizgrowth:r5-growth-pepper-yuho2019|「210店舗から115店舗へ計画を変更」]] → 直営44店の閉店、[[web:bizgrowth:r5-growth-pepper-yuho2019|「減損損失を2,716百万円」]] → 自己資本比率30.1%→2.0% → 翌年に利益の出ていた古い柱を売る（[[web:bizgrowth:r5-growth-pepper-yuho2020|「株式会社JPの全株式を譲渡」]]、85億円）→ [[web:bizgrowth:r5-growth-pepper-yuho2020|「継続企業の前提に関する重要な不確実性」]] → 行使価額修正条項付きの新株予約権で3,424百万円（既存株主は希薄化）。同じ年の初めに、減価償却を定率法から定額法に変え建物の耐用年数を18年→12年に見直し、営業利益が395百万円増えていた（崩れる年に「長く続く」前提で償却を軽くした）。加盟者は108→45（計算 G14、−58.3%）。

### 鎖B：急な出店の費用が先に来て、売上が育つ前に利益が消える（山岡家2010〜12年）
店102→137（2年で34.3%増、計算 G1）、営業利益率5.1%→3.2%→0.2%。会社自身がグラフに [[web:ramen:r4-ramen-yamaokaya-setsumei2603|「急速な出店に」]] よるコスト増と売上停滞と書き込む。純損失1.8億（2012）。有利子負債の総資産比率は64.5%の山から下がるまで10年以上かかった。

### 鎖C：工場を持つ会社は店を増やし続けないと工場が重い（幸楽苑）
1975年、店4つの段で「ラーメンと餃子を核にチェーン展開」と決め工場を建てた [[web:bizgrowth:r5-growth-kourakuen-yuho2018|「らーめんとギョーザを核として」]] → 2004年小田原・2007年京都に工場 → 2018年3月期、減損 [[web:bizgrowth:r5-growth-kourakuen-yuho2018|「減損損失2,838百万円」]]、[[web:bizgrowth:r5-growth-kourakuen-yuho2018|「スクラップ49店舗」]]、借入の特約に [[web:bizgrowth:r5-growth-kourakuen-yuho2018|「連結純資産維持の条項に抵触」]] → 京都工場の譲渡と [[web:bizgrowth:r5-growth-kourakuen-yuho2018|「セール・アンド・リースバック」]]。会社は自ら、出店が計画どおりでないと工場の稼働率が下がり借入が重くなる、とリスクに書いていた。年商は49期41,268百万円→52期25,023百万円（−39.4%、計算 G7）。

### 鎖D：赤字が続くと、銀行の約束が「決算書の数字」から「銀行が見張る計画」に締まる（幸楽苑2023）
前の期の特約は連結純資産を [[web:bizgrowth:r5-growth-kourakuen-yuho2023|「70％以上に維持すること」]] と当期損益を損失にしないこと。2023年の借入では、金融機関が指定する [[web:bizgrowth:r5-growth-kourakuen-yuho2023|「アドバイザリー会社が作成する」]] 計画を四半期ごとに下回らないこと、に変わった。運転資金は [[web:bizgrowth:r5-growth-kourakuen-yuho2023|「総額40億円のコミットメントライン」]]。

### 鎖E：高値の買収はのれんの減損として一度に出る（トリドール・すかいらーく）
トリドールは事業利益が過去最高（214.6億円）なのに、[[web:bizgrowth:r5-growth-toridoll-yuho2026|「減損損失は114億８百万円」]] と株式売却損で、営業利益は計画比−27.5%、当期利益は−58.0%（計算 G11・G12）。英国の買収先 [[web:bizgrowth:r5-growth-toridoll-yuho2026|「The Fulham Shore」]] は回復が遅れ再構築。すかいらーくは [[web:bizgrowth:r5-growth-skylark-yuho2025|「162,683百万円ののれん」]] が総資産の31.4%（計算 G13）。ファンドの買収の積み重ねの名残で、IFRSでは償却せず毎年減損テスト。

### 鎖F：本業と遠い多角化は数年で外す（幸楽苑・コメダ・力の源・ペッパー）
幸楽苑は自社が他社のFC加盟店になって焼肉・からあげを足した（2023年3月末に焼肉ライク12・からやま7・赤から5＝24店、計算 G9）→ 2025年9月末に0 [[web:ramen:r4-ramen-kourakuen-setsumei2511|「焼肉ライク」]]。2018年に加盟した [[web:bizgrowth:r5-growth-kourakuen-yuho2018|「食材保証金 500万円」]] の相手（いきなり！ステーキ）は翌年に崩れた。コメダの別業態「やわらかシロコッペ」は0→7→18→11→2→0（2018〜2021年）、高級喫茶は [[web:bizmgmt:r4-mgmt-wiki-komeda|「コーヒー一杯1,200円から各種」]] で2005〜2013年の8年で閉店（ウィキペディアの記述。有報では確かめていない）。力の源は米国の中華チェーンとの日本の合弁を [[web:bizgrowth:r5-growth-chikara-yuho2026|「一風堂事業へ経営資源を集中させる目的」]] で2022年に譲渡。

### 鎖G：本部が倒れると加盟店に連鎖する（ペッパー・田所商店）
ペッパーのFC加盟者は1年で108→45。田所商店の本部は、開示書面の決算の表で純資産がマイナスの年がある（[[web:bizgrowth:r5-growth-jfa-tadokoro|「-1,192,366」]]、単位千円の当期純損失）。加盟店から見ると「本部の決算書を読む」ことが加盟の判断になる。

### 鎖H：任せた海外は、店数も品質も相手しだい（力の源・幸楽苑）
力の源のライセンスの国（中国・マレーシア・タイ）は当期に店が減った。幸楽苑はタイの子会社を2011年に作り2016年に解散 [[web:bizgrowth:r5-growth-kourakuen-yuho2018|「KOURAKUEN(THAILAND)」]]、いまはタイの会社とのFCで9店。ハチバンは国内では中部支社と工場を2003年に閉鎖した（国内の横の拡大の失敗と、海外を任せた成功が同じ会社にある）。

## 10. 上場・買われる・やめる の仕組みと崩れ方

- **入る**：グロースは株主 [[law:primary:r5-growth-jpx-shinki-growth|「150人以上」]]・流通株式時価総額5億円以上・公募500単位以上・1年以上の事業、利益の基準なし。スタンダードは株主 [[law:primary:r5-growth-jpx-shinki-standard|「400人以上」]]・流通株式時価総額10億円以上・最近1年の利益1億円以上・3年以上。プライムは流通株式比率35%以上、2年の利益の合計25億円以上 [[law:primary:r5-growth-jpx-shinki-kijun|「最近２年間の利益の額の総額が 25 億円以上」]]。
- **居続ける**：グロースの時価総額は今は40億円以上（上場10年後から）、2030年3月1日から100億円以上（上場5年後から）。外れたら1年の改善期間、外れて3か月以内に計画の開示 [[law:primary:r5-growth-jpx-iji-growth|「監理銘柄・整理銘柄に指定後」]] 上場廃止。
- **崩れ方**：伸び率の要求が出店を急がせる（ペッパーの有報は重視する指標に売上と利益の伸び率を挙げる。それが出店を急がせたのは【推論】）。流通株式が少ないと維持が危うい（魁力屋33.53%、社長と資産管理会社で [[web:bizgrowth:r5-growth-sakigake-yuho2025|「発行済株式総数の62.7%を所有」]]）。社長の個人保証が残る（魁力屋 [[web:bizgrowth:r5-growth-sakigake-yuho2025|「債務保証を受けております」]]）。株価が安いと同業に買われる（大戸屋）。
- **やめる**：MBO（すかいらーく94.38%）、創業家のTOB→90%未満なら [[web:bizgrowth:r5-growth-plenus-q3-2023|「4,264,300株を１株に併合」]] で少数株主を端数にして買い取る（プレナス [[web:bizgrowth:r5-growth-plenus-q3-2023|「2,640円を乗じた金額」]]、[[web:bizgrowth:r5-growth-plenus-q3-2023|「2023年２月24日をもって上場廃止」]]）。
- **ゲームで崩れない入れ方の案**：上場の後も「維持の条件（時価総額・流通株式）」「株主の期待（伸び率）」「買われる危険（株価が安いとライバルが株を集める）」を毎期判定する。資金が無制限になる Coffee Inc 2 の崩れ（DESIGN-RAMEN b.1 G4）は、増資には株主総会と希薄化（持ち分が下がり、50%を割ると買われうる）が要る形にすれば起きない【推論】。

## 13. ゲームへの写し方

**最小の写し方**（今の DESIGN-RAMEN に足す）：
1. 6章の11本の行を e.4・e.6 の判断に対応させ、「重みを動かす状態変数」を式の入力にする（出店の速さ÷店数、自己資本比率、工場の稼働を埋める先、ロイヤルティの型）。
2. c.3 の段の条件を12章のとおり直す（FC は工場を待たない、工場の審査は稼働の見通し）。
3. 銀行の態度を年で変える（緊急保証の年は赤字でも借りられる：開業パネルの2009年以降）。財務制限条項を「警告→特約の追加→外部の監視→期限の利益の喪失」の段で締める（幸楽苑）。
4. ライバルの「今後の方針」を中華料理店の分布で置く（廃業11.2%・拡大縮小7.1%・多角化4.1%・専門店化2.5%・移転2.5%）【推論：施設の回答をライバルの年あたりの行動の割合に読み替える】。

**大胆な写し方**（会社の段で遊び方が変わる）：
1. **会社を分ける**：持株会社と運営会社。設備と工場をどちらに持たせ、どんな料金（経営指導料・設備の賃料）を取るかで、運営会社の利益率は1%（ギフト）にも10%にもなる。本社費の配り方で「赤字の店」の判定が変わる（ギフトの監査上の主要な検討事項 [[web:ramen:r4-ramen-gift-yuho2025|「一定の猶予期間については営業損益がマイナ」]]スでも兆候なし）。本支店会計と減損の橋になる。
2. **FC本部の料金表を自分で作る**：定額・売上比例・段階制・技能割引・ロイヤルティなし（卸で稼ぐ）から選び、加盟店の行動（売上を追うか、本部を見限るか）が変わる。加盟店の毎年の中途終了2.36%を基準に、料金と本部の決算で上下させる。
3. **不動産の事業部**：店を借りる／持つ／借りて加盟店に又貸しする（コメダ）／売って借り戻す（幸楽苑）。リース債権・差入保証金・固定資産売却損益の場面。
4. **上場の段**：上場の審査（社長の個人保証の解消・流通株式）→上場後の毎期の維持判定→株価が安いとライバルのTOB→MBOで上場をやめる道。
5. **買われる・買う**：弱ったプレイヤー自身が買われる結末（大戸屋型：経営陣が替わるが会社は続く）と、ライバルの老舗を事業譲受で買う道。
6. **海外**：直営・合弁・ライセンスを選び、後で形を変えられる（力の源の台湾）。

## 15. 反証と限界

- **成功例の会社自身の撤退**：コメダは別業態「やわらかシロコッペ」を4年で閉め（有報の店数の表）、ウィキペディアでは高級喫茶・セルフ式の店も閉めた。上海は2017〜2026年に1店から最大7店、いまは5店（有報）。日高屋は直営主義を書きながら、2025年に新潟でFC契約を結んだ。ハチバンは国内の中部進出を2003年に畳んだ。力の源は海外の合弁を売り、台湾は買い戻し、中華の合弁は譲渡した。成功の筋書き（工場1つ・直営・任せる海外）は、同じ会社の失敗と並べると「いつでも効く型」ではない。
- **研究ごとのばらつき・「差はない」の結果**：開業の年の景気による生存の差は10年で2ポイント未満（米国の研究）。借入の却下率は2009年以降、赤字・黒字で差がない（公庫）。「飲食の9割が1年で潰れる」は誤りで、1年目の廃業は約17%（米国西部・チェーン除外、[[web:bizgrowth:r5-growth-arxiv-mortality-pdf|「commonly claimed」]] の通説への反論、寿命の中央値は [[web:bizgrowth:r5-growth-arxiv-mortality-pdf|「about 4.5 years」]]）。日本のラーメン店の数字ではない。
- **対象の違い**：中華料理店の統計は食堂・レストランを含み、ラーメン店だけではない。事業承継の公庫の調査は全業種のネット調査。開業パネルも全業種。開示書面の14チェーンは協会の会員で書面を公開する本部（中堅以上に偏る）、数字は自己申告で協会は確かめていない [[web:bizgrowth:r5-growth-jfa-kaiji-list|「利用上の注意」]]。喫茶の2.8%は公庫の融資先77施設の総平均。
- **1社の数字**：本部の利益率（コメダ）、FC利益÷直営利益（大戸屋）、運営会社の利益率（ギフト）はどれも1社。「FC本部は利益率が高い」と一般化しない。
- **因果を会社が書いていない所**：ギフトの「プロデュースが工場を早めた」、魁力屋の「上場で出店の信用」は私の読み（【推論】）。
- **数え方の違い**：すた丼は2025年度にFC店が8減ったのに中途終了0、ゆで太郎の2024年の内訳は合計が合わない。開示の数字は定義しだい。
- **不利な記述**：ペッパーは崩れる年に減価償却を軽くした（定率→定額、耐用年数18→12年で営業利益+395百万円）。成功例のコメダも、加盟者の高齢化（[[web:bizgrowth:r5-growth-komeda-yuho2026|「ＦＣ加盟者の高齢化」]]）と店の老朽化を自らリスクに書く。
