# 依頼の台帳（取りまとめ役 → 外の作業者）

取りまとめ役が PR のコメントで出した依頼と、相手の受領を追う。オーナーの指摘（2026-10-24：Codex が途中の依頼を見落とし、オーナーが気づいた）から作った。

**使い方**
- 依頼を出したら1行足す。相手の「受領：<ID>」か、依頼に答える中身の返事が来たら「受領」を埋める。
- 30分たっても受領がなければ、同じ PR でもう一度声をかける。さらに30分なければ、オーナーに「その Codex のセッションに一言送ってほしい」と頼む（PR のコメントでは止まったセッションが起きないことがある）。
- 片付いたら「済」にする。済んだ行は残す。
