# ホームの試作の仕様（PROTO-SPEC-home）：T1 店の前の数

2026-11-04、取りまとめ役。元は `docs/DESIGN-UI-IDEAL.md` 2.2 画面2・6.1 T1・9章 問1、`docs/BIZ-UIREF.md` 18章 問1 と上部の帯の測り（197.8px＝23.4%、14px で 240.9px）。

## 1. 目的
ホーム（店の前）の「数」の置き方を4版（(b) は2通りで計5画面）作り、**同じ1か月**を遊ばせて比べる。主役は全版で「次の書類1枚」（決定済み）。ゲームのファイルは変えず、`boki2/proto/home/` の中だけで完結。

## 3. 1か月の中身（全版で同じ。11/04 に Codex の相談 PR #14 を受けて書き直した）
**ゲームの目標**：ネットキャッシュ（現金＋普通預金−借入金）1億円、期限は10期＝120か月（`docs/DESIGN-RAMEN.md` のゴールと期限、段0）。数と線はこの目標に合わせる（純資産ではない）。

**月初（1年目の5月、仮）**：普通預金 3,000,000・現金 100,000・借入金 0 → ネットキャッシュ 3,100,000。経過は1か月（残り119か月）。

**先月（仮の固定の値。先月比に使う）**：売上 180,000、先月末の手もとに残るお金（現金＋普通預金）3,100,000（＝今月初）、先月のネットキャッシュの増え方 +40,000（先々月末 3,060,000 → 先月末 3,100,000）。手もとに残るお金の先月比は「今月のいまの値 − 3,100,000」（月末で −25,000、チラシなら −45,000）。月初のペース +40,000 だと b1 の見込みは約2,423か月（約202年）で、そのまま出す（届かないことが見えるのが比べどころ）

**今月の書類6枚**（この順。仕訳の机は簡略：札を押すと正しい仕訳が出て「記帳した」を押すだけ。比べるのはホーム）：

| # | 書類（相手の1文） | 仕訳 | 動く数 |
|---|---|---|---|
| 1 | レジ「今週の売上、現金で 120,000円」 | 現金 120,000 ／ 売上 120,000 | 売上・現金 |
| 2 | 問屋「食材 40,000円、月末払いで」 | 仕入 40,000 ／ 買掛金 40,000 | （現金は動かない） |
| 3 | 大家「今月の家賃 80,000円、口座から引き落とし」 | 支払家賃 80,000 ／ 普通預金 80,000 | 普通預金 |
| 4 | アルバイト「今月のお給料 60,000円、現金でお願いします」 | 給料 60,000 ／ 現金 60,000 | 現金 |
| 5 | カード会社「カードの売上 90,000円、入金は来月」 | 売掛金 90,000 ／ 売上 90,000 | 売上（現金は動かない） |
| 6 | 道具屋「お玉、5,000円。現金で」 | 備品 5,000 ／ 現金 5,000 | 現金 |

**判断の札**（3枚目の後に1回）：「チラシを打つ（20,000円、現金）／打たない」。打つなら 広告宣伝費 20,000 ／ 現金 20,000。

**月末の結果**（検算済み）：売上 210,000（先月比 +30,000）。手もとに残るお金は 3,100,000＋120,000−80,000−60,000−5,000＝3,075,000（チラシを打てば 3,055,000）。ネットキャッシュも同じ（借入金 0）で、今月の増え方は −25,000（チラシなら −45,000）。売上は増えたのにお金は減る（掛けとカードの入金が来月のため）。**これが数を見せる版で気づけるかが比べどころ**。

**見込みの計算**：
- `b1`（見込みの日付）：ペース＝今月のネットキャッシュの増え方（記帳した分まで）。月初でまだ記帳がないときは先月の +40,000 を使う。見込みの月数＝(1億−いまのネットキャッシュ)÷ペース。ペースが0以下なら「このペースでは届かない」。「このペースだと◯年目の◯月」を出す
- `b2`（逆算）：必要な毎月の増え方＝(1億−いまのネットキャッシュ)÷残りの月数（120−経過）。「1億まで、毎月 ◯円ずつ増やせば10年目に届く（いまは毎月 ◯円）」
- 前提（ペースの出し方・期限）は線を押すと出す。計算の式はコードのコメントに書く

## 4. 記録（外へは送らない）
`localStorage` と「記録を書き出す」ボタン（JSON）：版、1か月を終えるまでの時間、ホームを開いた回数、数・線を押した回数、判断の札の選択、月末に出す2つの問い（「いまお店の口座のお金はいくら？」「1億まであとどれくらい？」を4択で）の答え。

## 5. 見た目と大きさの約束
幅 390×844 と 1280×800。字は 14px 以上、押せる所は 44×44px 以上。各版で「次の書類の札」の上端の位置（画面の上から何 px か）と、店の絵の高さを測って記録する。動きは数が変わるとき 1秒以下、`prefers-reduced-motion` で止める。

## 6. 受け入れの基準
1. 5画面（a・b1・b2・c・d）の全部で1か月を最後まで遊べる（自動の打ち手で確かめ、出力を残す）
2. 5章の測り（2つの幅×5版）：次の書類の札の上端の位置、店の絵の高さ、帯・数の部分の高さ（`d` は 211px 以内か）、最小の字、最小の押せる大きさ
3. 4章の記録が書き出せる
4. ゲームのファイルを変えていない
