2. **上位30項目のうち、資料で向きと大きさまで埋まった（支持・修正・否定）のは1項目（S1 の修正）だけ。一部が8、埋まらず（探したが無い）が21、未探索は0**（`fill-ramen-count-v2.out.txt`）。1.0 は「埋まった8」と書いたが、自分の語の定義に照らすと、米国の4店（S4）・宿泊客の数（S5）・向きだけの記述（S3）・ネットの再共有（M10・M2・M1）・基本の1杯の値段（L4）・生き残った企業の年の集計（M13）は、範囲の違う資料か向きだけ、または問いの物差しが違う。1.0 で「探していない」と書いた4項目（M16・R4・M17・M8）と、探した記録のなかった6項目（L2・L3・M5・M6・M7・R1）は、版1.1 で J-STAGE と国立国会図書館サーチで探した（記録は `research/searches/fill-ramen.jsonl`）。どれも数は見つからなかった。
3. **8月の山は、日の型の置き方を変えても残る（指数107〜123）。上乗せの多くはお盆＝帰省と夏休みの暦に重なる。「休み13・8月そのもの14」という分け方は使わない。** 家計調査の日別支出（2025年、二人以上の世帯）の中華そば（外食）の8月は126.9。お盆の扱い・お盆の日の範囲・夏休みの平日を型に入れるかで、日の型を除いた8月の水準は106.7〜122.5（7通り）、日を復元抽出しても107.1〜121.9（`fill-ramen-season-v2.out.txt`）。お盆の4日を型から外すと暦の分は12.7→4.4に下がり、**1.0 が「休みの日の多さ」と呼んだ分の大半は帰省のお盆そのもの**だった。2023・2024年の8月も年の最多で、2025年の型で当てはめると実際は予測より6低い（2025年は強い年）。7月は谷ではない。
4. **家計の「土日祝は平日の2.3倍」は家族の外食の倍率で、店の土日÷平日ではない。** 同じ表のこづかい(使途不明)の行は土日祝÷平日が0.59（私の計算。年末年始を除き祝日を土日に入れた。検査役の0.63は土日だけの比）。勤め先の昼食は中華そばの行に出ない。立地の向きは、オフィスの休日の谷は実務者の一般論だけ、業界団体の唯一の実例は都市立地の低価格ラーメンが [[web:ramen:r6-fill-jf-202605|「連休や休日も賑わい」]]（2026年5月）で逆向き。住宅地の8月は「住人が出ていく町は谷・人が帰ってくる町は山」に分かれる【推論】。学生街の休みの落ち込みは米国の飲食3店で40〜60%（25%・70%の両端は菓子店）。
5. **天候：「寒いほど汁麺に追い風」「天候の主役は雨・台風」は、業界団体の12か月の数と合わないので消した。** 日本フードサービス協会の月次12本で、FF の「麺類」の伸びから FF 全体の伸びを引いた差は、東京が前年より暑い月に平均+0.6、涼しい月に−1.3、気温の前年差との相関 r＝0.42、雨天日数の前年差とは r＝−0.35（12点、`fill-ramen-weather-v2.out.txt`）。協会は寒い11月に「気温の低下とともにラーメン業態が好調」と書くが、その月の麺類は FF 全体を3.1ポイント下回る。暑さで客が減った記録もある：一風堂の力の源は [[web:ramen:r4-ramen-chikara-tanshin2026|「猛暑や残暑等の気候変動」]] による既存店の客数の減少を書き、協会は2025年9月を [[web:ramen:r6-fill-jf-202509|「特に厳しい残暑と物価高騰」]] で外食控えと書く（麺類は冷たい限定品で伸びた）。12点では気温と雨と店の数の増えを分けられず、**気温の向きは決まらない**。
6. **地域の採算：オーナーの2つの例は、前提を両側でそろえると同時にはほぼ成り立たない（0.01%）。成り立つのは、銀座の側だけ値段を統計の617円にするか家賃を募集の倍に置き、奥多摩の側だけ家族で回して店主の取り分を小さくする時。** 店の広さは公庫の中華料理店1〜4人の 58.6㎡（約17.7坪）を使った。銀座（坪42,497円×17.7坪＝月75.3万円）で1日100杯は、1杯617円なら人と店主の取り分によらず赤字、800円ならアルバイト2人以上か「1人＋店主15万円以上」で赤字、1,000円ならアルバイト3人か「2人＋店主30万円」で赤字、1,300円以上なら表のどの組み合わせでも黒字（その他25万円・返済税保険8万円の置き値で。`fill-ramen-region-v2.out.txt`）。奥多摩で1日30杯は、**固定費と店主の取り分の合計が月46.7万円以下（1杯890円の時）なら黒字**で、家族だけで回せば店主15万円でも+2.7万円、アルバイト1人（6時間）を雇うと店主0円でも−1.5万円。立地（家賃）だけの差は、人と値段をそろえると分岐の杯数で1.4〜2.8倍（広さ10坪〜17.7坪、人0〜2人）。
7. **地域で散らばりの大きい値と、利益に効く値は順が違う。** 散らばりは家賃（住宅、75%点÷25%点 1.36）＞値段（1.18）＞最低賃金（1.04）。1つずつ動かした利益への効きは値段（25%点→75%点で+12.9万円）＞家賃（−7.3万円）＞最低賃金（−0.9万円）。銀座の1,000円の行では、坪単価を倍にすると−42.5万円、人を1人増減すると±25.6万円で、**家賃の効きは人1人より大きい**（1.0 の「家賃より値段と人の数」は誤り）。
8. **集客の打ち手の「当たりの確率と大きさ」は、ラーメン店の数では埋まらなかった。** ネットの投稿の再共有の研究で言えるのは**ネットの再共有の広がり**だけ：再共有が100人以上に広がる投稿は [[web:ramen:r6-fill-goel-twiral|「1 out of every 4,000」]] で、多くの投稿は再共有されない。テレビ・取材などの露出が起きる確率（店1軒・1年あたり）や、露出の後の客数の増え方とは母集団も物差しも違うので、M1・M2 を埋めない。
9. **開店景気（M13）は、この資料では支えられない。** 公庫の新規開業パネルは年末ごとの「黒字基調か」を生き残った企業で数えたもので、開店直後の数週〜数か月の客数は測っていない。1.0 の表の「否定」は取り下げた（0章と表と件数をそろえた）。
10. **「チェーンと個人店で向きが変わる」を分ける資料は1本もない。** 季節の店の側の資料は、業界団体の会員社・山岡家・米国のチェーンで、すべてチェーン。1.0 はこの軸を立地の軸に吸わせて「芯」と書いたが、取り下げて穴として残す（1.6）。

### 1.6 チェーンと個人店（穴）

オーナーの言葉「チェーンと個人店・立地で向きが変わる」のうち、**チェーンと個人店を分ける資料は1本もない。** 1章の店の側の資料は、業界団体の会員社（チェーン）、山岡家・幸楽苑・力の源（チェーン）、米国の学生街の Qdoba・Which Wich・Chipotle（チェーン）で、個人店の季節の数は無い。家計調査は店の種類を分けない。

- 1.0 は「立地の型ごとに休日の符号が変わるのが、チェーンと個人店・立地で向きが変わるの芯」と書いた。資料のある立地の軸に、資料のない軸を吸わせた読みなので取り下げる。
- 分ける材料になりうる向き【推論】：山岡家は繁忙期にクーポンを減らして店の負荷を下げる＝収容の大きいチェーンは山を取りにいける。収容の小さい個人店は山で行列と取りこぼしになる。差は「チェーンか個人か」より「収容と人の厚さ」の軸かもしれない。資料ではない。
- 埋めるには、個人店の季節の声（店主の発信・取材の記事）か、個人店の POS の集計が要る（やっていないこと）。

### 2.7 オーナーの例を、前提を両側でそろえて試す

オーナーの例「銀座だと100杯でも赤字、奥多摩なら30杯でも採算」を、**雇う人時・店主の取り分・家族の労働（無給の人時は両側とも数えない）・その他の固定費・返済税保険・原価率・営業日数を両側でそろえ**、場所の違い（銀座の値段・坪単価・広さ、奥多摩の値段・家賃）だけを別々に振った（QUALITY 6.3 の末尾の決まり）。

| 格子 | 通り | 両方の例が同時に成り立つ |
|---|---|---|
| そろえる（雇う人時0〜24時間×店主0〜30万円×その他15〜25万円×返済0/8万円×原価率30/35%×20/25日）、銀座の値段617〜1,500円・坪36,250/42,497/85,000円・10/17.7坪、奥多摩の値段747〜1,000円・家賃0〜10万円 | 311,040 | 6,550（2.11%） |
| 同上で、銀座の値段を800円以上、坪単価を資料のある2つ（36,250・42,497円）に限る | 165,888 | **11（0.01%）** |
| 銀座の雇う人時だけ奥多摩より8時間多い | 311,040 | 10,960（3.52%） |
| 銀座の雇う人時だけ奥多摩より16時間多い | 311,040 | 16,700（5.37%） |
| 1.0 の形（銀座3人8時間・店主30万円、奥多摩は家族・店主0円） | 1 | 成り立つ（銀座−7.3万円・奥多摩+12.7万円） |

- そろえて両方成り立つ6,550通りのうち、銀座の値段は617円が3,913、坪単価は85,000円（資料の無い仮置き）が5,056、雇う人時は0時間が4,449。資料のない端を外すと0.01%（11通り、すべて銀座800円・雇う人時0〜8時間）。BIZ-RAMEN 第4版の検査で出た0%・0.01%（`docs/analysis/ramen-v4-recheck.js`）と同じ桁。
- **結論（オーナーの例に合う向き）**：銀座で100杯でも赤字になるのは、1杯800円以下でアルバイトを雇う店、1,000円でアルバイト3人か「2人＋店主30万円」の店。奥多摩で30杯でも黒字になるのは、アルバイトを雇わず（家族で回し）、店主の取り分が月15万円前後までの店。**どちらの例も、それぞれの側の店の形の1つとしては成り立つ。**
- **結論（オーナーの例に逆らう向き）**：同じ人の使い方・同じ取り分の店を2つの場所に置くと、2つの例が同時に成り立つのは、銀座の値段を統計の617円にするか家賃を募集の倍に置いた時だけ（資料の範囲では0.01%）。1杯1,300円以上の銀座の店は、アルバイト3人・店主30万円でも100杯で黒字。アルバイトを1人雇う奥多摩の店は、30杯では店主0円でも前提の54%で赤字、店主15万円なら97%で赤字。
- **例が成り立つのは、どの前提が違う時か**：(1) 銀座の側だけ人を厚く雇い（または値段が800円以下）、店主の取り分を引く、(2) 奥多摩の側だけ家族で回し、店主の取り分を小さくする。オーナーの例は「場所の差」より、**場所ごとに違う店の形（人の厚さ・値段・取り分）**を言っているものとして写すのが資料と合う【推論】。
- ゲームでは、この2つを同じ式（2.5）の別の選択として出せる：銀座で安く多く売る店は人を厚くすると赤字、奥多摩で家族の店は少ない杯数でも続く。

## うまくいく理由（季節と地域で売上が上がる店の因果）

1. **家族客と帰省の客を取れる立地 → 休みの日とお盆に山 → 年の売上の厚み**：家計の家族の外食は土日祝に平日の2.3倍前後で、8月の山は型の置き方を変えても107〜123で残る（1.1）。山を取るのは、休日に家族が来て、お盆に人が帰ってくる町の店【推論】。絡む変数：**町の人の流れ（帰ってくる町か）×客層（家族）×暦×収容**。収容が足りないと山は行列と取りこぼしになる（山岡家は繁忙期にクーポンを減らす）。
2. **観光の季節のある場所 → 宿泊客の山の月に人が増える**：観光型の宿の月の振れ幅は観光県で約2倍、非観光型でも1.45倍（1.5）。絡む変数：**立地（観光地）×月×収容**。値段を上げられるかの資料は無い（1.0 の「値段も上げやすい」は訪日客の話で、季節の話ではないので消した）。
3. **暑い月に冷たい品を出せる店 → 暑さの客の減りを埋める**：幸楽苑は夏の最盛期に冷たい麺7品で注文の3割、協会の2025年8・9月の麺類は冷たい品とビールで伸びた（1.3）。絡む変数：**気温×品目の入れ替え（冷やし・つけ麺）×酒**。汁麺だけの店はこの埋め方ができない【推論】。
4. **人を家族で回せる店 → 分岐の杯数が小さい → 少ない客でも続く**：奥多摩の想定で家族だけなら店主0円の分岐は約22杯、30杯で店主15万円でも+2.7万円（2.4）。絡む変数の筆頭は**人の数（家族の労働）**で、次に家賃と値段。
5. **値段を上げられる立地 → 同じ杯数でも黒字**：銀座で1杯1,300円なら、アルバイト3人・店主30万円でも100杯で+12.4万円（2.3）。利益への効きは値段が最も大きい（2.2）。絡む変数：**値段×立地の客層（商業立地は客単価の高い業態が成り立ちやすいと実務者のコラムは書く）**。

## うまくいかない理由

1. **立地と休みの向きの取り違え → 連休・お盆に谷**：オフィス立地は休日の売上が期待できない（実務者の一般論）。学生街は休みの間に飲食の3店で40〜60%落ちる（米国のチェーンの店長の申告）。都市の住宅地は住人が帰省で出ていくお盆に谷になりうる【推論】。絡む変数：**立地の型×暦×町の人の流れ**。反対の記録として、都市立地の低価格ラーメンが連休にも賑わった月がある（2026年5月）。
2. **安い1杯 × 厚い人 × 高い家賃 → 100杯でも赤字**：銀座で1杯800円・アルバイト2人なら、店主0円でも100杯で−19.5万円（2.3）。絡む変数：**値段×人の数×家賃**（家賃の効きは人1人より大きい、2.6）。
3. **少ない杯数の店で人を雇う → 赤字**：奥多摩の想定で30杯にアルバイト1人（6時間）なら店主0円でも−1.5万円。元店主は1日40杯でも返済の後に月12万円しか残らず「生活するのも厳しい」と書く（2.4）。
4. **暑さ・天候で汁麺の客が減る**：一風堂の既存店の客数は猛暑・残暑で減った（1社）。協会は2025年9月の全体の客足の鈍りを厳しい残暑と物価高に帰した。雨の多い2026年6月は麺類の客数が99.9%（雨と低温が同時で分けられない）（1.3）。
5. **打ち手の当たりの大きさが分からないまま頼る**：当たりの確率と大きさは店の数で埋まらなかった（3章 M1・M2）。言えるのはネットの投稿の再共有がほとんど広がらないことまで（100人以上に広がるのは4,000件に1件）。

## 反証と限界

- **家計調査は家族の外食**。単身者・勤め先の昼食（こづかいの行）・観光客を含まない。世帯の支出で、どこで食べたかではない（帰省先・旅行先での外食も世帯の側に入る）。2025年1年の日別で、2023・2024年は月の値で当てはめただけ。
- **業界団体の月次は前年比**で、水準は言えない。「麺類」はうどん・そばのチェーンを含む。協会の説明の文は会員社の声の要約で、原因の検証ではない。12点の相関で、気温・雨・店の数・前年の反動を分けていない。2026年7月の麺類は報告が404で欠け、8月の報告の時系列の表にも麺類の行は無い。
- **学生街の数字は米国の1つの通りの4店の店長の申告**（2014年、チェーンと菓子店）。
- **宿泊旅行統計は宿泊客の数**で、店の売上ではない。日帰りの観光客（奥多摩のハイキング客など）は入らない。
- **地域の採算の試算は【推論】の数が多い**（その他の固定費・返済・原価率・営業日数・奥多摩の家賃・坪単価の倍）。格子の割合（48%・55% など）は振った幅で動く。検査役の格子の割合と私の格子の割合が違うのはこのため（2.3・2.4）。そろえた格子の0.01%も、資料のない端を外した時の値で、端を入れると2.11%。
- **小売物価の中華そばの値段は、1市あたり少数の店の銘柄の値**。区部617円は銀座の個人店の値段の代わりにならない。
- **公庫の経営指標は年の記載がなく**、中華料理店（中華そば店を含む）の融資先の平均。58.6㎡ は1〜4人の店の平均で、ラーメン専門店の値ではない。
- **拡散の研究はネットの投稿の再共有**で、店の来店ではない。
- **版1.1 の検索は J-STAGE と国立国会図書館サーチの書誌の API**。どちらも題と書誌で探す形で、要旨の無い論文・本文の PDF・雑誌の記事の本文は読めていない。CiNii は使っていない。
- **自分に不利な結果**：上位30項目のうち、向きと大きさまで埋まったのは1項目（S1）、**埋まらなかったのは21項目**（探したが無い）。集客の打ち手の数字（反応率・常連化・頻度・期間・呼び戻し・賞の効果・炎上の減り・クーポンの上乗せ）は、補填の前と同じく置き値のまま。上位30の外も、M31 の人の費用を除き埋まらなかった。
