4. **休みの日の倍率は立地で逆になる。** 家計（住宅地・ロードサイドの客）では土日祝は平日の2.3倍 [[web:bizmgmt:r6-fc-estat-kakei-hibetsu-202508|「1か月間の日別支出」]]、一方でオフィス立地は「休日の売上が期待できない」[[web:ramen:r6-fill-inshokuten-office|「休日の売上が期待できない」]]、業界団体も都市立地の低価格ラーメンを「平日集客が中心」と書く [[web:ramen:r6-fill-jf-202605|「平日集客が中心の都市立地の低価格らーめ」]]。学生街は休みに売上が25〜70%落ちる（米国の大学の隣の店長4人の申告）[[web:ramen:r6-fill-dailytexan-springbreak|「60 percent drop in sales」]]。観光県の観光型の宿は山と谷が約2倍、東京は1.2倍 [[web:ramen:r6-fill-mlit-shukuhaku-2025|「観光目的の宿泊者が50％以上」]]。
5. **夏枯れの宣伝の主張は一次の統計と合わない。** 「夏季の外食ラーメンへの支出は有意に落ち込む」というセミナーの案内（主催者の文）[[web:ramen:r6-fill-prtimes-osaki-natsu|「有意に落ち込む傾向」]] は、家計調査の8月最多と逆向き。主張として記録し、根拠にしない。
6. **地域の採算：「銀座は100杯でも赤字」は1杯の値段しだい、「奥多摩は30杯で採算」は固定費がかなり低い時だけ。** 値段は81市で465〜993円（2.1倍）、住宅の家賃は3.4倍、最低賃金は1.18倍で、**差の主な源は家賃と値段**（`docs/analysis/fill-region.py`）。銀座の家賃坪4.2万円・10坪・3人【推論】の試算では、区部の統計の617円なら100杯で月44万円の赤字、1,000円なら店主の取り分の前で＋23万円、1,300円なら＋75万円。奥多摩の想定（家賃6万円・1人＋店主【推論】）では店主0円の分岐が34杯で、30杯は月6万円の赤字。

8. **「開店景気の後に落ちる」は、公庫の追跡調査では見えない。** 開業後の黒字基調の割合は年を追って上がる（50.9%→76.1%、生き残った企業の集計）[[web:ramen:r6-fill-jfc-panel-211221|「50.9％から76.1％へ」]]。月単位の山は見えないので、元の推論は「否定」でなく「この資料では支えられない、年単位では逆」。

## 問いの設計

### 問うたこと
- **肯定側**：季節・立地・地域で売上が上がる店は、何と何が絡んで上がるのか（暦の休み×客層×収容、観光の山×立地、値段の水準×家賃）。打ち手が当たる時、当たりの大きさはどう分布するか。
- **否定側**：夏枯れは本当にあるのか、どの立地で、どれだけ。学生街・オフィス街の谷の深さ。銀座のような高家賃の所で杯数が多くても赤字になる仕組み。開店景気の落ち込み。
- **補填の問い**：元の推論の向きは資料と合うか、大きさは幅で言えるか。合わない時は否定として同じ重さで書く（手抜きの予想⑥）。

## うまくいく理由（季節と地域で売上が上がる店の因果）

1. **休みの日の家族の客を取れる立地 → 休みの月・日に山 → 年の売上の厚み**：家計の中華そばの外食は土日祝に平日の2.3倍、8月は休みの並びを除いても114（1.1）。山を取るのは住宅地・ロードサイドの家族向けの店で、山岡家は繁忙期を8・12・1月と書く。絡む変数：**立地の型×客層（家族）×暦×収容**。収容が足りないと山は行列と機会損失になる（山岡家は繁忙期にクーポンを減らす）。
2. **観光の季節のある場所 → 宿泊客の山の月に客が増える → 値段も上げやすい**：観光型の宿の月の振れ幅は観光県で約2倍（1.3）。ギフトは観光地・都市部で客単価も上がると書く（BIZ-RAMEN 8章）。絡む変数：**立地（観光地）×月×値段の位置**。
3. **寒い月に汁麺が伸び、暑い月は冷たい品で埋める**：業界団体は11月に「気温の低下とともにラーメン業態が好調」、8月は冷たい品とビールで麺類が伸びたと書く（1.2）。絡む変数：**気温×品目の入れ替え（つけ麺・冷やし）×酒**。
4. **家賃が低い所 → 分岐の杯数が小さい → 少ない客でも続く**：奥多摩の想定・元店主の地方の型で、店主0円の分岐は33〜34杯（2.2）。絡む変数：**家賃×人の数（家族の労働）×返済**。

## うまくいかない理由

1. **立地と休みの向きの取り違え → 連休・お盆に谷 → 月の売上の穴**：オフィス立地は休日に売上が大きく落ちる（実務者）。学生街は休みに25〜70%落ちる（店長の申告）。絡む変数：**立地の型×暦**。
2. **高い家賃 × 安い1杯 → 100杯でも赤字**：銀座の家賃坪4.2万円で1杯617円なら、100杯でも月44万円の赤字（2.2）。値段を上げられない立地（低価格の業態・区部の価格帯）で特に重い。絡む変数：**家賃×値段の位置×人の数**。
3. **雨・台風・天候の外れ → 客数の前年割れ**：2026年6月（雨天16日）と2026年8月（雨天12日）の麺類の伸びの鈍り（1.2）。
4. **打ち手に頼る集客 → ほとんどは何も起きない**：ネットの発信の73〜95%は誰にも広がらない（3章 M2）。大当たりは大きな発信源しだいで、店が選べる所は少ない。

## 反証と限界

- **家計調査は家族の外食**。単身者・勤め先の昼食・観光客を含まない。8月の山を全部の立地に広げてはいけない（論証検査役の指摘と同じ）。1.3 で立地ごとに向きを分けたのはこのため。また2025年1年分で、年の振れは見ていない。
- **業界団体の月次は前年比**。水準（何月が多いか）は言えない。「麺類」はうどん・そばのチェーンを含む。協会の説明の文は会員社の声の要約で、原因の検証ではない。
- **学生街の数字は米国の1つの通りの4店の店長の申告**（2014年）。日本の大学の隣のラーメン店の値ではない。日本の学生街は大学の外食への依存の度合いが違う可能性がある【推論】。
- **宿泊旅行統計は宿泊客の数**で、店の売上ではない。日帰りの観光客（奥多摩のハイキング客など）は入らない。
- **地域の採算の試算は【推論】の数が多い**（10坪・人数・その他の費用・奥多摩の家賃）。オーナーの指摘への判定（修正）は「この前提なら」の条件つき。前提を変えた感度は fill-region.py の引数で変えられるが、表には6通りしか載せていない。
- **小売物価の中華そばの値段は、1市あたり少数の店の銘柄の値**。区部617円が中央より安いのは、調べる店がチェーン寄りの可能性があり、銀座の個人店の値段の代わりにはならない（だから1,000円・1,300円の場合も並べた）。
- **公庫の経営指標は年の記載がなく古い版の可能性**。形（小さな店ほど分岐点を超える）にだけ使った。
- **拡散の研究はネットの共有の出来事**で、店の来店ではない。M2 の判定（中央はほぼ0）は「何も起きないことが多い」の向きだけ。
- **自分に不利な結果**：上位30項目のうち16項目は埋まらなかった。特に集客の打ち手の数字（反応率・常連化・呼び戻し・賞の効果）は、補填の前と同じく置き値のまま。
