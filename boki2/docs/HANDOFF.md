## 1. これは何か
日商簿記2級を「遊んでいるうちに身につく」ゲーム。ブランチ `boki2-quest`、フォルダ `boki2/`。
公開版（Claude Artifact、ユーザー本人のみ閲覧可）：**ピヨ商店** https://claude.ai/artifact/PxvGJeU1WaaXfWjDuUMo3G 。作り方は `node boki2/tools/build.js <出力.html>`（`index.html` を skeleton なしの1ファイルに）を Artifact ツールで同じファイルパスから publish。別の会話から更新するときは url にこのURLを渡す。
旧版（章ごとの学習ゲーム `classic.html`）の公開版：https://claude.ai/artifact/QpHMU1edQXWmZDD7vscbc9（Version 8 で止める。作り方は `--page classic.html`）

## 2. ユーザーが求めていること（原文の要点。最優先）
- 一周すれば本試験で満点。小学生でも飽きずに本質を理解できる。実務での使われ方も体得できる
- 試験は CBT（ネット試験）を想定
- **用語・概念をただ羅列するのは禁止**。本質が理解できる仕組みと、体系的に理解できる学習スキーム
- **「教科書が画面に置きかわっただけ」は不可**。①勉強している実感がなくずっと楽しい ②暗記の苦痛が少ない ③行動が反映される双方向の体験（ログインボーナス・量に応じた報酬などの表層的ゲーミフィケーションは不可） ④いつの間にか2級を習得
- 数値目標（図解いくつ等）だけで品質を決めない。概念ごとに必要な表現・思考プロセス・負荷を考える
- 方針を大きく決めるときはサブエージェント Fable 5.1（Agent ツールで model: "fable"）と議論する
- 日本語で話す
- **時間・作業量を理由に選択肢を棄却することは禁止**。時間はいくらかけてもよい（2026-10-19）
- 方向転換（2026-10-19 オーナー提案・合意）：**行動力はあるが会計知識ゼロの社長に振り回される経理部（先輩＝ナビゲーター、新卒＝プレイヤー）の経営シミュレーション**。借入・資本調達・工場新設・M&A・決算対応・棚卸などの実務シーンを乗り越えながら、2級の範囲と要諦を体系的に理解する。「なぜその処理が必要か、間違えると何が起きるか」を知ることが核心で、**誤った選択の先にバッドエンドを経験させる**

## 3. 確定した方針
**`boki2/docs/PEDAGOGY.md` がすべての基準。** 要点：
- 中心の遊び＝ピヨの会社を1か月ずつ経営・記帳（証憑が届く→記録→月末締め→結果が会社に返る）
- 新しい用語は4拍（困りごと→原理の問い（手で操作＋理由を選ぶ）→結果→名前）でしか出さない。1画面の本文は180字まで
- 背骨＝8原理（P1二面性・P2純資産・P3期間帰属・P4評価・P5表示・P6原価の流れ・P7計画と差異・P8経済的実体）と操作の型5つ
- 報酬はコイン・XP等を廃止し、会社の成長・権限・自動仕訳ルール（熟達の結果）・原理マップ・判断の結果で表す
- 模試は「検定会場」として残す（CBT形式）

- **検定会場（`js/app.js` の `SCREENS.exam` / `examplay`）は本番の形**（DESIGN-REVISION 6章 優先3）：
  - 第1問・第4問(1)の科目は問題ごとに5〜8個の候補（`shortOptions`：正解＋問題の opts→同じ章→同じ分類）
  - 同じ側に同じ科目を2行書くと0点（`form().dup`）、金額は半角数字だけ（`strictNum`、入力中に枠が赤くなる）
  - 問題文は選択・書き込み不可（`.noink`）、計算用紙は2枚（各30行・1200字）
  - 採点後はまず点数だけ（本物と同じ）→「振り返る」で各問の正誤・解説・先輩の下書き、誤りの3分類（習っていない／忘れていた／計算・形式・時間）と戻り先、合格ラインとの距離（何点落としても大丈夫だったか／何を拾えば届いたか）。分類は本人が選び直せ、`S.exams[].miss` に残る
  - 通しは2段（1段目 時間なし→2段目 90分）。自己ベストは90分の回だけ
  - 大問別の連続練習：先輩の手本（下書きを1手ずつ）→なぞる→自分で→時間あり（目安の分数）。手本・なぞりでの正解は定着（間隔反復）に数えない
  - 操作の練習（1題・採点なし）：プルダウン・半角・2行に分けて0点を体験
  - 下書きは大問ごとの手順（`GEN_DRAFT`）。題ごとの `draft` と範囲タグ `scope` はエージェントが作成中
- 章の問題：未達（範囲外）に「参考（2級では出ない）」、2027年度モードで出ない問題に印
- ピヨ商店（1年目＋2年目）：公開 Version 10（2026-10-20）。保存・成長の記録・確認テスト（docs/STORAGE.md）
- 検査：validate / sim-check / lexicon-check / coverage / law-check / research-check。ブラウザ試験は scratchpad の `sim/play2.js`・`sim/room-test.js`・`sim/hall-test.js`・`exam/exam-test.js`（新セッションでは消える）
