# 簿記2級クエスト コンテンツ執筆ガイド

データはすべて `js/data/*.js` に置き、グローバル `BOKI` の登録関数を呼ぶだけのプレーンな JS です。
ゲームエンジン (`js/app.js`) はこのデータを読むだけなので、データ側は表示を気にせず中身に集中してください。

検証: `node boki2/tools/validate.js`（全データファイルを読み込み、貸借一致・勘定科目の存在・ID重複・穴埋め数などを検査）

## 1. 章 (chapter)

```js
BOKI.chapter({
  id: 'c01',            // 一意。c00〜c45 は CONTENT 計画表の番号どおり
  world: 'w1',          // w1〜w9
  title: '株式の発行',
  sub: '会社をつくる・お金を集める',   // 1行サブタイトル
  scene: {              // ステージ冒頭の「現場シーン」。実務で“いつ・誰が・なぜ”この知識を使うか
    place: 'ミライ商事 本社 会議室',
    lines: [            // [話者キー, セリフ]。話者キーは下の「キャラクター」参照
      ['bucho', '来月、新しい工場のために株式を発行して資金を集めることになったの。'],
      ['senpai', '払込金が入ったら、すぐ仕訳を切らないとね。'],
      ['piyo', '株を売ったお金は「借金」じゃないんだピヨ？'],
    ],
    mission: '株式発行・増資の仕訳を切れるようになる',
  },
  lessons: [            // 3〜6枚の解説カード。1枚 = スマホ1画面に収まる量（目安 120〜300字 + 図）
    { t: 'カードの見出し', h: 'HTML（下のショートコード可）' },
  ],
  real: {               // 章クリアで手に入る「実務カード」（コレクション要素）
    t: '増資の実務フロー',
    where: '経理部・総務部／取締役会議事録・払込金保管証明書',  // どの部署・どの書類・いつ
    h: '実務での流れ・使われる書類・会計ソフトでの入力・ミスしやすい点など（HTML）',
  },
  accounts: ['当座預金', '普通預金', '資本金', '資本準備金', 'その他資本剰余金', '株式交付費', '創立費', '開業費'],
                        // 仕訳問題の勘定科目ピッカーに出す候補（試験の「勘定科目の候補」に相当）。
                        // 正解科目は自動で追加されるので、ここには紛らわしい“ひっかけ”も入れる。8〜14個
  qs: [ /* 問題（下記）。1章 8〜12問。仕訳が出る論点は半分以上を仕訳問題に */ ],
});
```

## 2. 問題 (qs の要素)

共通フィールド:
- `type` : `'journal' | 'choice' | 'number' | 'fill' | 'sort'`
- `q`    : 問題文（HTML可）。**試験と同じ書きぶり**の文にする（「〜した。」で終わる取引文など）
- `exp`  : 解説（HTML・ショートコード可）。**なぜそうなるか**を必ず書く。計算過程は式で
- `real` : （任意だが強く推奨）実務メモ。「現場ではこの仕訳は〇〇のときに切る」「請求書の△△欄を見る」など1〜2文
- `lv`   : 難易度 1（基本）〜3（本試験レベル・ひっかけ）。各章に 1〜3 をまんべんなく

### 2-1. 仕訳 `journal`
```js
{ type: 'journal', lv: 2,
  q: '増資にあたり株式200株を1株￥5,000で発行し、払込金は当座預金とした。資本金には会社法が認める最低額を計上する。',
  ans: { dr: [['当座預金', 1000000]], cr: [['資本金', 500000], ['資本準備金', 500000]] },
  alt: [ /* 別解があれば {dr, cr} を配列で */ ],
  opts: [ /* 省略可。章の accounts の代わりに使う候補 */ ],
  exp: '払込金額の1/2以上を資本金に…[[je: 当座預金 1000000 | 資本金 500000, 資本準備金 500000]]',
  real: '増資の払込は「別段預金」にいったん入り、登記後に当座預金へ振り替える実務もあります。' }
```
- 金額は **整数（円）**。カンマ無しの数値で書く
- 借方合計 = 貸方合計 であること（検証スクリプトでチェック）
- 同じ側に同じ科目を2回書かない（まとめる）
- 勘定科目は `accounts.js` のマスタに存在する名前を使う。無い科目は自分のファイル冒頭で `BOKI.addAccounts({...})` で追加
- 「仕訳なし」が正解の問題は `ans: 'none'`

### 2-2. 選択 `choice`
```js
{ type: 'choice', q: '…はどれ？', c: ['選択肢A', '選択肢B', '選択肢C', '選択肢D'], a: 2, exp: '…' }
```
`a` は 0 始まりのインデックス。選択肢は 2〜4 個。正解の位置はばらけさせる（エンジンでもシャッフルする）

### 2-3. 数値 `number`
```js
{ type: 'number', q: '当期の減価償却費はいくら？', a: 180000, unit: '円', exp: '…' }
```
`unit` は '円' '%' '個' 'kg' '時間' など。率は整数か小数（例 37.5）。

### 2-4. 穴埋め `fill`（表・計算書・原価計算表など。本試験の第2〜5問形式）
```js
{ type: 'fill',
  q: '次の資料にもとづき、損益計算書の空欄を埋めなさい。<table>…資料…</table>',
  sheet: '<table class="sheet"><tr><td>売上高</td><td>{{0}}</td></tr><tr><td>売上原価</td><td>{{1}}</td></tr>…</table>',
  blanks: [ 5000000, 3200000, { opts: ['売上総利益', '営業利益', '経常利益'], a: 0 } ],
  exp: '…' }
```
- `sheet` 内の `{{n}}` が入力欄になる（n は 0 始まり、`blanks` の添字と一致）
- 数値欄は数値、語句欄は `{opts:[...], a: 正解インデックス}`
- マイナス表示が必要な欄は負の数で書く（例 -30000）。表に「△」を印字したい場合は空欄の外に書く

### 2-5. 分類 `sort`（タップで仕分けるミニゲーム）
```js
{ type: 'sort', q: '次の費用を「製造原価」と「販売費及び一般管理費」に分けよう',
  bins: ['製造原価', '販売費及び一般管理費'],
  items: [['工場の電気代', 0], ['本社の家賃', 1], ['工場機械の減価償却費', 0], ['営業部員の給料', 1]],
  exp: '…' }
```
items 4〜8 個。

## 3. 本試験形式の大問 (`BOKI.exam`)  ※模擬試験モード用

```js
BOKI.exam({
  id: 'x3a', part: 3,          // part: 2 | 3 | 4 | 5（4 は第4問(2)。第1問・第4問(1)は章の仕訳問題から自動出題）
  title: '損益計算書の作成',
  q: '問題文と資料（HTML）。決算整理事項は <ol> で列挙',
  sheet: '解答用紙（HTML, {{n}}）',
  blanks: [ … ],               // 配点は part の点数を空欄数で均等割り（第2・3問:20点, 第4問(2):16点, 第5問:12点）
  exp: '解説（HTML）。各空欄の計算過程を順に',
});
```
- 1問あたり空欄 5〜12 個が目安。**数値は必ず自分で検算すること**（node で計算スクリプトを書いて確認推奨）

## 4. ショートコード（lessons.h / exp / real / q で使える）

| 書き方 | 表示 |
|---|---|
| `[[je: 当座預金 1000000 \| 資本金 500000, 資本準備金 500000]]` | 仕訳（借方 \| 貸方。行はカンマ区切り、科目と金額は半角スペース） |
| `[[t: 売掛金 \| 前期繰越 300, 売上 800 \| 回収 700, 次期繰越 400]]` | T勘定（勘定名 \| 借方側 \| 貸方側。各行「ラベル 金額」、金額省略可） |
| `[[box: 仕掛品(材料費) \| 月初 100個 2000, 当月投入 900個 18000 \| 完成 800個 16000, 月末 200個 4000]]` | ボックス図（左右2列。T勘定と同じ文法だが見た目が原価計算用） |
| `<div class="point">…</div>` | 重要ポイント枠（黄） |
| `<div class="warn">…</div>` | ひっかけ注意枠（赤） |
| `<div class="real">…</div>` | 実務メモ枠（緑） |
| `<div class="formula">…</div>` | 公式枠（等幅・中央） |
| `<table>` | そのまま表として整形される |
| `<b>`, `<em>`, `<br>`, `<ul><li>` | 通常のHTML |

ショートコード内の金額はカンマ無し数値（表示時に自動でカンマが入る）。T勘定・ボックス図の金額には `?` も書ける。

## 5. 品質基準
1. **正確さ最優先**：日商簿記2級（2026年度出題区分）に準拠。勘定科目名は日商の標準的な名称
2. **本質→ルール→計算** の順で解説。「なぜその科目なのか」「なぜその金額なのか」を必ず説明
3. **実務との接続**：scene・real・各問の real で「どの場面で・誰が・何を見て」この処理をするかを具体的に
4. 子どもでも読める平易な言葉（専門用語は初出で言い換え）。ただし内容は本試験レベルまで到達させる
5. 各章の最後の数問は本試験レベル（lv:3）で、ひっかけや複合論点を含める
6. 絵文字は使わない（UIで装飾するため）
