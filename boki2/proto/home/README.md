# ホームの試作（T1）

`docs/CODEX-TASK-proto-home.md` と `docs/PROTO-SPEC-home.md` に従い、同じ1か月を5版で比べる独立した試作。仕様3章の更新（43ac7d0、PR #14 の回答6619786282）を反映した。

## 開き方

リポジトリのルートで `python3 -m http.server 8000` を起動し、`http://localhost:8000/boki2/proto/home/?v=a` を開く。素の HTML・CSS・JavaScript のみ。ビルドや依存のインストールは不要。モジュールを使うため `file://` では開かない。

- `?v=a`：数なし、店の絵と次の書類。
- `?v=b1`：1億への線と見込みの日付。
- `?v=b2`：1億への線と期限からの逆算。
- `?v=c`：売上・手もとに残るお金・先月比。
- `?v=d`：口座のお金・借入金・手もとに残るお金・月・方針の帯。
- `&lock=1`：比べる版の切り替えを隠す。試遊・実測・撮影ではこの指定を使う。

## 共通の1か月

1年目の5月。月初は普通預金300万円・現金10万円・借入金0円。6枚の書類を同じ順で記帳する。3枚目のあとにチラシ2万円（現金）の判断が現れる。数を確認してから判断でき、未回答なら4枚目を開く前に判断の札が出る。最後は「今月は締められる」の札から月末の4択2問へ進む。

目標はネットキャッシュ（現金＋普通預金−借入金）1億円、120か月。経過1か月・残り119か月。b1 のペースは今月初からのネットキャッシュの増え方、未記帳の間だけ先月の4万円を使う。0以下なら到達日を出さない。b2 は残額を119か月で割って必要月額を出す。月数・必要月額は切り上げる。式は `model.js` にコメントで記載した。線を押すと、仮の前提と現在の数を読める。

月末の売上は21万円（先月比＋3万円）、口座は292万円。手もとに残るお金はチラシなし307.5万円、チラシあり305.5万円。掛け仕入とカード売上では現金を動かさない。

## 記録

`localStorage` の `boki2.proto.home.v1` に、版ごとの試遊を保存する。もう一度遊ぶと古い記録を残して新しい試遊を始める。再読み込みで途中から再開できる。保存できない端末では画面下に知らせ、メモリー上の記録を書き出せる。

「記録を書き出す」で全試遊の JSON を表示し、選択・コピーまたはファイル保存できる。版、開始・締め時刻、締めまでのミリ秒、ホームを開いた回数、数・線を押した回数、判断、2問の回答と正誤、出した選択肢の並び（`quizOrder`）と選んだ位置、操作時刻の列を含む。選択肢は記録idと問いを種に並べ替え、再読み込みでも同じ並びを保つ。締めまでの時間には4択の回答時間を含めない。

アプリは外部へ通信しない。CSP の `connect-src 'none'` でも禁止する。ゲーム本体の保存・ファイル・計算とは共有しない。

## 自動検査と画面写真

Playwright と Chromium を利用できる環境で次を実行する（検査だけの依存。本体には不要）。

```
node boki2/proto/home/check/run.cjs
```

実行時だけローカルの HTTP サーバーを起動し、終了時に閉じる。Chromium の既定パスは `/usr/bin/chromium`。違う場合は `CHROMIUM_PATH` で指定する。

- `check/results.json`：5版×2画面サイズ×チラシ2択＝20通りの打ち手と実測の生データ。
- `check/measurements.md`：上のデータから生成した表。月初・月末の両方。
- `check/index.html`：画面写真20枚の目録（版×画面サイズ×月初/月末）。月末はチラシを打ち、4択に答えた後。
- `check/record-*.json`：実際の書き出しの例10件。自動操作の記録であり、人の試遊データではない。
- `check/prototype.log`：検査の出力。
- `check/regression/`：既存ゲームの必須検査の出力と終了コード。

測りは DOM の `getBoundingClientRect()` と `getComputedStyle()` による。字は見える文字ノード、押す所は見えるボタン・リンク・入力欄が対象。44pxの条件は各要素の幅と高さの両方で判定する。記帳・判断・月末の問い・書き出しの窓も検査する。画像の高さは `.stage`（店の絵の領域）を測る。dの帯の高さは店名のヘッダーも含め、画面上端から帯の下端までを測る（a〜cの数の領域の高さはヘッダーを含めない）。

## やっていないこと

- 人による比較試遊、学習効果・楽しさ・続けたさの測定。どの版を採用するかは決めていない。
- 新しい Mobbin 検索や外部資料の取得。指定された設計書の引用・比較の枠を使った。
- 本番ゲームへの接続、120か月の経営、自由な仕訳入力、町・帳簿・成長の各画面。比べる対象をホームにそろえるため、書類の机は正しい仕訳の確認と記帳だけ。
- 店の絵の本制作。5版とも同じ仮のSVGを使い、絵の出来による比較の偏りを避けた。
- 実機のタッチ操作、Safari・Firefoxでの確認。ブラウザ検査はChromium。
