# 簿記2級クエスト

日商簿記2級の全範囲（商業簿記・工業簿記）を、ゲームを進めながら身につけるブラウザゲームです。
プレイヤーは「ミライ商事」の新人経理として、本社 → 子会社 → 工場とキャリアを進めます。

`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。進み具合はブラウザの localStorage に保存されます。

## 中身

| | |
|---|---|
| ワールド | 9（株式会社 / 商品売買・収益認識・税 / 預金・手形・債権・外貨 / 固定資産・リース / 有価証券・引当金・税効果 / 決算・財務諸表・本支店 / 連結 / 工業簿記の基礎・個別原価 / 総合原価・標準原価・CVP） |
| ステージ | 47（各ステージ＝現場ストーリー → 解説レッスン → クイズ → 実務カード獲得） |
| 問題 | 598問（仕訳・選択・計算・穴埋め・仕分け） |
| 模擬試験 | 本試験と同じ5問構成・90分・100点。第2〜5問の大問32題＋仕訳バンクから毎回ランダムに組む |
| その他 | ワールドごとのボス戦、仕分けラッシュ（3モード）、今日の復習（翌日・3日後・7日後の間隔反復）、テーマ別の成績と特訓、まちがいノート、勘定科目図鑑、バッジ、デイリーミッション |

## ファイル構成

- `index.html` — エントリーポイント
- `css/style.css` — 見た目（ライト／ダーク両対応）
- `js/core.js` — データ登録用の `BOKI` 名前空間・ワールド・キャラクター定義
- `js/data/*.js` — 勘定科目マスタ、各章、模試の大問
- `js/app.js` — ゲームエンジン
- `CONTENT_GUIDE.md` — 問題・レッスンの書き方
- `tools/validate.js` — データ検証（貸借一致・勘定科目・穴埋め数など）: `node boki2/tools/validate.js`
- `tools/build.js` — 1ファイルにまとめる: `node boki2/tools/build.js dist/boki2-quest.html --full`
- `docs/UPDATE_PLAN.md` — 網羅性の検証結果とアップデート計画
