# 簿記2級クエスト（ピヨ商店）

日商簿記2級の全範囲（商業簿記・工業簿記）を、会社を経営しながら身につけるブラウザゲームです。
プレイヤーは新卒の経理ピヨ。会計知識ゼロで行動力だけはある社長ミライに振り回されながら、先輩タカシと一緒に、屋台から始まる会社を1か月ずつ記帳・決算していきます（1年目：商店、2年目：増資・2号店・工場）。

`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。設計の土台は `docs/PEDAGOGY.md`、2年目の設計は `docs/YEAR2.md`。

## 中身

| | |
|---|---|
| 会社 | 1か月ずつ：書類が届く→記帳→月末の締め→結果が会社に返る。新しい言葉は「困りごと→原理の問い→結果→名前」の順でしか出ない。判断の先に結末（バッドエンドを含む） |
| 練習室 | 会社の外で練習する場所。論点ごとの参考書と問題（48章・約710問）、まちがいノート、検定会場 |
| 検定会場 | ネット試験（CBT）の本番の形：5問・90分・100点。大問85題＋仕訳バンク。採点後の振り返り（誤りの3分類と戻り先）、大問別の連続練習（手本→なぞる→自分で→時間あり） |
| 成長 | マップ（8原理）・論点ごとの成長、日をあけた想起（会社の場面・章の問題・検定会場の大問の間違い） |

旧版（章ごとの学習ゲーム）は `classic.html` に残しています（新しい機能は入りません）。

## ファイル構成

- `index.html` — エントリーポイント（ピヨ商店）
- `classic.html` — 旧版（章ごとの学習ゲーム。`js/app.js`）
- `js/sim/*.js` — 会社の台本（1年目 `scenario.js`・2年目 `year2.js`）・エンジン・言葉の関所・保存・成長
- `js/hall.js` — 検定会場（両方のページで共通）
- `css/style.css` — 見た目（ライト／ダーク両対応）
- `js/core.js` — データ登録用の `BOKI` 名前空間・ワールド・キャラクター定義
- `js/data/*.js` — 勘定科目マスタ、各章、模試の大問
- `js/app.js` — 旧版のエンジン
- `CONTENT_GUIDE.md` — 問題・レッスンの書き方
- `tools/validate.js` — データ検証（貸借一致・勘定科目・穴埋め数など）: `node boki2/tools/validate.js`
- `tools/build.js` — 1ファイルにまとめる: `node boki2/tools/build.js dist/piyo.html --full`（旧版は `--page classic.html`）
- `docs/UPDATE_PLAN.md` — 網羅性の検証結果とアップデート計画
- `docs/CRAWL.md` — 外部の学習サイトを取得して教材と突き合わせる手順（`tools/crawl.js`・`tools/compare-crawl.js`）
